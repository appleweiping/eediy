## 根据公开大纲自建练习

把主题合并为 convolution/system properties、z-transform、DTFT/sampling、DFT、filter/
multirate 几段。每段留一份推导和一个短脚本：sampling 构造 aliasing 反例，DFT 区分
zero-padding 与真实分辨率，FIR 从 passband/stopband 规格量出实际 ripple。用一段固定
信号，从 pole-zero 与频谱预测到 filter implementation，并用 error log 解释一次失败。

这些独立练习没有对应的 UIUC homework 或 exam；题面来源写“公开 outline + 外部教材”，
HTTP 401 的文件也不进入公开仓库。若访问状态变化，在 2026-07-30 这一日期后追加新日期即可。
这条路线最值得反复做的是同一固定信号：从 pole-zero 预测频谱，再经过 sampling、DFT 与
FIR，最后解释 aliasing、zero-padding 和实际 ripple 分别在哪一步产生。它把约 40 个课次串成
一条因果链，而不是一组互不相干的小脚本。
