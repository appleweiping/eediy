## 第一页先建 normalization ledger

EE261 最常见的失败不是不会积分，而是把不同约定算出的正确式子拼在一起。开课前选定并写下：连续 Fourier transform 的指数符号与 \(2\pi\) 位置；频率变量用 \(f\) 还是 \(\omega\)；rect、sinc 与 Shah/III 的定义；DFT 与 inverse DFT 的 \(1/N\) 放置；二维 transform 的坐标与 determinant scaling。之后每次 scaling、duality、Poisson summation 或 sampling 都先回到账本，而不是凭记忆修常数。账本不只是公式表，还要写变量的物理单位和定义域。时间缩放会同时改变频谱宽度与幅度，二维坐标变换还会带来面积尺度；若只修正横轴而漏掉系数，图形可能“像对的”却不守恒。每次换教材、软件函数或题解约定时，先做一个高斯或矩形的往返变换，确认 inverse 能还原原信号，再继续推导。

Stanford Engineering Everywhere 的 [EE261 主页](https://see.stanford.edu/Course/EE261) 对这门 Brad Osgood 的课程给出明确目标：不仅计算 transform，还要识别何时、为何以及怎样使用它。公开 [Syllabus and Schedule](https://see.stanford.edu/materials/lsoftaee261/Syllabus.pdf) 标为 Fall 2007，并说明日程只是 approximation；课程从 Fourier series 走到 Radon transform 与 medical imaging。Normalization ledger 是 EEDIY 补充，不是 Stanford handout。

## 用 4 副镜头而不是章节摘要

第一副是 representation lens：Lecture 1–10 从 periodicity、orthogonality 与 Fourier series 进入 continuous transform、duality、scaling、convolution 和 central limit theorem。每个结果都同时写 analysis 与 synthesis，并用 Parseval 或 dimensional relation 做 1 次反向检查。第二副是 distribution lens：Lecture 11–16 用 rapidly decreasing test functions、tempered distributions、delta 与 Shah 处理普通函数失效处，并把 diffraction 与 crystallography 接进来。

第三副是 sampling lens：Lecture 17–22 从 interpolation、aliasing 进入 DFT 与 FFT。不要把 sampling theorem 缩成 \(f_s>2f_{\max}\)；要写出 spectrum replication、anti-alias assumption、finite record、periodic indexing 和 window/leakage 尚未被理想公式消除的边界。第四副是 operator-and-geometry lens：Lecture 23–30 从 linear systems、impulse response、LTI eigenfunctions 走到二维 transform、rotation/scaling、lattices、tomography 和 Radon inversion。

这 4 副镜头有意跨越传统 signals 教材的分章：同一个 delta 既是 distribution，也是 sampler；同一个 reciprocal relation 既解释时频缩放，也解释晶格；同一个 projection-slice relation 把二维 spectrum 接到 tomography。读完一组 lecture 后应画“对象—运算—domain—application”图，而不是只列 transform pairs。

## 5 个黑板诊断比视频进度更可信

诊断 1：在自己的 convention 下推导 rect \(\leftrightarrow\) sinc，并用 scaling 检查宽度与幅度。诊断 2：把 delta、unit step 与 Shah 当作 distributions 操作，说明哪些乘法或卷积没有自动定义。诊断 3：从 Poisson summation 推出 sampling spectrum replication，并构造 2 个连续正弦在同一采样率下产生相同 samples 的例子。

诊断 4：手算一个小 \(N\) DFT，说明 periodic indexing、circular shift 和 FFT factorization；诊断 5：证明二维 Fourier transform 在旋转下怎样变换，并用 projection-slice theorem 解释 Radon data 与频域切片。第 1 项失败补 calculus/complex exponentials，第 2 项回到 Lectures 11–14，第 3–4 项回到 Lectures 17–22，第 5 项回到 Lectures 26–30。

这些是 EEDIY placement diagnostics，不是 Stanford exam。至少 4 项应在不查看 solution 时完成定义、推导与 convention audit；若只会调用 FFT 或显示图片，却不能解释 normalization 和坐标变化，先不要把课程标为完成。

## 它不是 signals 课，也不是实现型 DSP 课

MIT [6.003 Signals and Systems](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/) 更适合第一次建立 continuous/discrete LTI、convolution、difference/differential equations、Laplace/z-transform、causality 和 system response 的工程骨架。EE261 假定学习者能承受更数学化的 Fourier 语言，把 distributions、Poisson summation、diffraction、lattices 与 Radon transform 串成主线；它不负责完整补齐 ROC、state representation 或 control-oriented system modeling。

MIT [RES.6-008 Digital Signal Processing](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/) 则把 z-transform、digital network structures、IIR/FIR design、coefficient quantization 与 FFT 变成 20-lesson implementation spine，并为 Lecture 2–20 给 solution packets。想理解 Fourier ideas 在数学、光学和 imaging 间为何共用，选 EE261；想设计 realizable discrete filters，选 RES.6-008；LTI 基础不稳，先 6.003。EE261 的 DFT/FFT 段不能替代完整 DSP implementation course。
