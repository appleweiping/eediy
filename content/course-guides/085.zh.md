## 课程页是 Spring 2016，lab 文件却主要来自 2014

Cornell [ECE 2200 Signals and Information](https://ocw.ece.cornell.edu/courses/ece-2200-signals-and-information) 保存的课程说明是 Spring 2016 本科二年级版本：每周两次 lecture、隔周一次 lab、3 次 prelim 与 1 次 final，指定 McClellan、Schafer、Yoder 的 *Digital Signal Processing First* 第二版（2016）。这套档案最适合已有基础 signals 知识、想补一轮实验型 DSP 的学习者。公开 lab PDF 标题多写 Spring/Fall 2014，因此网页年份、教材年份与实验年份应分别记录。

课程从 discrete-time signals、LTI/filter/spectral response 走到 A/D、D/A，再协调 CT Fourier transform、DTFT、DFT/FFT 与 z-transform。所需基础包括 complex exponential、calculus、基础 differential equation 和 MATLAB/NumPy 向量操作。短序列 convolution 手算、sampled sinusoid 和 normalization/aliasing 解释可以具体检查这些能力。

## 作业与反馈

公开 [Homework and Exams](https://ocw.ece.cornell.edu/courses/ece-2200-signals-and-information/ece-2200-homework-and-exams) 有 Homework 1–10 及全部 solution，也有 Exam 1–3 和 Final 及 solution。每章保留 homework 首稿，延迟查看 solution；每次 prelim 按原卷限时，订正按 representation、convolution、frequency、sampling、transform property 与 algebra 分类。没有 lecture notes，指定教材与题目就是概念主线，答案只能用于订正。

内容顺序建议为 DT signal/LTI 与 convolution，Fourier representation 与 filter，采样与转换，CT/DT transform，最后 DFT/FFT 与 z-transform。每完成一段，用同一 signal 在 time、frequency、pole-zero 三种表示中互相核对；单位、sample index、Hz/rad/sample 和 transform normalization 都要写出。

## 实验与项目

公开 [Projects and Labs](https://ocw.ece.cornell.edu/courses/ece-2200-signals-and-information/ece-2200-projects-and-labs) 列 Lab 1–5，均无 solution。具体任务颗粒度很高： [Lab 1](https://ocw.ece.cornell.edu/files/2017/03/ece2200_lab1-17mpqlz.pdf) 学 MATLAB 脚本与函数、vectorization、离散信号与 echo；Lab 2 用 44.1 kHz audio、Fourier coefficient、beat、AM 与 spectrogram；[Lab 3](https://ocw.ece.cornell.edu/files/2017/03/ece2200_lab3-1619n2x.pdf) 通过 two-point running average/difference filter 在 time/frequency domain 比较低通与高通，并处理 image。

Lab 4 做二阶 notch IIR 的 pole-zero/frequency response，再进入 scalar Kalman filter；[Lab 5 Shazam](https://ocw.ece.cornell.edu/files/2017/03/ece2200_lab5-220hsqe.pdf) 从 8 kHz resampling、log spectrogram、peak constellation、fan-out pair 建 database，再匹配 clip。部分 handout 依赖 Blackboard 下载的 `.m`、audio/song database 或旧 MATLAB function，公开 OCW 没有保证这些 ancillary file 都存在；缺文件时应记录并用自建小 dataset 复建目标，不能声称原 lab 全部可运行。

## 原始信号与版本决定实验能否复查

每个 lab 保存脚本与函数、输入 provenance、sample rate、raw/processed signal、带单位 plot 和一条重跑命令。Shazam substitute 至少公开合法的小型音频集或可生成 signal、特征表 schema、train/query split、首选匹配与 failure examples；版权歌曲不进入仓库。Kalman 与 IIR 要同时给出 equation、parameter 与 empirical result，避免函数调用替代理解。

沿着上述 Cornell 官方 homework/exams 与 projects/labs 页面，可以尝试 10 份 homework、4 次考试和 5 个 lab。Cornell OCW 没有 lecture notes、TA 当面指导、Blackboard、lab machine 或正式评分，solution 也只覆盖 homework/exams，不覆盖 labs。这门课最需要保持清醒的地方，是 Spring 2016 课程说明与 2014 实验材料之间始终存在版本断层。
