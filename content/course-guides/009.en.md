## Matrix Structure Comes Before Algorithm Names

Gilbert Strang's MIT 18.065 Spring 2018 moves from the fundamental subspaces,
LU/QR/SVD, least squares, and PCA into optimization, sparsity, matrix
completion, SGD, and neural networks. The complete
[video lectures](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/video_galleries/video-lectures)
are easy to follow, but success means explaining how matrix structure
constrains an algorithm, not recalling a list of model names. Review 18.06
first if projections, eigenvalues, and the SVD do not yet illuminate
\(Ax=b\).

## Pair Every Topic with a Hand Calculation and Numerical Experiment

The official [syllabus](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/pages/syllabus/)
uses the commercial book *Linear Algebra and Learning from Data*; the whole
book is not included. The collected
[assignments](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/pages/assignments/)
also lack solutions, so create your own feedback. Derive a small case, then
inspect singular-value decay, condition number, residual, and backward error
on real data. Compare normal equations, QR, and SVD for least squares. For a
randomized method, preserve the seed, repetitions, and error interval.

## Make the Project Answer a Matrix Question

There is no exam. The
[final project](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/pages/final-project/)
replaced the final 3 assignments. A useful independent project starts with a
falsifiable metric and delivers data provenance, a simple baseline, matrix
dimensions and complexity, a stability check, rerunnable code, and a failure
case. An image-compression study can plot a rank–error–storage curve; a PCA
study should explain how centering, scaling, and missing values change the
directions. Merely calling a library or assembling a model leaderboard misses
the structural viewpoint that makes 18.065 distinctive.

During the retrospective, change the factorization or regularization, ask
whether the conclusion survives, and deliberately find a counterexample.
18.065's structural insight often comes from explaining why a method fails on
that class of matrices, not from the best-looking curve.
