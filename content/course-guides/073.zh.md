## 课程定位与归档状态

Åström 与 Murray 的 [Feedback Systems 2e](https://fbswiki.org/wiki/index.php/FBS) 提供 2020-07-24 版本全文，15 章从 feedback principles、modeling 和 dynamics，推进到 state/output feedback、PID、frequency design、robust performance、fundamental limits 与 architecture。逐章 companion material 有什么用什么；部分栏明确写 `None available`，并非每章都有作业或答案。

适合的读者已会微分方程、线性代数和基本 Python，想把物理建模、设计与 robustness 连起来。除 2e 逐章 exercise 外，Caltech 官方页面的 [Fall 2003 homework 存档快照](https://web.archive.org/web/20040820025958id_/http://www.cds.caltech.edu:80/~murray/courses/cds101/fa03/homework.html) 还保留 HW1–HW8、midterm、final 及 solutions，可作为有反馈的历史 coursework；使用时要标明它对应 CDS 101/110 旧课，而非 2020 版统一 grader。若只需线代/SVD，选当前 EE263；若要更深 LDS，选 EE363。

## 拿一个物理对象做完 model–analysis–design

为巡航控制或直流电机写 nonlinear equation，标输入、状态、输出、扰动与单位；工作点线性化得到 state-space、transfer function 和 simulation interface，每次简化都注明丢失的 saturation、delay 或 unmodeled mode。[Chapter 1–4 exercises 与 Feedback Principles](https://fbswiki.org/wiki/index.php/Feedback_Principles) 的巡航控制等例子适合这一段。

Chapter 5–10 中，每个 pole/zero 结论都用 characteristic equation、step/Bode/Nyquist 图和极限情形互查。官方 [Python repository](https://github.com/murrayrm/fbs2e-python) 的 figure scripts 采用 BSD-3-Clause；记录 upstream commit、Python 和 `python-control 0.10.1`，复现一张有解析预期的图作为基线，再分别改变 physical parameter、disturbance 与 noise setting。

Chapter 7–12 为同一对象比较 state/output feedback 与 PID/loop shaping。tracking、disturbance band、overshoot、control effort、sensor noise 和 actuator limit 共同约束 gain。两条路线都保留 controller equation、closed-loop poles/loop shape、相同工况和能暴露边界的失败案例。

## Robustness 要用失败边界说明

Chapter 13–15 为参数区间、高频未建模动态、sensor noise 和 actuator saturation 建扰动包络，扫描名义控制器，并区分调参不足与 nonminimum-phase zero、delay、Bode integral 等结构限制。failure map 要列 perturbation、mechanism、metric、accept/reject threshold 与 redesign；所有工况都成功，通常说明范围太窄。

[Solutions manual 的存档说明](https://web.archive.org/web/20100616051415id_/http://www.cds.caltech.edu/~murray/amwiki/index.php/Solutions_manual) 明确只向 instructors 提供。没有公开答案时，用量纲、极限情形、独立推导和小仿真交叉检查，不寻找受限镜像。
