## 这是一门“证明与反馈都公开”的信息论主线

本文固定为 Stanford EE276 Winter Quarter 2025-26，而不是把历年讲义、YouTube 补充视频和当期课堂混在一起。[官方 course information](https://web.stanford.edu/class/ee276/info.html)把目标概括为信息的度量、表示与通信：从 entropy、mutual information 和 compression，走到 reliable communication、channel capacity、error correction 与 rate distortion。正式先修只写 basic undergraduate probability 与接受抽象推理的意愿；实际开课门槛则是能用概率语言写证明，而不只是会代公式。

这一版的评分构成为 homework 20%、midterm 35%、final 45%。公开资料最大的优势不是数字多，而是反馈链闭合：8 次 homework 都有 solutions，2-hour midterm 和 3-hour final 也公开了含完整解答的试卷。与此同时，Gradescope 提交、Canvas/Panopto 当期录像、TA 批注和课堂问答仍需 Stanford 身份。本文是 R0 资料核验，不把公开答案等同于获得校内评分。

## 18 讲如何把“压缩”和“通信”接起来

[官方 outline](https://web.stanford.edu/class/ee276/outline.html)估计安排 18 lectures。前段建立 entropy、conditional/joint entropy、relative entropy、mutual information、AEP 与 typicality；随后用 prefix code、Shannon code、Kraft inequality、Huffman code、entropy rate 和 universal compression 回答“源最少需要多少 bit”；中段以 channel capacity、continuous information、AWGN、direct/converse channel coding 回答“噪声信道最多能可靠传多少”；末段进入 polar codes、rate distortion、method of types、strong/joint typicality。

这些主题不宜按术语表平铺。建议维护一张 theorem dependency sheet：每条结论写清随机变量、分布、block length、极限方式和使用的 inequality。例如 AEP 先把长序列压缩成 typical set 的计数问题，source coding converse 再说明低于 entropy 的代价；capacity 的 direct part 构造可行 code，converse 则把任何 code 的性能压回 mutual information 上界。若笔记只剩结论，没有 quantifier 与失败条件，后面的 rate distortion 和 method of types 会变成无法校验的公式堆。

### 打开 solution 之前，先过 proof gate

1. 给一张小型 joint pmf，独立计算 H(X)、H(X|Y) 与 I(X;Y)，并用 KL divergence 或 chain rule 解释 I(X;Y) 为什么非负。
2. 对一个 convexity 题，能正确选择 Jensen、log-sum 或 data-processing inequality，写出等号条件，而不是只给数值例子。
3. 能说明 law of large numbers 在 AEP 中控制什么，区分 convergence in probability 与逐点相等，并完成一次 Gaussian density 与 differential entropy 的代数整理。

若第 1 题连 support 为 0 的项都处理不清，先补离散概率、conditional distribution 和 expectation；若第 2 题只能背 inequality 名称，先补 convexity 与基本证明；若第 3 题把有限 block 的频率直接当作极限概率，先补随机变量收敛。每推进一个主题，再从 theorem 的结论倒推必须满足的假设，并找一个删掉假设便失效的例子。证明题保留逻辑骨架，构造题保留码本或算法，计算题保留精确式、近似式和误差来源。

## 把 8 份 solution 变成延迟反馈

[官方 homework page](https://web.stanford.edu/class/ee276/homework.html)列出 HW1–HW8，并为每一份同时提供 question PDF 和 solution PDF；其中 HW3 已进入 arithmetic coding，HW5 使用 Fano inequality，HW6 涉及 polar decoding。不要沿着网页顺序同时打开两份文件。先下载题目，把解答移出工作目录，完成无提示作答并给每题标记“definition / proof / construction / computation / counterexample”；隔 24 小时再核对 solution，记录第一个错误前提，随后关闭答案重做整题。

## 两场考试只在封闭条件下有价值

[官方 exams page](https://web.stanford.edu/class/ee276/exam.html)公开 midterm 与 final 的 problem-and-solution PDF。第一次应按 2-hour 和 3-hour 限时盲做；第二次只用答案建立 rubric，区分漏掉假设、方向错误、证明缺口、算术错误与表达不充分；第三次在 7 天后不看答案重做错题。公开 solution 能回答“标准论证走哪条路”，但不能替代 Gradescope 对部分分、TA 对含混证明的追问或考场条件。

校正时不要只抄一份更漂亮的证明。把原答案切成“已知、目标、关键不等式、等号条件、结论”几格，逐格标出从哪里开始失效；若错误发生在问题建模，后面的代数即使与解答相同也不能得分。重考只看这份错因标签，不看标准推导。

学习顺序由两次盲测切开：先用 HW1–HW3 建立 measures、AEP 与 source coding，在容量与 AWGN 边界做 midterm；再推进 HW4–HW8、polar code、rate distortion 和 types，最后把 final 留作完全封闭的总测。重做时若只能复述官方句式却无法更换分布或参数，反馈仍未闭环。

## 录像、旧讲义和参考书的证据边界

[Previous Notes](https://web.stanford.edu/class/ee276/previous_notes.html)明确把旧 notes 标为 auxiliary：它们覆盖大部分 Lecture 2–18，但不保证等同于当前讲授，Lecture 6 还指向受限 Canvas video。当前 outline 公开的 slide 也不构成完整逐讲录像。[官方 reading page](https://web.stanford.edu/class/ee276/reading.html)列出的外部 YouTube playlists 是补充说明，不是 Stanford lecture recordings；Cover–Thomas、Polyanskiy–Wu 等教材也有各自的购买或访问条件。

因此，结课记录应分三栏：current public（outline、8 个 solved HW、solved midterm/final）、auxiliary public（previous notes、外部 playlists）、institutional missing（Canvas/Panopto、Gradescope、TA feedback）。没有官方 lab、code grader 或 course project 的公开记录，就不要虚构一个“EE276 实验周”。独立学习的最低证据应是 8 份盲做稿与延迟重做、2 份限时考试、依赖图、错因统计，以及能够从空环境重跑的一个计算实验。

## 最后才做 finite-block 计算实验

EEDIY 补充项目是“BSC 上有限 block coding 与容量界的对照”，不是 Stanford 官方 project。先推导容量 `1-h2(p)`，再实现 repetition、random linear code 与一个小型 polar code，在相同 channel crossover probability 下扫描 block length、rate 和 decoding error；保留 code construction、seed、原始 trial count 与 confidence interval。验收要求包括独立 encoder/decoder round trip、极端 `p=0` 与接近 `p=0.5` 的边界测试、经验误码率和理论界的差异解释，以及他人一条命令可重建图表。只用合成 bit 和模拟信道，不引入真实个人数据或通信内容。
