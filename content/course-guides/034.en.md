## An Eight-Week Analog Course Centered on Op-Amps

NPTEL [Analog Circuits](https://nptel.ac.in/courses/108101094) is IIT Bombay
course 108101094. Its stable
[syllabus PDF](https://archive.nptel.ac.in/content/syllabus_pdf/108101094.pdf)
moves from ideal op-amps, nonidealities, and Bode/feedback analysis through
stability, active filters, and oscillators, reaching diodes and BJTs only at
the end. Choose it if you already know KCL/KVL, RC response, and ideal op-amp
analysis. For transistor-level analog IC design, it is preparation
rather than the destination.

The permanent page changes with new NOC runs. The
[2019 archived preview](https://onlinecourses-archive.nptel.ac.in/noc19_ee10/preview)
is a more stable self-study reference. Enrollment, deadlines, certificates,
and exam rules belong only to the run actually joined and should not be mixed.

## Follow Every Circuit into Its Nonidealities

For an inverting stage, derive ideal gain and then add finite open-loop gain,
bandwidth, offset, bias current, slew, and output swing. For a filter, derive
the transfer function and Bode prediction from pole placement before running
SPICE. Record the op-amp model, supply, temperature, source and load, and
software version in every netlist. An oscillator also needs a startup and
amplitude-limiting explanation, not merely a periodic trace.

The 2019 [announcements](https://onlinecourses-archive.nptel.ac.in/noc19_ee10/announcements)
show 8 weekly assignments for that run, but anonymous access does not
guarantee a permanent complete problem, answer, and grader set. Use weekly
staged problems and check them with limits, SPICE, or a text; do not report a
personal score as an NPTEL grade.

## Put Protection, Gain, Filtering, and Offset in a Sensor Front End

Build a low-voltage sensor front end with input protection, gain, active
filtering, offset, and an output interface. State signal range,
noise/headroom, and stability before corner sweeps and measurements at key
frequencies. Common-mode range, GBW, slew, and load conditions for the real
op-amp must come from consistent datasheet conditions; combining unrelated
typical values invents a device. This chain tests whether the course topics connect
without mistaking demonstrations for a complete hardware laboratory.

Finally, read the datasheet backward from an output-distortion or stability
failure into the test conditions for common mode, output swing, load
capacitance, GBW, and phase margin. Identifying which specification limits the
design first is the step from platform exercises to a real op-amp.
