## 先看四个实验，再决定要不要学 6.111

MIT 6.111 是一门数字系统实验与项目课。Spring 2006 版本前半学期讲组合逻辑、Verilog、
时序模块、FSM 与同步、存储器和时序、算术结构、模拟构件、系统集成、可重构逻辑、视频、
性能变换和数字系统功耗；最后 5 周则停止常规 lecture/recitation，把课堂时间完整交给
final project。先看 [Calendar](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/calendar/)
会比只扫 lecture 标题更容易看清这门课：Verilog 只是开场，真正占时间的是接口、时钟、
同步、验证、拆分和调试。

官方 [Syllabus](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/syllabus/)
说明不要求预先有数字设计经验，6.004 也不是硬性先修，可以先修、后修或同学期修；
但学生必须有基础电路理论背景。这里的“不要求经验”不能理解为“从第一天开始学逻辑门
和编程”。开始前至少应能读组合逻辑真值表、理解寄存器在时钟边沿更新、使用一种编程
语言表达状态和数据流，并能看懂基本示波器波形。

若只需要系统学习 HDL 与计算结构，[MIT 6.004](../digital-logic/037-6-004.md) 或 DDCA
更像教材课。如果只能二选一：想先把数字设计知识补齐，我会选 6.004；已经能读基本
时序图，想把 FPGA 做到公开演示和技术报告，我会选 6.111。

## Lab 1–4 具体做什么

[Labs](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/labs/)
公开实验 PDF、Verilog 模板、`.ucf` 引脚约束和部分支持模块。四个实验一项接一项：

1. **Lab 1：基础数字设计。** 熟悉综合、下载、板级 I/O 与 checkoff，先确认工具链、
   约束文件和板卡连线能一起工作。
2. **Lab 2：traffic-light controller。** 用 FSM 表达状态、输入和时序，训练可观察的
   状态转换与测试场景。
3. **Lab 3：memory tester。** 让控制器主动读写并判断存储器结果，开始处理协议、地址、
   数据路径和错误报告。
4. **Lab 4：Pong video game。** 把复杂 FSM、视频时序、输入和显示组合起来，第一次
   面对多模块系统集成。

三个 problem set 主要为实验准备，且
[Assignments](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/assignments/)
给出 solutions；另有一次正式 quiz。先做对应题目，再开 lab 模板。否则等到板上没有
画面时，时序概念、约束文件和接线问题会混在一起，很难判断是哪一层出了错。

## Final project 要过哪些检查点

Syllabus 把下面的比例称为 **approximate breakdown**：final project 约占 37%，四个
labs 合计约占 37%。1–3 人自选题后，需要依次完成组队、
abstract、proposal conference、block-diagram conference、design presentation、
custom checklist、实现与调试、最终 demo/video 和 report。即使系统没有完全工作，
也必须演示并提交书面报告才能通过。项目即使没有全部跑通，设计取舍、失败位置和剩余
问题也得说清楚。

[Projects](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/projects/)
公开 15 组 2006 年案例，包括拳击游戏、鼓机、指纹验证、3-D Pong、主动声纳、卡拉OK、
视频监控和 CDMA 解码。它们适合用来观察 block diagram、阶段汇报、final report 与 demo
怎样配合，不应被当成 15 套今天可以一键复现的项目仓库。

独立学习拿不到 TA conference，可以自己设 3 次书面检查点：第一次冻结需求、接口和
时钟域；第二次拿出最小可演示切片，同时检查验证计划和资源预算；第三次按 custom
checklist 逐项验收。这 3 次检查不是 MIT 原课活动，但比做到最后一周才第一次上板更
接近原课的项目节奏。

## 把 2006 年 labkit 移到今天

原 labkit 使用 Xilinx Virtex-II 与 ISE Foundation；官方当时写的是约“6 million gates”
和“state-of-the-art”，都是 2006 年语境；`.ucf` 约束、视频接口、存储器和支持模块也
绑定这块课程自制板。
旧 labkit documentation 的深链目前会重定向到 MIT MTL 首页，器件 datasheet 又因版权
原因未随课程提供。直接宣称原实验在现代板卡上可运行，会掩盖最重要的移植工作。

选择当前可得 FPGA 后，先列一张 migration matrix，把原器件、接口、时钟、存储和约束
格式逐项对应到新平台；随后分开验证时钟、复位、单个 I/O、视频时序和存储接口，再移植
实验功能。综合成功只说明代码通过了综合器，还需要保留时序报告、CDC 假设、资源占用、
仿真测试和板上 checkoff。板级操作保持低电压，改线前断电，不把未知 PMOD、电源轨或
激光/高功率外设接入自学项目。

### 一份能让别人复查的项目记录

以 2006 项目页中的视频或通信系统为参照，一份项目记录至少要有：标出模块责任和时钟域
的 block diagram；接口与时序约定；可自动运行的 testbench；综合与时序报告；分阶段
checkoff；故障日志；最终 demo 和技术报告。只上传 Verilog 文件，看不出系统是否真的
上过板，也看不出失败发生在哪个接口。

[Exams](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/exams/)
提供当期 quiz 与 2003/2004 练习卷，可用于检查时序、FSM、存储和系统概念。
[课程首页](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/)
可以补齐 syllabus、日历和项目材料。开始前先确定一块确实能买到、文档完整的 FPGA，
并确认自己愿意逐项重写约束和板级接口；如果只想跟着旧 PDF 原样操作，这门 2006 课程
并不是省事的选择。
