## 这门课训练的是从规格走到滤波器

[EPFL DSP 2](https://www.coursera.org/learn/dsp2) 有 3 个 modules、3 次 graded
assignments 和 5 个 Python/Jupyter labs，内容从 digital filters、filter design 走到
stochastic/adaptive processing。它适合已经能用卷积、DTFT/DFT 和复频响分析 LTI 系统，
现在需要把 passband、stopband、delay 与计算量变成设计判断的人；这些基础仍靠背公式时，
先修 DSP 1 更实际。

## 三段内容都回到一张 filter specification

从音频问题写清保留频段、允许失真、过渡带和延迟，再比较窗函数与 Parks–McClellan 在阶数、
ripple、group delay 和 multiplication count 上的差异。nonlinear processing 要用双音输入
观察 harmonic 与 intermodulation，避免把削顶误当作普通 stopband leakage。echo
cancellation 则记录 step size、收敛曲线、residual echo 和 reference-path 改变后的恢复；
“听起来更好”不能代替 target 与 measured value 的并排比较。

不必为三段内容各起一个 project。选定输入、幅度标度和边界处理后，把规格、两种
设计、自动指标、失败样本与选择理由放在一个 filter case study 里。若 IIR 系数经过量化，还要重新检查 pole；若是 adaptive
filter，则固定随机种子并展示失配后的跟踪。

## 旧版 NumEx 只承担数值参照

官方旧仓库 [DSPNumex](https://github.com/LCAV/DSPNumex) 中，
[NumEx5](https://github.com/LCAV/DSPNumex/tree/master/NumEx5) 可补 LTI，
[NumEx7](https://github.com/LCAV/DSPNumex/tree/master/NumEx7) 可补 stochastic signal
processing。它们没有按当前 5 个 lab 名称组织，也不包含平台 grader 或完整反馈。Coursera
lab、旧版 NumEx 和个人实现应保持来源区分；当前 graded work 的访问取决于账户方案。那张规格表
还应在短序列、长序列与幅度变化下重复检查，确认边界处理、启动暂态和数值精度没有被误写成
滤波器本身的性能。只有此时，失败案例才真正指向 filter design 的选择。
