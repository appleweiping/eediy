## 课程定位与先修

Stanford [EE 359 Winter 2020](https://web.stanford.edu/class/ee359/) 由 Andrea Goldsmith
授课，[Course Info](https://web.stanford.edu/class/ee359/courseinfo.html) 要求 EE 279
或同等基础。课程从 propagation/fading、capacity、diversity 和 adaptive modulation 走到
MIMO、OFDM、spread spectrum 与 multiuser。它适合已经会 probability、random processes、
digital communications 和 SVD，想把 channel assumptions 变成设计取舍的人；第一次学习
AWGN、complex baseband 或 symbol error 时，应选基础通信课。

## 作业与反馈

[Lectures](https://web.stanford.edu/class/ee359/lectures.html) 提供 20 讲 slides/summary，
视频进入 Canvas，不能算匿名公开视频。每讲建立 model card：channel distribution、slow/
fast、flat/frequency-selective、CSI、power/bandwidth constraint 与 metric；2020 的
LTE/5G 案例用于解释理论，不能替代当前标准。

[Homework](https://web.stanford.edu/class/ee359/homework.html) 公开 Homework 1–8 与
solutions，coding questions 还要求 scripts。保留首次作答后再核对，记录 random seed、
parameter sweep、unit 和最早错误。公开解答不包含 Canvas 分数、Piazza 更正或 staff feedback。

## 考试档案跨了多个年份

[Exam page](https://web.stanford.edu/class/ee359/exam.html) 标题为 Fall 2017，并混有
2015–2017 practice papers；某个 2020 midterm solution 使用 `restricted/mt20_soln.pdf`。
因此每份卷须记录 year、question access 与 solution access，不能把旧卷改写成 Winter 2020，
也不能由文件名推断受限答案内容。

## 项目题目越窄越好

[Projects](https://web.stanford.edu/class/ee359/projects.html) 列出 2020 主题与往年作品。
站外项目应选可证伪问题，例如指定 fading/CSI 下 diversity combining 对 outage 的影响，而非
“实现 5G”。从 SISO Rayleigh 或 MRC baseline 出发，再用 Monte Carlo 报 sample count、
confidence interval 和失效条件；MIMO/OFDM 另记 matrix dimension、power allocation、
cyclic prefix 与 synchronization。最终报告需要把 Goldsmith 理论、2020 课程材料和个人实现
分开，并保留解析与仿真不一致的案例。
项目主表应把理论假设、仿真参数与图中坐标逐项对应，并同时给出名义点和一个边界条件。若调整
随机种子、归一化或信道定义便改变主张，报告要保留这次失败并缩小适用范围；这比增加更多无线
术语更能说明已经掌握课程中的模型判断。

EE 359 最终训练的是 model judgment：知道一条 outage 或 BER 曲线依赖哪种 fading、CSI 与 power normalization，也知道条件一变时结论会从哪里裂开。
