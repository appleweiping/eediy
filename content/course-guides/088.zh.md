## 先接受它是 1987 年课程的数字重放

MIT 的 [RES.6-008 主页](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/) 标注 “As Taught In Spring 2011”，但课程说明同时写明：这套 distance-education course 由 MIT Center for Advanced Engineering Studies 在 1987 年开发，面向工作中的 engineers and scientists。2011 是 OCW 资源页的课程标识，不应把黑板录像、器件语境或教材年代描述成 2011 年重新录制。

[Introduction](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/pages/introduction/) 要求 advanced calculus、初步 complex variables，以及连续时间 linear systems 中 Laplace/Fourier transforms 的先前训练；它不要求已经学过 discrete-time signals、z-transform 或 DFT。开课前应能独立计算连续时间卷积、判断 LTI、用复指数解释频率响应。缺少这 3 项时，先补 signals and systems，而不是期待 Lesson 1 同时补齐。

## 公开包是 20 课、2 个演示和 19 份解答

[Video Lectures](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/video_galleries/video-lectures/) 列出 Lecture 1–20，另有 “Sampling, Aliasing, and Frequency Response” Demonstration 1 与 2。两段 demonstration 不应计作 Lecture 21–22。逐项检查这 22 个资源页时，每页都提供英文 caption track 与 transcript 下载入口；例如 [Lecture 1](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/resources/lecture-1-introduction/) 可直接查看或下载 transcript。后续可用性仍应以当前 OCW 页面为准。

[Study Materials](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/pages/study-materials/) 为 Lecture 1–20 各给 1 份 notes PDF，内容包含 chalkboard images、slides、解释与 homework problems；Problem Solutions 从 Lecture 2 连续列到 Lecture 20，共 19 份。准确说法是“20 课讲义中嵌入问题，后 19 课有对应 solution packet”，不是“19 套独立、按现代作业格式编排的 problem sets”。

[Readings](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/pages/readings/) 逐课映射 Oppenheim 与 Schafer 的 *Digital Signal Processing*（Prentice Hall, 1975）章节。该书是 required text，但 OCW 只给书目信息和 section mapping，没有公开整本电子书。讲义与解答可以直接访问；核心教材的取得、版本和许可要由学习者另行解决。

## 按“表示—变换—实现—算法”重放

第一卷是 Lecture 1–7：difference equation、discrete convolution、DTFT 与 z-transform。每个序列都建立 4 联表：时域定义、DTFT、z-transform、ROC；因果性与稳定性必须从 ROC 说清，不能只留下一个有理式。第二卷是 Lecture 8–10：DFS、DFT 与 circular convolution。用长度 \(N\) 的周期延拓解释为什么 circular convolution 不是“算错的 linear convolution”，再写出 zero-padding 何时使两者一致。

第三卷是 Lecture 11–17：linear digital networks、IIR/FIR structures、coefficient quantization、IIR design、Butterworth 与 FIR design。比较 direct form、cascade 与 parallel realization 时，应追踪 pole/zero sensitivity、state scaling、overflow 和 delay count，而不是只验证理想 \(H(z)\) 相同。第四卷是 Lecture 18–20：从 DFT 计算进入 FFT；至少手推 1 次分解，写清 index permutation、twiddle factor 和 operation count。

每卷还要保留一种“同一对象的多种表示”。例如差分方程、冲激响应、系统函数和框图必须指向同一个系统；频域采样、周期延拓与循环卷积必须共享同一索引约定；滤波器规格、极零点和实现结构必须能互相还原。若转换后只剩相似图形，却对不上延迟、比例或收敛域，应停下纠正表示，而不是继续播放后面的录像。

Introduction 给出的提供方节奏是每 lesson 约 5 小时，并建议先录像、再教材、最后 problems。这个数字是历史 distance-course 的估计，不是 EEDIY 工时承诺。更可靠的推进条件是：当前 lesson 的非星号题首稿冻结、units/ROC/index convention 检查通过，才打开 solution；星号题按官方说明属于 optional extension。

## 4 个断点最能暴露伪熟练

断点 1：给定一个差分方程、初始静止条件和输入，分别用递推、卷积、z-transform 得到同一输出，并解释 unilateral/bilateral 约定。断点 2：给定有理 \(X(z)\)，列出可能的 ROC，逐个判断 causal、right/left-sided 与 stable；若只做 partial fraction，不算完成。

断点 3：对两个有限序列同时计算 linear 与 \(N\)-point circular convolution，给出避免 time aliasing 的最小 padding 长度。断点 4：同一高阶 IIR 用 direct-form 与 second-order sections 实现，在量化系数和有限精度下比较 pole movement 与输出误差。前 3 项是课程主干；第 4 项把 Lecture 13 的 parameter quantization 接到当前实现。它们是 EEDIY placement diagnostics，不是 MIT 考试题。

若断点 1 失败，补 DT LTI 与 transform convention；断点 2 失败，停在 Lecture 5–7；断点 3 失败，重做 Lecture 8–10；断点 4 失败，回到 structures 和 numerical representation。至少 3 项可独立完成且交叉验证后，再进入自拟项目。

## RES.6-008 与 6.341 的边界在深度和实践

MIT [6.341 Discrete-Time Signal Processing](https://ocw.mit.edu/courses/6-341-discrete-time-signal-processing-fall-2005/) 是 2005 秋季 graduate subject，明确假定已熟练掌握 LTI、sampling、Fourier 与 bilateral z-transform，正式 prerequisite 是 6.011。它在共同的 DFT、structures、IIR/FIR 基础之外继续到 decimation/interpolation、sample-rate conversion、linear prediction、short-time Fourier analysis、filter banks、multirate、Hilbert transform、cepstral analysis 与 applications。

公开反馈也不同。6.341 有 Problem Set 1–11 及解答、考试与解答，并要求 2 个 MATLAB projects 和 written reports；项目材料仍引用 MIT Athena 与旧版 MATLAB 环境。RES.6-008 的优势是从零引入离散时间并保持 20 课连续叙事，后 19 课有解；它没有公开 exams、code lab 或 project。第一次学 DSP 选 RES.6-008，已通过 z/DFT/filter-design 诊断并需要 multirate、STFT 与 project 证据时转 6.341。

## 非官方代码实验只负责补“可运行”

EEDIY 建议另建 1 个 current-toolchain repository，明确标为非官方补件。最小范围包含：用直接定义与 FFT 计算 DFT 并比较误差/operation trend；用 overlap-safe convolution 检查 padding；从 specification 设计 1 个 IIR 与 1 个 FIR；把高阶 IIR 分别实现为 direct form 和 SOS；对 coefficient word length 做 sweep。每项保留 tests、frequency response、impulse response、pole-zero plot 和 failure note。

可以使用当前 Python/NumPy/SciPy、JuliaDSP 或 MATLAB/Octave，记录版本和 floating/fixed-point 假设。不要把库函数返回图当作 filter design 解释；必须说明 passband/stopband、sampling frequency、normalization、phase、transient handling 与 numeric tolerance。课程没有要求实时 audio、DSP board 或 fixed-point deployment，因此这些扩展也不能写成 MIT lab。

## 结课包要保留历史边界

完成证据包括：Lecture 1–20 的 video/notes ledger；2 个 sampling demonstrations 的观察记录；1975 textbook 的 section mapping 与实际使用版本；Lecture 2–20 共 19 份 solution packet 之前的题目首稿；4 个断点；以及 1 个明确标为 EEDIY supplement 的 code repository。没有公开 exam 时，不用自拟分数伪造课程 grade；可用闭卷概念复述、同构算例和 regression tests 补验证，但要标来源。

结课记录应当保留这门课独有的边界：1987 CAES 来源、20 课加 2 个演示的资源表、Lecture 2–20 的解答结构、1975 教材映射，以及 Lecture 13 的量化问题。缺了这些仍能成立的文字写得过于泛化。本页依据官方公开材料整理，不冒充维护者修课经验；纠错请带 course ID 088、Lecture 编号、PDF 页或官方 URL 与复核日期。
