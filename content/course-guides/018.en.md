## Find the Scale before Calculating Precisely

MIT 6.055J/2.038J Spring 2008 teaches dimensional analysis, extreme cases,
scaling, successive approximation, balancing, and symmetry. The official
[syllabus](https://ocw.mit.edu/courses/6-055j-the-art-of-approximation-in-science-and-engineering-spring-2008/pages/syllabus/)
requires only 8.01 and 18.01. For independent study, choose it before a formal
modeling course if an unfamiliar problem immediately sends you searching for
a formula. The goal is not uncanny
guessing, but finding controlling quantities, dominant mechanisms, and the
source of uncertainty.

## Read the Book with the Answer Covered

The [readings](https://ocw.mit.edu/courses/6-055j-the-art-of-approximation-in-science-and-engineering-spring-2008/pages/readings/)
provide Mahajan's open manuscript. Hide each worked solution and first list
possible variables, dimensionless groups, extreme limits, and the expected
order of magnitude. Then compare why the author chose a different
approximation. Dimensional analysis constrains form but does not determine
every constant; scaling can miss geometry changes and boundary effects. For
each method, state what it eliminates and what remains unknown.

The [assignments](https://ocw.mit.edu/courses/6-055j-the-art-of-approximation-in-science-and-engineering-spring-2008/pages/assignments/)
contain 6 required sets with full solutions and an optional Set 7. Spend 45
minutes building a dimensionally consistent model before reading a solution,
then redo the problem from blank paper. There was no conventional exam; the
campus grade was 100% homework.

## Study notes

Estimate a nearby EE quantity each week: RC settling time, wire heating,
small-motor thermal time, or wireless-node battery life. Sketch first, list
variables and the approximation hierarchy, then look up known values and check
the result afterward. For a final unseen problem, give an
order of magnitude before consulting a datasheet, revise it afterward, and
identify which parameter changed the conclusion most. Locating whether an
error came from a constant, model, or arithmetic is more valuable than
guessing a number correctly; keep the estimate range distinct from
measurement uncertainty.
