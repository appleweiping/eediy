## 用 bias、\(g_m\) 与 \(r_o\) 比较 BJT 和 MOS

每个器件都从 charge/cross-section 推出 terminal equation，再由 bias point 得 small-signal
model，最后检查 amplifier 的 gain、input/output resistance、headroom 与 bandwidth。
对 common-emitter、common-source 和 differential pair 都依次分析 DC bias、中频、pole/zero
和 large-signal swing；这样才能看出哪些结论来自 topology，哪些来自 device law。

首页列出 Homework 1–14、2 次 midterm 与 final。[Homework 1](https://people.eecs.berkeley.edu/~boser/courses/105/assignments/H1.pdf)
可直接进入；答案覆盖不均，虽有 [Final Solution](https://people.eecs.berkeley.edu/~boser/courses/105/assignments/FINAL_solution.pdf)，
多数 homework 没有同样支持。独立做题后用 operating-region、KCL residual、gain/headroom
limit 和 SPICE 复核。

## 用两级放大器组织仿真实验

归档还保留 [LTspice Guide](https://people.eecs.berkeley.edu/~boser/courses/105/resources/LTSpice.pdf)，
但不少 lab handout 与反馈原本在 bSpace，不能完整复刻。可以低压完成 BJT/MOS
characterization、单级 amplifier、frequency response 与 differential pair，最终做一条
两级 tuned/amplifier chain。每次保存 bias、器件实测值、模型来源、原始波形和一次故障定位。
最后应能回答：器件参数的变化经过哪些偏置与小信号关系，才变成系统 gain、bandwidth 或失真。

完成 nominal 链路后，故意改变一个 bias resistor、增加 load 或移除 bypass capacitor。
预测哪些 node voltage、pole 和输出指标会变化之后再测量。能从症状追到器件 region 或
small-signal path，比一次漂亮的 AM 输出更接近 EE105 的实验性格。把故障前后的工作点并排，
如果电路只是偶然恢复却说不出哪个 bias 或 small-signal path 改了，排故还没有完成。
