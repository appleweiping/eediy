## 为证明而学的信息论讲义课

MIT [6.441 Spring 2010](https://ocw.mit.edu/courses/6-441-information-theory-spring-2010/)
从 entropy、typicality、source coding 走到 capacity、Gaussian channels、multiple access、
broadcast 与 side information。它适合已有 probability、random processes、linear algebra
和证明训练，想理解 achievability/converse 与 multiuser models 的人；需要视频、逐题答案或
编程项目作为主反馈时，应另配更完整课程。

## 课程结构

[Lecture notes](https://ocw.mit.edu/courses/6-441-information-theory-spring-2010/pages/lecture-notes/)
公开 23 讲。每个 theorem 至少写出 alphabet/channel model、概率假设、constraint、limit 和
证明最脆弱的一步；coding theorem 分开 direct 与 converse，Gaussian result 写明 power/
noise，multiuser result 画清各端知道什么。再加入 `failure if removed`：删去 memoryless、
stationarity、fixed variance 或 decoder side information 后，结论哪里改变。

## 作业与反馈

[Assignments](https://ocw.mit.edu/courses/6-441-information-theory-spring-2010/pages/assignments/)
提供 Problem Set 1–9，却没有 solutions；OCW 也没有公开视频或成套考试，原 project 题面
并未完整公开。每题保留 `claim / proof / numerical check / unresolved`，有限 alphabet
枚举或 Blahut–Arimoto 只能验证特例，不能替代一般证明。没有答案时，最有价值的产物是可准确
提问的最小 lemma，而非从数值结果反推“定理正确”。

结课建立 source coding、single-user channel、Gaussian/multiuser 3 张 synthesis notes，
并分别验证 Huffman average-length bound、对称信道 capacity 和 Gaussian MAC region。
程序保存 pmf、precision 与 stopping rule，清楚标成独立数值练习，不冒充 MIT project。
最终索引逐项区分 theorem、example 与 conjecture，并记录 lecture/page 和外部证明来源。
多用户部分还要为每个结论画出发送端、接收端、消息与旁信息，避免把单用户容量公式直接搬到
共享信道。证明卡住时写出最小未解引理，再用极端分布或小字母表寻找反例；数值通过只能缩小
疑点，不能把尚未证明的命题升级为课程定理。结课时随机抽取一个结论，说明其可达性构造与逆向
上界各依赖什么，才能证明这套讲义已经从公式集变成论证结构。

6.441 学到位以后，看到一个 capacity 式子会自然追问 alphabet、constraint、achievability 和 converse；公式本身只是论证的中间站。
