## 这是给成熟模拟设计者的题目库

MIT 6.331 Spring 2002 的官方
[Syllabus](https://ocw.mit.edu/courses/6-331-advanced-circuit-techniques-spring-2002/pages/syllabus/)
要求 6.301 与 6.302，并写明 “no equivalents”。课程默认你已能做晶体管级放大器、loop gain、
stability、noise/offset 和 transient，再进入 sample-and-hold、ADC/DAC、reference、
oscillator、PLL 与 power converter。若小信号、Bode/Nyquist 和台面测量还不能互相印证，
这门课不适合作为捷径。

## 访问与版本说明

[Calendar](https://ocw.mit.edu/courses/6-331-advanced-circuit-techniques-spring-2002/pages/calendar/)
能给出主题顺序，但 OCW 没有 lecture notes、lecture video 或 exam。
[Assignments](https://ocw.mit.edu/courses/6-331-advanced-circuit-techniques-spring-2002/pages/assignments/)
公开 6 套 problem sets 和 3 个 design problems。design 要细到 technician 可以按文档搭建：
具体器件、数值、tolerance、bias、接口、worst case 和 test method，而不只是 block diagram。

每个 design 都建立 requirements matrix，把 spec 分配到 calculation、simulation 与 bench test。
ADC/DAC 则把 quantization、reference、offset/gain、linearity、settling、noise 和 clock
jitter 分解成 error budget，再由预算选择 architecture；从熟悉芯片反推需求会颠倒设计因果。

## 实验与项目

[Labs](https://ocw.mit.edu/courses/6-331-advanced-circuit-techniques-spring-2002/pages/labs/)
公开 3 个实验。现代迁移要重新核对 supply、logic level、reference range、input protection、
timing 与 pinout，并限制在隔离低压和受控储能。报告应按 reference、switch/buffer、conversion
core、clock/control、output reconstruction 分段排错，保留 raw waveform。

最终交付一个 technician-ready design 和对应实验：每项指标注明 nominal、worst-case 与尚未
验证的部分，并从系统取舍、电路 headroom/stability、测量带宽/grounding 三个方向各挑战一次。
这套公开材料很适合高阶练习，但需要另找权威理论来源，不能单独组成从零开始的完整课程。

最后把 reference、temperature、supply 或 source impedance 推到边界，试着让设计失败。
若某项只依赖 datasheet typical value，就提出 measurement 或 fallback；“没观察到问题”
无法构成 worst-case 论证。仪器精度、保护限制和校准状态决定了边界试验实际覆盖到哪里，
不要把没有进入的温度或负载区域画进安全范围。
