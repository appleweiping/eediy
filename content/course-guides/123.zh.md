## 先承认这是一门研究生 transport 课

MIT **10.626 Electrochemical Energy Systems, Spring 2014** 的官方[syllabus](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/syllabus/)把 10.50 Analysis of Transport Phenomena 列为先修，并按每次 1 小时、每周 3 次组织课堂。课程不是“电池常识”或 DIY battery guide，而是用 equivalent circuit、thermodynamics、reaction kinetics、transport、electrostatics、porous media 与 phase transformation 分析 battery、fuel cell、supercapacitor 和 electrokinetic system。若还不能从 conservation law 写出 flux balance，先补传输现象，不要靠看完视频弥补数学断层。

官方评分结构也暴露了课程重心：problem set 占 40%，take-home midterm 占 30%，open-book final 占 30%。这 3 个数字只说明 2014 校内课怎样考核，不提供校外成绩、grader 或教师反馈。商业教材和部分 research article 需要另行合法取得；OCW 页面公开不等于所有 assigned reading 都在同一许可下免费分发。

## 用 3 个门槛题判断能否进入 Session 1

第 1 题：从一维扩散或迁移过程写出守恒方程，给出边界条件，并用无量纲化判断主导时间尺度。第 2 题：用电化学势或能斯特关系解释平衡电压怎样随浓度、温度变化，并检查符号与单位。第 3 题：为电阻—电容等效电路写出复阻抗，解释奈奎斯特图中的高频截距和特征时间。任何一题若只能套公式，应先补对应的传输现象、热力学或线性系统。

这 3 题是 EEDIY 的 placement diagnostic，不是 MIT 的 prerequisite waiver。真正的通过标准是能写 assumption：electroneutrality 是否成立、activity 是否被 concentration 代替、isothermal 是否合理、interface 是否被 lumped。答案数值正确但假设说不清，仍不足以开始 porous electrode modeling。

还要检查数学表达能否回到物理量。通量的正方向、界面法向和电流符号若没有在图上固定，后续的反应速率与边界条件很容易互相抵消；把浓度直接当作活度，则必须写明近似适用范围。对每个方程先做单位核对，再写守恒体积和控制面。这样，错误会在进入数值求解器之前暴露，而不是由一条看似平滑的曲线掩盖。

## 3 个导入 session 之后，再用 5 个编辑层组织模型

官方[calendar](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/calendar/)逐项列出 38 次课。前三次不是模糊的“应用与数学背景”：Session 1 是教学大纲与课程概览，Session 2 是原电池基本物理与电化学能量转换，Session 3 是电化学储能。它们构成三次官方导入课；这里保留英文 session 编号，方便读者回到原日历逐项核对。

从 Session 4 开始，本指南才做一层明确标注的 EEDIY 编辑重组，而不是声称 MIT 把课程命名成五层：4–7 是电路与阻抗；8–15 是热力学；16–24 是反应动力学；25–34 是输运与反应—扩散；35–38 是双电层、超级电容器、多孔介质、尺度分析与多孔电极综合。自学顺序沿这五个耦合层推进，但阅读索引仍保留原来的 38 个 session 编号。

第一层留下一本电路辨识笔记：从电压、电流瞬态拟合最小等效电路，并说明参数能否被唯一辨识。第二层留下一份热力学账本：把化学势、开路电压、稳定性与相行为的推导彼此对照。第三层把 Butler–Volmer 类动力学的极限情形、Tafel 行为与交换电流假设写在同一页。第四层从扩散、迁移守恒走到无量纲群。第五层才把双电层、界面动力学与输运合成多孔电极模型，并检查网格、时间步、质量守恒和能量一致性。

这些层不能一次全部塞进同一个黑箱。每加入一种物理机制，都先保存上一层的基准输出、守恒残差、参数表和极限情形。新模型若改变旧结果，必须说明来自新增机制、参数重新辨识还是数值离散。特别是多孔介质的有效输运系数和界面面积，不能被当作随意调节的拟合旋钮；来源、单位和适用范围都要进入参数账本。

[Lecture Notes index](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/lecture-notes/)并不是 38 份同版本教师讲义。官方索引混合了 2014 student scribe notes、2011/2012 旧讲义、教材章节与 research reading，而且并非每个 session 都有一份当前 note。学习记录必须标 source year 与 document type；不能把旧稿、学生笔记和正式 2014 lecture 一律写成“38 讲配套讲义”。

## 5 份 problem set 没有 solution，要主动设计反馈

官方[Assignments page](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/assignments/)列出 Problem Set 1–5，并明确写明 solutions unavailable。先在无参考答案条件下做首稿；每题保存 governing equation、boundary condition、units、limiting case 与 numerical residual。订正可以依靠 conservation residual、analytical special case、两个独立 numerical discretization 或不交换最终答案的 peer derivation，不能用来源不明的 solution archive 补洞。

反馈强度应随模型层增加。等效电路可用闭式响应校验；热力学可检查 Maxwell 型一致性与平衡极限；动力学可检查小过电位和大过电位极限；输运模型必须检查全局质量守恒与网格、时间步收敛；多孔电极还要做参数扰动。若只得到一条看似合理的放电曲线，却没有残差与收敛证据，仍未完成对应层。

这些问题适合训练推导，却不会提供校外 grade。完成表应把每题分成 attempted、independently checked、peer-reviewed、unresolved 4 种状态，不用模糊的“done”隐藏无解答带来的不确定性。

同伴复核也需要边界。复核者可以检查控制体、符号、量纲、数值收敛和物理解释，却不应发送一份可直接替换首稿的完整答案。若两种推导得出不同结果，先列出各自的状态变量、参考电位与边界条件，再寻找第一个分歧，而不是用多数意见决定。保留争议记录，比事后只保存整洁答案更能说明学习者建立了模型判断。

## Midterm 能闭环，final 只能做开卷迁移检验

官方[Exams page](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/exams/)公开 2014 midterm 及其 solution，也公开 final，但没有 final solution。Midterm 应先在 take-home 条件下独立完成并锁定首稿，再用官方 solution 做 error taxonomy：model choice、sign/unit、algebra、boundary condition 或 physical interpretation。重做时换一组 parameter 或 boundary condition，避免只记住步骤。

Final 则按 open-book transfer test 使用：事先限定可查材料，记录每题 model-selection time 与 unresolved assumption，完成后用 dimensional analysis、conservation、special case 和 peer rubric 复核。没有官方 solution 时，不能把 self-score 写成 MIT score。若 final 暴露 porous transport 断层，应回到 Session 25–38，而不是继续堆应用论文。

## 校外实践默认 simulation 与公开数据

EEDIY 建议建立一个“模型—数据工作室”：数据只能来自许可条款明确的公开电化学数据集、明确标注的合成轨迹，或经书面授权且不含机密信息的工业电化学数据。为等效电路、能斯特/热力学关系、Butler–Volmer 动力学、扩散与多孔耦合各留一个可运行的 notebook，再用预先留出的轨迹检查参数能否迁移。这是 EEDIY 补充项目，不是 MIT 10.626 官方实验或作业。课程公开页在本次审读中没有给出硬件实验、物料清单（BOM）、代码评分器或可复现的电池循环测试装置。

实体边界必须比模型边界更严格。默认不组装自制 cell，不拆解 battery，不给 unknown、damaged、swollen 或 salvaged battery 充放电，不做 overcharge、short-circuit、thermal-abuse 或 gas-generation test。不得把课程中的 battery/fuel-cell model 变成家庭化学或高能量实验说明。若确有机构批准的低能量 electrochemical measurement，只能在合格监督下使用已批准体系、隔离且 current-limited 的 instrumentation、SDS/PPE、ventilation 与废物流程；本页不提供实施授权。

一份合格的模型—数据报告应分开讨论模型适用性、参数可辨识性、测量不确定度与安全范围。公开或获授权的数据也要记录许可或授权、来源、温度、循环规程和缺失的元数据；合成数据必须明确标为 synthetic。不得使用专有数据、受保密协议（NDA）约束的数据，或未经实验室、企业授权的数据，也不能用“去掉文件名”冒充获得了发布许可。曲线拟合得好不能证明机制唯一，更不能导出对真实电池健康或安全的诊断结论。

参数辨识必须与预测分开。若同一条 trace 同时用于选择模型、拟合参数和宣称准确，就没有独立证据说明模型能迁移。应预先划定拟合区间与留出区间，报告残差结构而不只给平均误差，并讨论不同参数组合是否产生近似相同输出。无法唯一辨识时，结论应缩小为“在该输入范围内可描述数据”，不能升级为材料性质或退化机制的测量。

## 与光伏路线的分工，以及怎样证明学完

TU Delft 的[Photovoltaic Energy Conversion](https://ocw.tudelft.nl/courses/solar-energy-engineering-photovoltaic-energy-conversion/)以 semiconductor/light conversion、solar-cell physics 与 PV performance 为主；10.626 以 electrochemical storage/conversion、interfacial kinetics 和 transport 为主。想解释 photon 到 electrical power 的转换，优先课程 ID 122 的 PV 路线；想建立 battery/fuel-cell 内部的 thermodynamics–kinetics–transport 模型，再选 10.626。二者都属于能源，却不能用一套“电化学/半导体都讲能量”的介绍互换。

结课包应包含 3 个门槛题、按 38 个 session 标 source year/type 的阅读索引（其中 Session 1–3 保留官方导入标题）、5 份 problem set 的状态与检查证据、midterm 首稿/solution error taxonomy、无 solution 的 final transfer report、5 个 EEDIY 编辑层的模型 notebook、model-to-data report 和安全范围声明。明确列出未复现的 grader、教师反馈、商业 reading 与实体实验。
