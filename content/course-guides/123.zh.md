## 课程定位与先修要求

MIT **10.626 Electrochemical Energy Systems, Spring 2014** 的 [syllabus](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/syllabus/) 把 **10.50 Analysis of Transport Phenomena** 列为先修，课堂每次 1 小时、每周 3 次。它用 equivalent circuit、thermodynamics、reaction kinetics、transport、electrostatics、porous media 与 phase transformation 分析 battery、fuel cell、supercapacitor 和 electrokinetic system，远深于电池常识。无法从 conservation law 写 flux balance 时，应补 transport。

校内评分是 problem set 40%、take-home midterm 30%、open-book final 30%；这些数字只描述 2014 课程，不给校外学习者 grader。商业教材和 research reading 也不因 OCW 页面存在而自动开放。

三类基础模型足以判断准备程度：从守恒定律推出带边界条件的扩散问题；用 electrochemical potential 或 Nernst relation 解释平衡电压随浓度、温度改变；为 resistor–capacitor network 写 complex impedance，并解释 Nyquist plot 的 high-frequency intercept。每题还要声明 electroneutrality、activity/concentration、isothermal 与 lumped-interface 假设；算出数字却说不清这些条件，仍不适合直接进入 porous-electrode model。

## 课程结构

[Calendar](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/calendar/) 列出 38 个 session：Session 1 是 syllabus/overview，Session 2 是 galvanic-cell physics，Session 3 是 electrochemical storage。自学时可重组成：Session 4–7 看 circuit/impedance，8–15 看 thermodynamics，16–24 看 kinetics，25–34 看 transport/reaction–diffusion，35–38 再合并 double layer、supercapacitor、porous media 与 porous electrode。

换到更复杂的模型时，不要丢掉前一步的 limiting case、conservation residual、parameter table 与 baseline。等效电路要问 identifiability；Butler–Volmer 要检查小/大 overpotential；transport 要做 mesh、time-step 和 mass-balance 检查；porous media 的 effective coefficient 与 interface area 要有来源和单位。多个参数都能拟合一段阻抗弧时，应报告相关性或置信区间，不能把一次收敛当成唯一物理解。

[Lecture Notes index](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/lecture-notes/) 混合 2014 student scribe notes、2011/2012 旧讲义、教材章节与论文，并非 38 份同版本教师讲义。笔记应标 source year 与 document type。

## 五份无解作业之后，midterm 是唯一完整反馈

[Assignments](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/assignments/) 有 Problem Set 1–5，官方注明 solutions unavailable。首稿至少保存 governing equation、boundary condition、units、limiting case 与 numerical residual；可用 analytical special case、conservation 或 2 种 discretization 交叉检查，不能拿来历不明的答案补洞。

[Exams](https://ocw.mit.edu/courses/10-626-electrochemical-energy-systems-spring-2014/pages/exams/) 提供 2014 midterm 及 solution，也提供没有 solution 的 final。独立完成 midterm 后，按 model choice、sign/unit、algebra、boundary condition 与 physical interpretation 订正；final 则作为 open-book transfer test。若 porous transport 暴露断层，回到 Session 25–38，并让 self-score 保持自学记录的身份。

## 把参数拿到留出条件上，才能知道模型有没有用

数值研究可分别实现 equivalent circuit、Nernst/thermodynamics、Butler–Volmer、diffusion 与 porous coupling，再把拟合参数移到留出的 current、temperature 或 concentration 区间。说明 residual structure、conservation 与 parameter identifiability；若一条 trace 同时负责选模型、拟合和检验，就没有迁移证据。公开数据要保留 license、temperature、cycling protocol 与缺失 metadata，synthetic data 需明示。

本路线止于 MIT 公开的建模材料，不包含 hardware lab。公开页没有 BOM、code grader 或 battery-cycling setup；自制 cell、拆电池及 overcharge、short-circuit、thermal-abuse 不属于本路线。若研究 photon 到 electrical power，转向 TU Delft [Photovoltaic Energy Conversion](https://ocw.tudelft.nl/courses/solar-energy-engineering-photovoltaic-energy-conversion/)；若要解释 battery/fuel-cell 内部的 thermodynamics–kinetics–transport，就留在 10.626。一份能说明适用区间与失效点的 model-to-data report，足以呈现这门课的建模深度。
