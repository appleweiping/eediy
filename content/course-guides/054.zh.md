## 课程定位

MIT [6.1810 Fall 2023 OCW](https://ocw.mit.edu/courses/6-1810-operating-system-engineering-fall-2023/)
与同学期 [PDOS 课程站](https://pdos.csail.mit.edu/6.1810/2023/)。RISC-V xv6 小到可以
通读，却包含进程、页表、trap、文件系统、锁和网络。`xv6-labs-2023` 是整学期实验仓库；
`util`、`syscall`、`pgtbl` 等才是各实验的起始 branch。持续变化的 `xv6-riscv` main
与这些 handout 的实验基线不能混为一谈。

官方 [Overview](https://pdos.csail.mit.edu/6.1810/2023/overview.html) 面向已有 C 和系统
基础的学习者。所需基础包括指针、结构体、函数指针、并发 C、Unix shell、Git 和基本虚拟
内存，以及用 backtrace、地址和源码缩小一次崩溃的能力。RISC-V 汇编尚不熟时，可以补到能读
trap path 的程度。

## 书、源码和 Lab 要交错使用

[2023 课程固定的 rev3 xv6 book](https://pdos.csail.mit.edu/6.1810/2023/xv6/book-riscv-rev3.pdf)
不适合与代码分开读。学 process
后从 `userinit` 追到 scheduler；学 page table 后手工翻译一条虚拟地址；学 trap 后跟一条
用户指令经过 trampoline、kernel handler 再返回。每次追踪都记录 page table、CPU mode
和相关锁。

[xv6-riscv](https://github.com/mit-pdos/xv6-riscv) 可作源码参照，但实验应在课程仓库的
指定 branch 完成。每个 lab 开始时记录 `origin/util`、`origin/syscall` 等对应起点的 commit；
书则固定为课程站提供、标注 2022-09-05 的 rev3 PDF。这样“书的版本”和“某个 lab 的代码
commit”各自明确，不把一个仓库名误当成所有实验共用的单一版本。每次修改都以 `make qemu`
与 `make grade` 结果为基线，并记录 compiler、QEMU 与 host OS。

第一项 [utilities lab](https://pdos.csail.mit.edu/6.1810/2023/labs/util.html) 实现
`sleep`、`pingpong`、并发筛素数、`find` 与 `xargs`；handout 明确把 `origin/util`
称为本 lab 的 branch。后续 system calls、page tables、traps、copy-on-write、network
driver、locking、file system 和 `mmap` 也各有对应 branch；切换实验时以该 handout 指定
的起点为准，才能保持题面、grader 与代码一致。

## 每项 Lab 都围绕一个内核不变量

handout 的单项测试与完整 `make grade` 构成回归基线；另加一个边界输入，例如 pipe 提前关闭、
内存不足、并发 unlink 或跨页 copy。改动前写出页引用、锁顺序或 transaction 等不变量；
改动后保留一段最小失败，包括触发命令、panic/backtrace、根因和修复证据。公开测试通过
并不能覆盖所有并发和故障路径，但这份记录能说明为何改动应该成立。

推荐按依赖推进：utilities 与 system call，page table 与 copy-on-write，trap 与 alarm，
sleep/wakeup 与 locking，最后连接 inode、log 和 buffer cache。结课索引把每个 lab 对应到
book 章节、关键源码、测试和一处失败案例。

## 访问与版本说明

公开站提供 handout、书、源码和本地评分脚本，却没有课堂、TA 反馈、隐藏测试或 Gradescope
分数。本地 grader 适合做回归，结果只代表公开测试。工具链使用 RISC-V GCC/binutils、GDB 与 QEMU；
在 Linux/WSL 中固定版本，避免更新造成伪故障。

最后挑一次真实的 xv6 内核错误，沿“调用入口—共享状态—错误返回—释放路径”找到根因，再让
自加边界测试在 Fall 2023 分支上通过。xv6 只是一套教学内核：它很适合看清不变量怎样被破坏，
却没有生产系统所需的加固、恢复和敏感数据保护。
