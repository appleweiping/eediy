## 课程定位

MIT [6.245](https://ocw.mit.edu/courses/6-245-multivariable-control-systems-spring-2004/) 是 Spring 2004 的研究生多变量控制课，适合已经学过经典 SISO 控制和线性系统、想继续理解鲁棒控制的人。[Syllabus](https://ocw.mit.edu/courses/6-245-multivariable-control-systems-spring-2004/pages/syllabus/) 把 6.302 与 6.241（或 16.30）列为先修，后续内容包括 Youla/Q parameterization、LQ、\(H_\infty\)、\(\mu\)-synthesis、LMI 和 model reduction。

这门课真正抬高门槛的地方，是把单回路的增益与相位直觉换成方向性的思考。一个带交叉耦合的 \(2\times2\) transfer matrix 就能暴露差距：逐元素增益看似温和，最大 singular value 对应的输入方向却可能让两个 SISO loop 同时闭合后失稳。若 controllability、observability 或 internal stability 仍需反复查定义，先回到 6.241 会更顺畅。

## 课程材料

[Lecture Notes](https://ocw.mit.edu/courses/6-245-multivariable-control-systems-spring-2004/pages/lecture-notes/) 是学习主线；[Calendar](https://ocw.mit.edu/courses/6-245-multivariable-control-systems-spring-2004/pages/calendar/) 则给出了清楚的推进顺序：MIMO representation 与 stability，parameterization 与 performance，LQ/\(H_\infty\)，再到 uncertainty、\(\mu\)、LMI 和降阶。讲义的价值不只在公式，还在于反复追问 plant、uncertainty、performance output 和 controller class 究竟如何定义。

[Assignments](https://ocw.mit.edu/courses/6-245-multivariable-control-systems-spring-2004/pages/assignments/) 使用当年的 MATLAB/Simulink 以及 Control System、LMI、\(\mu\) toolboxes。现代 MATLAB 最接近原题环境；Python 或 Octave 也能承担部分计算，但旧函数与 \(\mu\) 工具的数值输出未必完全相同。自学时更值得守住的是题目的 plant、权函数和性能问题，而非复刻每个 2004 年命令。

## 课程任务

官方成绩由 homework 50% 和 2 次 quiz 各 25% 构成，没有 final；OCW 未公开 quiz 原卷或解答。最适合贯穿全课的是同一个二输入二输出对象：从两个独立 SISO loop 出发，恢复交叉耦合，比较 \(H_\infty\) 权函数与 \(\mu\) 不确定性结构，再观察降阶怎样改变 peak sensitivity、control effort 和 tracking。这里最有启发性的结果往往是失败设计——它会直接指出某条权函数、耦合方向或降阶选择为何与原规格冲突。
