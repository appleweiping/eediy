## 6.661 把灵敏度、孔径和分辨率放进一套预算

MIT [6.661 Spring 2003](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/)
从 thermal/shot noise、receiver sensitivity、mixers 和 optical detection，走到 antennas/
apertures、binary communication/coding、interferometry、radar/SAR 与 estimation。
[Calendar](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/pages/calendar/)
列出 24 lectures 和 2 次 quizzes。它适合已有 probability/random processes、Fourier、
linear systems、complex envelope 与基础 antenna 概念，想一起讨论 detection 与 resolution
的人；这些先修仍不稳时，不宜把它当通信或天线入门。

## 课程结构

[Lecture Notes](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/pages/lecture-notes/)
应围绕 `source → receiver input` 的 link budget、`receiver input → statistic` 的 noise/
detection budget，以及 `aperture/sampling → estimate` 的 resolution budget 阅读。每个噪声
模型写明 one-/two-sided PSD、impedance、bandwidth 与 reference point；天线段从 power
flux、effective aperture 和 mismatch 复核 Friis；radar/SAR 段则复用 receiver noise 与 aperture，
继续算 range、angular resolution、ambiguity 与 estimation error。

## 13 套带解答题是主要优势

[Assignments](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/pages/assignments/)
公开 Problem Set 1–13 与 13 份 solutions，PS1 另有 hints。写下模型和首条方程后才读解答，
订正遗漏假设、normalization 和系统接口；再按 noise/receivers、antennas/apertures、
communication detection、imaging/radar/estimation 重组题目。随机抽题时应能在 5 分钟内说明
source、noise entry、observable、estimator 与 metric，而非复述代数。

## 没有 quiz paper，就用独立数值题补练习

[Syllabus](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/pages/syllabus/)
和讲义支持理论自学，但没有公开视频、code repository、lab instructions、dataset 或公开
quiz papers。适合另做一项明确标注的独立数值练习：给定 transmit power、propagation loss、aperture、
noise temperature 与 bandwidth，推可探测距离，再用 Monte Carlo 检查 detection/false
alarm，并改变 aperture sampling 观察 resolution/sidelobes。保存 seed、unit、normalization
与 confidence interval；关掉 noise、扩大 aperture、增加 trials 这 3 个 sanity checks
解析趋势为结果提供约束。项目只验证 3 张 budget，不能包装成 MIT hardware lab。三张预算还要引用
三张预算共用一份参数表，使发射功率、带宽、孔径和噪声温度在不同章节保持一致。接收机部分记录噪声从哪
一级进入并怎样折算到判决点；天线部分说明极化、匹配和有效孔径；成像部分区分采样造成的旁瓣
与估计算法误差。若数值曲线偏离理论，从单边/双边谱密度、功率单位和参考面查起，再讨论模型
不足。口头说明一个参数如何分别影响灵敏度、检测概率和空间分辨率，能检验接收、天线
与遥感之间的联系是否真的建立。

6.661 的独到之处，是 aperture、bandwidth 与 noise temperature 会一起改变 receiver sensitivity、detection probability 和 spatial resolution；三部分不能各算各的。
