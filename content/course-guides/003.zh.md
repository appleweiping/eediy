## 把 18.03SC 当成输入—状态—响应课，而不是解法目录

MIT [课程主页](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/)
对应 Fall 2011 的 OCW Scholar 版本，由 Arthur Mattuck、Haynes Miller、Jeremy Orloff 与
John Lewis 共同呈现。公开版有 38 个 session，每个 session 组合 written notes、lecture
video、problem-solving video、practice problem 与 problem set。课程方给出的量级是平均
每个 session 超过 3 小时、总计约 150 小时；它描述完整参与的工作量，不是要求所有学习者
按同一速度观看。

这门课最容易被误读成“可分离、一阶线性、二阶常系数、Laplace 各背一个模板”。更有效的
主线是：从物理量和守恒关系建立方程，区分输入与状态，求出 transient 与 steady response，
最后用单位、极限、图像和初值回查。对 EE，这条链直接通向 RC/LRC、正弦稳态的 gain/phase、
poles、convolution 和 state-space；但课程不包含离散时间、sampling、Z-transform 或
通信系统。

## 一只 RC、一项复指数、一个 2×2 系统构成入口

官方 [Syllabus](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/syllabus/syllabus/)
要求 18.01，令 18.02 为 corequisite，并预期向量、矩阵运算和 vector-valued function。
开始前完成三个 EEDIY 诊断；它们不是 MIT 官方入学考试：

1. 从 \(C\,dv/dt=(V_s-v)/R\) 读出状态、输入、时间常数与单位，不查公式解阶跃响应，并用
   \(t=0^+\) 与 \(t\to\infty\) 检查。若只能写答案，先补导数、指数函数和 Kirchhoff 建模。
2. 计算 \(e^{j\omega t}\) 通过一阶线性方程后的幅值与相位，并把复数答案还原为实信号；
   若极坐标、Euler 公式或相位约定不稳，先补复数。
3. 对一个有两个不同实特征值的 \(2\times2\) 矩阵，求 eigenpairs、画 nullclines 和相图，
   再解释初值怎样选择模态系数；若矩阵运算和几何解释断开，先补线性代数。

第 1 项决定能否建模，第 2 项决定能否读频率响应，第 3 项决定能否进入 coupled systems。
把诊断结果写进学习日志，而不是用“微积分学过”概括。

## 先建模，再让四个单元逐步增加表示法

官方 [Unit I](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/unit-i-first-order-differential-equations/)
从 first-order ODE、direction field、Euler method、linear equation 和 autonomous equation
进入建模；Unit II 处理 second-order constant-coefficient linear equation、oscillation、
forcing、resonance、complex exponential 与 frequency response；Unit III 把 periodic
input、Fourier series、Laplace transform 和 convolution 接到同一响应问题；Unit IV 再把
一条高阶方程改写成 first-order system，研究 eigenvalue、phase portrait、matrix
exponential 与 nonlinear linearization。

课程特有的顺序不应打乱。先在 Unit I 学会“从量到方程”和 reality check；Unit II 才把
transient/steady 与 amplitude/phase 分开；Unit III 再比较 Fourier 与 Laplace 对输入的
两种拆法；最后在 Unit IV 把 scalar transfer representation 与 state representation
并置。直接从 Laplace 表格开学，会在初值、因果性和物理量单位上留下无法看见的洞。

每个模型保存四行审计：方程从哪条关系来，initial condition 在何时给出，homogeneous
与 particular 各代表什么，结果怎样用单位/极限/数值积分复核。最难也最有价值的不是求根，
而是从图像、极点和相图判断增长、衰减、振荡、resonance 与 stability 是否符合原系统。

## Part I 与 Part II 不能互相代替

公开 Scholar problem set 把每个集合分为 Part I 与 Part II：Part I 检查基本技能，
Part II 处理更长的多步与现实建模题；两部分都有完整 solution。正确用法是先盲做 Part I，
若同一技能错误超过一次就回对应 session；Part I 稳定后再做 Part II，并强制写 reality
check。只做 Part I 会把课程降成符号练习，只做 Part II 又会让代数失误掩盖模型判断。

Unit I–III 各有 practice exam、practice solution、正式 exam 和 solution。以官方
[Exam 3](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/unit-iii-fourier-series-and-laplace-transform/exam-3/)
为界，Fourier、Laplace 与 convolution 必须能在计时条件下选择，而不是看见关键词才查表。
每次考试保留首稿，把失分分成建模、方法选择、代数、初值、单位和解释；看 solution 后重做
同题的变参数版本。公开页面没有列出校外自动 grader，PDF 解答提供反馈，不提供 MIT 成绩。

Mathlet 是官方列出的交互 Java 演示，属于 Fall 2011 的 legacy tool。若现代浏览器不能
运行，使用 direction-field 或 phase-portrait 的本地静态/数值图代替，不要修改浏览器
安全策略。图形替代必须保存方程、参数、积分步长和软件版本，不能只留截图。

## Unit IV 的出口不是另一次单元考，而是综合期末

官方 [Unit IV](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/unit-iv-first-order-systems/)
把 systems 放在最后；公开结构中 Unit I–III 各有 1 次单元考试，Unit IV 之后直接进入
[Final Exam](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/final-exam/)。
期末页提供 practice final、practice solution、正式 final 与 solution。因此结课门槛是
3 次单元考试加 1 次综合期末，而不是杜撰第 4 次 unit exam。

Unit IV 完成时，应能把同一个二阶 LRC 模型写成四种互相核对的表示：time-domain ODE、
complex-frequency transfer expression、convolution/impulse response 和 2-state
first-order system。这个“四表示档案”是 **EEDIY 补充，不是 MIT 官方作业**；它只用公开
模型或合成参数，不连接实体电路。提交推导、极点与单位、数值阶跃/正弦响应、误差图、环境
锁定和一条重运行命令。

## 与 6.003 的边界要写在选课决定里

Fall 2011 [6.003 Syllabus](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/pages/syllabus/)
同时处理 continuous-time 与 discrete-time signal，加入 Z-transform、sampling、
modulation、LTI representation、feedback、communication 和 signal processing。
18.03SC 的中心问题是怎样建立并解读微分方程；6.003 的中心问题是怎样用统一的信号与系统
表示分析变换、采样和互连。ODE、complex exponential 与 convolution 尚不稳时先修
18.03SC；已经能解释 poles 和 impulse response，目标转向离散时间、频域和系统设计时进入
6.003。二者有重叠，不是重复课。

可审计的结课记录应包括 38 个 session 的完成索引、各 unit 至少 1 份 Part I/II 首稿与
订正、3 次 unit exam、1 次 final，以及上述四表示档案。索引不是打勾表：每项要链接到方程、
首稿、错误编码或可重运行产物。本文为 R0 公开材料审读，不声称亲历课程；反馈请给出具体
session/PDF、初值与符号约定、Mathlet 或浏览器状态及最小复现步骤，以便区分内容勘误、
约定差异与旧工具故障。
