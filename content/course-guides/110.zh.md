## 访问与版本说明

Cornell [ECE 4880 Radio Frequency Systems](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems) 适合已有 RF 基础、想把器件非理想性折回系统预算的人。课程从 transmission line 与 Smith chart 走到 gain、noise、mismatch、nonlinearity、mixing、receiver architecture 和 phase noise。问题在于，[lecture index](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems/ece-4880-lectures-notes-and-handouts) 只剩 Lecture 6–11 与 Handout 1–9，Lecture 1–5 明确缺席。正式先修是 ECE 3030 或教师许可，这个缺口不能用“从第六讲开始看”轻轻带过。

已有 transmission line、S-parameter 和基础 RF budget 的人，会喜欢它把 component nonideality 一路推回系统性能。第一次接触 RF 的人则应依 [Syllabus](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems/ece-4880-syllabus/) 补 reference impedance/plane、S-parameter 与 Smith matching。RFIC bias/layout 也不在课程范围内，别期待六份后半程讲义兼任 RFIC 设计课。

## 题解很大方，年份却容易看错

[Homework and exams](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems/ece-4880-homework-and-exams) 有 HW1–HW10 solution，以及 Prelim 1、Prelim 2 和解答。这在 RF 公开课里相当难得，适合独立算完整条 cascade，再逐级找 dB/dBm/W/Vrms、reference direction、noise reference plane 或 stage order 的错误。

Final 与 solution 标的是 Fall 2015，而主档案是 Fall 2016。旧 final 当然能检查稳定概念，却不能据此恢复 2016 的覆盖与评分。RF 计算最怕一张软件截图吞掉单位和参考面；手写每一级 gain、noise 和 mismatch 的数值，往往比更复杂的仿真更能抓错。

## 安全说明

[Projects and labs](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems/ece-4880-projects-and-labs) 公开 6 份无解实验：instrument/spectrum、VNA/S-parameter/de-embedding、splitter/coupler、amplifier、oscillator/mixer 和 free proposal。后面的材料出现 600 MHz–2 GHz、约 30 dBm 与 jammer 示例，它们只属于校内合规实验语境，不提供开放空间操作许可。

物理路线需要获准频谱、校准仪器、合格监督、shielding 或 dummy load/attenuation，以及明确的 power limit。[FCC Part 15](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-15) 只适用于相应司法辖区；别的地区遵守本地规定。没有这些条件，就停在数据、仿真和低能量受控测试，不会因此少学 receiver budget。

## 校外最值得做的是四层分开的 receiver budget

从 [IBIS Touchstone 2.1 规范](https://ibis.org/touchstone_ver2.1/touchstone_ver2_1.pdf) 中的 S2P 开始，做 passive insertion/mismatch、reciprocity、passivity 与 energy-balance 检查，并写清 port order、reference impedance 和 reference plane。Touchstone 也能装 active small-signal parameter，二端口还可选 noise parameter；因此“Touchstone 等于无源器件”本身就是误解。

active 层另给 bias、temperature 和 reference plane，由 \(S_{21}\)、transducer gain 或 available gain 得出增益，并检查 stability。只有文件含 noise parameter 或另有 noise model，才谈 noise figure 与 Friis。nonlinear 层用 two-tone sweep，给出 tone spacing 和输入功率区间，只在压缩前、基波与 IM3 斜率接近一和三的区段外推 IIP3；线性 S2P 不会凭空产生互调。LO 层再用独立 phase-noise PSD，注明 single-sideband convention、carrier 与 offset integration band，算 integrated phase/time jitter 和 reciprocal mixing。

用 synthetic 或许可清楚的数据扫描 blocker、bandwidth 与 stage order，标题就写 **simulation-only receiver budget**。它的范围止于仿真，与 VNA calibration 和 Cornell Lab 6 分开。若四层模型各自说得清来源和适用范围，并能指出某一级为什么成为整机的第一个瓶颈，这门残缺归档依然能教出很扎实的 RF 系统判断。
