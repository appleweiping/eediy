## 课程定位

Berkeley [EECS 151 Catalog](https://www2.eecs.berkeley.edu/Courses/EECS151/)
的 lecture 覆盖 Verilog、combinational/sequential logic、FSM、memory/cache/FIFO、
pipeline 与 power/reliability，但学生还要至少选 1 门 lab。匿名用户能看到课程目标，
拿不到 CalNet 内的完整 slides、starter、server、autograder 与现场反馈。下文把它作为
数字 IC 路线的质量标杆，不把独立练习写成 151LA/151LB 课程作业。

## 工具与环境

[EECS 151LA](https://www2.eecs.berkeley.edu/Courses/EECS151LA/) 是 ASIC 路线，从 HDL/
testing 走到 synthesis、floorplan、place-and-route、timing/power 与 chip assembly；
[EECS 151LB](https://www2.eecs.berkeley.edu/Courses/EECS151LB/) 则把 processor、cache
和 peripheral 放到 FPGA。两者共享 RTL、testbench、synthesis 与 timing，却有不同交付物：
ASIC 依赖合法的 standard-cell/PDK 和 physical closure，FPGA 依赖 board、constraints、
bitstream 与 host interface。

可用一个 pipelined RTL block 判断基础：写 specification、latency/clock/reset/CDC、reference
model、assertions 与 regression；综合后解释 critical path、area/resource 和 warnings。
然后手工 trace 一个 3-stage RISC-V subset 的 hazards。若还做不到，数字逻辑与体系结构就是当前缺口。

## 作业与反馈

HKN 的 [EECS 151 Exam Archive](https://hkn.eecs.berkeley.edu/exams/course/EECS/151)
有若干年份的 midterm/final 与 solutions，可以检查 bit width、Verilog semantics、timing、
pipeline 和 memory；EDA flow 与 board demo 则要靠后面的项目。做题时同时标出试卷年份，
分数只用于自测。

独立项目可选小型 RISC-V core 或 streaming accelerator。ASIC-like 路线用许可清楚的
educational flow，做 synthesis、placement/routing、STA 和 flow 支持范围内的 DRC/LVS；
FPGA-like 路线做 implementation、timing、hardware counters 与固定输入 demo。两者都要在
相同 workload 下比较至少 2 个设计点的 clock、cycles、area/resource、power proxy 和验证
成本。

比较前固定 tool version、constraints、input 与 correctness oracle。分别说明 pipeline depth、
cache size 或 parallel lanes 怎样影响 Fmax、cycles、area 与 verification effort，并把一个
被否决方案放回表格：是哪条 timing、area 或 correctness 约束淘汰了它？EECS 151 最有价值的
地方正是这一步——同一个 RTL 决策进入 ASIC flow 与 FPGA flow 后，瓶颈往往不是同一个，
实现时也就会做出不同取舍。
