## 课程结构

IIT Bombay / NPTEL [Principles of Digital Communications](https://nptel.ac.in/courses/108101113)
当前标注 Jul–Oct 2026、12 周、65 讲。
[Syllabus](https://archive.nptel.ac.in/content/syllabus_pdf/108101113.pdf) 要求 signals
and systems 与 basic probability/random variables。内容从 information/source/channel
coding、signal space 与 AWGN detection，走到 PCM/DPCM、line coding、pulse shaping/ISI、
ASK/PSK/FSK/QPSK/MSK 和 Hamming code。它适合需要完整推导链的人；概率、convolution 或
energy/power signal 尚不稳时，需要回到基础。

## 一条端到端模型约束全部内容

全程维护 source symbols → source code → waveform → pulse shaping → channel → matched
filter/statistic → decision → channel decode。每层写 rate、bandwidth、energy normalization、
synchronization/CSI 和 error metric，尤其区分 `Es/N0`、`Eb/N0` 与 sampling SNR。结课至少
完成 Gram–Schmidt 与 matched-filter equivalence、raised-cosine eye diagram、以及小型
Hamming generator/parity-check/syndrome；再在固定 `Eb/N0` 下比较理论 BER 与 Monte Carlo，
保留 confidence interval 和 normalization 失败案例。
