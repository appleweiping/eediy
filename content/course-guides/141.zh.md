## 这门课从 EE 105 的终点开始

Berkeley [EE 140 / EE 240A Spring 2025 主页](https://people.eecs.berkeley.edu/~pister/140sp25/)
把课名写作 Analog Integrated Circuits，使用同一套讲义、homework、lab 与 project，
但本科/研究生分别指定 Razavi 第 2 版和 Gray/Hurst/Lewis/Meyer 第 5 版教材。两本都是
需另行取得的商业教材。官方
[catalog](https://www2.eecs.berkeley.edu/Courses/ELENG140/)
把 EE 105 列为先修，并说明课程包含 transistor amplifier、op-amp、feedback、
frequency response、bias/reference、ADC、switched-capacitor filter、comparator，以及
hardware laboratory 和 design project。

“上过 electronics”不足以代替 EE 105。先拿一只 MOS common-source stage 完成 3 个动作：
从 bias 求 \(g_m,r_o\) 与 gain；由节点 capacitance 估 dominant pole 和 step response；
放进 feedback 后读出 loop gain、phase margin 与 output swing。第 1 项失败先补 device
region 与 small-signal model，第 2 项失败补 Bode/pole-zero，第 3 项失败补 feedback 和
stability。再试着解释 differential pair 的 common-mode limit；若仍只能照抄 schematic，
先回到 EE 105 或 Cornell ECE 3150 一类有完整 solved homework 的器件—电路课程。本页的
诊断是 EEDIY 建议，不是 Berkeley 的选课许可。

## 21 份 lecture PDF 和 10 份 homework 组成校外手算主线

官方 Spring 2025 lecture directory 列出 21 份 PDF。课程从 diode/BJT/MOS physics、
small-signal model 和
single-pole common-source amplifier 起步，经过 active load、current mirror、
differential pair、2-stage op-amp、feedback/stability/compensation、RHP zero 与
supply-independent bias，再进入 telescopic/folded cascode、switched capacitor、
ADC/PGA、StrongArm comparator、gain boosting 与 noise。它不是“按器件逐章复习”，而是
手算估计不断变成下一次 schematic、simulation 和 design review 的起点。

官方 homework directory 包含 HW1–HW10；HW7 还保留原版与 v2。当前目录直接给出的
homework solution 只有 HW8
和 HW10，另有 Spring 2025 Midterm 2 solution。主页同时链接多个往届网站与 solved
midterm/final，因此反馈资源很多，但不是“10 份当前 homework 全有解答”。先按当前
lecture 顺序做 HW1–HW10，HW8/HW10 用于校准解题写法；其余题在使用旧解前记录学期、
题号与电路是否相同，不能用相似标题掩盖 topology 或 process parameter 已变。

手算页至少保留 bias region、\(V_{OV}\)、small-signal parameters、gain/pole、swing/
common-mode 和 power 的假设。仿真若不吻合，先定位 model simplification、schematic
错误还是 PDK behavior，再改尺寸。Course page 明确鼓励协作与 debug 帮助，但要求自己
写答案、自己画 schematic，并引用旧解来源；独立学习也应保留这条 attribution 边界。

## Final project 把所有受限环节收在一个 mixed-signal chip

官方 [project specification](https://people.eecs.berkeley.edu/~pister/140sp25/labs/project.pdf)
要求 3 人 analog team 为一个 battery-powered mixed-signal product 设计 8-bit SAR ADC、
switched-capacitor PGA、bandgap/temperature sensor、analog multiplexer，以及 analog/
digital regulators。输入 battery 范围写为 3.2 V 到尽可能接近 1.6 V，consumer
temperature range 为 0–70 °C；各 block 最后必须通过系统接口连接。它不是 EEDIY 自拟
op-amp 练习，而是 Spring 2025 的真实课程 project。

Project 的价值在于逼迫局部指标互相冲突：folded-cascode gain/bandwidth 会进入 PGA 和
regulator，reference/noise 会进入 ADC，clocked switch 与 charge injection 会进入
PGA/SAR，battery droop 又限制 headroom。阅读 project 时可建立一张 requirement trace：
每项 spec → 手算 → schematic/testbench → corner/temperature sweep → integration
waveform → design decision。只是 PDF 本身并不开放所需 Berkeley server、configured
SKY130/Cadence flow 或 GSI sign-off；没有这些条件，不能把 project 标为已完成。

## 校外路线在 Virtuoso 前停一次，再决定是否做非官方移植

公开理论路线可以完整使用 21 份 lecture PDF、HW1–HW10 与当前/历年 solved exam。
Lab 1 只完成手算/LTspice 子集；Lab 3 只执行实际拿到输入文件的仿真题，并把实体测量与
TA/GSI sign-off 标为未执行。对 HW 没有解答的部分，保存首次推导、用已解 exam 交叉检查
并提交同伴 review；不要寻找受限 bCourses/Ed Discussion 内容。课程页把成绩讨论指向
bCourses / Ed，匿名校外读者也不能获得原课堂 grade、staff feedback 和 discussion
history。

若要继续，可另建一个明确标注的 “EEDIY open-EDA port”；它不是 Berkeley Lab 2、4–8
或 final project。先选择许可清楚的 PDK、model 与 simulator，只移植一个小 block，并为
原 SKY130/Cadence task 与新 flow 建立 spec/testbench 对照。公开 repo 不得包含 Berkeley
instructional files、商业 model、license key 或从服务器复制的 library。未独立验证
device、corner、parasitic、noise 与 mixed-signal behavior 前，只能说“替代实现”，不能
说“等价复现”。

本次审读没有在 Spring 2025 主页、lecture/HW directory 或 lab PDFs 上发现允许再分发整套
材料的明确许可声明；因此 EEDIY 应链接原页，不镜像 PDF。教材同样不得以非授权副本补齐。
访问公开不等于获得再发布许可。

## 选择 Berkeley，是选择一条有断点的深链

Cornell 的官方 ECE 3150 archive 显示 12 份 solved homework、solved exams 和 Lab 1–3
solutions。与它相比，EE 140/240A 更集中于 op-amp、compensation、bias、
switched-capacitor、ADC 与 mixed-signal integration，且真实 project 更深；Cornell 的
公开答案回路更完整。需要第一次打通 device-to-amplifier 时先选 Cornell；先修扎实、愿意接受
Virtuoso/project 断点时再选 Berkeley。

依据上文官方 course page 与公开索引，公开层的完成证据应包含 HW1–HW10 首稿/订正、
至少 2 套 solved exam 的计时答卷、Lab 1/Lab 3 中可重跑的 LTspice 子集，以及按 21 份
lecture 建立的 hand-analysis ledger。受限层单独列 Lab 1/Lab 3 的实体/sign-off 部分、
Lab 2、4–8 与 project 的“读过但未执行”范围。若有人真正完成校外 open-EDA port，反馈应附 PDK/
simulator 许可、版本、block、testbench、corner 与差异报告；这类可审阅产物才可能改变
“校外不可完整复现”的判断，单张成功 waveform 不足以改变页面状态。
