## 从场与 reference sphere 建立参数

这门课依赖三项底功：由 vector potential 得 Hertzian dipole far field；由 normalized power
pattern 积分得到 beam solid angle/directivity；在 dipole、slot 或 aperture 问题中明确
coordinates、polarization、feed/reference plane、far-field 与 boundary assumption。gain、
directivity、efficiency、effective aperture 和 Friis 要在同一 reference sphere 上闭合；
混用 \(1/r\) field 与 \(1/r^2\) power density 时，应补电磁场和传输线。

公开讲次可按 radiation/pattern、antenna parameters、wire antennas、arrays、aperture/reflector、
generalized/MoM 与 measurements 组织。每段留下解析式、dimension/power check 和模型边界；
最后一讲的 measurements 只是讲授内容，官方公开页面没有 lab manual、BOM、dataset、starter
或 autograder。

## 以无源数值模型作为最终作业

结课可选 short-dipole MoM、linear-array synthesis 或 passive antenna/matching sweep，明确
geometry、material/boundary、frequency、mesh convergence、pattern normalization 与
analytic cross-check，并保留一个近似失效的案例。这是独立数值项目，NPTEL 并未把它列为 lab。
[openEMS](https://github.com/thliebig/openEMS) 是活跃的 GPL-3.0 EC-FDTD solver，
仓库提供 Python/MATLAB 的 simple patch、bent patch 与 array tutorials。它只承担数值仿真，
与 NPTEL measurement 分开。可从 simple patch 改 geometry 或 substrate，逐次做 mesh refinement，
同时报告 \(S_{11}\)、resonance、near-to-far pattern 与 power balance，并用解析长度估计
检查数量级。
默认不连接 transmitter、PA、microwave source 或 antenna，也不向自由空间发射；VNA、
anechoic chamber 或 antenna range 只应在机构批准且由 RF 专业人员监督的实验室使用。数值
报告还应把方向图采样、积分误差、网格或基函数选择与条件数列在结果旁，并用 reciprocity、
功率守恒或解析短偶极子交叉验证。若改变网格便移动主瓣或增益，数值模型收敛后再讨论天线
设计取舍；这样公开录像才能转化为可检查的方法，避免沦为天线名称清单。

天线仿真最难的往往不是画出主瓣，而是证明 gain 与 beam shape 不再随 mesh、domain 和 normalization 漂移；这也是公开录像能带走的关键方法。
