## 三个门槛题都要画坐标与 reference sphere

第一题：从 electric vector potential 或 magnetic vector potential 出发，为 Hertzian dipole 写出远场 \(E_\theta\)、\(H_\phi\) 的角度与距离依赖，说明忽略了哪些近场项。第二题：给定 normalized power pattern \(F_n=U/U_{\max}\)，由 \(\Omega_A=\int F_n\,d\Omega\) 与 \(D_0=4\pi/\Omega_A\) 求 beam solid angle 和 directivity，并从图上确定 half-power beamwidth；再说明没有 \(P_{\rm rad}\) 或 \(U_{\max}\) 就不能恢复绝对 radiation intensity，因为 \(P_{\rm rad}=\int U\,d\Omega\)。最后把 efficiency、gain、effective aperture 和 Friis equation 接起来。第三题：对一个 dipole、slot 或 aperture 问题明确 coordinate system、polarization、feed/reference plane、far-field condition 与 boundary assumption，并判断何时 transmission-line matching 不能替代 full-wave analysis。

至少前两题可独立完成，才进入 Lecture 1。若把 gain 与 directivity 当同一量、把 \(1/r\) 场项与 \(1/r^2\) 功率密度混用、或没有固定 polarization/reference plane，先补电磁场、传输线和网络理论。每题还要保留单位检查、极限情形、参考球半径和一张标出法向量的草图；若换坐标系，必须把极化基矢的变换写出来。这三题是 EEDIY placement diagnostic，不是 NPTEL 入学或证书判定。

## 40 讲分成六个可检查的模型台阶

Lecture 1–5 从 potentials、current element 与 radiated-field properties 到 far field/pattern；6–11 建立 directivity/gain、efficiency、beamwidth、polarization、impedance、effective aperture、Friis transmission 与 antenna temperature；12–16 是 dipole、monopole、balun、loop 与 folded dipole；17–21 进入 array theory、broadside/endfire、parasitic 与 log-periodic，22 讲 aperture analysis，23 回到 parasitic/log-periodic 续讲，24–25 是 horn，26–29 是 single/dual reflector；30–36 从 generalized antenna 和 wave-equation solution 走到 slot、open-ended waveguide、microstrip、wire-current numerical evaluation 与 Method of Moments；37–40 收尾于 pattern synthesis、UWB 与 measurement。

每个台阶必须留下一个可复核产物：field-term ledger、parameter derivation、wire-antenna comparison、array-factor notebook、aperture/reflector approximation sheet、MoM convergence report。Lecture 40 “Antenna Measurements” 是一讲内容，不是公开实验任务；课程主页和 API 在本次审读中没有给出 lab manual、BOM、measurement dataset、code starter 或 autograder。不能把看过 measurement lecture 写成“完成天线实验”。

## 实践默认是无源模型，不是发射

EEDIY 补充项目可选一个：短 dipole 的 MoM current/pattern、linear array synthesis，或 passive antenna/matching model 的 parameter sweep。交付物包括明确的 geometry、material/boundary、frequency range、mesh convergence、far-field normalization、analytic or independent reference 与失败案例。它是 EEDIY simulation supplement，不是官方 NPTEL lab，也不能替代当期 assignment、监考 exam 或 certificate。

默认不得连接 transmitter、PA、microwave source 或 antenna，不得在自由空间发射，不得把“低功率”当成免除频谱许可和 RF exposure assessment 的理由，也不得尝试 high-power microwave、open waveguide 或未知同轴负载。软件得到的匹配和辐射结果不证明实体结构安全、合规或可制造。

任何 VNA、anechoic chamber、antenna range 或实体馈电工作都只能在机构批准的实验室、由合格 RF 人员监督，使用额定 50 Ω cable/load/attenuator、功率与频率限制、校准件、联锁/屏蔽、ESD 与 emergency shutdown procedure。不得带电换接，不得直视或靠近受激 aperture，测量前必须完成频谱授权与人员暴露评估。本页不提供硬件操作许可。
