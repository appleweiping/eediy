## 课程定位

MIT **2.71 Optics, Spring 2014** 是本科版，**2.710** 是研究生版。[Syllabus](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/syllabus/) 的正式先修是 8.02 Physics II、18.03 Differential Equations 与 2.004 Dynamics and Control II；2.710 在 HW4–HW6 增加题目，并要求 final project。官方先修不含 semiconductor devices。

进入前可拿一套双透镜例题检查准备度：光线传递矩阵求像面，相量/Jones 矢量解释延迟器，傅里叶变换解释有限光瞳的分辨率。缺哪一项就补近轴光学、电磁波或空间频率。

需要视频带着入门时，NPTEL [Introduction to Photonics](https://nptel.ac.in/courses/108106135) 可作导引；其 [Downloads API](https://nptel.ac.in/api/downloads/108106135) 有 48 个 lecture/tutorial/demonstration 条目，但 `assignments` 为空。2.71 的优势是推导、problem set 和历年考试。

## 双透镜题要在 ray、wave、Fourier 三种视角下说得通

[Calendar](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/calendar/) 列 25 个 session，[Lecture Notes](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/lecture-notes/) 只有 12 份 PDF；Session 7、25 是 review，实质主题约 10 组。公开站没有完整 lecture video。

光线部分覆盖几何/近轴光学、程函、GRIN、仪器与孔径，需要统一参考面和符号。波动部分由电磁方程进入干涉、偏振、波片与双折射，再由复振幅回到探测器辐照度。傅里叶部分把传播核、光瞳/传递函数、Fresnel/Fraunhofer 衍射、成像、Gaussian 光束与探测器放在同一图里，并检查采样、视场和能量归一化。

三种表示各有不同的失效检查。光线矩阵要验证表面顺序、行列式、无焦极限与主光线/边缘光线；波动计算要声明偏振基和时间约定，并在零光程差、正交偏振、相干性消失时闭合；傅里叶传播要把光源、传播核、光瞳与探测器的采样间隔对齐。结果随 padding 或网格改变时，先修正数值表示，不把它解释成新的光学效应。

## PS1–PS6 与考试形成不对称反馈

[Assignments](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/assignments/) 有 PS1–PS6：PS1–PS4 有 solution，PS5–PS6 没有，PS3 在 Calendar 标为 optional；2.710 还扩展 HW4、HW5、HW6。选定本科或研究生范围后，独立作答并按 ray sign、boundary condition、polarization basis、Fourier normalization、sampling 与 approximation 订正。

[Exams](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/exams/) 只有部分 solved：2004、2008 Quiz 1 与 2009 Quiz 2 无解；2012 Quiz 1/2 有解；2013 final 只有 practice solutions 与 Problem 4 solution；2014 Quiz 1/2 和 final practice 有解。2014 适合计时检查，2012 作为第二样本，旧无解题用于迁移。订正时把错误定位到 sign convention、场与强度、Fourier scaling、aperture sampling 或近似范围，避免只记住某一届的数值。

## 访问与版本说明

用 MATLAB、GNU Octave 或 Python 做一个双透镜与孔径例题：ABCD 矩阵追迹光线，复光场穿过孔径，再比较 Fresnel/Fraunhofer 条件下的 PSF、MTF 与分辨率。写清波长、网格、归一化、padding、软件版本和随机种子；将间距减半、扩大视场后，焦点、能量与结论应稳定。

每次近似还要写适用的 dimensionless condition，并保留一个可手算的 lens 或 aperture baseline。这样遇到 diffraction discrepancy 时，可以回到具体 session、problem、Fourier convention 与最小样例，避免笼统归因于 MATLAB 或 Python。数值传播还应在空孔径、无限孔径和远场极限下退回已知结果，并用 Parseval 或能流检查 normalization。

2.710 原 project 是 2–3 人组队，mentor 建议 simulation，并在 Session 23–24 展示，但 OCW
未公开 prompt、data 或 rubric。站外路线可做到 PS1–PS6、跨年份 solved exam 订正、12 份
note map，以及由同一命令生成的 propagation study。最值得查的是 Fresnel/Fraunhofer 切换后
PSF、MTF 与能量是否仍一致；实体 laser table 与 lab qualification 则不在公开材料范围内。
