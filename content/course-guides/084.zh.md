## 这是 1987 video course 的 2011 OCW 重刊

MIT [RES.6-007 Signals and Systems](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/) 页面标为 Spring 2011，但课程最初为 1987 年 workplace distance education 录制；录像中的设备与表述属于当时版本。它适合想把连续时间和离散时间成对学透、又愿意逐讲做题的人。官方 [Introduction](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/pages/introduction/) 假定 calculus、complex-number manipulation 和一些 differential equation，circuits 或 mechanics 背景属于可选准备。

## 课程结构

官方 [Video Lectures](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/video_galleries/video-lectures/) 共 26 讲：1–6 建立 signals/systems、convolution、LTI 与 differential/difference equation；7–12 讲 CT/DT Fourier series、transform 与 filtering；13–19 处理 modulation、sampling、interpolation 和 CT/DT interface；20–24 进入 Laplace、z-transform、CT filter 到 DT filter 的映射与 Butterworth；25–26 用 feedback 与 inverted pendulum 收尾。

[Lecture Notes](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/pages/lecture-notes/) 与录像分工明确：视频擅长展示推导动机，notes 更适合查定义和条件。课程最好的设计，是让 convolution sum/integral、CT/DT Fourier transform、Laplace/z-transform 始终成对出现；公式外形相似，但 independent variable、frequency periodicity、ROC 与 stability 条件并不相同。

老录像的节奏也有独特价值。convolution 不只停在积分式，而是借图形移动解释系统怎样累积输入；sampling 从连续谱的复制进入离散频率周期性；到了 Laplace 与 z-transform，又反复用 ROC 连接代数表达和因果性、稳定性。连续与离散在这些位置交替出现，避免了把 sampling 和 filter mapping 学成教材末尾两个孤立章节。

## 每一讲都有 problem set 与 solution

[Assignments](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/pages/assignments/) 为 26 讲逐讲配 problem set 和 solution，从 introduction 一直做到 inverted pendulum。官方说明 recommended problems 应视作 required，并提醒 solution 只用于确认或最后求助。题解与自己的路径不同时，真正需要比较的是假设、变换约定与结果，而非把推导改成标准写法。

课程没有正式 exam 页面，但逐讲题集已经形成非常连续的练习链。若时间有限，convolution、sampling/aliasing、ROC 与 CT/DT filter mapping 是最不应跳过的部分，因为它们把前后两半课程真正接了起来。

## 数值练习

一个 companion notebook 可以跟随同一波形：解析 Fourier transform 给出基准，数值采样观察 window/leakage，降低 sample rate 制造 alias，再用 convolution 与 frequency multiplication 两条路径检查 filter。图上至少要分清 \(f\) 与 \(\omega\)、Hz 与 rad/s，以及 CT/DT normalization；否则“频谱不对”很难定位。

官方 [Readings](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/pages/readings/) 映射到 1982 年 Oppenheim–Willsky 教材，OCW 没有附送整本版权书。尽管录像年代较早，这套连续/离散对照、完整 notes 和逐讲题解的组合，今天仍很少见。
