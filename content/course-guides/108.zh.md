## 6.013 的难点，是让积分定律真正进入器件

MIT 6.013 **Electromagnetics and Applications, Spring 2009** 是 David Staelin 的本科课。官方 [syllabus](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/syllabus/) 要求相当于 18.01、18.02、8.01、8.02、6.002 与 6.00 的准备，具体包括 complex number、vector operator、简单 matrix operation、calculus、RLC circuit、Maxwell equations 和 Fourier transform。它不是只讲电磁场边值题：课程把场与波一路接到 motor/generator、MEMS、transmission line、resonator、waveguide、antenna、wireless link、fiber、laser 和 acoustics。

版本必须写全：这是 Spring 2009 校内课的 OCW 档案。原班每周有两次 1 小时 lecture、两次 1 小时 recitation 和一次 1 小时 tutorial；公开页保留讲义、教材、题目、答案与演示，却不再提供 2009 tutorial、TA 批改、课堂参与分或 MIT credential。原评分公式、两次 quiz 与 final 只能用于理解当年考核，不能把本地自评分包装成 MIT 成绩。

## 用三张草稿纸做先修诊断

第一张：从积分形式的 Faraday/Ampère–Maxwell/Gauss 定律，经清楚的正方向和边界假设，写到 differential form；再对一个 uniform plane wave 验证 \(E/H\)、相位和 Poynting vector 的单位。第二张：为 step 加载的 transmission line 写 traveling waves、reflection coefficient 与初始/终值，区分 line impedance、load impedance 和 Thevenin source。第三张：从 RLC resonator 的能量交换推导 \(Q\) 与 bandwidth 的关系，并解释损耗增加时 pole、linewidth 与 stored energy 怎样变化。

至少两张能在不查答案时完成，才进入 Lecture 1。若 vector calculus 只能逐分量机械求导，或 phasor 与 time-domain quantity 混用，先补多元微积分、信号与电路。每张还要把参考方向、参考平面、材料参数来源、量纲检查和一个极限情形写在最终式旁边，不能只留算出的数字。EEDIY 的这三张诊断不是 MIT placement exam；它们的作用是提前暴露数学符号与物理方向尚未对齐的地方。

## 24 讲是一条从场到能量再到端口的链

官方 [calendar](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/calendar/) 与 [lecture notes](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/lecture-notes/) 对应 Lecture 1–24。Lecture 1–4 建立 Maxwell、media/boundary、uniform plane wave 与 Poynting theorem；5–7 把 field energy 变成 force、motor、generator、MEMS 与 Laplace boundary problem；8–10 处理 anisotropic/lossy/plasma media、Snell、TE/TM 与 Brewster；11–16 进入 delay、transient、transmission line、Smith chart、resonator、waveguide；17–20 走到 antenna、link、radiation 与 diffraction；21–24 收束于 fiber、laser、acoustics 和 speech generation。

每一段都保留同一张审计表：control volume 或 contour、state variable、constitutive relation、boundary condition、power/energy balance、可观测 terminal quantity。这样做能防止“场论会推、网络题会算，但两者接不上”。官方还提供一份 5 MB 的 [open textbook](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/resources/mit6_013s09_notes/)，适合查完整推导；24 份 lecture notes 更适合沿课堂顺序定位，不要把二者当两套需要重复通读的教材。

## 12 份 problem set 的答案并不齐

官方 [assignments](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/assignments/) 列出 Problem Set 1–12。公开 solution 只对应 2–7、9、11、12；Problem Set 1、8、10 没有公开解。第 12 份在原班是附解发放、用于学习而不收取的练习。先做题再看答案的规则不能因为答案齐全程度不同而改变：每题先固定 diagram、known/unknown、law、boundary 与 unit，再写计算。

有解题用来训练 error taxonomy：orientation/sign、constitutive model、boundary matching、complex algebra、power balance 或 limiting case。无解题至少用两条独立证据复核，例如 energy conservation 加 limiting case，或 closed-form special case 加数值离散收敛。若到 Problem Set 3 仍经常在边界两侧把 normal/tangential component 写反，退出并回到 Lecture 1–4；到 Problem Set 6 仍不能从 energy derivative 解释 force，也应暂停。

## Quiz 不是公式记忆，final 要跨三个表示域

官方 [exams](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/exams/) 公开 Quiz 1、Quiz 2 与 Final Exam，三者都有 solution 和 equation sheet。先按原 equation sheet 限时作答，再用答案按“field picture—mathematical boundary—network/output quantity”三栏订正。只对数值答案并不足够；每个错题还应指出功率通过哪些边界流入或流出、能量储存在哪里，以及功率在哪里耗散。

Quiz 1 适合放在 Lecture 10 后，Quiz 2 放在 wireless 部分附近，final 留到 Lecture 24 后。不得先刷 solution 再计时。原班还有 recitation、tutorial 和课堂评分语境，OCW 自学者没有这些反馈渠道；本地 rubric 应明确写成 EEDIY self-review，而不是复刻校内 grade。

## 演示是解释材料，不是家庭复现实验

官方 [movie demonstrations](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/movie-demonstrations/) 有 15 个 MATLAB 生成的 movie，覆盖 free-space/lossy/plasma wave、polarization、array pattern、aperture、quarter-wave transformer、resonator、acoustic wave 与 terminated line，部分附 script。它们是计算演示，不代表学习者获得重做原物理演示、激光、雷达、MEMS、motor 或高功率 RF 装置的授权。

EEDIY 建议的补充产物是一个纯 simulation 的“能量账本”：选择 transmission-line transient、resonator 或 antenna link 之一，在 notebook 中同时画 field/network quantity、瞬时或周期平均 power、某一时刻的 stored energy，以及随时间累积的 dissipated energy；用两个网格或步长检查收敛。它是 EEDIY supplement，不是 MIT 6.013 官方 lab、Problem Set 或 grader 任务。

默认不接市电、motor/generator、laser、RF power amplifier、waveguide source 或未知 antenna，不重现电弧、等离子体和辐射演示。任何实体工作都必须由机构实验室批准并由合格人员监督，使用隔离与限能供电、额定线缆/终端/探头、护罩、interlock、emergency stop 和适用的 RF/laser/electrical safety procedure；本页不提供台架操作授权。

## 结课要能在场、能量与端口之间往返

完成包应包含三张先修诊断、Lecture 1–24 的审计表、Problem Set 1–12 的首稿与复核状态、Quiz 1/2 与 final 的限时记录、一个 EEDIY simulation 能量账本，以及明确的未复现清单：tutorial、TA feedback、校内评分和实体演示。对任一 transmission line、resonator 或 antenna 问题，都应能从 Maxwell/boundary 走到 terminal quantity，再用 Poynting/energy balance 反查。

若只能操纵 Smith chart 而说不清反射波的能量，或会背 Poynting theorem 却无法解释 circuit power，就还没有跨过 6.013 的核心门槛。本页为 R0 官方材料审读，不声称完成 Spring 2009 课程。纠错请给出课程 ID 108、具体 lecture/problem/exam 与官方证据，不要提交危险硬件操作记录或伪称 MIT 评分。
