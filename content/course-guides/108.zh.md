## 6.013 的难点是把场真正接到器件端口

MIT [6.013 Spring 2009](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/syllabus/) 是 David Staelin 的本科电磁学课程，明确要求 18.01/18.02 微积分或同等背景、8.01/8.02 物理或同等背景，以及 6.002 电路和 6.00 编程，课程还会使用 Fourier 方法。它不止做边值题，而是把 Maxwell、介质与波接到 motors/generators、MEMS、transmission line、resonator、waveguide、antenna、fiber、laser 和 acoustics。最适合已经会 vector calculus 与 phasor，却还不能让 field、energy 和 terminal quantity 互相核对的人。

三张推导最能暴露基础缺口：从积分定律写到 differential form 并固定方向；为 step-loaded transmission line 写 traveling waves、reflection 与初终值；从 RLC 能量交换解释 \(Q\) 和 bandwidth。每页都注明参考面、材料参数、单位与极限情形。哪一张失败就补哪一块，不必用一个总分决定能否开课。

## 课程结构

[Calendar](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/calendar/) 的 Lectures 1–4 建立 Maxwell、boundary、plane wave 与 Poynting；5–10 进入 force、motor/MEMS、Laplace problem、lossy media 与 TE/TM；11–16 处理 transient、transmission line、Smith chart、resonator 与 waveguide；17–24 再到 antenna/link、diffraction、fiber、laser 和 acoustics。每段都保留 control volume、constitutive relation、boundary condition、power balance 和可观测端口量。

官方 [Assignments](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/assignments/) 有 Problem Set 1–12，但只有 2–7、9、11、12 的公开解答。无解题至少用 energy conservation 加 limiting case，或 closed-form special case 加数值收敛两种证据复核。[Exams](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/exams/) 的两次 quiz 与 final 均有 solution 和 equation sheet，订正时同时画 field picture、写 boundary，并指出功率流入、储存与耗散位置。

三个小问题足以检查这些概念是否真的接通。对 step-loaded line，把 \(\Gamma\)、traveling waves、terminal voltage and current 和能量反射放在同一时轴；对 cavity 或 lumped resonator，从 stored energy 与 loss 推出 \(Q\)，再与 bandwidth 交叉核对；对简化 antenna link，用 radiation pattern、polarization、距离和 effective aperture 闭合功率预算。每一题都改变一个边界或材料参数，检查端口结果能否由场和能量两条路径同时预测，并用量纲和无损极限再验一次。

数值图不能代替 boundary-condition audit。画 field map 时注明网格、domain truncation、激励、reference plane 与 normalization，并报告一次 mesh refinement；导体、介质交界处还要逐项检查切向与法向分量的连续条件。画 S-parameter 时同时给 passivity、reciprocity 或 energy residual。若结果只在某个网格或参考阻抗下成立，限制必须留在图旁，不能被导出图片吃掉。

## 开源工具只承担端口数据的现代检查

非官方 [scikit-rf](https://github.com/scikit-rf/scikit-rf) 是活跃的 BSD-3-Clause Python RF/microwave 库，含 network、S-parameter、transmission line、calibration 和仪器数据工具。MIT 公开材料没有把它列为 lab，Maxwell 推导仍需独立完成；适合在完成场与传输线分析后，用版本化 Touchstone 或合成网络检查 reference impedance、de-embedding、cascade 与功率波约定。

课程的 15 个 MATLAB movie 是计算演示，不授权在家复现激光、雷达、等离子体、电机或高功率 RF。公开路线保持纯理论与仿真即可。

## 选一个器件，把 field 推到 port

选 transmission line、resonator 或 antenna link：从 Maxwell 与 boundary conditions 推到端口量，用 Poynting theorem 或 energy balance 反查；数值模型随后改变材料、长度或负载，检查结论对离散步长是否稳定。报告保存场图、参考面、端口参数、瞬时或平均功率、stored/dissipated energy 和误差来源。

若只会用 Smith chart 却说不清反射能量，或会背 Poynting theorem 却接不到 circuit power，三个表示仍然分离。真正读懂 6.013 后，应该能把一个物理过程分别写成场分布、能量流和可测端口量，并由其中一种预言另外两种怎样变化。
