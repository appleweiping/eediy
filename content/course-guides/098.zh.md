## 6.011 的看点，是三门课突然开始互相解释

MIT [6.011 Spring 2010](https://ocw.mit.edu/courses/6-011-introduction-to-communication-control-and-signal-processing-spring-2010/)
由 Alan Oppenheim 与 George Verghese 授课，共 26 讲。
[Syllabus](https://ocw.mit.edu/courses/6-011-introduction-to-communication-control-and-signal-processing-spring-2010/pages/syllabus/)
要求掌握 6.003、6.041（或同等内容），以及 18.03 中与 linear ODE、eigenvalue/eigenvector
相关的内容。它适合已经
分别学过 signals、probability、control，却还没把 state estimation、projection 与 detection
连起来的人；任何一门仍是首次接触时，先修完整导论。

## 课程结构

[Calendar](https://ocw.mit.edu/courses/6-011-introduction-to-communication-control-and-signal-processing-spring-2010/pages/calendar/)
从 Fourier/sampling、state-space、observer/feedback，转入 MMSE/LMMSE、WSS/PSD、Wiener
filter，再到 PAM/QAM、hypothesis testing、matched filter、spectral estimation 与
information theory。可以拿一个二阶 state-space model 和一条带噪 binary link 做独立对照：
控制段设计 observer，随机段从 covariance 得 LMMSE/Wiener estimate，通信段再把投影解释成 matched-
filter statistic。变量换名后仍能说明内积、随机性与 observable，才抓住整合价值；这两个例子不是 MIT 原作业。

## 两个例子检验概念能否跨语境

针对前述例子，比较 observer poles、estimation covariance、Wiener theory 与 sample
estimate 的差异，以及固定 `Eb/N0` 下 PAM/QAM detection。自建练习明确标成独立补充，
并用 rank、orthogonality principle、energy normalization 或 analytic limit 校验，不能冒充
原 MIT problem sets。最后从“orthogonal error”出发，口头解释 observer、LMMSE 与
matched filter 各自的对象、内积和可观测量；接口说不清时，说明统一语言仍未建立。数值档案
还要明确过程噪声、观测噪声与符号先验分别在哪里进入模型，并改变一个参数，观察它在控制、估计和
检测三个语境中产生可解释的后果。能做到这种跨语境迁移，才算补上了缺少每周作业留下的练习空洞。
