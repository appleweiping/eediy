## 课程定位与版本

NPTEL Biomedical Instrumentation（course 102106669）是一门 12 周本科 core，默认学过 basic electrical engineering、sensing、measurement 与 transduction。2026-07-29 核对时，页面同时提供 109 节视频目录和更新的 [12-week syllabus](https://archive.nptel.ac.in/content/syllabus_pdf/102106669.pdf)：前者按器官与设备展开，后者把 AFE/noise 提前，并在最后加入 laser safety、isolation、IEC 60601、FDA 与 EMI/EMC。两份目录的项目顺序并不对齐。

[课程页面](https://nptel.ac.in/courses/102106669) 当时显示该轮可免费学习，证书考试另行报名并收费；这些日期与资格只属于 2026 cohort。课程的主要价值是传感器到仪器系统的全景，证书安排则应按 cohort 重新确认。

## 用一条信号链读完整门课

最清楚的主线是 `measurand → transducer → analog front end → sampling/filtering → display or control`。例如以 ECG 为例：electrode 把生理电势变成微伏级差分信号，AFE 的 input impedance、CMRR、noise 与 saturation 决定它是否还能被可靠采样，motion、工频和 ground loop 又会怎样进入记录。再把同一组问题迁移到 pressure、flow、EMG 或 pulse oximetry，就能看出哪些原则属于通用测量，哪些取决于具体传感器。

课程后半列出 ventilator、pacemaker、defibrillator、dialysis 等设备。自学部分聚焦 function block、signal path 与 failure mode，临床操作不在范围内：sensor drift 会让显示值缓慢偏离，amplifier saturation 会裁平异常波形，filter 也可能删掉真正的低幅结构。这样的具体失效路径，比背一串仪器名称更接近课程要训练的工程判断。

## 一个合适的计算练习

公开页面没有 hardware lab、BOM、代码仓库或 weekly assignment spec。可用 PhysioNet [MIT-BIH Arrhythmia Database](https://physionet.org/content/mitdb/1.0.0/) 或 synthetic waveform 做一个非诊断性滤波实验：保留原始片段，画出 filter response，并比较处理前后的幅值、时延和边缘效应。数据集标签可以用来定位片段，却不能被扩写成新的医学判断。

如果还想系统练习 filter、estimation 与 image processing，MIT [HST.582J Biomedical Signal and Image Processing](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/) 有公开 computational assignments/labs；它适合作为后续计算课程，与 NPTEL 本课的实验范围分开。

## 人体连接与临床边界

!!! danger "不要把教学电路接到人体"
    本页默认不采集新的人体数据，也不把自制 electrode 或 circuit 接到人。IEC 60601 与 FDA 出现在 syllabus，只说明课程会讨论安全和监管问题，并不认证设备、授予临床资格或允许诊断。人体连接、隔离、漏电、单故障和合规判断必须由当前标准、合格设备与专业团队处理。
