## 这套课靠文字推导成立，不靠视频

Cornell [ECE 3150 Microelectronics](https://ocw.ece.cornell.edu/courses/ece-3150-microelectronics/)
是 Spring 2016 的 junior-level 课程。从 carrier、drift-diffusion、recombination、PN
junction 开始，课程继续到 MOS capacitor、MOSFET/BJT、单级与多级 amplifier、
differential pair、高频模型、feedback、RF mixer、CMOS、subthreshold、FinFET 与
quantum transport。官网没有指定教材，也没有 lecture video；可贵的是 27 份推导型
handout、12 份 homework 及逐份 solution、midterm/final 及 solution，再加实验 handout
形成了连续的书面材料。

正式网页只标明本科三年级，没有公布一串先修课号。EEDIY 的编辑自测是：试着从连续性
方程解释 drift 与 diffusion；画正反偏 PN 结的能带和载流子；判断 NMOS/PMOS 工作区；
从偏置点画小信号模型；读 complex gain、pole 与 phase margin。它不是 Cornell 的选课
标准，也没有统一通过数量。每个做不出的动作只指向相应复习：电荷守恒、基础电路、器件
方程或频域分析；补完后直接试做有关 handout 的首个例题，比刷一套“先修测试”更可靠。
这几项也不是彼此独立的知识清单：如果会列节点方程，却无法说明晶体管为什么处在某个
工作区，问题多半在器件模型；如果直流点正确而相位判断混乱，才需要回头补频域。先定位
推理断点，再补一小段材料，能避免把整门基础课重学一遍。

## Handout、Homework 与 Lab 怎样接起来

[Lecture Notes and Handouts](https://ocw.ece.cornell.edu/courses/ece-3150-microelectronics/ece-3150-lecture-notes-and-handouts/)
按 1–27 编排，[Homework and Exams](https://ocw.ece.cornell.edu/courses/ece-3150-microelectronics/ece-3150-homework-and-exams/)
公开 12 份 homework、midterm、final 及全部解答。下表是 EEDIY 根据主题跨度做的阅读
分组，不是 Cornell 发布的周历，也不表示每份 HW 只对应一个 handout。

| 阅读段 | 主要模型 | 紧随的书面练习 | 实验接口 | 在下一段前停下来检查 |
| --- | --- | --- | --- | --- |
| Handouts 1–10 | semiconductor statistics、transport、recombination、PN junction、LED/solar cell、MOS capacitor、MOSFET 大/小信号 | 先做 HW 1–5 中同主题问题，再看对应 solution | Lab 1：diode IV、小信号参数、exponential amplifier 与 FFT | 能否从数据提参数，并指出 series resistance、temperature 或 high injection 使指数模型失效的位置 |
| Handouts 11–18 | CS/CG/CD、active load、current mirror、cascode、multistage、differential amplifier | 先做 HW 6–10；每道题标出所有器件工作区 | Lab 2：CD4007C 的 NFET/PFET 与 CMOS inverter；Lab 3：ALD1105 cascade、mirror、cascode | DC bias、small-signal gain、input/output resistance 是否由同一组参数推出 |
| Handouts 19–27 | Miller effect、frequency response、stability/compensation、folded cascode、mixer/converter、CMOS、subthreshold、FinFET | 做 HW 11–12，再用 midterm/final 闭卷抽查 | Lab 4：开放题，但公开 brief 将它写成 optional bonus | 高频极点和近似的来源是否说清；器件模型在哪个电压、频率或尺度不再可信 |

这里的停顿点是从 27 份 handout 的主题转换推得的编辑安排，不是“学习者通常会在此
失败”的调查结论。解答也应当最后使用：保存首次作答，按 model choice、sign、algebra、
unit 分类订正，隔几天只重做错题。看懂 solution 不能替代从空白页建立近似。
每一段还要留一份“假设清单”：哪些结被当作热平衡，哪些器件忽略沟道长度调制，哪些
电容在当前频率被视作开路或短路。下一段使用旧结论时，先翻这张清单；这样从器件到放大器
的过渡不是换一套公式，而是主动检查旧近似是否仍成立。

## 公开实验并不对称

[Projects and Labs](https://ocw.ece.cornell.edu/courses/ece-3150-microelectronics/ece-3150-projects-and-labs/)
列出 Lab 1–4。Lab 1 的 diode IV 扫描使用 1 台 Keithley 2400 SMU 与 Labtracer
2.0；handout 同时说明每个 bench 配有 2 台 SMU。它从 1N914A IV 提取大/小信号参数，
再由 function generator、oscilloscope FFT 和 MATLAB
`besseli` 比较 exponential amplifier 的 harmonics。Lab 2 用 2 台 SMU 测 CD4007C
的 NFET/PFET 与 CMOS transfer curve。Lab 3 用 ALD1105 做 common-source/
common-drain cascade、current mirror 和 cascode，在 1 kHz 小信号下测 DC bias 与
voltage gain；改变 \(R_L\) 的 sweep 刻画 loaded gain/output behavior。Lab goals 提到
input/output resistance，但公开 handout 没有给出一套完整、独立的 input-resistance
测量步骤。

版本裂缝必须保留：课程首页是 Spring 2016，而公开 Lab 1 PDF 标 Spring 2015；其余
实验材料来自 Spring 2016。Labs 1–3 有 solution，Lab 4 没有。首页概述还提到 4 个
labs 与 1 个较开放的 design project，但公开的
[Lab 4 brief](https://ocw.ece.cornell.edu/files/2017/03/ece3150_lab4-1cyoaq6.pdf)
明确写 optional bonus：最多 2 人，schematic 与拟测规格先经教师批准，现场 demo，
不用 write-up，TA support 有限。公开索引中没有另一份独立 project brief、Lab 4
solution、样例评分或教师反馈，不能把开放项目写成已经完整公开。

## 官方仪器、现代替代与新增误差

只有笔记本电脑时可以练习 handout 中的模型、参数提取算法与电路分析，但不能写成
“重做 Labs 1–3”。截至 2026-07-29，公开索引和所链接实验文件没有提供可下载的原始
IV 数据集，也没有原器件的制造商 SPICE model package。没有自己的实测数据时，只能
使用带版本的 datasheet 曲线或明确标注的 synthetic model 来演示方法；这类结果不能与
Cornell 原测量作数值对比。

| 原实验对象 | 现代做法 | 不能忽略的新误差或差异 |
| --- | --- | --- |
| 1 台 Keithley 2400 SMU + Labtracer 2.0 单路扫描（每 bench 配 2 台） | 现代 SMU；或 current-limited source + precision shunt + DMM/DAQ | compliance、burden voltage、lead resistance、current floor、NPLC/integration time 与采样顺序 |
| 2 台同步 SMU，分别控制 gate/drain 或 source/sense | 2 个可协调 source-measure channel；若顺序扫描，记录等待时间与温度 | gate/drain bias 不同步、self-heating、hysteresis 与漏电可能改变 IV |
| 50 Ω function generator 与指定 DC offset | 明确 source/load termination 的 AWG，先用 DMM 核对实际 offset/amplitude | 高阻与 50 Ω 端接切换会造成 2 倍幅度误解；offset 与 clipping 会改变工作点 |
| Oscilloscope FFT + Tek OpenChoice export | 现代 DSO 导出 time trace，再用版本固定的 FFT script | window（原 Lab 1 用 Flattop）、record length、sample rate、noise floor、averaging 与 amplitude calibration |
| MATLAB `besseli(n,a)` | 记录 MATLAB 版本，或使用版本固定的 `scipy.special.iv(n,a)` | library version、dtype、overflow/scale convention 与 dB normalization |
| CD4007C、ALD1105 与 1N914A 实物 | 有相同丝印器件时记录 lot/package；否则只用版本化 datasheet 或 synthetic model | threshold、\(\lambda\)、matching、body tie、temperature、package parasitic 与 layout 均可能不同 |

每个 netlist 都要附 model file、下载或录入来源、版本/日期、具体参数及改动记录；只写
“generic NMOS”不足以让另一个人重算结果。若 manufacturer model 后来可以获得，也要把
旧 synthetic run 留下，不能悄悄替换后继续沿用原图。
同样，原始数据与派生数据要分开保存。采集文件保持只读，清洗、单位换算、平滑和参数
拟合由脚本完成；图中每条曲线都能追到输入文件和脚本提交。平滑后的曲线不能再叫原始
测量，手工从 datasheet 取点也要记录页码、坐标轴与取点方法。

## 分别完成 Lab 1、2、3 的方法练习

Lab 1 的关键不是画一条光滑 diode curve，而是从 IV 拟合 \(I_S\) 与 ideality factor，
用 held-out 区段观察误差，再由 bias 点得到 differential resistance。若数据来自
datasheet digitization 或 synthetic model，图标题和 CSV 都要标明，报告只能说“参数
提取方法运行成功”。Harmonic 部分要保存 time trace、FFT window、采样率与每阶幅度，
并解释 Bessel 预测与数值 FFT 的 normalization。

Lab 2 要把 \(I_D\!-\!V_{GS}\)、多条 \(I_D\!-\!V_{DS}\)、\(g_m\)、\(g_o\) 与 inverter
transfer curve 串起来；同一模型参数必须同时面对这些曲线，不能每张图重调一套。若
顺序模拟 NFET/PFET 和 inverter，bulk connection、sign convention 与 sweep direction
必须写在 netlist 旁。

Lab 3 的公开 handout 测 DC node voltage 与 1 kHz 小信号 gain；\(R_L\) sweep 直接给出
loaded gain 随负载的变化，用来讨论 output behavior。Input resistance 需要另设激励与
电流/压降测量，而公开 handout 没有给出完整做法，不能从同一组 \(R_L\) 数据顺带声称
测得。它也没有要求完整的 frequency-response sweep。EEDIY 可以在复核 DC 工作区与
1 kHz 结果后增加 AC sweep、pole 与 bandwidth 分析，但必须直接标成“EEDIY
extension”。不要把这项扩展倒写成 Cornell Lab 3 的原目标。
三项练习的比较表也不能强行凑齐“理论、仿真、实测”三栏：没有自己的台面数据时，实测
栏应明确空缺；使用 synthetic model 时，理论和仿真共享同一参数来源，二者一致只能检查
方程与实现，不能证明模型描述了某颗真实器件。真正测量后再讨论仪器误差、器差和温漂。

## 什么时候选择 ECE 3150

这门课适合愿意在 device equation、transistor stage 与测量之间来回核对的人，不适合
依赖视频建立第一印象的人。合规实验室路线要用隔离低压、current limit、断电改线，并由
熟悉 SMU 与示波器的人监督首次上电；纯软件路线则专注模型和算法，明确缺少实际器件、
仪器噪声与 layout 影响。
判断是否学完，不看读过多少页，而看能否面对一条陌生曲线说明：先选哪种物理模型、从
哪里提参数、用哪一段数据检验、残差呈现什么结构、下一步测量怎样区分几个可能原因。
这段说明如果说不清，继续堆更复杂的放大器并不会自动补上器件理解。

结课时可把一个 diode/MOS 参数提取过程与一个 cascode 或 differential stage 放进同一
份技术记录：原始或 synthetic 数据来源、推导、版本化 netlist、参数脚本、DC/AC/
transient、PVT sensitivity、残差和模型失效条件都要齐全。它是 EEDIY 的综合练习，
不是 Cornell 新增 project。ECE 3150 真正稀缺的不是主题数量，而是每个器件近似都会在
HW、考试或实验中再次承担后果。
