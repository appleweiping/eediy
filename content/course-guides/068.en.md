## EE263 Changed Courses in 2025

This guide covers Stephen Boyd’s 2008 *Introduction to Linear Dynamical
Systems* archive, not the current Stanford EE263. Since Fall 2025, the
[EE263 home](https://ee263.stanford.edu/) has described *Matrix Methods:
Singular Value Decomposition*; the old linear-dynamical-systems material moved
to and was extended in EE363. Saying that “EE263 has complete video, homework,
and exams” now risks splicing 2 substantially different courses together.

Current EE263 is advanced applied linear algebra: range and null space,
orthogonality, QR, least squares and least norm, eigenvalues, symmetric
matrices, SVD, Gaussians, and MMSE, with applications in signals, machine
learning, control, navigation, circuits, and finance. Its prerequisites are
Engr 108/Math 104-level linear algebra and basic probability. The archived LDS
course instead expects linear algebra, differential equations, Laplace
transforms, and transfer functions. Both are valuable, but their entry points,
tools, assignments, and outcomes differ.

## What the Current Matrix Methods Course Makes Public

Summer 2026 is in person and video is Canvas-only, so an outside reader cannot
watch it. As of 2026-07-29,
[Lectures](https://ee263.stanford.edu/lectures.html) publishes 12 slide
sets, moving from linear functions and engineering examples through range/null
space, rank, orthogonality, QR, least squares, multi-objective least squares,
and least-norm solutions. The complete Fall 2025 sequence shows later topics
including projectors, recursive estimation, Gauss–Newton, eigendecomposition,
SVD, Gaussians/MMSE, and spectral graph embedding.

Current [Homework](https://ee263.stanford.edu/homework.html) uses Julia; other
languages are not supported or graded. Data is JSON, and derivations and code
are submitted through Gradescope. HW1–HW5 were public on the review date.
[Exams](https://ee263.stanford.edu/exams.html) lists Homework 25%, Midterm 25%,
and Final 50% as an approximate grading policy that may be revised. Exams are
normally in person, with no electronics and one formula sheet. For the current
SVD/MMSE course, keep a separate set of notes around these Julia assignments
and current slides. The 2008 video and MATLAB data do not belong to this
version.

## The 2008 LDS Archive Is the Better Public Course

The [Stephen Boyd 2008 Archive](https://ee263.stanford.edu/archive/) provides
20 slide/support-note sets, a 414-page reader, and a complete homework
problem bank. [Stanford Engineering Everywhere](https://see.stanford.edu/Course/EE263)
adds 20 videos and transcripts, 9 homework groupings, practice and formal
midterm/final exams, and MATLAB data. If I had to choose a course that an
outside learner can complete from public pages, I would choose this 2008
archive: the notes, video, problems, exams, and data connect.

The 20 lectures divide into 4 parts:

1. **Matrix problem language:** applied linear algebra, QR, least squares, and
   least norm.
2. **Autonomous systems:** matrix exponential, eigenvectors, diagonalization,
   and Jordan form explain state evolution.
3. **Input/output systems:** forced response and examples such as aircraft
   dynamics connect matrix models to systems.
4. **Structural properties:** symmetric matrices, norms, SVD,
   controllability/state transfer, and observability/state estimation.

This is not merely a matrix-decomposition review. Archived problems model
wireless power control, mechanical systems, AR/MA/ARMA, networks, tomography,
temperature control, minimum input, and state transfer. One matrix language
connects modeling, estimation, and control.

## 3 Checks Before Starting the Archive

Given a second-order state equation, form the state transition and check every
matrix dimension. Given an overdetermined system, distinguish the
least-squares residual from the solution. Given a transfer function, explain
how it relates to a state-space realization. If you can invert a matrix
numerically but cannot explain range, null space, or conditioning, review those
topics first. If `ẋ = Ax + Bu` still does not connect to differential
equations and forced response, review dynamical systems. These 3 small
problems say more about readiness than a transcript that only says “linear
algebra.”

## How to Work Through the 20 Lectures

Use the reader and slides for QR and least-squares/least-norm homework first.
Then move to autonomous LDS and connect `ẋ = Ax` with the matrix exponential
and eigenstructure. Follow with the input/output and aircraft or mechanical
examples. Finish with controllability and observability: can the state be
reached, and can it be reconstructed from outputs? Keep the model, derivation,
numerical result, and error check for each block.

The archived MATLAB data can be moved to Python or Julia, but record the
variables, matrix dimensions, and a reference result before changing
languages. The port also needs numeric tolerances and checks for sparse versus
dense data, storage order, and plotting differences. If a data file is
missing, return to the archive or SEE page for its source; current
Julia-homework JSON is not a substitute for an archived dataset.

For a final piece of work, choose one archived modeling problem and submit the
problem statement, matrix model, reproducible code, and an analytic/numeric
cross-check. Use controllability, observability, or estimator error to say
where the model stops working. This extends an archived problem; it is not an
official Stanford final project.

## Keep the Two Versions in Separate Notes

The current Summer 2026 course is still changing, so its slide and homework
counts and exam details need a review date. The
[2007–08 Course Information](https://web.stanford.edu/class/archive/ee/ee263/ee263.1082/courseinfo.html)
lists the approximate grading policy as Homework 15%, take-home Midterm 40%,
and take-home Final 45%, while reserving the right to revise it. Those figures
belong only to that historical version. Current EE263 names no required or
optional textbook. Boyd and Vandenberghe’s *Introduction to Applied Linear
Algebra* is a more elementary reference and does not exactly match the current
course.

The choice is straightforward: use current Matrix Methods for SVD/MMSE and the
Julia assignments; use the 2008 LDS archive for a public course with video,
problems, exams, and MATLAB data. Put the version in the title of the notes
instead of merging both under “EE263.”
