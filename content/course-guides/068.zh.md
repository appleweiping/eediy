## 当前 EE263 已经换课

自 Fall 2025 起，[Stanford EE263](https://ee263.stanford.edu/) 已改为 *Matrix Methods: Singular Value Decomposition*；旧版 linear dynamical systems 主线由 EE363 延续。当前课覆盖 range/null space、QR、least squares/least norm、eigenvalues、SVD、Gaussian model 与 MMSE，要求 Engr 108/Math 104 水平的线代和基础概率。若目标是 controllability、observability 与 state-space dynamics，应直接选 2008 归档，不要把旧视频接到当前作业上。

## 当前课程的材料与访问

Summer 2026 是现场课，录像在 Canvas。核验至 2026-07-29，[Lectures](https://ee263.stanford.edu/lectures.html) 发布到第 12 组 slides；完整的 Fall 2025 序列有 30 组，并延伸到 recursive estimation、Gauss–Newton、Gaussian/MMSE 与 spectral graph embedding。

[Homework](https://ee263.stanford.edu/homework.html) 使用 Julia 和 JSON 数据，当前公开 HW1–HW5；[Exams](https://ee263.stanford.edu/exams.html) 给出的 approximate policy 是 homework 25%、midterm 25%、final 50%，但 Canvas、Gradescope、录像与反馈不匿名开放。

[CVXPY](https://github.com/cvxpy/cvxpy) 可在推导之后独立核对 bounded least squares 或 KKT 条件；当前 EE263 指定的作业环境仍是 Julia。最清楚的做法是保留同一 \(A,b\)，把手算、Julia 作业与 CVXPY 结果分栏比较 residual、constraint 与 dual interpretation；不要把 Python 重写误称为课程作业。

## 2008 年线性动力系统归档

[Stanford Engineering Everywhere](https://see.stanford.edu/Course/EE263) 汇集 20 场视频与 transcript、9 组 homework、midterm、final 和 MATLAB 数据；配套 archive 还有 lecture slides、support notes 与 414 页 course reader。它要求线代、微分方程、Laplace 与 transfer function，从 least squares 和 matrix exponential 走到 state-space response、SVD、controllability 与 observability。

这条线可以始终用同一个物理系统：由 ODE 得到 \(A,B,C,D\)，比较 free/forced response，改变 state coordinates 后检查 input-output behavior，再用不可达或不可见 mode 解释 rank test 的物理意义。迁移 MATLAB 数据到 Python/Julia 时保持矩阵维度、容差和原始对照结果。历史 [2007–08 course information](https://web.stanford.edu/class/archive/ee/ee263/ee263.1082/courseinfo.html) 的 homework 15%、take-home midterm 40%、take-home final 45% 只属于旧版。

要 SVD/MMSE 与 Julia，选当前 Matrix Methods；要公开的视频、题目、考试和数据齐全的 LDS 课程，选 2008 归档。笔记标题也应把这两个版本写开，避免同名课程造成假连续性。
