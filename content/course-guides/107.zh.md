## 访问与版本说明

[Cornell Fall 2026 roster](https://classes.cornell.edu/browse/roster/FA26/class/ECE/3030)
把 PHYS 2213、MATH 2930，以及 ECE 2100 或 ENGRD 2100 列为 2026–2027 目录课程的先修；真正匿名可学的是 Farhan Rana 的
[Fall 2007 archive](https://ocw.ece.cornell.edu/courses/ece-3030-electromagnetic-fields-and-waves-2/)。
它从 static Maxwell/Poisson/Laplace、materials 与 waves，走到 transmission lines、
waveguides、antennas、scattering 和 apertures。它适合已会 vector calculus、ODE、phasor、
complex power 与基础 transmission line，想用连续讲义和题解走完整电磁主线的人。Fall 2026 先修声明
与 2007 教学档案要分开记录；需要现代 lab 或 project 时应另选入口。

## 36 组讲义是一条物理路线

[Lecture Notes](https://ocw.ece.cornell.edu/courses/ece-3030-electromagnetic-fields-and-waves-2/ece-3030-lectures-notes-and-handouts-2/)
共 36 组，可按 static fields、waves/materials、transmission-line matching、guided modes、
radiation/antennas、scattering/apertures 阅读。每段都从坐标系、Maxwell equation 与 boundary
condition 出发，再用 dimension、energy/power 或 limiting case 检查。只会套 Smith chart、
TE/TM cutoff 或 antenna formula，而不能说明 reference direction 和 material assumption，
就还没有把各段接起来。

## 12 套题解是主要反馈

[Homework and Exams](https://ocw.ece.cornell.edu/courses/ece-3030-electromagnetic-fields-and-waves-2/ece-3030-homework-and-exams-2/)
提供 12 套 homework 及 solutions。解答延迟到独立推导后使用，订正区分 coordinate choice、
phasor sign、impedance normalization 与 boundary condition。同页还列 Exam 1、2、3 与
Final，但主页又写 2 次 prelim + final；归档内部不一致，因此试卷只能按文件标题和年份作
自测，不能重建一个并不存在证据的统一评分结构。

## 最后画一张跨尺度 Maxwell 场图

公开页说明 labs/projects 不可用；空占位标题也不能证明存在实验包。最终从 static field、
wave/interface、line matching、waveguide 和 antenna 各选代表题，保留坐标选择、边界条件、
推导和能量检查，再画一张图说明同一 Maxwell 方程怎样改变近似与 observable。Smith-chart
或 waveguide 数值脚本可标成独立补充验证，不能称为 Cornell lab；需要现场 RF 测量时，应
另配明确公开、具备安全条件的实验课程。最终地图还应标明每次近似成立的尺度、材料与观察区，
让静态、导波和辐射公式之间的切换都有明确理由。

[Meep](https://github.com/NanoComp/meep) 是活跃的 GPL-2.0 FDTD
electromagnetics solver，仓库有 straight/bent waveguide、cavity 与 far-field examples。
它不是 Cornell lab。可从 straight waveguide 改写一个最小模型，明确 cell、resolution、
PML、source 和 reference plane，做 mesh refinement，并把 propagation constant、cutoff
或 power flux 与手算极限核对。若 refinement 后这些量仍明显漂移，场图再漂亮也不能回答
waveguide 是否收敛。
