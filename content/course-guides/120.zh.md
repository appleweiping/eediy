## 课程定位

MIT [6.685 Electric Machines, Fall 2013](https://ocw.mit.edu/courses/6-685-electric-machines-fall-2013/pages/syllabus/) 是 James Kirtley 的研究生课，适合已经学过电力基础、想进入机器动态与 drive model 的人；先修为 6.061/6.690 Introduction to Electric Power Systems 或教师许可。合适的起点是能做三相相量与 per-unit 换算，用 reluctance、flux 和 coenergy 从磁路推出力/转矩，并由感应机等效电路解释 slip、功率流和 torque-speed。三相功率与磁路都不稳时先补电力系统；稳态已会但没见过 Park transform 和状态方程，可以进入本课并为动态建模留出额外时间。

## 12 章讲义要按 24 讲依赖阅读

[Course Notes](https://ocw.mit.edu/courses/6-685-electric-machines-fall-2013/pages/course-notes/) 有 12 章，但官方提醒章节顺序与授课顺序不同。依照 calendar，可把内容分成场/能量/材料，同步机与 Park transform，感应/直流/磁阻机，动态与驱动，以及永磁/BLDC 五段。每段先写 phase/line、peak/RMS、mechanical/electrical angle 和转矩正方向，再做气隙、slip 或 d/q 参数的极限检查；电机公式即使符号一致，也常因 convention 混用而错。

[Assignments](https://ocw.mit.edu/courses/6-685-electric-machines-fall-2013/pages/assignments/) 的 Problem Set 1–11 全有解答。PS1–3 处理 force、magnetic circuit 与 loss；PS4–7 进入 synchronous、winding、induction 与 DC；PS8–11 覆盖 reluctance、dynamic simulation、drive/control 和 PM/BLDC。每题先重画磁路或等效电路，再用功率平衡和极限工况复核。公开 [Exams](https://ocw.mit.edu/courses/6-685-electric-machines-fall-2013/pages/exams/) 只有两场 1.5 小时 quiz 与答案；原 syllabus 提到的 3 小时 final 未公开，不能宣称完整考试复现。

场与电路之间至少做一次显式能量核对。由磁共能对位置或角度求导得到 force/torque，同时从气隙场和端口功率建立独立预算；对同步机再把 electrical angle、pole pair 与 mechanical speed 写在同一行。进入 Park transform 后，固定 abc→d/q 的符号、缩放和 rotating-frame direction，用 balanced steady state 验证恒定 d/q 量，并检查瞬时三相功率在变换前后是否守恒。

感应机的等效电路、torque-speed curve 与动态状态模型也应共享参数。改变 rotor resistance、inertia 或 load torque，分别预测 starting current、breakdown torque、slip 和 transient settling 的方向，再运行模型。若稳态曲线与动态最终点不相交，先检查 base quantities、leakage convention 和 mechanical equation，而非调 solver 掩盖差异。

## 建模方法

Aalto Electric Drives 团队的非官方 [motulator](https://github.com/Aalto-Electric-Drives/motulator) 是 MIT 许可的 Python motor-drive/grid-converter simulator，有 DOI、文档、测试和 induction、synchronous-reluctance、PM synchronous machine 示例。它是独立实现，与 6.685 代码或答案无关。适合把课程方程映射到连续时间机器模型与离散控制器，比较启动、负载阶跃和不同 solver 设置；参数、abc↔d/q convention 与功率残差仍须独立写清。

## 在相同额定值与负载条件下比较两种机型

课程没有公开 lab 或 project。可用题目给定参数，分别为同步机和感应机建立稳态/动态模型，画 power-angle 或 torque-speed、一次 start-up/load-step、loss/efficiency 与参数敏感性。同步机覆盖 no-load、rated 和 overload；感应机覆盖 low、nominal 和 high slip。图旁给出能量/功率 residual，并检查步长或 solver 改变后暂态是否稳定。

公开路线不需要给三相电机上电。实体机器、VFD、直流母线和转子需要额定防护、隔离/限流、急停、机械护罩和专业监督。完成公开题目、quiz 与可复现双机型报告，可以形成诚实的学习档案；它不补上缺失 final，也不授予 MIT 学分。

把 induction machine 与 synchronous machine 放在同一组 torque–speed、flux 与 transient 条件下比较，才会看见两种模型真正不同的地方；上电技能仍属于实验室。
