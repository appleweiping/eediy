## 把课程当成一次闭环设计审查

6.302 最好的入口不是“什么是反馈”，而是一份会失败的设计。给定电机或运放 plant \(P(s)\)、传感器 \(H(s)\)、执行器限幅和目标 bandwidth，先画完整 loop：参考输入、扰动、测量噪声、控制量和输出各从哪里进入。再写 \(S=(1+L)^{-1}\)、\(T=L(1+L)^{-1}\) 与 \(L=PCH\)，说明提高低频 loop gain 会改善什么，又把哪些噪声、饱和或鲁棒性问题推到别处。若只会套闭环传递函数而不能标出每条通道，先回到 block diagram、LTI 与 Laplace transform。

MIT 的 [syllabus](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/syllabus/) 将 Spring 2007 的 6.302 标为 graduate introduction to feedback-system design。正式背景写成 6.003、2.003 或 16.04 之一；还默认有 6.002、6.071 或 16.04 一类电路实验经历，保留 8.01/8.02 的物理直觉并接触过 complex variables。上面的 loop review 是 EEDIY 诊断，不是 MIT 官方 prerequisite exam。

## 官方档案由 4 条材料链组成

[Calendar](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/calendar/) 列出 L1–L24 与 R1–R26：从 desensitivity、modeling、first/second-order response、steady-state error 进入 root locus、Nyquist、Hall/Nichols、Bode margins 与 “Bode obstacle course”，再到 lead/lag、op-amp minor-loop compensation、lightly damped quadratics、describing functions、oscillators 与 conditional stability。课程不是现代 state-space survey；它把 classical loop analysis 反复压到电子和机电 plant 上。

练习链是 [Problem Set 1–10](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/assignments/)，公开页只有题目 PDF，没有 solution 栏。辅导链有 26 次编号 recitation；[recitation 页面](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/recitations/) 公开 R1–R20 与 R23–R26 的 24 份 handouts，并明确 R21 “Block diagrams from circuits” 与 R22 “Return ratio” 没有 handout。不要把 26 次排课写成 26 份可下载讲义。

实践链在 [labs 页面](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/labs/)：Lab 1 是同一 servomotor 的 Prelab/Lab 1A、1B、1C、1D，另有 Motor Lab Take-Home Quiz；Lab 2 是设计项目，3 选 1——PLL、thermal-control system 或 magnetic levitator。syllabus 把 1A–1D 称为 4 个短实验，页面又以 “Lab 1” 汇总它们；两种计数描述的是同一组材料，不应宣传成 5 个彼此独立的官方实验。

## 每个设计必须过 5 个 gate

Gate 1 是 model audit：从电路定律或力矩平衡推出 plant，列出被忽略的 pole、delay、friction、saturation 与 sensor dynamics；不能从目标 Bode 图倒猜一个方便模型。Gate 2 是 stability audit：在相同 sign convention 下用 root locus 与 Nyquist 给出一致结论，并记录 encirclement、右半平面 pole 数和闭环 pole 位置。

Gate 3 是 loop-shaping audit：先写 tracking、disturbance rejection、noise、control effort 与 robustness 的频带，再放 lead/lag 或 minor loop；gain margin 和 phase margin 不是孤立分数。Gate 4 是 nonlinearity audit：检查 actuator limit、integrator windup、dead zone、rate limit 和描述函数可能遗漏的动态。Gate 5 是 implementation audit：对元件容差、采样/计算 delay、op-amp GBW、slew rate、电源范围和接地写 worst-case argument。

这 5 个 gate 对应课程自己的重心：6.302 不只让 closed-loop pole 落在左半平面，还要求设计者解释物理 plant、频率权衡和实际放大器。每份题解或 lab memo 至少关联 1 个 gate；若只留下 MATLAB 图而没有 plant equation、规格与失败原因，就没有完成设计审查。建模记录还要交代线性化工作点和适用振幅：同一个电机在摩擦死区附近、同一个运放在输出摆幅边缘，都可能不再服从纸面模型。频率图应注明开环还是闭环、输入输出单位、相位展开方式与未建模动态；改变 compensator 后，重新检查全部通道，而不是只展示被改善的一条曲线。这样才能区分“数值看起来稳定”和“设计论证可以复核”。

## 没有原装电机台时要诚实降级

实体 Lab 1 依赖 2007 年 MIT 的 servomotor、接口与仪器环境，Lab 2 的热控和磁悬浮方案也涉及 heater、power electronics、moving hardware 或 unstable plant。物料、接口板、供应电压、机械限位和安全监督不能从讲义标题推断。校外默认先读 handout、重建方框图并在仿真中复现 nominal 与 perturbed plant；没有等效 BOM、current limit、emergency stop 和合格监督，不要通电追求“原课程体验”。

若具备正规的低压实验条件，对照上述官方 Lab 1A–1D 清单，EEDIY 只建议选 1 条硬件路径并先做 risk review：电机堵转电流、旋转部件、热表面、线圈反灌、运放输出限幅和测量接地。记录仪器型号、供电上限、机械约束、关断条件和观察者。完成 simulation 不等于完成 Lab 1A–1D；阅读 PLL/thermal/maglev handout 也不等于完成 Lab 2 design project。

## 6.302 与 CDS/FBS 的分工不是新旧替换

Åström 与 Murray 的 [Feedback Systems 2e 页面](https://fbswiki.org/wiki/index.php/FBS) 公开 2020-07-24 的完整第二版，并在 2024 年把 Python figure sources 更新到 python-control 0.10.1。其 15 章从 modeling、state/output feedback、observability 与 Kalman filtering 延伸到 loop shaping、robust performance、fundamental limits 和 architectures；这更接近 Caltech CDS 101/110 及现代控制的宽度。FBS 页面是书与补充材料入口，不是 6.302 的官方替代学期。

6.302 的不可替代处是 classical feedback 的电子/机电密度：Hall/Nichols、Bode obstacle course、op-amp internal/minor-loop compensation、PLL 和 servomotor labs 都指向真实 loop 的 return ratio 与 compensation。若目标是第一次从传递函数做到硬件 loop review，先 6.302；若已会 Nyquist/lead-lag，目标是 state estimation、state feedback、robustness 与 architecture，转 FBS/CDS；做现代 control project 时可用 FBS 补 6.302 的 state-space 缺口，但不要删掉它的 actuator、sensor 与 saturation 审查。

[Exams 页面](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/exams/) 公开的是 selected previous exams：2003 Quiz 1，以及 2003、2004、2005、2007 四份 final；没有 solution 链，且官方提示 2005 Final 的 Problem 4 缺 figures。syllabus 课程安排有 2 quizzes 与 final，但公开 archive 并没有对应 3 份完整 2007 assessment package。Problem Set 1–10 同样无解，校外也没有 grader、staff feedback 或 design review。因此更正链不能伪装成官方答案：先冻结推导，再用极限情形、量纲、独立数值计算和另一种稳定性判据交叉核验；仍有分歧就保留 unresolved 标记。历史试卷缺图时只完成不依赖缺失信息的部分，并在记录中注明不可判定，不从邻题猜图。若同伴参与复核，保存的是误差类别与修改理由，而不是把非官方意见写成 MIT 评分。

## 4 个诊断决定补课位置

诊断 1：从电机电气—机械参数推出二阶 plant，并说明传感器与 amplifier pole 是否应进入 \(L(s)\)。诊断 2：给定一个有右半平面 pole 的 loop，按选定 contour 完成 Nyquist encirclement 计数，并与 root locus 核对。诊断 3：为指定 crossover 设计 lead compensator，计算 phase margin、低频误差与高频 noise amplification。诊断 4：给定饱和和 delay，说明线性 margin 为什么不足，并提出可测试的限制条件。

第 1 项失败补 circuits、mechanics 与 modeling；第 2 项失败补 complex analysis、Bode/Nyquist sign convention；第 3 项失败补 frequency response 与 sensitivity functions；第 4 项失败补 nonlinear/implementation limits。至少 3 项能在无参考答案时完成推导、交叉检查和单位审计，再进入 Lab 2 设计；这些阈值是 EEDIY 的 placement rule。

## 结课交付是一份能被反驳的设计记录

依据上文链接的官方 calendar、recitation、assignment、exam 与 lab 清单，完成包应包含 L1–L24 topic map、可用的 24 份 recitation handouts 与 R21/R22 缺口、Problem Set 1–10 首稿、5 份公开历史 exam 的限时记录、Lab 1A–1D 的 plant/loop memo、以及 PLL/thermal/maglev 中 1 个 design dossier。硬件未执行时在 dossier 首页写 simulation-only；执行时附 BOM、limits、risk review、raw measurements、model mismatch 与 shutdown evidence。

另附五项设计审查表、4 个诊断、更正日志，以及 FBS 中 state/output feedback、estimation、robust performance 与 architecture 的缺口图。最终档案必须一眼能看出这是 6.302：return ratio、Bode obstacle course、minor-loop op-amp、servomotor 1A–1D 和三选一设计项目都应留下具体痕迹；若去掉这些内容后仍像任意控制课导读，就还没有完成。本页只依据公开材料作判断，不冒充课程完成者的第一手复盘。
