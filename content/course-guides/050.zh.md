## 先用一扇 CMOS 门判断这门 2003 年课程是否适合你

MIT 6.374 是 Fall 2003 的研究生课。官方
[Syllabus](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/syllabus/)
把先修写得很窄也很硬：需要 6.012 或同等的器件物理，以及 6.004 或同等的逻辑设计。
开始前不妨只做一扇 CMOS inverter：画 VTC 并标出 noise margin；由器件和负载电容估算
上升、下降延迟；列出一次翻转的动态能量；最后解释版图寄生为什么会让手算失效。若只能
写 Verilog、不能回答 transistor sizing 和 capacitance 从哪里来，应先补 MOS 大信号、
小信号与 RC；若会算器件却不熟悉组合/时序逻辑，则先补 latch、register 和 timing
constraint。这个自测是 EEDIY 的分流方法，不是 MIT 的入学考试。

这也解释了它和 Berkeley EECS 151 的差别。当前
[EECS 151 课程说明](https://www2.eecs.berkeley.edu/Courses/EECS151/)
从 Verilog、FSM、算术单元和存储器出发，分别通往 FPGA 与 ASIC lab；6.374 则把视角压到
CMOS gate、interconnect、clock、memory cell 的 delay、energy 与 layout。第一次接触
数字硬件时应先选 EECS 151 一类的 top-down 课程；已经能写、仿真并验证 RTL，想知道门级
实现为什么慢、为什么耗能，才适合进入 6.374。学生自办的 EECS151 Tapeout 是另一个当前
伴学参照：它明确要求 EECS 151 与 ASIC lab 背景，并围绕 Chisel、Chipyard、SKY130 和
SoC tapeout 展开，不能拿来证明 MIT 这套 2003 工具链今天仍可原样执行。

## 24 次课堂围绕同一条 delay–energy–layout 链收拢

官方 [Calendar](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/calendar/)
列出 24 次课堂。前 4 讲从 short-channel MOS model、inverter VTC、propagation delay、
parasitic capacitance 进入 switching、short-circuit 与 leakage power；Lecture 5–9
比较 static、ratioed、pass-transistor、dynamic logic，并用 logical effort、adder、
multiplier 和 shifter 把 sizing 接到结构选择。Lecture 12–17 转向 latch、register、
metastability、interconnect、clock skew/jitter 和 clock distribution；Lecture 18–20
处理 ROM、PLA、SRAM、DRAM 与 sense amplifier；Lecture 21–22 以 voltage scaling、
switching-activity reduction 和 VLSI test 收尾，Lecture 23–24 留给项目展示。

公开页没有 lecture video。所谓 “Lecture Notes” 实际是一张按教材章节映射的主题表，
并指向 Rabaey、Chandrakasan、Nikolic 第 2 版教材网站的 slides。那一页注明 slides
版权属于 Prentice Hall/Pearson，只给使用该书的教师有限教学许可，并明确禁止再发布；
指定教材本身也需另行取得。因此，可公开执行的核心不是“下载一套开放讲义”，而是
calendar、5 份 problem set、工具说明、quiz 与项目格式。阅读时应以每个设计量是否进入
同一张账为准：

- inverter 段同时保存 DC transfer、手算 \(t_p\)、SPICE transient 与 extracted
  capacitance，不能只报一条 waveform；
- logic 段把 topology、transistor count、worst-case path、activity factor 和 energy
  写在同一页，避免把更快误写成无条件更好；
- sequential/interconnect 段分别记录 setup/hold、skew/jitter 假设、wire RC 与 buffer
  chain，先说清 timing model 再看数值；
- memory/test 段把 cell、sense path、array organization 与 fault model 分层，不用
  “跑通一个 SRAM schematic”代替可测的 read/write margin。

## 五份题的反馈完整，两个 Quiz 并不完整

[Assignments](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/assignments/)
公开 Problem Set 1–5、每份 solution，并为 PS1–PS4 附 FAQ；PS3 与 PS5 还引用
0.25 µm CMOS process parameters。先在空白页完成模型选择、近似与单位，再用 solution
区分四类错误：device region 选错、capacitance 漏项、critical path 选错、energy/power
定义混用。FAQ 应在第一次作答后看；否则它会把原本可以诊断的建模缺口提前抹掉。

[Exams](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/exams/)
只列 Quiz 1 与 Quiz 2 的试卷。课程索引虽带有 “Exam Solutions” 资源标签，但本次审读的
exams 页和两份下载文件没有另列解答；不要据标签把它们写成两套 solved exam。Quiz 1
覆盖 inverter 与 combinational logic，Quiz 2 覆盖 arithmetic、interconnect、
sequential circuit 与 memory。更稳妥的用法是闭卷完成、保留首稿，再用已解 problem set
为同类模型做交叉核对；无法确认的 quiz 小问应进入讨论或勘误清单，而不是从未知来源寻找
答案。

官方评分也说明反馈重心：5 份 problem set 占 20%，两个 quiz 各占 25%，final design
project 占 30%。直接公开的 [project guidelines PDF](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/3fd5ad1346a5389abc54bd158606a17a_guidelines.pdf)
规定两页上限，并要求说明哪些想法成功、哪些失败，列出 3 个最有创新性的想法，附
simulation path；另有一页 technical-summary form。它们没有给出可由校外学习者照做的
统一 project specification 或示范结果，因此是报告格式，不是一个已经公开的电路题目。

## Magic、HSPICE 和 0.25 µm 只能放进历史通道

官方 [Tools](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/tools/)
列出 Magic、HSPICE 与 NanoSim，Syllabus 还提到 IRSIM；公开页提供 Magic/HSPICE
说明并外链 0.18/0.25 µm model，但没有在该页授予今天的 HSPICE/NanoSim 使用许可，也
没有证明旧 model 仍可合法取得或与当前工具兼容。因此应把商业工具访问标为“待学习者
自行核验”，而不是直接写成可下载。不能把一个现代 open PDK 的数值塞进 PS3 的 0.25 µm
参数，再宣称复现了官方答案；process、model card、supply、temperature 与 extraction
rule 一变，delay、leakage 和 layout 都已经是另一项实验。

更清楚的做法是保留两条互不混算的记录。历史通道只完成官方题目，使用题面给定参数，并
把无法合法取得的 simulator/model 标为未执行。现代通道是明确标注的 EEDIY 补充，不是
MIT lab 或 project：在一个依法可用、版本固定的 PDK/EDA 环境中选择 inverter 加一条
代表性逻辑路径，依次提交手算 RC/energy model、pre-layout SPICE sweep、DRC-clean
layout、parasitic extraction 与 post-layout comparison。扫描 input slew、load、
supply 和 transistor size 时，先写预期趋势，再解释模型与仿真的差；不要预设一个跨
PDK 通用的百分比阈值。

## 结课证据应当能指出模型在哪一层失效

一份可信的公开学习记录应包含 PS1–PS5 首稿与订正、两个 quiz 的计时首稿、逐项假设表，
以及一份 delay–energy–layout 审计包。审计包至少保存 schematic/netlist、model 与工具
版本、sweep script、原始输出、版图与 DRC/extraction report，并把 pre-layout 与
post-layout 差异追到具体 parasitic 或 sizing 决策。若没有合法的 HSPICE/NanoSim、
process file 或可用的 layout flow，就以 solved problem sets 和分析报告结束；缺少工具
不是许可绕行的理由。

这门课因此仍可作为 transistor-level digital IC 主线，但不是现代 RTL-to-GDS 安装手册，
也不是 tapeout 资格证明。提交课程反馈时，请注明使用的是官方 0.25 µm 题面还是哪一个
现代 PDK、工具版本、完成到 pre-layout 还是 post-layout，并附不含受限 model 的最小复现
步骤。这样的报告能让后续学习者判断是概念问题、年代问题还是许可问题，也不会把校外
模拟包装成 MIT 6.374 的完整复现。
