## 先修要求

NPTEL [Analog IC Design](https://nptel.ac.in/courses/108106105) 是 IIT Madras 的 12 周
课程。合适的基础包括求 MOS operating point、画 small-signal model、分析 common-source
与 differential pair，并从 loop gain 判断 stability；只学过 ideal op-amp 还不够。
官方 [Syllabus](https://archive.nptel.ac.in/content/syllabus_pdf/108106105.pdf) 把 MOS
review、noise/mismatch、feedback/compensation、single/two-stage op-amp、telescopic、
folded-cascode、fully differential 与 CMFB 连成一条设计链。
它适合已经能把偏置、小信号和反馈放进同一份设计记录的人；理想运放仍是主要工具时应改选前置课。

内容以 [2018 archived preview](https://onlinecourses-archive.nptel.ac.in/noc18_ec05/preview)
作为稳定参考；当前 [NOC26-EE66](https://onlinecourses.nptel.ac.in/noc26_ee66/preview) 只决定 2026
的服务、deadline 与证书。两次运行分别记录。

## 比较 topology 时固定 gain、GBW 与 swing

对每种结构固定比较 gain、GBW、phase margin、slew、output swing、common-mode range、
noise、power、load 和 mismatch。完成 hand budget，并在相同 supply、current、load 与
device model 下比较 SPICE 结果。two-stage 的 compensation 还要计入面积、slew 与 settling，
不能只展示最终赢家。

2018 [Announcements](https://onlinecourses-archive.nptel.ac.in/noc18_ec05/announcements)
显示 Assignment 0 与 12 次 weekly assignments，多数周曾发布解答，但 Assignment 12 支持
不完整且旧 grader 未必可用。独立完成后看答案；缺失周用教材、同伴或仿真复核。

## 完整 op-amp 设计才会暴露取舍

给定 supply、load、DC gain、UGB、phase margin、slew、input/output range、noise 与
power，至少比较 2 种 topology。testbench 分开做 DC、differential/common-mode AC、
loop stability、large-signal step、slew、settling、load/supply sweep 与 noise。fully
differential 设计还需要单独验证 CMFB 的 sensing range、target common mode、startup 和
stability。

noise 与 mismatch 也不能在前几周讲完就消失。建立 input-referred budget，区分 thermal、
\(1/f\)、systematic 与 random mismatch，并说明积分带宽；模型没有统计参数时就留下未验证，
随手挑选的分布提供不了工艺证据。

公开材料没有 PDK、layout、DRC/LVS 或 post-layout extraction。使用 generic model 时，
matching 与 parasitic 只能标为未验证；没有统计模型时，Monte Carlo 也没有可信输入。公开材料的边界意味着
可评价的成果是解释约束怎样淘汰结构，观看 12 周内容本身不构成一次 IC implementation。

最终保留一个被淘汰 topology 及其失败原因。若所有候选都只留下成功曲线，读者看不到 gain、
headroom、power、stability 和 settling 之间真正发生过的取舍。

最后一张 constraint table 把每项规格连到计算、仿真或明确的未知项；当两个结构都达到
nominal 指标时，真正决定取舍的是 corner、settling 与实现复杂度，而不是哪条曲线更好看。
