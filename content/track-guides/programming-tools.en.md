There is no conventional examination archive, but current Python 3 material and programming exercises provide sustained practice. The [official archive](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/) for [MIT 6.087](016-6-087.md) shifts to compilation, pointers, array layout, files, and system interfaces through notes, exercises, laboratories, and source. Dated UNIX commands need documented modern equivalents. Add [MIT 6.057](017-6-057.md) only when later work actually contains `.m` files, a lawful MATLAB environment, or toolbox dependencies; its [official syllabus](https://ocw.mit.edu/courses/6-057-introduction-to-matlab-january-iap-2019/pages/syllabus/) is not a license. A GNU Octave port must name syntax, toolbox, and numerical differences.

The normal route is not all three courses. [Signals and systems](../signals-systems/index.md) can use Python for a reference model and selected 6.087 tasks for arrays, files, and performance. [Embedded systems](../embedded-systems/index.md) warrants the complete C compilation, memory, and I/O path. ## Make one numerical kernel answer to both a language contract and diagnostic tools

Choose an FIR filter, calibration curve, register conversion, or CSV parser. In Python, state data type, shape, units, missing values, boundary length, and exception behavior, then establish a reference with hand-solvable examples and unit tests. The C version explicitly selects integer widths, signedness, buffer ownership, length parameters, overflow policy, and return codes. Both consume vectors for normal, empty, maximum and minimum, truncated, malformed, and floating-boundary inputs. Integers agree exactly; every floating tolerance follows from the algorithm and representation.

Name the Python interpreter and dependencies and the C compiler, language standard, warning flags, and optimization. Compile under strict warnings and apply AddressSanitizer, UndefinedBehaviorSanitizer, static analysis, and boundary inputs. A benchmark states input size, CPU, optimization, and peak memory. Encapsulate serial, GPIO, or instrument input as a host-side byte stream and test disconnection, timeout, partial frames, and replay. A container constrains user-space dependencies but says nothing about equivalent USB timing, drivers, or real-time latency. Deleting an error case or widening a tolerance is not a diagnosis.

## A binary instrument log turns course exercises into auditable software

Define a compact format with a sync word, timestamp, channel, fixed-point ADC value, and CRC. Python generates valid and damaged examples, supplies the reference parse, converts units, and plots. C uses a streaming buffer for endianness, split frames, bad CRC, counter wrap, and overflow. At least ten fixed files cover a noise prefix, half frame, invalid length, bad CRC, wraparound, and consecutive frames; the implementations emit identical structured results. Introduce one off-by-one, sign-extension, or scaling defect, reduce it to the smallest input, and add that input to regression.

From a clean checkout, one command should rebuild the format specification checks, vector checksums, builds, tests, benchmark results, and short analysis. Changing a valid channel count or sample rate should not require an edit to parser state. Damaged data reports its location instead of silently producing plausible engineering values. This result is more precise than claiming fluency in Python and C: it demonstrates that the same instrument bytes obey one contract under two memory models.
