# 前言

电子工程公开课并不少。真正费时间的是判断：这门课现在还剩下哪些材料，作业能不能得到反馈，需要什么软件和仪器，以及它和旁边那门同名课程到底差在哪里。

EEDIY 把这些判断放到课程页里。每门课都尽量给出官方入口、公开讲义与作业、答案或其他反馈、先修要求、工具与硬件条件，以及校外自学者实际能完成到哪一步。相邻课程会直接比较，不用读者自己在十几个标签页之间猜。

导航和课程页的阅读方式直接借鉴 [CSDIY](https://csdiy.wiki/)；电子工程部分则重新核对，因为器件、仪器、EDA 许可和实验安全会改变一门课是否真的可学。

选课时先打开课程的第一份实质性作业。能取得题目、反馈和所需工具，通常比课程首页是否漂亮更重要。同一主题先选一门主线；遇到访问、先修或风格问题，再换替代课或补充材料。

## 实验条件也是先修

程序写错通常可以重跑；接错电源、误用电池、激光、射频功率或旋转机械，后果可能不是一次失败测试。课程出现实验，不等于家庭环境就适合复现。遇到市电、高压、高电流、高功率储能、强光、射频辐射、化学品或加工设备时，应使用合规设施和合格监督；条件不够就停在解析、仿真、公开数据或低能量教学平台。

!!! danger "接通电源前，先读安全指南"
    [实验安全指南](guides/safety.md)列出了可以继续、应改用仿真和必须进入合格设施的边界。它不替代设备手册、实验室流程或当地规则。

## 找到问题就开始

今天只需选一门最接近当前问题的课程，确认第一份作业、反馈和工具是否可用，然后完成一个能被答案、测试、仿真或测量校正的小任务。页面有失效链接、版本变化或判断缺口时，使用页末对应的反馈入口；有完整证据和修改建议时，走[贡献入口](contributing.md)。
