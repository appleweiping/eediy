# 前言

电子工程的公开课并不少。真正稀缺的是另一种东西：有人把 syllabus、作业、答案、实验、工具版本和访问条件逐项看过以后，愿意直接告诉你这门课能不能独立完成，缺口在哪里，以及什么时候应该换课。

一个视频能播放，不等于一门课能自学。一份 lab handout 能下载，也不等于你拥有课程账号、校内仪器、私有仓库或安全的实验环境。旧课程可能资料最完整，却依赖已经过时的软件；当前课程可能仍在开设，却把作业反馈放在登录或付费之后。EEDIY 要处理的就是这些不够漂亮、但会决定你能否学下去的细节。

本站有意沿用 [CSDIY](https://csdiy.wiki/) 的内容范式。值得借鉴的并不只是导航和配色，而是把一门具体课程当成一篇值得认真维护的文章：讲清资源、作业、项目、体验边界，并把纠错留给社区。EEDIY 把这套做法移到电子工程，同时补上硬件成本、测量证据和实验安全。

## 为什么还需要这份指南

课程清单只能回答“有什么”。真正开始学习以后，问题会迅速变得具体：

- 题目公开了，答案或 grader 是否也公开？没有反馈时，怎样知道推导错在模型还是代数？
- 实验写着“使用示波器”，实际是否还要求专用教学台、校内 EDA、许可证或助教签字？
- 页面展示的是哪一年版本？当前课程是否已经改名、拆课、换平台或转为付费服务？
- 仿真可以验证哪一层结论？哪些测量、安全或制造问题不能靠一张漂亮曲线替代？
- 学完后应留下什么：首次答卷、更正记录、波形、原始数据、版图检查，还是一份能复现的项目报告？

每份深度导读都应当给出这些问题的课程特有答案，而不是把同一套周数、项目模板和赞美句换个课名。

## 先说明我们知道什么，也说明不知道什么

EEDIY 目前是一项开放的编辑工程，不是一位作者的完整 EE 学习回忆录。这里不会为了模仿个人口吻而虚构“我学过”“我踩过坑”。页面会明确区分三种状态：

| 状态 | 它证明了什么 | 它还没有证明什么 |
| --- | --- | --- |
| 资料索引 | 课程身份、官方入口、材料范围和明显限制已经核对 | 尚未逐项审读作业，也不能单独作为选课结论 |
| 资料考察 | syllabus、结构、作业、实验、考试和版本已按一手资料审读 | 没有学习者记录时，不声称真实耗时或亲历体验 |
| 学习者复核 | 有可追溯的完成范围、产物、耗时和卡点 | 一个人的经历仍不能自动写成普遍规律 |

这条边界会让有些页面暂时显得简短，但比把批量生成的文字包装成成熟推荐更诚实。课程页底部的讨论和结构化反馈入口，就是把资料考察逐步变成真实学习记录的地方。

## 从哪里开始

不必先读完整个网站。选一个和自己当前状态最接近的入口，完成一个小闭环，再回来改路线。

- 几乎从零开始：做[起步诊断](getting-started.md)，先找到代数、三角函数、微积分、物理或计算工具中的第一个断点。
- 数学与物理基础尚可：从[数学基础](math-foundations.md)和[全局路线](roadmap.md)进入电路与信号主干。
- 已学过基础电路：打开[课程总览](courses/index.md)，比较一门理论课和一门有反馈的实践课，不要只看学校或课程等级。
- 已有研究或求职目标：从[学习路线](routes/index.md)倒推最短先修链，并用[项目实践指南](guides/projects.md)规定可审查的产物。

## 电子工程不是一条直线

不同方向共享数学、物理、计算和测量基础，但各自沿不同的深度轴发展。先建立共同语言，再选择一到两个主方向，同时保留对其他方向的接口级理解。

| 方向 | 核心问题 | 典型完成证据 |
| --- | --- | --- |
| 电路与模拟电子 | 如何权衡噪声、带宽、功耗和非线性？ | 放大器、滤波器、电源与测量报告 |
| 数字系统与 FPGA | 如何把行为规格变成时序正确的硬件？ | HDL 模块、验证平台与时序报告 |
| 嵌入式与实时系统 | 硬件与软件如何在资源和时序限制下协同？ | 驱动、数据记录器与硬件在环测试 |
| 信号、通信与信息论 | 如何从不完整、有噪声的观测中恢复信息？ | DSP 流水线、链路预算与误码实验 |
| 控制与机器人 | 如何让动态系统稳定、可观测并达到目标？ | 系统辨识、控制器与闭环测试 |
| 电磁、射频与光子学 | 场和波如何在结构、介质与频率之间传播？ | 场仿真、天线或无源网络分析 |
| 电力与能源 | 如何安全、高效地转换、传输和管理能量？ | 变换器仿真、热分析与保护方案 |
| 半导体与集成系统 | 材料和器件如何形成可制造、可验证的系统？ | 器件模型、版图检查与 PVT 分析 |

## 自学的自由与代价

自学的好处很直接：你可以暂停、重放、换一个教师的解释，也可以在一个真正没懂的模型上多停几天，而不是被学期进度拖着走。公开课程还允许你比较不同学校对同一个主题的取舍，这对跨越器件、系统和软件边界尤其有用。

代价也同样直接。你通常没有助教、同伴、统一实验台和隐藏测试；不知道自己错了，往往比不会做更危险。EE 还多一层现实约束：有些实验需要昂贵仪器、受控工艺或训练过的监督者，不能靠意志力补齐。本站提供的路线不能替代大学实验室、教师反馈或正式资质，它只能帮助你看清哪些部分公开可做，哪些部分需要换一种证据，哪些部分应该停下。

## 一份课程页应该把话说清楚

打开课程页时，先找六件事：

1. 真实的讲次、单元、作业、实验、考试或项目，而不是课程宣传语。
2. 和相邻候选课的区别：第一次学、补缺和进阶分别该选谁。
3. 答案、grader、助教反馈、器材和软件究竟公开到哪一步。
4. 开始前能做的诊断，以及失败后应该补哪一段先修。
5. 能证明完成的具体产物，并明确哪些任务是 EEDIY 补充而非官方作业。
6. 版本、登录、付费、许可和安全边界，以及最近一次核验日期。

等级描述的是**当前公开版本对独立学习的可执行性**，不是对学校、教师或学科价值的排名。

!!! danger "先读安全指南，再接通电源"
    课程中出现实验，不代表它适合家庭环境。市电、储能电容、高功率电池、旋转机械、激光、射频功率与高温工艺都需要匹配风险的设施、训练和监督。无法确认边界时，只做仿真或使用经验证的低能量教学平台。开始前请阅读[实验安全指南](guides/safety.md)。

## 评论、纠错与真实学习记录

每个课程页都使用稳定课程 ID，把中英文讨论连到同一条公开记录。可以报告失效链接、版本变化、作业结构和亲历卡点，也可以提交不含答案的学习产物。事实纠错需要一手来源；亲历经验需要说明完成范围；凭据、私人联系方式、受限答案和未授权副本不应进入评论。

如果一条反馈被核实，它应当回到正文，而不是永远埋在评论区。具体流程见[贡献指南](contributing.md)。

## 今天就开始

- 只有 30 分钟：完成[起步诊断](getting-started.md#start-diagnostic)，只修第一个失败项。
- 正在上一门课：用对应课程页检查缺少的是题目、反馈、工具还是实验条件。
- 已有项目想法：购买器件前先写[一页规格](guides/projects.md#project-spec)。
- 发现事实不对：在课程页底部选择最接近的反馈类型，并附上证据。
