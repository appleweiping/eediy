## 使用路线前

- 同一知识缺口选一套主材料即可；已经具备相应能力时，直接从阶段检查开始。
- 阶段末的题目或项目用来判断知识是否接得起来，不用为了凑数量重复做同类作业。
- 市电、高压、射频辐射、激光、化学品或加工设备只在合规设施和合格人员现场监督下操作；条件不足时改用解析、仿真或公开数据。
