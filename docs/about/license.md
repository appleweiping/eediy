# 许可与引用

EEDIY 把“站点代码”“原创编辑内容”和“第三方资源”分开处理。链接到免费公开材料，不代表该材料进入本项目的许可范围。

## 许可分层

| 内容 | 默认许可 | 说明 |
| --- | --- | --- |
| 配置、脚本、样式与站点代码 | MIT License | 可以使用、修改和分发，需保留版权与许可文本 |
| 原创指南、筛选说明与路线文字 | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.zh-hans) | 可以分享与改编，需署名、链接许可并标注修改 |
| EEDIY 名称与品牌标志 | 项目标识 | 许可不授予商标权，不得让衍生版本看起来像官方发布 |
| 第三方课程、视频、书籍、论文、代码、数据和标志 | 各权利人条款 | 本项目通常只提供链接与原创概述，不重新授权 |
| 贡献者提交的第三方片段 | 来源许可与合理引用边界 | 必须注明来源、范围与适用许可；无法确认时不收录 |

## 怎样引用本网站

建议包含页面标题、贡献者、许可、页面链接、访问日期和修改说明：

> EEDIY Contributors，《页面标题》，CC BY 4.0，访问于 YYYY-MM-DD，页面链接。修改：翻译并节选。

引用课程事实时，最好同时引用课程的官方原始页面。EEDIY 的核验记录能说明我们在某日观察到什么，但官方页面才是课程名称、政策和材料的权威来源。

## 可以与不可以

### 可以

- 在课程规划、讲义或文章中改编原创路线并按 CC BY 4.0 署名；
- 在自己的项目中复用站点代码并保留 MIT 许可；
- 链接到具体页面，说明你采用或不同意的筛选判断；
- 提交翻译、更正和来源清晰的少量引用。

### 不可以

- 把被链接的整套课程、教材、视频或答案复制到本仓库；
- 移除第三方版权、许可证、作者或访问限制；
- 把 EEDIY 的链接描述成对第三方材料的再授权；
- 使用名称、标志和页面外观误导读者，把衍生站点冒充官方版本；
- 上传个人数据、密钥、受控技术资料或违反课程诚信规则的内容。

## 链接失效与权利请求

发现链接失效、署名错误、许可不兼容或材料不应出现时，请提供：

1. 准确页面和相关段落；
2. 你与材料的关系（如适用）；
3. 原始权利或许可证据；
4. 希望更正、替换还是移除；
5. 安全或法律紧急程度。

维护者应先避免进一步传播有争议的材料，保留必要的审计记录，核对来源并公开记录结论。善意的权利请求不要求权利人先提出完整替代文案。

完整条款见仓库根目录的 `CONTENT_LICENSE.md`、`LICENSE` 与

副本。
