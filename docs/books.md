# 教材与长期阅读

教材适合承担定义、推导、例题和长期参考，但不能独自提供完整的学习闭环。先从[课程导航](courses/index.md)确认课程目标、先修、公开资源和反馈条件，再决定需要哪一本主教材、哪些章节以及怎样验证理解。本页不按名气罗列书目，而是给出一套能持续使用的选择与阅读方法。

## 教材在自学系统中的角色

一套稳健的学习材料通常包含四种角色：

| 角色 | 解决的问题 | 使用边界 |
| --- | --- | --- |
| 主教材 | 建立统一符号、概念顺序和核心推导 | 同一阶段只保留一本，避免在不同符号体系之间频繁切换 |
| 参考教材 | 为难点提供另一种解释或更完整证明 | 按问题查阅，不从第一页重新开始 |
| 习题来源 | 暴露理解缺口并训练计算、建模和论证 | 必须安排答案、数值结果或同伴评审作为反馈 |
| 工程手册 | 查询器件、公式、单位、近似和设计范围 | 适合查证，不替代概念学习与推导 |

课程页面中列出的讲义、教材、练习和考试已经按资源类型分开记录。选择前先阅读页面的“公开资源完整度”“风险与缺口”和最近复核日期。

## 选择教材的五个门槛

1. **目标匹配：**目录必须覆盖当前阶段的可验证能力，而不只是名称与方向相似。
2. **先修可承受：**随机抽取三页推导，确认符号、数学工具和物理背景大部分能够跟上。
3. **练习可反馈：**至少存在一种可靠反馈方式，例如答案、测试、仿真、测量或结构化互评。
4. **版本可追踪：**记录版次、章节编号和勘误来源；多人协作时使用同一版本。
5. **访问可持续：**在开始长期计划前确认许可、费用、地区、格式和无障碍条件。

如果一本教材在前三项中有两项不满足，应先更换主教材或补先修，而不是依靠增加阅读时长硬撑。

## 按任务建立书架

不要一次采购完整专业书架。先让每一项材料对应一个当前任务：

| 当前任务 | 优先入口 | 阅读重点 |
| --- | --- | --- |
| 补微积分、线性代数与微分方程 | [工程数学](courses/mathematics/index.md) | 定义、典型推导、代表性习题和量纲检查 |
| 建立电路模型 | [电路基础](courses/circuits/index.md) | 建模假设、符号约定、极限情形和可测量量 |
| 学习信号、系统与变换 | [信号与系统](courses/signals-systems/index.md) | 时域与频域之间的对应、稳定性和物理解释 |
| 进入概率与随机过程 | [概率、统计与随机过程](courses/probability-statistics/index.md) | 条件、分布、期望、估计与不确定性 |
| 处理场、波与边界 | [电磁场](courses/electromagnetics/index.md) | 坐标系、边界条件、近似范围和能量关系 |
| 为项目查工具与记录方法 | [实践指南](guides/index.md) | 可复现环境、原始数据、验证步骤和安全边界 |

先打开方向页，再比较主线、替代和补充课程。课程角色描述的是怎样组合材料，不代表需要把所有材料都读完。

## 不同阶段怎样读

### 基础阶段

以例题和短练习驱动阅读。每读完一个定义，立刻写出一个正例、一个反例和单位或几何解释；每读完一节，完成少量能覆盖不同错误类型的题目。此时追求的是符号熟练度和基本模型，不是证明数量。

### 核心阶段

把章节内容放入真实系统。学习微分方程时连接 RC、RLC 或机械类比；学习线性代数时连接状态空间、最小二乘或网络方程。建议同步使用[数值计算与模型验证](guides/numerical-computing.md)，用计算结果检查手工推导，而不是用软件替代推导。

### 方向深入

改为问题驱动阅读：先写出研究或设计问题，再定位所需章节、假设与定理。保留符号表和依赖图，记录某个结论依赖哪些条件。遇到跨书符号冲突时，以自己的项目符号表为准，并注明转换关系。

### 项目阶段

教材退到参考位置。项目规格、数据和测试结果成为主线，教材用于解释异常、选择模型和确认适用范围。按照[项目实践](guides/projects.md)保留设计决策、失败尝试和验收证据。

## 一章的闭环

一次有效的章节学习可以按以下顺序完成：

1. 用一句话写出本章要解决的工程问题。
2. 浏览标题、图和例题，列出已有知识与缺口。
3. 精读核心定义和推导，标注假设、单位与边界条件。
4. 合上材料，重建一段关键推导或概念图。
5. 完成至少一道概念题、一道计算题和一道迁移题。
6. 用答案、仿真、测量或互评校正，并把错误分类。
7. 写一段“何时不能使用本章模型”的说明。

只有能够重建、应用和校正，才把章节标为完成。阅读页数和划线数量不构成完成证据。

## 练习与答案

有答案时，先独立完成并保留原稿，再用另一种颜色记录更正原因。没有答案时，可以采用三级反馈：

1. 先做量纲、符号、极限情形和数量级检查。
2. 再用第二种方法交叉验证，例如解析解与数值解、节点法与功率平衡。
3. 最后提交给同伴或教师检查论证、假设和表达。

错误日志只记录可行动的信息：错误类型、触发原因、正确检查方法和下一次复习日期。[开始学习](getting-started.md)提供了建立反馈循环和四周节奏的具体方法。

## 数字版、纸质版与许可

选择格式时关注实际工作流。数字版便于搜索、引用和携带；纸质版便于长时间推导和并排阅读。无论格式如何，都应保存准确的书目信息和版次，不公开上传受限内容，不把个人购买权限当作可共享许可。需要引用、整理或贡献资料时，遵循[文献检索与证据评估](guides/literature-research.md)和[贡献指南](contributing.md)。

## 站内阅读入口

- 从[工程数学课程页](courses/mathematics/index.md)建立数学主线，并查看每门课程已经核验的讲义、练习与教材记录。
- 从[物理基础](courses/physics/index.md)补充力学、电磁学和波动背景。
- 从[全局路线](roadmap.md)判断当前只需基础理解还是方向深度。
- 数学基础不稳时先执行[EE 数学基础](math-foundations.md)；已有共同核心后再进入[EE 进阶数学](math-advanced.md)。
- 使用[数据与实验记录](guides/data-lab-notebooks.md)保存计算、图表、参数和更正过程。

## 完成标准

当你能为当前阶段明确写出一本主教材、使用章节、配套练习、反馈方式、版本信息和停止条件时，教材计划才算可执行。四周后检查完成率、错误分布和项目迁移效果；如果阅读很多却无法完成代表性任务，应减少材料并修复反馈链。
