# EE 数学基础

EE 本科的数学基础不必按照“学完微积分，再学线性代数，最后开始专业课”的顺序完成。电路会很早用到导数、积分和复数，信号会把微分方程、复指数与卷积放在一起，电磁场需要向量分析和曲面积分，控制则不断往返于状态方程、特征值和概率模型。更合适的安排是先建立一条可靠的微积分主线，同时尽早并入线性代数和低阶动态系统；哪门 EE 课先开始，决定下一段数学学到多深。

下面推荐的课程都有独立的课程页，那里记录了公开材料、答案覆盖和版本限制。本页解决的是另一件事：这些课该怎样组合，以及哪些内容不值得在专业课之前一次学完。

## 一条不必串行完成的主线

如果高中代数、三角函数、指数对数和复数运算还不稳定，先用短材料补到能够处理 \(e^{j\theta}\)、分式和二元方程组；这些内容不值得伪装成一门大学课。随后从 [MIT 18.01SC Single Variable Calculus](courses/mathematics/001-18-01sc.md) 开始微积分线。它的 [OCW Scholar 课程主页](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/) 把讲解、例题、习题、四次单元考试和期末放在同一套结构中，适合第一次完整学习。对 EE 而言，最先要拿到的是导数与局部线性化、定积分与累积量、指数响应以及 Taylor 近似，而不是把所有积分技巧练到竞赛熟练度。

学到基本积分后即可进入 [MIT 18.02SC Multivariable Calculus](courses/mathematics/002-18-02sc.md)，同时开始 [MIT 18.06SC Linear Algebra](courses/mathematics/004-18-06sc.md)。18.03SC 微分方程也不必等到 18.02SC 全部结束：单变量微积分和基本矩阵运算可靠后，就可以先学一阶方程与二阶常系数方程，再把向量场和多重积分留在另一条线上继续。这样安排的好处很实际——当电路课第一次写出 RC 方程、当信号课第一次讨论特征函数时，你已经见过这些对象，而不是临时查一张公式表。

如果微积分已修过但忘得不多，不建议把两门 Scholar 课从第一段视频重新播放。先看课程页列出的单元范围，直接做原课 problem set 或 exam；错在变量代换、积分域或级数误差时，再回对应单元。课程材料的完整性应当用来缩短回补路径，而不是强迫所有人重复同样的课时。

## 18.01SC 与 18.02SC 面向不同的建模对象

[18.01SC](courses/mathematics/001-18-01sc.md) 最适合用一维动态量来学：电容电流与电荷、功率与能量、器件工作点附近的小信号近似，都会把导数、积分和 Taylor 展开变成可解释的工程关系。课程官方给出的完整学习量级约为 150 小时，但这是包含阅读、练习和考试的整课估计，不是固定学期表。已经能独立处理指数衰减、分部积分、无穷级数与余项的人，可以从后半程的应用和考试开始；希望把微积分学成证明课的人则应另选偏理论的课程，18.01SC 的优势是完整、自洽和适合独立练习。

[18.02SC](courses/mathematics/002-18-02sc.md) 的难点通常不是多一个自变量，而是几何方向。其 [官方课程页](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/) 从向量、矩阵与空间曲线推进到梯度、重积分、线积分和曲面积分，最后用 Green、Gauss 与 Stokes 定理把局部量和边界量联系起来。对电磁方向，后两单元尤其重要：电荷密度的体积分、场沿路径的功、穿过曲面的通量，以及散度和旋度，都依赖坐标、法向和方向约定。课程的 Physics Applications 还直接触及 curl 与 Maxwell 方程。

若下一门课是电路或信号，18.02SC 前半段足以先开路，剩余内容可以与专业课并行；若下一门课是[电磁场](courses/electromagnetics/index.md)，则应把向量场、线积分、曲面积分与三大积分定理学完整。仅会对二元函数求偏导并不足以处理场问题，而一开始就追求微分形式与流形也没有必要。

## 18.06SC 应当尽早加入，而不是等微积分结束

[MIT 18.06SC Linear Algebra](courses/mathematics/004-18-06sc.md) 的 [Scholar 版本](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) 有 31 组按主题组织且带解答的习题，以及三次单元考试和一次期末。官方目录把 18.02 列为先修，但课程说明也明确指出完成本课并不需要微积分；真正需要的是向量、矩阵和三维坐标。因此，只要基本代数可靠，18.06SC 完全可以和 18.02SC 并行。

对 EE 学生，消元只是入口。节点电压法把网络写成 \(Ax=b\)，最小二乘处理过定约束与测量拟合，特征值和特征向量解释耦合系统的模态，SVD 则会在阵列、信号压缩、系统辨识和数值病态中反复出现。每学一种分解，都应同时问矩阵代表什么物理关系、解是否唯一、扰动会不会被放大。只会在小矩阵上算行列式，到了控制与信号课仍然会重新卡住。

18.06SC 没有官方编程实验或项目，这不是缺点。先把原生题目和几何解释做扎实，随后把同一方法带入专业课即可：在[电路](courses/circuits/index.md)中解一个节点方程，在[控制](courses/control-systems/index.md)中读状态矩阵的模态，或在带噪数据上比较正规方程与 QR/SVD。数值软件适合核对，不应替代对列空间、残差和条件性的解释。

## 18.03SC 是电路与信号之间最重要的一座桥

[MIT 18.03SC Differential Equations](courses/mathematics/003-18-03sc.md) 的 [Fall 2011 Scholar 版](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/) 共有 38 个 session。四个单元依次处理一阶建模，二阶方程、振荡与频率响应，Fourier/Laplace/卷积，以及线性系统、特征值、相图和矩阵指数。它比“按方程类型背解法”的教材更适合 EE，因为同一个问题会从输入、状态、暂态与稳态的角度反复出现。

最合适的伴随对象是一只低阶电路。学一阶方程时用 RC 阶跃响应理解初值和时间常数；学二阶方程时用 RLC 区分欠阻尼、临界阻尼和共振；学 Laplace 与卷积时求出同一系统的冲激响应，并用卷积表示零状态响应；进入一阶系统后，再用状态向量与特征模态重述它。这样，数学表达是在描述同一个对象，而不是四套互不相干的公式。

18.03SC 与[信号与系统](courses/signals-systems/index.md)有意重叠，但两者不能互换。前者着重从模型建立并理解微分方程，后者还要处理离散时间、采样、Z 变换和更系统的 LTI 表示。ODE、复指数和卷积尚不牢固时，先把 18.03SC 做到第三单元；这些已经顺手而目标转向采样和系统互连时，就应把时间交给信号课。

## 概率应按“系统”还是“数据”来选

第一次系统学习工程概率，默认选择 [MIT 6.041SC Probabilistic Systems Analysis](courses/probability-statistics/007-6-041sc.md)。它的 [Resource Index](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/pages/resource-index/) 把 25 讲、recitation、tutorial、11 份带解答的 problem set、测验和期末组织在一起。从随机变量、条件期望到 Poisson 过程、有限 Markov 链与极限定理，这条线最容易接到通信、随机信号、器件噪声和估计问题。它并不完整讲授宽平稳过程、自相关和功率谱；这些内容仍应在后续随机信号课程中学习。

如果近期目标是实验数据、参数区间、假设检验、bootstrap 或回归，则 [MIT 18.05 Introduction to Probability and Statistics](courses/probability-statistics/006-18-05.md) 更合适。其 [Spring 2022 课程](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/) 没有授课视频，却有连贯的课程读物、reading questions、11 份带解答的题集和 10 次 R studio。它把 Bayesian 与 frequentist 推断都放进同一条学习线，特别适合传感器重复测量和实验数据；代价是需要愿意读讲义并写 R，而不能把视频当作唯一入口。

两门课的多元微积分门槛都不能忽略：6.041SC 官方先修列出 18.01 与 18.02，18.05 官方先修为 18.02。若多重积分、二维积分域和变量变换仍不稳，先继续 18.02SC，再开始连续随机变量部分。

[Cornell ECE 3100](courses/probability-statistics/087-ece-3100.md) 的题目很有随机信号语境，但公开档案缺少讲义、项目和大部分解答，适合学完 6.041SC 或 18.05 后补题，不适合承担第一次讲授。6.041SC 与 18.05 也不必都完整修完：先选与下一门 EE 课更接近的一门，另一门在需要随机系统或统计推断时补对应部分。

## 让第一门 EE 核心课决定交错方式

- **电路起步：** 18.01SC 学到微分与积分后即可进入[电路基础](courses/circuits/index.md)，同时用 18.03SC 的一、二阶系统解释 RC/RLC。18.06SC 伴随节点分析学习，不必先等特征值章节结束。
- **信号与控制：** 先把 18.03SC 的复指数、频率响应、Laplace 与卷积连起来，18.06SC 并行学习投影和特征值；出现噪声、估计或随机输入后，再接 6.041SC。若状态空间仍只是一组符号，回到同一低阶系统比较微分方程、传递函数和矩阵表示。
- **电磁场：** 18.02SC 是主轴，尤其是向量场、线/面积分、散度、旋度与积分定理；18.03SC 只为低维动态模型或分离变量后出现的 ODE 提供语言，一般波动与边值问题还需要本页基础范围之外的偏微分方程方法。复数相量则应在进入频域场之前补齐。数值场图不能代替边界条件、材料假设与守恒检查；实体工作默认从分析和仿真开始，不接触市电、高压、强 RF 或来源不明的微波装置。
- **实验与仪器：** 完成 18.02SC 后可以较早加入 18.05，把同一组测量数据贯穿分布、区间、检验与回归。需要噪声过程和滤波时，再转向 6.041SC 及后续随机信号课程。

另有一门值得横向穿插的 [MIT 6.055J The Art of Approximation](courses/mathematics/018-6-055j.md)。它的 [公开课程](https://ocw.mit.edu/courses/6-055j-the-art-of-approximation-in-science-and-engineering-spring-2008/) 用量纲分析、极限情形、尺度律和平衡法训练“先估再算”。学过 18.01SC 的基本内容后即可选读，不必等全部数学结束；但它是一门判断模型尺度的补充课，不能替代微积分、线性代数或微分方程主线。

这些基础课的作用是让专业课中的方程不再陌生。进入[全局路线](roadmap.md)后，若真正的困难来自留数、奇异值、严格概率或数值病态，再到[EE 进阶数学](math-advanced.md)选择对应课程；没有具体问题时，不必提前完成整套进阶数学。
