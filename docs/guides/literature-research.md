# 文献检索与证据评估

搜索不是收集最多链接，而是找到足以支持或推翻一个工程判断的证据。课程页、教材、标准、数据手册、论文、应用笔记和论坛回答承担不同角色，不能用数量代替来源质量。

## 目的与学习成果

- 把宽泛主题拆成可检索、可判定的问题；
- 区分原始研究、标准/数据手册、综述、教学材料和经验讨论；
- 保存稳定书目信息、版本、页码和访问日期；
- 用证据矩阵比较方法、条件、结果和限制；
- 识别利益冲突、撤回、过期标准和不可复现实验。

## 最小环境

- 支持短语、布尔与站点筛选的搜索入口；
- 一个可导出开放书目格式的参考管理方式；
- 纯文本检索日志与证据矩阵；
- 机构图书馆或合法开放获取路径；付费访问不是核心要求。

不绕过访问控制，也不把未获许可的全文上传公开仓库。工具和索引会变化，应记录实际检索日期与数据库名称。

## 学习顺序

1. **定义问题：**写出对象、输入、输出、条件、比较项和决定阈值。
2. **建立词表：**列同义词、缩写、旧称、标准编号和排除词。
3. **来源分层：**先找教材/综述建立词汇，再回到标准、数据手册和原始论文。
4. **前后追踪：**检查引用文献与后续引用，寻找修正、复现和反例。
5. **证据提取：**记录测试条件、样本、指标、误差、限制和资助关系。
6. **停止规则：**新来源不再改变结论或关键空白已明确时停止。

## 验证任务：比较两种滤波实现

选择一个低风险问题，例如“给定采样率和资源限制时，FIR 与 IIR 的权衡”：

1. 写包含性能、资源、稳定性和延迟的决策问题；
2. 建立中英文关键词和排除条件；
3. 收集至少一项教学基准、一项原始/权威资料和一项工具实现资料；
4. 用证据矩阵统一记录条件，不直接比较不同定义的指标；
5. 找到至少一条反对初始偏好的证据；
6. 写一页结论，区分事实、推断、待验证假设和下一项实验。

验收要求每个关键判断都能定位到来源中的具体章节、表、图或数据，而非只有首页链接。

## 常见失败与排查

- **结果太泛：**加入器件、拓扑、指标、条件或标准编号。
- **只看搜索摘要：**打开原文并确认摘要没有脱离适用条件。
- **引用链自我循环：**回到最初测量或规范，识别重复转述。
- **只收支持证据：**明确搜索反例、负结果和边界条件。
- **不同指标直接比较：**统一定义、单位、带宽和测试环境。
- **链接失效：**保存 DOI、报告号、版本、作者、标题和合法存档信息。

## 可复现证据

- 研究问题、纳入/排除条件和停止规则；
- 数据库、检索式、筛选器和检索日期；
- 去重后的书目库与稳定标识；
- 筛选日志和排除原因；
- 含条件、指标、结果、限制的证据矩阵；
- 撤回/更正、标准版本和数据手册修订检查；
- 事实、推断和未决问题分开的综合结论。

## 成本、许可与无障碍

优先公开获取、作者存档、图书馆和标准的合法访问途径。记录需要付费或机构账号的来源，并尽量提供同等学习目标的开放替代。引用不等于获得再分发许可。

保存可由屏幕阅读器读取的文本笔记，不把结论只放在扫描图中。对视频或长文记录章节、页码或时间点；低带宽时先共享书目和摘要矩阵。

## 安全边界

- 不执行来源不明论文附带的代码、固件或脚本，先隔离并审阅；
- 不把论坛建议当作市电、高压、医疗或电池安全依据；
- 数据手册典型值不能替代最差额定值审查；
- 涉及出口管制、隐私或安全漏洞的材料遵守适用规则；
- 不伪造访问、实验复现或同行评审状态。

## 完成清单

- [ ] 问题、指标、条件与决定阈值明确。
- [ ] 检索式、数据库、日期和筛选条件已保存。
- [ ] 来源覆盖教学、权威/原始与实现层。
- [ ] 至少主动寻找一项反例或负证据。
- [ ] 关键结论可定位到具体证据。
- [ ] 标准、修订、撤回和许可已检查。
- [ ] 事实、推断、假设与空白分开表达。
- [ ] 书目与证据矩阵可导出和复查。
