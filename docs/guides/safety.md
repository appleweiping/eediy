# 实验安全

!!! danger "本页不是安全资质或操作授权"
    本指南只能帮助识别风险，不能替代所在机构的培训、标准操作程序、设备手册、风险评估或合格人员监督。若规则冲突，采用更严格的要求。没有受训监督、合格设施或明确额定值时，不接触市电、暴露带电部件、高能储能、强激光、射频功率、旋转机械、真空、高温或危险化学品。

安全不是项目结束时补写的一段话，而是决定**做不做、在哪里做、由谁做、怎样停止**的设计输入。

## 先判断能量与危害

| 类别 | 典型活动 | 默认决策 |
| --- | --- | --- |
| 绿色：软件与无源分析 | 手算、仿真、公开数据、未通电外观检查 | 可独立进行；仍需保护数据与视力/工效 |
| 蓝色：受限低能量教学实验 | 保护良好的低能量电源、已知元件、保守限流 | 完成额定值与接线检查后进行，首次操作最好有人复核 |
| 橙色：需要专门控制 | 较大电池组、电机、加热、强磁场、焊接烟雾、未知接地 | 需要书面风险评估、匹配设施和受训监督 |
| 红色：非家庭自学范围 | 市电、暴露高压/高故障电流、带电检修、Class 3B/4 激光、射频发射功率、洁净室化学工艺 | 仅在获准实验室由合格人员按正式程序执行 |

“低于某个电压”不等于绝对安全。储能电容、短路电流、潮湿环境、皮肤破损、尖锐探针、发热、机械能与电池化学都可能使低电压系统造成严重伤害。

## 五个不可跳过的问题

1. **能量从哪里来？** 包括电源、电池、电容、感性回扫、机械惯量、热、光与压力。
2. **怎样隔离和释放？** 断电并不代表已放电；写出验证无能量状态的方法。
3. **最坏失效是什么？** 短路、反接、过热、器件爆裂、失控运动、光束反射、烟雾或软件误动作。
4. **谁有资格复核？** 明确监督者、实验室规则和停止权限。
5. **发生异常时如何退出？** 在上电前确定断电装置、撤离路径与本地应急流程。

## 工作中的基本纪律

### 电气与储能

- 默认断电工作；固定设备需要遵守所在机构的能源隔离、挂牌与验证程序。
- 断开电源后，用匹配且已知正常的仪器验证状态；不要把开关位置当作无电证明。
- 电容、电池与感性负载可能在断电后保持或产生能量。使用设计好的泄放、保护和验证方法。
- 修改接线、移动探头、换量程或更换器件前先断能。
- 不绕过保险、联锁、保护地、隔离、外壳或设备保护。

美国职业安全与健康管理局的规则把断电作为暴露带电部件工作的默认控制，并规定未断电部件只能由合格人员使用匹配措施处理；学习者应把这当作最低警示，而不是家庭实验许可。参见 [OSHA 1910.333](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.333)。

### 电池

- 使用来源可靠、规格匹配、带适当保护的电池和充电器；
- 不使用鼓包、破损、过热、漏液或来源不明的电池；
- 防止端子被工具、首饰或散落金属短路；
- 充电、储存、运输和处置遵守制造商及当地规则；
- 不拆解电芯，不把工业散装电芯当作无保护消费电池使用。

高能量密度电池可能引发过热、灼伤、火灾或爆炸；美国消费品安全委员会特别警告散装 18650 电芯在短路、储存、运输和充电中的风险。参见 [CPSC 高能量密度电池工作页](https://www.cpsc.gov/Regulations-Laws--Standards/Voluntary-Standards/Batteries-Fire-High-Energy-Density)与[散装电芯警示](https://www.cpsc.gov/Newsroom/News-Releases/2021/CPSC-Issues-Consumer-Safety-Warning-Serious-Injury-or-Death-Can-Occur-if-Lithium-Ion-Battery-Cells-Are-Separated-from-Battery-Packs-and-Used-to-Power-Devices)。

### 焊接、返修与材料

- 使用稳定支架、耐热表面、护目镜和靠近源头的有效烟雾控制；
- 烙铁离手即归位，冷却前视为高温；切脚时控制飞散方向；
- 作业区不饮食，结束后洗手，避免把含铅或其他污染带入生活区域；
- 先阅读焊料、助焊剂、清洗剂和粘合剂的安全数据表。

松香基助焊剂烟雾可能造成职业性哮喘，不能用普通风扇把烟吹向他人来替代源头控制。参见英国健康与安全执行局的[焊接人员与松香基助焊剂烟雾说明](https://www.hse.gov.uk/asthma/solderers.htm)。

### 激光、射频与电磁场

- 不直视任何激光束，也不依赖可见亮度判断功率；
- 不使用未知类别、改装或标签不完整的激光；
- Class 3B/4 或任何可能产生危险直射/镜面反射的系统，只能在合格激光设施中使用；
- 发射射频前确认许可、频段、功率、负载和人员暴露控制；入门项目优先接收、仿真或屏蔽的小信号测试；
- 强磁场会吸引工具、影响植入式医疗器械并储存机械能，需专门控制。

美国食品药品监督管理局指出，激光亮度不能可靠表示功率，3B/4 类可能立即造成眼、皮肤或火灾风险。参见 [FDA 激光常见问题](https://www.fda.gov/radiation-emitting-products/laser-products-and-instruments/frequently-asked-questions-about-lasers)。

### 机械、热、真空与化学

- 执行器、无人机、机器人和电机应先限制速度、扭矩、行程和测试区域；
- 加热器、功率器件和负载在断电后仍可造成灼伤；
- 真空腔体、压力容器、制冷剂、刻蚀/清洗化学品和微纳加工设备不属于无监督家庭实验；
- 安全眼镜不是万能控制，优先消除、替代、隔离和工程控制，再按正式评估选择个人防护。

## 停止条件

<div class="ee-status ee-status--stop">
  <strong>立即停止并在安全距离断能：</strong>出现烟、火花、异常气味、膨胀、漏液、快速升温、保护装置动作、不可解释的高电流、不受控运动、结构破损、失去仪器参考或任何超出计划的状态。不要为了“再测一次”重新上电。
</div>

停止后：

1. 在不接近危险源的前提下断开能量；无法安全断能则撤离并启动本地应急流程；
2. 不触碰仍可能带电、发热、泄压或释放化学物质的装置；
3. 需要医疗、消防或专业处置时，联系所在地的紧急服务和实验室负责人；
4. 保留现场与数据，在合格人员复核并更新风险控制前不恢复实验。

不要直接接触仍与电源相连的触电者。只有在自身安全且能做到时才切断电源；随后按当地急救培训和应急调度指引处理。

## 设计评审中的安全证据

项目报告至少附：

- 危害、能量源和受影响对象；
- 消除、替代、隔离、工程控制、程序与个人防护的选择顺序；
- 元件与仪器额定值表；
- 正常、单点失效和误操作测试；
- 联锁、保险、限流、泄放和热保护的验证；
- 停止条件、监督者和恢复批准；
- 遗留风险与明确禁止的使用场景。

安全评审不是“已阅读注意事项”的勾选框，而是可检查的设计证据。
