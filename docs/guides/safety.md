# 实验安全

!!! danger "这不是操作授权"
    本页不能替代所在机构的培训、设备手册、标准操作程序、针对具体任务的风险评估或合格人员监督。规则不一致时采用更严格的一条。没有合格设施、明确额定值和受训监督时，不接触市电、暴露高压、高能储能、3B/4 类激光、危险化学品或无防护旋转机械。

开始实验前，先沿着可能的路径追踪电、热、光、机械或化学能会怎样到达人，再判断自己是否有资格、有设施控制它。护目镜只是某些场景中的一道防线，不能替代这一步。对学生最重要的能力往往是识别停止条件，而不是背一串通用阈值。

## 先问最坏情况下会释放什么

沿着所有能量源走一遍：电源和反向供电、充电电容、电池、飞轮和电机、弹簧与压力、激光、射频、热表面、真空容器、化学反应。不要把“低电压”自动等同于低风险；大电流电源可造成电弧和灼伤，电容能量随 \(CV^2/2\) 增长，电池短路与旋转件失效也可能在很短时间内释放大量能量。

然后问三个实际问题：怎样隔离能量，怎样确认隔离真的生效，失控时能否在不靠近危险区的情况下切断。开关、软件停止键和控制信号都可能失效，不能代替物理隔离。若不知道最大电压、可用短路电流、储能、转速、激光等级或化学品身份，就没有足够信息开始实验。

第一次上电应从最小能量开始：限流、限压、短时间、单一模块，并让急停或断电装置在伸手可及且无需越过装置的位置。人在通电后要做的动作越多，设计越需要退回去增加 test point、护罩、远程控制或隔离。

## 市电、高压与储能：没有合格监督就不做

美国 OSHA 的[电气作业规则 1910.333](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.333)把可能暴露的带电部件断电作为默认做法，并把无法断电时的工作限制给具备相应训练和防护的 qualified person。这是职业场所的最低警示，不是家庭或普通教学实验中开展带电市电/高压作业的许可。对没有资质的学习者，边界很简单：使用成品、封闭、合规的电源；不打开一次侧，不悬浮普通接地示波器，不靠“一只手”或绝缘手套把危险工作变安全。

断电也不代表已经安全。OSHA 的[危险能量控制规则 1910.147](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.147)要求隔离意外启动和储存/残余能量，并在工作前确认隔离。电容必须使用设计好的放电路径，等待设备规定时间，再由适当额定的仪器确认；不要用螺丝刀短路。还要考虑 backfeed、多个电源、马达回生、机械惯性以及储能重新积累。

锂电池只在制造商规定的电压、电流、温度、充电器和保护系统内使用。CPSC 对[拆包散装 18650 电芯](https://www.cpsc.gov/Newsroom/News-Releases/2021/CPSC-Issues-Consumer-Safety-Warning-Serious-Injury-or-Death-Can-Occur-if-Lithium-Ion-Battery-Cells-Are-Separated-from-Battery-Packs-and-Used-to-Power-Devices)的警告指出，裸露端子短路或错误充电可导致热失控、火灾和爆炸。来源不明、外皮破损、膨胀、渗漏、异常发热或经历撞击的电芯不继续测试；移开人员并按机构的电池事故流程处置。

## 激光和化学品不能凭亮度或气味判断

FDA 的[激光等级说明](https://www.fda.gov/radiation-emitting-products/laser-products-and-instruments/frequently-asked-questions-about-lasers)指出，3B 类直射可立即伤眼并伤害皮肤，4 类连反射光也可能造成眼、皮肤和火灾风险。可见亮度不能证明功率安全。等级、波长、最大输出、光路、反射面或护目镜适用范围有一项不明，就停止；3B/4 类、开放光路或需要绕过 interlock 的工作，只能在合格实验室和受训监督下进行。摄像头或手机屏幕不是护眼措施。

化学品必须有可读标签和当前 SDS，并且现场具备 SDS 要求的通风、PPE、储存、泄漏处理与废弃路径；没有这些条件就不用。电子实验常见的助焊剂也不能凭“大家都在用”忽略。英国 HSE 的[焊接作业人员健康资料](https://www.hse.gov.uk/asthma/solderers.htm)说明松香基助焊剂烟雾可造成职业性哮喘，并要求采用有效的源头抽排等控制措施。普通风扇把烟吹向房间另一处，不等于局部排风。

未知溶剂、混装容器、没有相容性资料的清洗剂、无法控制的粉尘或需要特殊废液处置的工艺，都应回到有制度的实验室。闻到气味不是测量方法；出现眼鼻刺激、呼吸不适、皮肤接触或异常反应时，立即停止、离开暴露区并按 SDS 和所在机构的应急程序处理。

## 旋转机械、热与压力需要物理边界

OSHA 的[机械防护要求 1910.212](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.212)明确覆盖旋转部件、夹点、飞屑和火花等危险。护罩和 interlock 是控制的一部分，不是影响拍摄或调试的附件。电机、风扇、主轴或飞轮运行前，应固定工件和传感器，收起导线、工具、长发和宽松衣物，并把观察点放在危险区外。

只要需要把手或探头伸进运动范围、护罩无法就位、转子有裂纹或不平衡、夹具额定值不明、振动/声音突然变化，就先切断并等待全部运动停止。示波器地线、传感器线或 USB 线也可能被卷入；线束固定是机械安全的一部分。

烙铁、功率器件、加热台和散热器在断电后仍可能灼伤；压力和真空容器可能因材料、窗口或接头失效而突然释放能量。额定温度/压力、容器完整性、屏障或合格监督不明确时，不自行尝试。不要用临时玻璃容器、3D 打印件或未知胶粘剂承受压力、真空或高温，除非其具体设计经过相应工程验证。

## 看到这些情况就停止

停止不是失败，而是实验仍然受控的证明。以下任一情况出现，都不要以“再试一次”继续：

- 电路或设备的来源、额定值、接地方式、能量或安全类别无法确认；
- 需要接触暴露市电/高压、绕过安全联锁（interlock），或在没有合格人员现场监督时带电测量；
- 电容/电池/机械储能没有可验证的隔离与释放路径，或可能重新积累；
- 激光等级、光路终点、反射风险或防护眼镜波长/OD 不明；
- 化学品无标签/SDS，缺少要求的通风、泄漏与废弃条件；
- 旋转机械缺护罩，工件、线束或转子不可靠，人员必须进入危险区；
- 出现烟、火花、异味、异常发热、膨胀、渗漏、跳闸、失控运动、异常噪声或振动；
- 你疲劳、独处、无法解释下一步，或现场没有安全撤离和断能方式。

异常发生时使用预先安排的安全断能源，不要伸手抓装置、移动鼓包电池或触碰可能仍带电的人和设备。撤离危险区，阻止他人接近，并联系现场合格人员或当地应急服务。未经查明原因、修正控制措施和重新确认边界，不在同一次实验中恢复运行。
