# 数值计算与模型可信度

求解器返回 `success`，只说明它按自身规则完成了计算。它没有证明微分方程写对、单位一致、时间步足以解析最快动态，更没有证明这个模型能代表桌上的电路。数值计算真正困难的地方，是把模型错误、离散误差、浮点误差、参数不确定度和实物偏差分开。

一个串联 RLC 阶跃已经足够暴露这些问题。取状态 \(x=[i,\ v_C]\)，写成
\[
\frac{di}{dt}=\frac{v_s-Ri-v_C}{L},\qquad
\frac{dv_C}{dt}=\frac{i}{C}.
\]
它有可手算的初始斜率、稳态值、极点和能量方向，又可以故意制造刚性、尺度失衡或欠采样。先把这个小问题做可信，再把同样的方法带到场求解、控制器或器件模型。

## 运行代码前，先规定哪些物理事实不能被违背

给每个量写 SI 单位和合理数量级，明确初值、激励、符号约定与边界。对零初始条件的直流阶跃，电感电流不能瞬间跳变；长期稳态时电容电流应趋近零；无源 \(R>0\) 时储能不能无故持续增加。再由 \(L\)、\(C\)、\(R\) 手算极点，判断应当过阻尼、临界还是振荡衰减。代码若违背这些限制，曲线再平滑也不值得继续调容差。

把“想知道什么”压缩成少数标量，例如峰值电流、过冲、2% 稳定时间和
\[
\Delta E = E(t)-E(0)-\int_0^t\!\bigl(v_s i-Ri^2\bigr)\,dt.
\]
这些量比逐像素比较两张图更敏感，也更容易写成测试。若参数来自测量，还要保留其来源与不确定度；NIST [Technical Note 1297](https://www.nist.gov/pml/nist-technical-note-1297)提供了评定、组合和报告测量不确定度的方法。它处理输入信息有多可靠，不能替数值算法估计离散误差。

## 让同一个求解器主动和自己“吵架”

用同一参数运行一组逐渐严格的配置，而不是只改一次步长后凭肉眼说“差不多”。SciPy 的 [`solve_ivp`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html)文档区分了用于保存输出时刻的 `t_eval` 与真正影响积分的 `rtol`、`atol`、`max_step`；把曲线画得更密并不等于积分更精确。可从默认方法开始，将容差逐档收紧，同时限制最大步长以解析预计的最快时间尺度。

每档记录函数计算次数、峰值、稳定时间和能量残差，再画“目标量相对最严格一档的变化”，而不是只叠加波形。至少再用一种独立办法对照：解析极点、频域传递函数，或性质不同的积分器。`solve_ivp` 文档建议显式 Runge–Kutta 用于非刚性问题，Radau/BDF 等隐式方法用于刚性问题；两类方法给出一致结果比把同一方法的容差拧得极小更有说服力。

收敛研究应分别记录空间离散与时间步细化，并追问同一个核心问题：随着离散尺度减小，目标量是否进入稳定的渐近趋势。不要把 Richardson 外推机械套到任何求解器；当解有不连续、事件漏检或尚未进入渐近区时，表面上的“收敛阶”没有可靠含义。对 RLC 练习，有效结果是多个细化等级指向同一极限，且独立物理量也同时改善。

## 细化后仍不稳定时，先给失败分类

容差越紧结果越乱，不一定是“电脑精度不够”。先检查单位和状态尺度：若一个状态约为 \(10^{-9}\)，另一个约为 \(10^3\)，单一绝对容差可能对两者含义完全不同。再检查刚性和不连续输入，确认事件或开关是否会在一个大步内被跨过。最后才检查舍入与消减；Python 官方的[浮点说明](https://docs.python.org/3/tutorial/floatingpoint.html)解释了多数十进制小数不能被二进制浮点精确表示，但这不等于所有数值偏差都可以归咎于浮点。

线性方程组或参数拟合对输入极敏感时，查看奇异值与条件数。NumPy [`linalg.cond`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.cond.html)计算给定范数下的矩阵条件数；大条件数提示输入微扰可能被放大，却不是“模型错误”的自动判决。此时应重新缩放变量，避免显式求逆，检查参数是否实际上不可辨识，并用合成数据测试已知答案能否恢复。

给每类错误使用不同诊断：

- **模型错误：**改变离散设置也稳定地得到同一个错误物理趋势；
- **离散错误：**步长或网格细化时目标量系统变化；
- **舍入/条件问题：**尺度调整、精度或算法改变后结果大幅变动；
- **输入不确定度：**算法已收敛，但允许参数范围改变了工程结论。

分类的目的不是给错误贴标签，而是决定下一步该改方程、改算法、补测参数，还是缩小结论范围。

## 最后一项对照必须离开这段程序

对 RLC 模型，用手算极点和直流极限核对动态，再与另一软件的频域结果或安全低压测量比较。测量曲线不一致时，不要马上把差异叫作“仿真误差”：探头负载、信号源阻抗、元件寄生、容差和仪器带宽都可能是模型中没有的物理量。逐项加入，观察哪一项真正解释偏差。

交付结果时保留方程、单位、参数来源、求解器与版本、容差、细化表、独立基准、残差定义和一条重建命令。报告的有效数字应受数值收敛和输入不确定度共同限制。若模型将决定电源、电机、射频发射或医疗装置的实际边界，软件结果只能用于提出测试条件，不能替代额定值、故障保护、合格人员和受监督验证。

当 RLC 练习能够在干净环境重建，并且故意改变单位、步长或阻尼时检查会给出可解释的失败，再进入[SPICE 电路仿真](spice-simulation.md)比较器件模型，或用[数据与实验记录](data-lab-notebooks.md)接入真实测量。
