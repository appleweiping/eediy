# 开始学习

一个可靠的计划应当同时回答：**我从哪里开始、每周做什么、拿什么证明完成、什么时候调整路线**。先用一个月建立学习系统，再追求课程数量。

## 三十分钟起步诊断 { #start-diagnostic }

这不是入学考试。每栏用“能独立完成 / 需要查资料 / 完全陌生”标记，并保留一份实际样例。

| 能力面 | 10 分钟任务 | 进入主线前的最低状态 |
| --- | --- | --- |
| 数学 | 化简一个含复数的分式，求一个简单函数的导数，并解释向量点积 | 能写出步骤、检查量纲；不要求速度 |
| 物理 | 画出一个电荷或质量系统的受力/场示意，说明能量从哪里来、到哪里去 | 能区分状态量、变化率与守恒关系 |
| 编程 | 读取一列数据，计算均值并画图；若不会，写出伪代码 | 能运行、修改并保存一个短脚本 |
| 电路 | 对电阻分压器写 KCL/KVL，预测负载接入后的变化 | 至少知道节点、电压、电流与参考地 |
| 测量 | 为“测一个未知直流电压”列出量程、接线、单位和风险 | 知道先检查额定值，不能凭感觉接线 |

诊断后只补**会阻塞当前目标**的部分。例如，准备学线性电路却不会微分方程，可以先开始直流与电阻网络，并把微分方程作为 RC/RL 暂态的并行线；不必等所有数学都学完。

## 选择每周节奏

| 可用时间 | 建议结构 | 一学期可期待的成果 |
| --- | --- | --- |
| 5 小时 | 理论 2h + 练习 2h + 记录 1h | 一门基础课程的核心单元 + 1 个仿真项目 |
| 10 小时 | 理论 3h + 练习 3h + 项目 3h + 复盘 1h | 一门主线课程 + 2 个有数据的小项目 |
| 15 小时 | 理论 4h + 练习 4h + 项目 5h + 复盘 2h | 主线与必要先修并行 + 1 个完整阶段作品 |

不要把视频播放时长当成学习时长。对推导和实验密集的课程，通常至少要为每小时课程内容安排一到三小时练习、查错与记录；具体比例以你的测量结果为准。

## 四周启动方案

### 第 1 周：建立工作台

- 从[全局路线](roadmap.md)选择一个 4 周问题，例如“解释并验证一阶 RC 暂态”。
- 选定一门主线课程的一个单元，不同时开启三个同类课程。
- 建立学习日志：日期、目标、实际用时、阻塞点、下一步。
- 安装最少的软件；先用仿真或安全的低能量平台，不急着买完整实验台。

**周产出：**一页目标说明、环境清单和第一份可运行笔记。

### 第 2 周：形成反馈

- 完成一组有答案、测试或可比对结果的练习。
- 每道错题只记录关键错误：概念、模型、代数、代码、仪器或单位。
- 对同一结论用两种证据交叉检查，例如手算与仿真、仿真与低压测量。

**周产出：**至少 5 个经校正的问题，以及一份错误分类表。

### 第 3 周：做一个微型项目

- 把目标写成输入、输出、约束和验收测试。
- 先预测，再仿真；通过安全检查后才连接硬件。
- 保存原始数据、图表生成脚本、关键参数与版本。

**周产出：**一个他人能按说明复现的最小项目。

### 第 4 周：口头考试与路线调整

- 不看资料，用 10 分钟解释模型、假设、主要公式与失败原因。
- 随机重做一道练习，并修改一个参数验证迁移能力。
- 判断下一阶段：继续主线、补一个先修、换替代课程，或暂停不匹配的方向。

**周产出：**一页复盘和下一个 4 周里程碑。

## 怎样阅读课程页面

先读“风险与缺口”，再点课程链接。推荐顺序如下：

1. **学习产出：**确认它解决你的当前问题。
2. **先修关系：**把硬性先修加入计划，把推荐背景放入按需查阅清单。
3. **资源矩阵：**确认练习、答案、实验和考核是否真实开放，而不是只看视频数量。
4. **工具与成本：**提前准备替代软件、器件、地区访问和无障碍方案。
5. **完成标准：**把课程要求转成自己的阶段证据。
6. **核验日期：**超过合理复核周期的外链要先抽查。

!!! tip "主线、替代和补充不能相加"
    同一主题选择一门主线即可。替代课程用于更换教学风格或资源条件；补充资源只处理特定难点。并行看三套讲义通常会稀释练习时间。

## 建立学习证据

每个阶段保留一个最小证据包：

```text
stage-name/
├── README.md          # 问题、结论、复现步骤
├── notes/             # 自己的推导与概念图
├── exercises/         # 代表性练习与更正记录
├── src/               # 仿真、代码、配置
├── data/raw/          # 不覆盖的原始测量
├── data/processed/    # 可重建的处理结果
└── report/            # 图表、误差、限制与下一步
```

仓库结构只是建议，关键是能回答：结果来自哪个版本、用了什么参数、原始数据是否保留、别人如何复现、哪里失败过。

## 成本与替代策略

- **软件先行：**先确认开源或免费工具能否覆盖学习目标，再接受许可证绑定。
- **借用优先：**昂贵仪器优先使用学校、创客空间或共享实验室，并接受现场培训。
- **模块化购买：**围绕当前项目买器件，不为“以后可能用到”囤积。
- **估算总成本：**把探头、转接、保护、耗材、运费和替换件纳入预算。
- **保留无硬件路线：**每个高成本实验都应有仿真、公开数据或远程实验的替代产出。
