# 如何使用这份指南

左侧目录里的课程不需要、也不可能全部学完。这不是另一份培养方案，而是一张带注释的资源地图：一门公开课实际开放了什么、默认你会什么、作业有没有反馈、实验需要哪些条件，以及哪些环节仍无法从公开页面确认。

先别从“哪个方向最热门”开始。打开一门课之前，写下你眼下真正想解决的问题。例如“我会算直流电路，但看不懂 RC 响应”“我写过 C，却从没读过数据手册”“我想知道自己是否真的喜欢芯片设计”。问题越具体，越容易判断一门课有没有帮到你。

## 先认清自己的起点

### 刚进入大学，或正在读 EE 低年级

不要急着绕过校内课去拼一套“更强”的课表。微积分、线性代数、物理和基础电路会在后面反复出现；公开课最适合补讲解、习题和实验，而不是让你同时背负两套完整进度。

如果还不清楚 EE 各方向在做什么，可以浏览 [MIT 6.01SC](courses/ee-introduction/019-6-01sc.md) 的系统视角，再从[数学基础](math-foundations.md)、[物理基础](courses/physics/index.md)和[电路基础](courses/circuits/index.md)里补当前学期真正用得到的内容。每周至少留一半时间做题、仿真或实验；连续播放视频通常只会制造熟悉感。

### 从软件、计算机或其他工科转来

会编程是明显优势，但它不能替代电路、连续时间模型和物理量感。最常见的误判是：能让开发板闪灯，就以为已经理解电源、接口和测量。

先试做三个小问题：给有负载的分压器写出输出；解释一阶系统的时间常数；说明示波器保护地为什么可能造成短路。前两个卡住，从 [MIT 6.002](courses/circuits/021-6-002.md) 和[数学基础](math-foundations.md)起；第三个说不清，先读[仪器与测量](guides/instrumentation-measurement.md)和[实验安全](guides/safety.md)，暂时只做仿真或合格教学平台上的低能量实验。

### 已经学过共同核心，正在选方向

不要一次选三个方向“系统学习”。从[学习路线](routes/index.md)挑一个最接近当前兴趣的方向，看完其中两三门代表课的作业和项目，再决定是否投入。

判断标准不是课程名字听起来多高级，而是你是否愿意追查这个方向最常见的失败：模拟电路里的偏置和噪声、FPGA 里的时序和 CDC、嵌入式系统里的并发和外设、通信里的随机模型、控制里的建模误差、场与波里的边界条件。愿意把哪类错误查到底，往往比“最喜欢哪节视频”更能说明方向是否合适。

### 时间有限，或暂时没有实验条件

从[精简核心路线](routes/essential-core.md)选择一门主课即可。没有硬件并不会挡住数学、电路分析、SPICE、信号处理、HDL 验证、控制仿真和公开数据研究；但报告里要明确写出哪些寄生、噪声、热、量化和制造问题尚未经过实测。

等到任务真的需要仪器或板卡，再围绕那个任务采购、借用或进入实验室。先买一桌器件，通常只会得到一桌尚未定义问题的器件。

## 五分钟先修诊断

不要用“学过这门课”判断先修；用一个能被检查的小任务判断。每行只做第一列，不查答案。卡住时先补右侧入口，能完成就继续向下找更接近目标的课程。

| 试做任务 | 合格信号 | 卡住先补 |
| --- | --- | --- |
| 给带负载分压器写节点方程，并判断负载变小时输出怎样变 | 方程、单位与极限方向一致 | [数学基础](math-foundations.md)与[电路](courses/circuits/index.md) |
| 从一阶微分方程预测 RC 阶跃的初值、终值和时间常数 | 不看仿真也能先画出定性波形 | [微分方程](courses/mathematics/003-18-03sc.md)与 [MIT 6.002](courses/circuits/021-6-002.md) |
| 说明一个超过 Nyquist 频率的正弦采样后会落到哪里 | 能写出采样频率、原频率与混叠频率的关系 | [信号与系统](courses/signals-systems/index.md) |
| 为“按键消抖后翻转 LED”画状态图并列出边界情况 | 状态、转移、时钟和复位条件明确 | [数字逻辑](courses/digital-logic/index.md) |
| 说明万用表测电流的接法，以及示波器保护地何时会造成短路 | 先说停止条件、额定值和限流，再谈接线 | [仪器与测量](guides/instrumentation-measurement.md)与[实验安全](guides/safety.md) |

这不是考试，也不需要五项全会。它只防止把课程标题、播放进度或会用某个工具误当成先修已经具备。

## 第一门课怎么选

下面不是先后严格的课表，而是几种常见的第一步：

| 你现在能做什么 | 先打开 | 为什么从这里开始 |
| --- | --- | --- |
| 高中数学尚可，但没学过大学 EE | [MIT 6.01SC](courses/ee-introduction/019-6-01sc.md) | 先看到系统、信号、软件与硬件怎样相遇，再决定缺口 |
| 正在学微积分/线代，电路几乎空白 | [MIT 6.002](courses/circuits/021-6-002.md) | 电阻网络、动态元件和器件模型会立刻暴露数学是否够用 |
| 会基础电路，想理解滤波和频谱 | [MIT 6.003](courses/signals-systems/083-6-003.md) | 用 LTI、卷积与变换建立信号和系统的共同语言 |
| 会编程，想接近数字硬件 | [Nand2Tetris I](courses/digital-logic/039-nand2tetris-i.md) | 项目从逻辑门走到处理器，环境成本比直接上 FPGA 低 |
| 想做 MCU/传感器项目 | [嵌入式系统方向页](courses/embedded-systems/index.md) | 先比较课程的板卡、调试和实验依赖，再选主线 |
| 已有本科核心，目标比较明确 | [方向路线](routes/index.md) | 直接按先修和项目证据进入相邻课程，不重复共同核心 |

如果两门课程看起来都合适，分别打开第一份作业。优先选择你能取得作业材料、反馈或参考结果的那一门；漂亮的课程首页和完整的视频播放列表，不能替代练习闭环。

## 课程页里哪些信息最重要

先读正文中的课程判断，再看资源清单。几处容易被忽略：

- **主线、替代、补充是关系，不是等级。** 同一主题通常只选一门主线；替代课用于换风格或访问条件，补充课只修一个缺口。
- **“先修与建议”不是一张混合清单。** “本站建议基础”是路线编辑判断；“官方先修说明”和“课程顺序要求”才记录提供方的正式条件。二者不能互相替代。
- **先看课程自己的作业。** 课程方发布的题目、实验和项目会直接链接；另写的自学练习只用于补缺口，不能混称为官方要求。
- **资源齐全不等于适合你。** 先修、语言、地区、许可证、硬件和反馈方式都可能决定课程是否可完成。
- **页底反馈入口能补正文没有的经验。** 做过课程的人可以提交版本变化、环境问题和真实工作量；入口会自动带上页面、语言和稳定 ID，方便维护者核对。

发现事实错误或失效链接时，直接选择页底对应的 GitHub 报告入口；想写完整学习复盘，再看[贡献指南](contributing.md)。一条带日期和原始链接的更正，通常比“这课很好”更能帮助后来者。

## 怎样才算真的开始

选择课程后，先完成一次最小闭环，而不是先设计半年计划：

1. 打开课程大纲和第一份实质性作业，确认访问、语言和工具条件。
2. 写下这部分要回答的一个问题，以及你已有的先修缺口。
3. 完成一道能被答案、测试、仿真或测量校正的任务。
4. 保留原始作答和更正原因；不要只留下整理后的正确版本。
5. 决定继续、补先修或换课，并把理由写进两三句话。

对一个 RC 阶跃问题，证据可以很小：手算时间常数、跑一次参数扫描、画一张带单位的图，并解释仿真与预测为什么一致或不一致。对一段 HDL，证据可以是一套自检查测试和失败波形。先把这种小闭环做通，再扩成课程计划。

需要保存环境、代码、数据和报告时，从[实践指南](guides/index.md)按问题选择工具；不要因为页面列出了十种工具就全部安装。

## 硬件和实验的边界

仿真通过只说明模型在给定条件下自洽，不说明实物一定安全或正确。第一次接触仪器时，应在有额定值说明、保护措施和现场监督的环境中学习接线。市电、高压、较大储能、激光、旋转机械、真空、化学品和高温工艺都不属于“照着网络教程试一下”的范围。

课程页如果标注仅仿真，就不要自行把建议项目扩展到实体设备。课程确实包含实验，也仍要遵守所在机构、设备厂商和实验室的安全流程。拿不准时停下来，改用低电压隔离平台、公开数据或仿真；[实验安全](guides/safety.md)列出了更具体的停止条件。
