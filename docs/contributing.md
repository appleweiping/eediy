# 贡献指南

EEDIY 欢迎课程推荐、链接复核、路线改进、翻译、项目复现、安全更正和无障碍优化。维护质量的关键不是贡献规模，而是让每项事实都可追溯、每项判断都说明依据。

## 适合贡献的内容

- 新增一门具有公开学习价值的课程；
- 修正链接、开放状态、先修、硬件、费用或许可变化；
- 补充课程的作业、答案、实验、代码与考核证据；
- 报告完成课程后的实际用时、阻塞点和替代方案；
- 改进一条路线的先修依赖或阶段出口标准；
- 提供可复现项目、测试数据和失败复盘；
- 补齐中英文翻译与无障碍描述；
- 提出安全边界或来源归属问题。

纯排名、宣传文案、无证据的“神课”评价、受限材料的未授权转载，或只包含外链的页面不适合作为课程条目。

## 证据优先级

优先使用：

1. 课程或机构的官方页面、教学大纲和公开仓库；
2. 教师或实验室发布的原始材料；
3. 软件、器件与仪器的官方文档/数据手册；
4. 可复现的学习者记录，用于补充而非替代官方事实；
5. 聚合页、论坛或视频列表只作为线索，需要回到原始来源核实。

外部网页会变化。所有重要资源字段必须记录**最后核验日期**；不要仅凭搜索摘要、缓存标题或旧截图断言仍然开放。

## 新课程的最低字段

| 字段 | 要求 |
| --- | --- |
| 标题、机构、课程号 | 与官方页面一致；没有课程号时明确说明 |
| 官方入口 | 优先稳定的课程主页，而非转载播放列表 |
| 方向与角色 | 选择一个主方向；说明主线、替代或补充角色 |
| 学习产出 | 3–6 条可观察能力，避免复制宣传语 |
| 先修 | 区分硬性、建议和可并行先修 |
| 资源矩阵 | 分别核验视频、讲义、练习、答案、实验、代码与考试 |
| 完成路径 | 给出建议顺序、关键作业和可替代反馈机制 |
| 时间与成本 | 提供方工时须附可追溯来源；否则标为维护者估算、说明依据并要求两周校准；同时披露付费墙、地区、软件和硬件 |
| 风险与陈旧点 | 旧工具、缺失材料、危险实验、不可复现环节 |
| 核验日期与证据 | YYYY-MM-DD，并链接到支持各项事实的原始页面 |

等级评价必须与资源证据匹配：

- **S：**可独立形成教学—练习—反馈—考核/项目闭环，关键资源公开且可访问；
- **A：**主体教学强，存在少量可明确补偿的缺口；
- **B：**某些环节很有价值，但不足以独立承担主线；
- 若证据不足，不先给高等级；标记待复核。

## 推荐的贡献流程

1. **先搜索：**确认课程、问题或更正没有重复记录。
2. **缩小范围：**一个变更解决一个清晰问题；大路线改造先提出讨论。
3. **收集证据：**逐项打开资源，检查是否需要登录、付费、地区访问或专用硬件。
4. **更新权威数据：**课程与路线的生成页面不直接手改。
5. **同步双语：**事实、数字、风险和链接必须一致；译名可以为读者自然表达。
6. **本地验证：**运行生成、严格构建与质量检查，阅读实际页面。
7. **说明判断：**在变更描述中列出新增/修改、证据、已知不确定项和截图之外的验证。
8. **响应评审：**以新证据解决分歧；无法确定时保留“待复核”，不强行定论。

## 双语一致性

翻译不是逐词替换。必须保持以下内容完全同义：

- 课程身份、链接与核验日期；
- 先修与完成标准；
- 资源是否开放及缺失项；
- 等级、角色和评分依据；
- 安全警告、成本、地区和许可限制。

可以本地化：

- 句式、术语解释和面向读者的例子；
- 机构/课程的常用中文译名，但首次出现保留官方名称；
- 学习时长单位与阅读顺序。

修改一种语言中的事实时，必须在同一变更中更新另一种语言。若无法完成可靠翻译，明确标记并请求语言评审，不要静默留下旧事实。

## 写作与引用

- 先给结论，再给证据与限制；
- 区分“官方声明”“贡献者核验”“基于证据的判断”；
- 具体说明缺失内容，不写模糊的“资源不全”；
- 工时只能使用两种来源：附可追溯证据的提供方数据，或明确标注的维护者估算；
- 维护者估算必须说明依据与假设，例如“每周 8–10 小时，包含作业”，并要求学习者先执行两周校准再制定长期计划；不得以“未知”替代该记录；
- 不大段复制课程简介、教材或他人笔记；用自己的话概括并链接来源；
- 不上传付费作业答案、受限课件、密钥、个人数据或未经许可的图片；
- 图片需要替代文本，图表同时使用线型/符号/标签，表格必须有明确表头。

## 安全内容的额外门槛

安全更改优先审查。涉及电气、激光、射频、电池、化学、机械或急救的具体陈述：

- 优先引用监管机构、标准组织、制造商或实验室正式程序；
- 不把某地区的法律阈值包装成全球通用的“安全线”；
- 不提供让无资质学习者绕过联锁、保护或监督的步骤；
- 有疑问时提高风险等级并建议仿真或合格设施；
- 明确教育性指南不构成操作授权。

## 变更说明模板

```markdown
## 变更
- 新增/修正：
- 影响的中文与英文页面：

## 证据
- 官方入口：
- 练习/实验/考核：
- 访问、成本与许可：
- 核验日期：

## 判断与不确定项
- 角色/等级依据：
- 工时来源（提供方证据，或维护者估算 + 依据 + 两周校准）：
- 已知缺口：
- 仍需复核：

## 验证
- [ ] 数据生成成功
- [ ] 严格站点构建通过
- [ ] 中英文事实一致
- [ ] 内部链接与关键外链已检查
- [ ] 安全与内容许可已审阅
```

## 评审者检查表

- [ ] 条目解决真实导航问题，而不是扩充数量；
- [ ] 每个关键事实能回到原始来源；
- [ ] 主线/替代/补充角色与现有路线不冲突；
- [ ] 等级反映自学闭环，不是机构声望；
- [ ] 缺失资源、旧工具、成本和硬件被清楚披露；
- [ ] 工时有提供方可追溯证据，或明确标为维护者估算并附依据与两周校准要求；
- [ ] 中英文数字、风险、链接和日期一致；
- [ ] 项目与实验没有越过安全监督边界；
- [ ] 第三方材料仅链接或在许可范围内使用；
- [ ] 自动检查通过，且人工阅读没有导航死角。

## 利益冲突与纠错

若你是课程教师、平台员工、内容作者、设备供应商或与推荐存在经济关系，请在变更中披露。利益关联不自动否定资源，但读者必须能够独立判断。

事实错误、安全风险与许可问题可以先提交最小更正，不必等待完整重写。请提供准确页面、当前内容、支持证据、建议修复和紧急程度。维护者应记录争议与解决理由。
