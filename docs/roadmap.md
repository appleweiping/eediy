# 一份仅供参考的 EE 学习规划

电子工程不是一条从“基础”直走到“高级”的单行道。模拟电路、数字系统、通信、控制、电磁场、电力和器件会共享一部分数学与物理语言，之后很快分叉；每个方向继续往下，都足以占满整个研究生阶段。

下面这份规划给的是课程之间的关系，不是要求每个人照抄的学期表。课程页里的先修与公开资源来自提供方材料；路线中的取舍属于编辑判断。第一次来，请先读[如何使用这份指南](getting-started.md)：同一主题只选一门主线，替代课不是加餐，缺少实验条件时也不要把仿真写成实测。

## 先把工具用到“不碍事”

EE 学生不需要先变成软件工程师，但代码、版本和记录会贯穿几乎所有方向。建议在第一门带计算或实验的课里顺手建立这些能力：

- 用 [Python 与 Jupyter](guides/python-jupyter.md) 读取数据、画带单位的图，并从原始数据重新生成结果；
- 用 [Git](guides/version-control.md) 保存可回退的代码、网表、报告和硬件版本；
- 需要编译原生代码时再学 [C 与 CMake](guides/c-cmake.md)，不要为了“以后可能用到”先配一整套复杂环境；
- 学电路时同步用 [SPICE](guides/spice-simulation.md)，但每次仿真都要有手算基准或极限检查；
- 第一次接触仪器前读[仪器与测量](guides/instrumentation-measurement.md)和[实验安全](guides/safety.md)。

如果目前只想了解 EE 全貌，[MIT 6.01SC](courses/ee-introduction/019-6-01sc.md)把软件、信号、概率、状态机和机器人放在一门导论里。它不是后续专业课的替代品，但很适合用来判断自己对哪类问题有耐心。

## 共同核心：后面会反复借用的语言

### 数学和物理不要一次学完再出发

微积分、线性代数、微分方程和概率都重要，但没必要先关起门学两年数学。更有效的安排是交错推进：

1. 用 [MIT 18.01SC](courses/mathematics/001-18-01sc.md) 和 [18.02SC](courses/mathematics/002-18-02sc.md) 建立单变量、多变量微积分；
2. 学电阻网络和线性系统时并行学 [MIT 18.06SC](courses/mathematics/004-18-06sc.md)；
3. 遇到 RC/RLC、机械类比和状态演化时进入 [MIT 18.03SC](courses/mathematics/003-18-03sc.md)；
4. 在噪声、随机信号或通信真正出现前完成 [MIT 6.041SC](courses/probability-statistics/007-6-041sc.md) 或适合自己背景的概率主线。

具体取舍写在[EE 数学基础](math-foundations.md)。物理方面，力学训练建模和能量观念，电磁学直接支撑电路、场、器件和电机；[物理方向页](courses/physics/index.md)列出了 MIT 8.01SC、8.02x、8.03SC 等入口。不要把物理课只做成符号计算，至少保留受力图、场线、边界和量纲解释。

### 电路、信号与数字逻辑构成第一轮专业核心

- **电路：**[MIT 6.002](courses/circuits/021-6-002.md) 是一条完整主线。节点法和等效电路之后，不要跳过动态元件、频率响应和器件模型；这些内容会在模拟、控制、通信、电力和仪器里不断回来。
- **信号与系统：**[MIT 6.003](courses/signals-systems/083-6-003.md) 把 LTI、卷积、变换、采样和反馈放进同一套语言。它对 DSP、通信和控制是先修，对任何处理传感器数据的人也很有价值。
- **数字逻辑：**希望先看到抽象层如何衔接，可以做 [Nand2Tetris I](courses/digital-logic/039-nand2tetris-i.md)；希望按本科 EE 的方式进入逻辑、状态机和处理器，可以比较 [MIT 6.004](courses/digital-logic/037-6-004.md) 与方向页中的替代课。
- **编程：**如果脚本和 C 仍然会阻塞作业，从[编程与工程工具](courses/programming-tools/index.md)按需补。目标是能读、改、测试课程代码，不是先学完一套与当前任务无关的软件栈。

共同核心不要求把每一门课刷到相同深度。至少应做到：能从假设写出低阶模型；能把手算、仿真和测量放在一起比较；能读基本原理图、数据手册和时序图；能保留一个别人可以重新运行的小项目。

## 时间有限时，删到什么程度

已经工作、转专业较晚，或只想修复本科基础时，可以先保留下面六块。它们不是“速成 EE”，而是一组继续深入时不容易绕开的接口：

| 模块 | 建议主线 | 做到什么再离开 |
| --- | --- | --- |
| 工程数学 | [数学基础](math-foundations.md)按需选 18.01/18.02/18.06/18.03 | 能为电路或动态系统写方程并检查数量级 |
| 电路 | [MIT 6.002](courses/circuits/021-6-002.md) | 能分析一个含动态元件或器件模型的网络 |
| 信号 | [MIT 6.003](courses/signals-systems/083-6-003.md) | 能解释卷积、频率响应、采样和稳定性 |
| 数字系统 | [Nand2Tetris I](courses/digital-logic/039-nand2tetris-i.md) 或 [MIT 6.004](courses/digital-logic/037-6-004.md) | 能用测试验证组合、时序模块和一个小型处理器结构 |
| 计算与记录 | [实践指南](guides/index.md)中当前任务需要的部分 | 代码、数据、环境和结论可以被重新运行 |
| 一次方向项目 | 从[方向路线](routes/index.md)选一个 | 有规格、模型、实现、验证和限制说明 |

如果你已经能用现有项目证明其中一项，就跳过；如果完全没有物理或数学背景，就不要因为“时间有限”而把它们删掉。

## 之后往哪里分叉

下面只解释每个方向的第一条主线和容易误判的地方。更完整的课程组合、替代方案和项目证据在对应方向页与路线页。

### 模拟电子与集成电路

一条常见顺序是：

`6.002 电路 → 6.101 模拟电子实验 → 微电子器件 → 模拟 IC`

[MIT 6.101](courses/analog-electronics/026-6-101.md) 的价值在于把放大、反馈、噪声和仪器变成真实实验；没有相应实验条件时，应先读课程页里的设备缺口，不要用几张理想 SPICE 波形替代实验。准备进入晶体管内部和芯片设计，再从[微电子](courses/microelectronics/index.md)连接到[模拟集成电路](routes/analog-ic.md)。这个方向会持续要求你在近似、摆幅、噪声、失配和工艺角之间做判断。

### 数字系统、FPGA 与体系结构

一条常见顺序是：

`数字逻辑 → 计算机组成 → HDL 验证 → FPGA/SoC 或体系结构`

[UCB CS61C](courses/computer-architecture/048-cs-61c.md)适合把 C、汇编、处理器和存储层次接起来；[MIT 6.111](courses/fpga-soc/042-6-111.md)则更偏大型数字设计和 FPGA 项目。这里最容易被作品演示掩盖的是验证：一个能在开发板上偶尔运行的设计，还需要自检查测试、约束、时序报告、CDC 处理和可复现构建。

### 嵌入式、PCB 与实时系统

从会写 C 到会做嵌入式系统，中间隔着数据手册、启动与链接、调试器、中断、总线、并发、功耗和板级问题。[UT Austin EE 319K](courses/embedded-systems/059-ee-319k-volume-1.md)是较平缓的 MCU 第一入口；想沿 reset、boot、linker 和寄存器层继续下潜时，再选 [Stanford CS107E](courses/embedded-systems/058-cs-107e.md)。两者使用不同板卡，选课前先确认硬件是否仍能获得。

真正做板时，再进入 [KiCad 与 PCB](guides/pcb-kicad.md)；实时约束出现后看[实时与信息物理系统](courses/real-time-cps/index.md)。不要把 Arduino 库调用数量当作嵌入式深度，能解释一次总线超时、栈溢出或电源跌落更重要。

### 信号处理、通信与信息论

一条常见顺序是：

`6.003 信号与系统 → 6.041SC 概率 → DSP → 检测/估计或通信`

[MIT RES.6-008](courses/dsp/088-res-6-008.md)是第一次系统进入 DSP 的主线；已有离散系统基础、并且愿意完成较长研究生项目时，再进入 [MIT 6.341](courses/dsp/089-6-341.md)。[MIT 6.450](courses/communications/100-6-450.md)进入数字通信时会大量使用概率。只展示一段滤波后的漂亮波形不够，项目应保留采样条件、数据来源、基线、噪声假设和误差分布。

### 控制、机器人与自治系统

先学会从物理对象得到模型，再谈控制器。[MIT 6.302](courses/control-systems/067-6-302.md)可以作为经典反馈入口，之后按[控制与机器人路线](routes/control-robotics.md)进入状态空间、估计、最优控制或机器人。

控制项目最危险的错觉是“仿真稳定，所以实机安全”。执行器饱和、延迟、摩擦、传感器失效和机械限位都可能破坏模型。先在仿真和低能量教学装置中验证，并设计急停与故障状态。

### 电磁场、射频与光子学

多变量微积分、电磁学和复数场是共同入口。可以先比较 [Cornell ECE 3030](courses/electromagnetics/107-ece-3030.md) 与 [MIT 6.013](courses/electromagnetics/108-6-013.md)，再从[射频、微波与天线](routes/rf-wireless.md)或[光子与微系统](routes/photonics-mems.md)分叉。

这一方向不能只靠“公式代数”：几何、材料区域、边界条件、模式和校准方法必须说清。射频功率、激光、真空和工艺设备的实体实验需要合格设施。

### 半导体器件、VLSI 与制造

[MIT 6.012](courses/microelectronics/030-6-012.md)把半导体物理与器件模型接到电路，[MIT 6.152J](courses/fabrication-mems/126-6-152j.md)进一步进入工艺。之后可按[半导体与 VLSI 路线](routes/semiconductor-vlsi.md)选择数字 VLSI、模拟 IC、器件或制造。

器件曲线、SPICE 模型、版图和工艺数据代表不同层次，不能互相冒充。没有洁净室、化学品和工艺监督时，制造实践应停留在公开数据、版图规则和获准的远程/教学流程。

### 电力电子、电机与电力系统

这个方向同时调用电路、电磁、控制、热和保护。[MIT 6.622](courses/power-electronics/114-6-622.md)可以作为变换器理论入口；电机、电力系统和能源课程在[电力与能源路线](routes/power-energy.md)中分开组织。

市电、高压和大容量电池都不是自学入门实验材料。没有实验室、监督、隔离、保护和放电流程时，使用仿真或低能量教学硬件，并明确模型没有覆盖的开关寄生、热和故障能量。

### 仪器、传感与生物医学

这条路线从电路、信号、概率和测量共同出发。先把传感器激励、前端、采样、校准和不确定度连成一条测量链，再进入[仪器与生物医学路线](routes/instrumentation-biomedical.md)。生物信号项目若只会画图，却没有电极/传感器条件、滤波延迟、统计偏差和伦理边界说明，结论通常不可靠。

## 在校、就业与科研，路线怎样改

### 正在读 EE

把公开课当作校内课程的另一套解释和反馈来源。校内实验室、安全培训、教师答疑和同伴协作是网络课程很难替代的资源。若课程内容重复，优先做公开课里更好的作业或项目，但先确认学校的学术诚信和课程要求。

### 面向岗位

抽取几份真实岗位描述里的重复能力，再回到课程和项目找证据。FPGA 岗位需要的不只是 Verilog 关键字，嵌入式岗位也不只是某款 MCU；调试、测试、接口、版本和书面设计判断往往更能区分作品深度。不要为追工具名而跳过电路、信号或体系结构基础。

### 面向科研

尽早练习读论文、重建推导、复现实验和报告负结果。课程只负责把语言和经典模型交给你；研究问题通常不会配答案。选择一个窄问题做扎实，比同时“入门”多个前沿方向更接近真实科研。

## 定制自己的地图

从一个想解决的问题开始，在[课程导航](courses/index.md)里打开三门候选课，比较它们的第一份作业、公开反馈、先修和实验条件。选出一门主线后，再到[学习路线](routes/index.md)补相邻课程关系。

路线需要改动时，不要把已经做过的练习、代码和测量扔掉。保留证据，写明为什么换课：材料缺失、先修不合、实验不可得，还是教学方式确实不适合。这样的记录将来既能帮助你，也能通过页末课程复盘入口帮助下一位读者。
