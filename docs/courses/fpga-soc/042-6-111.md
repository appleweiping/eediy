# MIT 6.111: Introductory Digital Systems Laboratory

## 课程简介

- **所属大学：** MIT
- **课程编号：** 6.111
- **官方先修：** MIT 6.111 syllabus 不要求 6.004，但预期具备基础电路理论
- **本站建议背景：** 本站未另设准备条件
- **访问条件：** 无需注册公开访问
- **资料状态：** 2026-07-31；公开材料导读；后继课程复盘仅作背景

### 课程重点

MIT [6.111 Spring 2006](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/calendar/) 适合已经会写小型 HDL 模块、想练系统集成的人。前半学期讲组合逻辑、Verilog、FSM、同步、存储、算术、视频和系统集成，最后 5 周却干脆停掉常规 lecture，让 final project 接管日程。这个安排已经把课程性格说得很清楚：HDL 是工具，能否把多个模块接成可演示系统才是考题。

官方 [Syllabus](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/syllabus/) 没有把 6.004 设为硬先修，只要求基础电路理论；但校外自学若连组合/时序逻辑和 testbench 都陌生，会把所有时间耗在语法上。想补 HDL 与体系结构，应选 6.004。已经能写小模块、现在想学集成、调试和技术展示，6.111 才会显出价值。

### 实验与项目

官方 [Labs](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/labs/) 依次是基础数字设计、traffic-light FSM、memory tester 和 Pong video game，另有 3 个带解答的 problem set。前两项让逻辑真正碰到板上输入，memory tester 迫使地址、数据和控制路径分开，Pong 才把视频时序、游戏状态与输入塞进同一个系统。

Pong “能动起来”仍可能结构错误。pixel clock、game state 与 frame update 混在一起，画面照样可能工作，却藏着跨域或更新时序问题。memory tester 也不该只给 PASS/FAIL；地址错、数据错、控制时序错会留下不同症状。testbench 和 timing report 的用途，就是回答这些具体疑问，不必沦为项目目录里的两份装饰。

原 labkit 是 Virtex-II、ISE、`.ucf` 和专用视频/存储接口。换现代 FPGA 时，器件、时钟、I/O 电压、存储接口和约束格式都要重新决定。旧 PDF 可以提供设计题，却不会为新板自动生成一个可工作的 port。

### Final project 的会议比外设数量更重要

[Projects](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/projects/) 留下 15 组案例。项目约占原课 37%，先后经过 abstract、proposal conference、block-diagram conference、design presentation、custom checklist、demo/video 和 final report；系统没有完全工作，也得当场展示并指出坏在哪里。这门课偏爱清楚的模块边界、时钟域和一个很早就能跑的 minimum demo，外设数量倒在其次。

MIT 的 Andi Q. ’25 在 [6.2050 完课复盘](https://mitadmissions.org/blogs/entry/6-2050-field-programmable-gate-awesomeness/)中说明 6.2050 是 6.111 的后继课：Fall 2023 前 7 周做 SystemVerilog、仿真与 FPGA labs，后 6 周做 final project。她的小组用麦克风、声音定位和电机做一只转向声源的机器猫，工具包括 Vivado、FPGA、Manta 与示波器；垃圾位、调试器崩溃、标错端口、电机耗电过大导致 FPGA 崩溃，以及机械噪声，都成了真正的排错内容。这是一份后继课程的一手经历，不能据此断言 Fall 2023 与 Spring 2006 的四个 labs 相同。

Ganesh Ajjanagadde、S. Jain 与 J. Thomas 的非官方 [6.111 Project](https://github.com/gajjanag/6111_Project) 则是一个很好的成品样本：仓库标明 Fall 2014、GPL-3.0，自动投影倾斜补偿系统的 Verilog、abstract、checklist、presentation 和 report 都在。它只是一份 Fall 2014 独立项目，值得读的是一项实现怎样同时变成一场 demo 和一份技术说明。

### 只够做一件事，就把 project 做到能解释失败

[Exams](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/pages/exams/) 有 Spring 2006 quiz 与 2003/2004 练习卷，可用来查 FSM、存储和时序概念。但 6.111 不该被做成另一门刷题型数字逻辑课。

一个合适的校外项目不必堆外设：让最小数据通路在一个时钟域跑通，再加入跨域、存储或视频中的一项；用仿真抓协议问题，用板上观测抓 reset、约束与物理接口问题。最终 demo 若失败，也要能把故障压缩到某个模块、时钟边界或供电/接口条件。能解释“为什么没有完全工作”，往往比一段偶然跑通的视频更接近 6.111。
