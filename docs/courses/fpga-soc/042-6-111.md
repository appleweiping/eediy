## 实践闭环

### 《Introductory Digital Systems Laboratory · MIT 6.111》可综合流处理 SoC 子系统

这是维护者为《Introductory Digital Systems Laboratory · MIT 6.111》建议的自学项目，不是课程官方作业。为FPGA 与片上系统实现含寄存器接口、DMA/流接口和中断的可综合子系统，先完成仿真与时序收敛，再可选在低压开发板演示。

**来源：** 维护者建议项目

**交付物**

- 寄存器表、总线/流接口、时钟复位和性能目标规格
- RTL、驱动/固件、参考模型、断言与随机测试平台源文件
- 不少于 10000 个事务的日志、波形、覆盖率、资源和时序报告
- 一份软硬件协同报告，包含吞吐/延迟、CDC 风险和一次缺陷修复

**验收**

- 随机回归与参考模型逐位一致，协议和 CDC 检查零未豁免错误
- 覆盖复位中事务、最大突发、持续背压、计数器回绕和非法寄存器访问
- 综合后满足预先声明时钟约束，最差裕量不小于 0 ns
- 注入一次中断丢失或跨时钟错误，证明断言/测试能稳定捕获

**复现要求**

- 提交 RTL、固件、约束、测试、板级引脚文件和 README
- 固定仿真/综合/SDK 版本、器件型号、种子和一键回归命令
- 保存原始回归、综合、时序和可选板级串口日志

**安全边界：** 低能量实验 — 板级演示仅限合规低压开发板、限流 USB 供电；核对 I/O 额定值、电平和引脚，断电接线，禁止外接市电、大电流负载或运动机构。
