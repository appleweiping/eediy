### 作业与反馈

Cornell [ECE 5330 Semiconductor Optoelectronics](https://ocw.ece.cornell.edu/courses/ece-5330-semiconductor-optoelectronics/) 对应 **Fall 2014**。页面同时写 **Undergraduate (senior level)** 与 **comprehensive graduate-level course**，无需替官方消解；真正门槛是量子力学、电磁辐射（ECE 3030），以及半导体器件物理（ECE 4570）或固体物理（ECE 4070），官网明确不建议缺项者选课。

原班作业占 35%、期中占 25%、期末占 35%、教师裁量占 5%，没有指定教材。公开层有讲义、作业和解答，却没有视频、完整代码仓库、项目或实验。

进入 Handout 1 前可做三类诊断。量子部分用无限深势阱检查波函数归一化、宇称与矩阵元；电磁部分从切向边界条件推反射/透射，再用 Poynting 能流查功率；器件部分画异质结或 PIN 的平衡/正向偏置能带图，把 Fermi/准 Fermi 能级、掺杂、产生、复合和电流密度接起来。任何一类只能背结论，都应补对应先修。

### 课程结构

[Lecture Notes](https://ocw.ece.cornell.edu/courses/ece-5330-semiconductor-optoelectronics/ece-5330-lectures-notes-and-handouts/) 有 Handout 1–16。Handout 1–4 从半导体、异质结/量子阱、Fermi 黄金律、增益/自发辐射走到 III–V 能带结构；5–7 处理光探测器、太阳能电池、介电响应、LED 与复合；8–11 接波导、SOA、量子阱跃迁和激光速率方程；12–16 再进入谐振腔、S/T 矩阵、DBR/DFB/VCSEL、啁啾/线宽、可调谐激光与等离激元。

每个器件都沿 `carrier state → transition/material gain → optical mode/confinement/loss → terminal power/efficiency/threshold/bandwidth/noise` 追踪。material gain、modal gain 与 net terminal gain 各有边界；每次跨层要写 normalization、loss 与 carrier assumption。比如 laser threshold 同时闭合 carrier rate 与 photon rate，photodetector responsivity 也要能从吸收、收集效率和外部端口定义一路追溯，不能在中间偷换 normalization。

### 8 份 solved homework 决定节拍

[Homework and Exams](https://ocw.ece.cornell.edu/courses/ece-5330-semiconductor-optoelectronics/ece-5330-homework-and-exams/) 公开 HW1–8，8 份都有 solution。HW1–5 覆盖 quantum/semiconductor、heterojunction、gain、spontaneous emission 与 solar-cell thermodynamics；HW6 是 SOA/waveguide，HW7 是 InGaAsP laser/rate equation，HW8 是 DBR、VCSEL、S/T matrix 与 DFB，题面说明它持续 2 周、计普通作业的 2 倍。

按概念闭合点安排作业更稳：前段把 band/carrier 接到 transition，中段再把 photodetector、solar cell 与 LED 接到 observable，后段才进入 mode、SOA、laser 和 cavity。先保留无提示首稿，再从首个物理分歧判断是 material parameter、occupation、matrix element、mode normalization、unit 还是 numerical method 出错；订正后换材料或 cavity 参数重算，而不是逐行抄解答。数值图同时保存 equation、initial condition、tolerance、units、raw array 与 limiting case。

公开 midterm 是 open book，但 solution unavailable；final exam 也未公开。HW1–5 后可以在不搜索答案的条件下完成 midterm，却不能据此生成 Cornell self-score。

### 访问与版本说明

HW6、HW7 与官方 [HW8 Problem 8.4](https://ocw.ece.cornell.edu/files/2017/03/ece5330_homework8-2fz4yrw.pdf) 引用 `ece533solver`，公开导航没有 executable 或 source。站外同名文件没有 Cornell 发布依据，也无法支撑“复现官方输出”的说法。

可独立实现 scalar 1D eigenmode solver：以 dielectric slab 的 effective index/cutoff 为基准，检查 grid、domain、boundary condition、mode normalization 与 failure range，并区分 bound、leaky 与数值伪模。保存随 domain 扩张和 grid 加密的 mode 轨迹；只报告最漂亮的一条 field profile 无法证明 mode 选择正确。S/T-matrix 部分则检查 zero-index-contrast reflection、lossless energy flux、DBR stopband trend 和 S/T conversion。这是数值补充，不替代被缺失工具阻塞的官方题。

### 以端口 observable 收尾

[MIT 6.977, Fall 2002](https://ocw.mit.edu/courses/6-977-semiconductor-optoelectronics-theory-and-design-fall-2002/) 更强调 theory/design、device noise 与 fiber communication，可在 Cornell 主线后扩展。最终从 photodetector、SOA、laser 或 VCSEL 中选择一个器件，交付 carrier/gain、mode/loss、terminal observable 的完整模型，并把 unresolved solver/midterm 项留在报告里。

Cornell 页面明确 Projects and Labs unavailable。家庭路线只做推导与离线计算；[OSHA laser hazards](https://www.osha.gov/laser-hazards) 也说明眼和皮肤的暴露风险。数值项目不包含 energization、alignment、detector calibration，也不构成 Cornell grade。
