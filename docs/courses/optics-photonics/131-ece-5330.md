## 用三项诊断守住强先修

进入 Handout 1 前，先做三项 EEDIY 诊断；它们不是 Cornell 官方入学考试。

1. **量子力学：** 对 \(0<x<L\) 的一维无限深阱，归一化 \(n=1,2,3\) 三个本征态，写出能量，计算 \(\langle1|x|2\rangle\)，并用关于阱中心的宇称解释为什么 \(\langle1|x|3\rangle=0\)。若只会抄能级公式，却不能解释波函数、态密度和占据的区别，先补量子力学。
2. **电磁辐射：** 对无损介质 \(n_1\) 到 \(n_2\) 的正入射，从切向场边界条件推出场幅反射/透射系数，再用 Poynting flux 验证 \(R+T=1\)，并说明为什么场幅不能直接当成功率。若边界条件、复相量或能流不能闭合，先补 ECE 3030 量级的波与辐射。
3. **半导体器件或固体：** 画出平衡和正向偏置下的异质结或 PIN 结构能带，标出 Fermi/quasi-Fermi level、掺杂与载流子流向，再用单位解释 generation、recombination、current density 的关系。若能带图和载流子统计互不相连，先补 ECE 4570 或 ECE 4070 量级内容。

任意一项明显失败都应暂停主线，而不是靠多看一遍讲义掩盖。补课后的复测应换参数、保留首稿，并写明修补的是边界条件、统计、器件图像还是单位。这里把官网的“strong prereqs”落实成可观察行为，但不把自拟题冒充官方豁免。

## 用“载流子—光子—模态账”串起 16 份讲义

官方[讲义目录](https://ocw.ece.cornell.edu/courses/ece-5330-semiconductor-optoelectronics/ece-5330-lectures-notes-and-handouts/)共有 16 份 handout。它们不适合压成 16 周打卡表；更稳的主线是一张四栏 ledger：**材料与载流子状态 → 跃迁、吸收/增益与自发辐射 → 光学模态、限制因子与损耗 → 端口可见的功率、效率、带宽、阈值或噪声**。每出现一个新器件，都要指出每栏采用了什么模型，哪一个量把相邻两栏连接起来，以及守恒关系在哪里。

Handout 1 回顾 semiconductor basics；2 进入 heterostructure、quantum well 与 strain；3 用 Fermi’s golden rule 组织 light–matter interaction、gain 和 spontaneous emission；4 处理 III–V bandstructure 与 tight binding。Handout 5 转向 photodetector 和 solar cell；6 把 dielectric response、free-carrier effect 与 Kramers–Kronig 接起来；7 处理 LED、辐射/非辐射复合和 lighting。到这里，ledger 的前两栏应能从能带与载流子统计走到可测的光电响应。

Handout 8 建立 waveguide mode；9 用 material gain、modal confinement、loss 与 carrier/photon equation 解释 SOA；10 回到 quantum-well transitions；11 进入 laser rate equations 与 dynamics。Handout 12 处理 cavity、S/T matrix、DBR 与 VCSEL；13 延伸到 grating、DBR/DFB；14 处理 chirp、phase noise 和 linewidth；15 是 tunable laser 与 carrier-induced index；16 收在 plasmonics 与 plasmon laser。后半段的关键不是多记器件缩写，而是能追踪“材料增益为什么没有自动变成端口增益”“腔损耗怎样进入阈值”“相位扰动怎样变成 chirp 或 linewidth”。

自学节奏应按概念闭合点推进：Handout 1–2 后做 HW1–2，3–4 后做 HW3–4，5–7 后做 HW5，8–10 后做 HW6，11–16 后做 HW7–8。这个分段是 EEDIY 的执行建议，不是 Fall 2014 官方周历；ledger 还没有把定义、方程、近似与可观测量连起来时，该段就不算完成。

## 让 8 份作业决定节拍，而不是让解答领跑

官方[作业与考试页](https://ocw.ece.cornell.edu/courses/ece-5330-semiconductor-optoelectronics/ece-5330-homework-and-exams/)公开 HW1–8，并为 **8 份作业全部提供 solution**。HW1 是 semiconductor 与 quantum review；HW2 覆盖 heterojunction、quantum well、quaternary material 与 PIN；HW3 处理 optical transient 与 gain；HW4 处理 spontaneous emission、matrix element 和 gain 随温度的变化；HW5 把 solar cell 接到 thermodynamics；HW6 包含 SOA 与 waveguide solver；HW7 处理 InGaAsP laser、transient 和 rate equation；HW8 覆盖 DBR、VCSEL、S/T matrix 与 DFB，并在题面明确说明它是两周长作业、**计作普通作业的两倍**。

每份作业至少保留两件东西：未经解答提示的 first attempt，以及单独的 correction memo。首稿必须写到真正的阻塞点，不能用“参考解答略”收尾；memo 则把错误归到材料参数、载流子统计、跃迁模型、模态归一化、单位、数值方法或物理解读。看过 solution 后，应隔一段时间重做核心推导，并用新参数检查是否只记住了答案形状。公开解答提供文本反馈，不是自动 grader，也不提供原班成绩。

HW3 与 HW4 适合各留一份数值 notebook：前者保存 transient/gain 的方程、初值、步长或容差和解析极限，后者保存 matrix element、温度、占据与 gain 曲线之间的依赖。曲线图必须随附单位、参数表、原始数组和至少一个极限检查；“与解答图像相似”不能替代量纲、符号和守恒验证。

可做一项明确标注为 **EEDIY 非官方补充** 的替代练习：用 Python 或 Octave 从头实现 scalar 1D eigenmode solver，先在解析 dielectric slab 极限上核对 effective index 与 cutoff，再做网格加密、计算域扩展和边界条件敏感性测试。模型卡必须记录方程、折射率剖面、边界条件、离散方式、模态选择、归一化、单位、软件版本和失效范围。这个 1D 练习用于验证数值直觉，不是 `ece533solver` 的重发布或等价替身，也不能替代 HW6、HW7 或 HW8 Problem 8.4 中依赖缺失工具的官方结果。

HW8 中不依赖该工具的 S/T-matrix 工作可依据讲义中的层与界面定义另行实现，但同样应标成 EEDIY 实现，且不能据此把 Problem 8.4 的依赖缺口写成已解决。验收至少包括无折射率反差时的反射极限、无损结构的能流守恒、层数增加时 DBR stopband 的合理趋势，以及 S 与 T 表示互相转换的一致性。数值溢出或病态性也应留在模型卡里，不能只展示最好看的谱线。

## Cornell 用来闭环，MIT 用来扩展设计视野

[MIT 6.977 Semiconductor Optoelectronics: Theory and Design](https://ocw.mit.edu/courses/6-977-semiconductor-optoelectronics-theory-and-design-fall-2002/)对应 Fall 2002，与 ECE 5330 同样从 semiconductor–photon interaction、gain 和 laser rate equations 走向 resonator 与 integrated laser structure。它更明确地把 theory/design、device noise 和 fiber-optic communication 应用放在课程描述中，并公开 problem sets，适合在 Cornell 主线之后扩大设计与系统视角。

若当前目标是独立学习的反馈闭环，Cornell 的 16 份 handout 加 8 份全部带解答的 homework 更容易形成“推导—作答—订正”链；若已经能稳定完成这条链，再读 MIT 的设计、噪声与通信材料会更有效。这个选择是材料结构上的分工，不是质量排名，两门课也不应因主题相邻而被混成同一版本。
