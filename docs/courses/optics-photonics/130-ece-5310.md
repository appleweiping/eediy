### 课程定位与先修

Cornell [ECE 5310 Quantum Optics for Photonics, Fall 2013](https://ocw.ece.cornell.edu/courses/ece-5310-quantum-optics-for-photonics/) 是一门每周 3 次 lecture 的研究生课，有 midterm 和 final，不指定 textbook。旧 [Course Information](https://courses.cit.cornell.edu/ece531/Info/Info.htm) 明确要求 electrodynamics/optics 与 quantum mechanics；课程开头会统一符号，却不会重讲这两门先修。

开始前应熟悉 two-level Hamiltonian、density matrix、commutator、tensor product、trace 与 partial trace。若还不能区分 pure/mixed state，或不知道 Schrödinger、Heisenberg 与 interaction picture 中谁随时间变，先补量子力学会更省时间。

### 用 two-level system 串起前半程

[Lecture Notes and Handouts](https://ocw.ece.cornell.edu/courses/ece-5310-quantum-optics-for-photonics/ece-5310-lectures-notes-and-handouts/) 从 density matrix、Rabi oscillation、coherence 与 EIT 起步，随后量子化 electromagnetic field，进入 number/coherent/squeezed state、correlation 和 homodyne/heterodyne detection，最后讨论 cavity QED、amplifier、laser、optomechanics 与 quantum information。教师保留的 [Lecture Index](https://courses.cit.cornell.edu/ece531/Lectures/Lectures.htm) 很适合恢复顺序，但它只是 2013 年档案，不代表当前开课。

这门课最容易混淆的是“公式里的量”和“实验读到的量”。以 driven two-level system 为主线，分别写清 field amplitude、Rabi frequency、population、coherence 与 detector signal，再比较 Schrödinger 和 interaction picture 的写法。只要这一个模型的归一化、单位和近似讲清楚，后面的 cavity 与 laser 会顺很多。

### Homework 1–10 值得完整做

[Homework and Exams](https://ocw.ece.cornell.edu/courses/ece-5310-quantum-optics-for-photonics/ece-5310-homework-and-exams/) 公开 Homework 1–10 及全部 solutions，在量子光学公开课里很难得。先独立做主推导，再用解答核对 sign、operator ordering 与 normalization；随后改变 initial state、detuning 或 decay，看原方法是否仍然成立。同页 Exam 1 有解答，可以限时做；Final 没有解答，适合用 trace、probability 与几个解析极限自检。

### 一个数值延伸

公开包没有课堂录像、代码、实验数据或可复现的原 project。若要补一个数值练习，选 driven two-level system 或 lossy cavity 即可：把 master-equation integration 与一个解析极限比较，并扫描 detuning 或 decay。two-level 模型检查 trace 与 Hermiticity；cavity 模型说明 Fock-space cutoff 并做一次收敛比较。这个练习补的是模型直觉，不是 Cornell 的光学搭建和探测器标定。
