### 课程定位

MIT 研究生课 [3.46 Photonic Materials and Devices, Spring 2006](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/) 每周 2 次、每次 1.5 小时。[Syllabus](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/pages/syllabus/) 以 Saleh 与 Teich 的商业教材为主读物，它不在免费包内。合适的基础包括 electromagnetic wave/phasor、基础 quantum/semiconductor physics、linear algebra，以及阅读 slab-waveguide、transfer-matrix 或 coupled-mode model 的能力。

材料数据、器件与制造语境停在 2006；基础的 mode、resonance、carrier 与 nonlinear relation 仍有价值，current state-of-the-art 结论需另查现代一手文献。

### 课程结构

[Lecture Notes](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/pages/lecture-notes/) 从 optical material、waveguide、WDM filter、ring resonator、photonic crystal，走到 semiconductor electron/photon、LED、laser、crystal growth、defect/strain，再到 nonlinear optics、modulator、III–V processing、detector 与 micro/nanophotonics。

用一张 `material → geometry → mode/carrier → device metric → system tradeoff` 表串起 21 讲。前段检查 boundary、normalization、dispersion、loss、coupling；中段把 band structure、carrier distribution、recombination、gain 与 threshold 放进同一 budget；后段比较 speed、efficiency、noise、insertion loss 与 fabrication tolerance。旧 material parameter 要保留 wavelength、temperature 与来源，换新数据则重新计算。

### 作业与反馈

[Assignments](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/pages/assignments/) 有 7 套 homework，无 solutions。每题写出 model/approximation，再查 dimension、limit 与 order of magnitude；waveguide/resonator 可用独立 sweep，carrier/laser 需检查 particle 与 power balance。

[Exams](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/pages/exams/) 提供 7 次 weekly quiz 和 final，也无 solutions。quiz 可按 20–30 分钟计时，final 留到第一次器件设计推演之后；没有独立依据的结果标 uncalibrated，不把第三方题解称为 MIT answer。

### 4 轮器件设计迭代才是课程特色

[Projects](https://ocw.mit.edu/courses/3-46-photonic-materials-and-devices-spring-2006/pages/projects/) 有 4 个连续设计节点。原课通常由 MIT 与 Singapore 两端各 2–3 人组队，做约 20 分钟、5–6 页 slides 的 presentation，之后提交 corrected slides 与 2 页 report。题目包括 waveguide/solar/Bragg/fiber、erbium ring laser、detector 和实时设计任务。

公开包没有 fabrication、bench protocol、measurement data、code repository 或 tests，因此这些项目属于 design exercise。lab 训练还需要设备、测量数据和现场指导。独学可提交 requirements、analytical model、parameter sweep、tolerance/noise budget、5–6 页展示和 2 页修订报告；MATLAB 或其他代码均标个人实现。

四轮迭代按器件链逐步收紧：先确定 optical function、geometry 与 material；再核对 gain/loss 或 source budget；随后检查 detector noise、responsivity、bandwidth 与 readout interface；最后做 system tradeoff 和口头答辩。选择 erbium ring laser 时检查 threshold 与 loss，选择 detector 时比较 dark current、area 与 bandwidth，选择 waveguide/Bragg 时检查 cutoff、reflection bandwidth 与 fabrication bias。每个关键选择都展示 hand-derived limit、numerical sweep 和被否决的设计分支。对 temperature、loss 或 process bias 不确定的项给出区间，观察参数变化是否让方案排序翻转。

7 套作业、7 次 quiz、final、至少 2 轮项目迭代与 1 页 2006/当前差异表共同构成课程成果。最后让 1 个设计连接 material、confinement、gain/loss、source/detector noise、readout 和 fabrication tolerance；没有 measurement 时，结论止于“在模型与假设下成立”。

材料参数一旦换成现代来源，要同时重算 confinement、loss、threshold 与 thermal budget，并在差异表中列出原值、条件和来源；不能只替换一个更漂亮的折射率或效率数字。

每轮答辩选出一个最关键的质疑，下一轮用手算、sweep 或 tolerance case 回应；这种前后变化比最终一张顺滑曲线更能解释设计为何成立。
