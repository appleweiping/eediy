## 先画光线，再决定是否从这门课进入 optics

MIT 2.71 是 Spring 2014 的本科 Optics；同一课堂的 2.710 是研究生版本。官方
[Syllabus](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/syllabus/)
列出 8.02 Physics II、18.03 Differential Equations 与 2.004 Dynamics and Control II
作为先修，并说明 2.710 在 HW4–HW6 增加分析题，还要求 final project。它不是从 Snell
law 开始的科普课，也不能用“会做薄透镜题”代替电磁波、微分方程和 LTI 理论背景。

开始前，拿一个两透镜系统完成 3 次表达：用 ray-transfer matrix 求像面和放大率；用
phasor/Jones vector 解释一片 retarder；用 Fourier transform 说明有限 pupil 怎样限制
resolution。第 1 项失败先补 paraxial optics 与矩阵，第 2 项失败先补 Maxwell equation、
complex amplitude 与 polarization，第 3 项失败先补 spatial frequency 与 convolution。
这是 EEDIY 的最小补课定位，不是 MIT 的成绩线。

如果主要需要视频带着建立 photonics 词汇，NPTEL 的
[Introduction to Photonics](https://nptel.ac.in/courses/108106135)
更像第一次入口。它的官方 [downloads API](https://nptel.ac.in/api/downloads/108106135)
目前列出 48 个 course-download 条目，混合 lecture、tutorial 与 lab demonstration，
但 `assignments` 是空数组；因此可以把它写成 48 段公开视频入口，不能写成有 solved
assignments。当期注册与评测必须在选课时重查。2.71 的优势是书面推导、problem set 与
历年考核，适合已经能独立读公式并希望把 geometrical、wave、Fourier optics 接成一条
分析链的人。

## 用三种语言重写同一个 optical system

官方 [Calendar](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/calendar/)
列出 25 次 session，从 Nature of Light 到 scalar/vector wave optics review。
[Lecture Notes](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/lecture-notes/)
实际列出 12 份 PDF：其中 Session 7 和 25 是 review handout，其余形成 10 组实质主题；
并不是 25 讲都有讲义。公开站没有完整 lecture video。正确的阅读单位不是“每份 PDF”，
而是同一个系统在 ray、wave 与 spatial-frequency 表示间怎样保持一致。

### Ray：先固定平面、符号与 aperture

Session 2、4、7、10 的材料覆盖 geometrical optics、paraxial matrix、eikonal、
gradient-index 与 Hamiltonian optics；calendar 还把 instrumentation、microscope、
telescope、aperture 和 stop 放在这一段。每道题先画带方向的 reference plane，声明
radius、distance 与 angle 的正号，再检查 determinant、afocal limit 和 chief/marginal
ray。矩阵乘对却把面次序写反，仍然是物理模型错误。

### Wave：相位账必须能回到强度

Session 9、11、22 从 EM wave equation 进入 superposition、interference、
interferometry、polarization、waveplate 与 birefringence。不要把 complex field 的相位
直接当成 detector intensity；先写 polarization basis 和 time convention，再由 field
得到可测的 irradiance。把 path difference 取 0、互相正交 polarization 或 coherence
消失作为极限检查，比只看一张 fringe 图更容易发现假设混用。

### Fourier：把 propagation、pupil 与 image 放在一张频域图

Session 13、14、16、20 的讲义连接 spatial Fourier transform、Fraunhofer/Fresnel
diffraction、coherent filtering、depth of field、holography；calendar 还在 Session 18
加入 incoherent imaging、resolution 与 pupil，在 Session 21 加入 Gaussian beam 和
laser principle。这里的主线是明确 source、propagation kernel、pupil/transfer function
与 detector，而不是背 Fresnel/Fraunhofer 两个名字。每次近似都写出 dimensionless
condition，并用 energy normalization、sampling interval 与 field-of-view 检查数值图。

## PS1–PS4 是答案回路，PS5–PS6 要靠考试交叉检查

官方 [Assignments](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/assignments/)
提供 Problem Set 1–6；PS1–PS4 有 solution，PS5–PS6 明确没有。Calendar 还把 PS3 标为
optional，而 Syllabus 说明 2.710 在 HW4、HW5、HW6 有额外题。自学前先选定按 2.71
还是 2.710 范围，不要把 graduate-only 题做完后反过来声称本科主线必须如此。

有答案的题按“先做—再看—隔几天重做”处理。订正不能只写 algebra error，应分别标记
ray sign、boundary condition、polarization basis、Fourier normalization、sampling
或 approximation regime。PS5–PS6 没有官方解答，可以把同一知识点送到考试档案做第二
测量；若仍无法确认，就保留 derivation 和未决假设，不能借一份来源不明的解答填空。

[Exams](https://ocw.mit.edu/courses/2-71-optics-spring-2014/pages/exams/)
同时保留 solved 与 unsolved 材料：2004、2008 的 Quiz 1 和 2009 的 Quiz 2 无解答；
2012 的 Quiz 1、Quiz 2 有解答；2013 final 只给 practice problems with solutions 与
Problem 4 solution；2014 的 Quiz 1、Quiz 2 和 final practice problems 都有解答。
因此不能概括成“历年考试全部 solved”。先用 2014 套题作接近本学期结构的闭卷检查，
再用 2012 作第二样本，较早的无解答试题只用于迁移测试。

## MATLAB 传播实验是 EEDIY 补充，不是公开 lab

2.71 公共目录没有可复现实体 lab。Syllabus 描述的 final project 属于 2.710：2–3 人
组队，由 mentor 建议先做几项简单 simulation，并在 Session 23–24 展示；但 OCW 没有发布该学期
project topic、数据或评分样例。独立学习者可以做一份 MATLAB、GNU Octave 或 Python
数值档案，但必须写明“EEDIY 补充”，不能标为 MIT 2.71 lab 或 2.710 final project。

一个合适的档案只需沿课程的 3 种表示推进：先用 ABCD matrix 追一组 rays；再传播一个
complex field 通过 aperture；最后在 Fresnel 与 Fraunhofer 两种条件下比较 point-spread
function、modulation transfer 和 resolution。保存 input field、wavelength、grid、
normalization、boundary padding、software version 与随机种子。把 grid spacing 减半、
field-of-view 扩大，再检查焦点、总能量与主要结论；若结果随 padding 改变，就还不能当
成光学结论。

完成证据应包括 PS1–PS6 首稿与订正、至少 2 套有解考试的计时答卷、12 份 lecture-note
索引对应的概念图，以及这份可重算的传播档案。没有 project prompt、实体 lab 或视频的
部分明确写“未公开”，不靠 EEDIY 仿真把缺口涂掉。提交纠错时，最好附具体 session、
PS/exam 编号、采用的 Fourier convention 与最小数值样例；这比一句“衍射结果不对”更容易
回写正文。

## 激光台不是检验 Fourier optics 的家庭作业

公开自学路线默认 simulation-only。Calendar 提到 field trip、Gaussian beams、
principles of lasers、waveplates 与 holography，并不等于提供了一份校外安全 lab manual。
不要在家庭环境搭建裸露 laser beam、改造高压 laser supply，或用未知等级光源对准眼睛、
反射镜和相机；镜面反射、不可见波段、聚焦光束与高压电源的风险不会因输出“看起来很暗”
而消失。

需要实体光学时，应进入有激光分级、受控区域、beam enclosure/stop、合适 eyewear、
interlock、培训与现场监督的实验室，并使用该设施的 SOP。对本页的 R0 自学范围，能从
ray 到 field 再到 spatial spectrum 解释同一光路、完成题目反馈链并复算数值传播，已经
构成有边界的学习证据；它不是实验室资质，也不是原课程的完整课堂复现。
