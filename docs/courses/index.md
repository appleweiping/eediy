目录按方向组织课程。每篇课程页都先回答几个实际问题：从哪里开始，公开了哪些作业或实验，缺了什么，以及校外学习者能否真正做下去。

## 先选方向，再选一门课

1. 如果目标还不明确，先看学习路线；已经知道要学什么，可以直接进入相应方向。
2. 同一主题通常只选一门主课。先打开它的第一份作业或实验，再根据先修、访问条件和设备要求决定。
3. 页面若只有公开材料整理、尚无完整学习复盘，会直接说明；这类判断不能冒充上过课后的体验。
