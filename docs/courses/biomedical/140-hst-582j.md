## 先把“生物医学”限制在这套数据里

MIT HST.582J 是 Spring 2007 的研究生 Biomedical Signal and Image Processing。官方
[Syllabus](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/syllabus/)
把数字信号处理放进 cardiology、speech 和 medical imaging 场景，课程重心是五个
MATLAB laboratory projects。Lab 1 的确要求从 ECG 中滤除噪声并设计 ventricular
arrhythmia detector，Lab 3/4 也使用 clinical brain MRI 和 medical-image registration；
这些措辞描述 2007 年教学任务，不构成诊断授权或临床性能声明。

本导读只推荐离线计算：使用 OCW 已提供的数据包，不接人体电极，不采集志愿者信号，
不处理新患者资料，也不把分类准确率写成 sensitivity/specificity 的临床证据。课程
数据能检验算法是否按作业运行，不能证明它在医院、监护设备或特定人群中安全有效。
任何涉及人体测量、可识别健康数据或临床决策的延伸，都需要机构伦理、隐私、医疗和
专业监督；那已经超出公开自学范围。

## 把课号翻译成实验真正会调用的数学

官方先修允许 6.003 Signals and Systems、2.004 Dynamics and Control II、16.004
Unified Engineering IV 或 18.085 Computational Science and Engineering I。开课号
之外，先把 Lab 1 和 Lab 3 会调用的纸上计算做一遍：解释采样和 aliasing；由 difference
equation 判断 FIR/IIR 与稳定性；说明 DFT leakage 和 window 的关系；用 Bayes rule 写
二类 decision boundary；对一组二维点计算 covariance、eigenvectors 并解释 PCA。
前三项不稳时先补 signals/DSP，后 2 项不稳时在进入 classification、segmentation 与
blind source separation 之前补概率和线性代数。

[Lecture Notes](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/lecture-notes/)
覆盖 data acquisition、filtering、ECG、DTFT/DFT、sampling、speech、2-D image
processing、PDF/classification、density estimation、segmentation/registration、
random signals 和 blind source separation。24 个 lecture 位置并不都附讲义：
MRI、surgical applications、random signals III 与 wrap-up 没有对应公开 notes，部分
早期章节还来自 1999–2001 课程资料。因此这是一套有明确年代的 archive，不是 2026 年
医学影像或生理信号实践标准。

## 以 Lab 为主轴重排二十四讲

[Calendar](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/calendar/)
把课堂与每周 4 小时 lab 交错安排。独立学习时更适合围绕
[Labs](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/labs/)
的输入和产出读取相关讲义：

1. **Lab 0（可选，1 周）：**跑 MATLAB tutorial 和 self-test，只解决数组、绘图、
   脚本与文件加载；
2. **Lab 1 ECG（3 周）：**配 Lecture 1–6，做 acquisition、filtering、DTFT/DFT 与
   sampling；数据包有 12 个 `.txt`、11 个 `.mat` 和 1 个 `.m`；
3. **Lab 2 Speech Coding（3 周）：**配 Lecture 7–8，比较 source-filter
   analysis/synthesis、pitch detector、vocoder 与 linear prediction；包内有 2 个
   `.mat` 和 13 个 `.m`；
4. **Lab 3 MRI Segmentation（2 周）：**配 Lecture 9–14，做 noise reduction、tissue
   labeling、contour 与 3-D visualization；包内是 supporting data、9 个 `.m` 和
   2 个 `.gz`；
5. **Lab 4 Registration（2 周）：**配 Lecture 15–17，优化 2-D slice registration
   objective；包内有 1 个 `.mat` 和 22 个 `.m`；
6. **Lab 5 Blind Source Separation（2 周）：**配 Lecture 18–20，用 Wiener filtering、
   PCA、ICA 与高阶统计处理 maternal/fetal ECG；包内有 10 个 `.dat` 和 7 个 `.m`。

课程另有五份计分 Problem Set 1–5；[Assignments](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/assignments/)
页面还列出 X、Y 两份补充题，但 syllabus 的总评只计五份。原课程有两次 quiz，
OCW 没有公开 quiz 题或答案；Problem Set 页面也没有给 PS1–5 配独立解答。自学者应把
这部分标为反馈缺口，不能把“题目可下载”写成“题解完整”。

## 五份报告比五个能运行的 notebook 更重要

官方 [Syllabus](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/syllabus/)
规定 lab reports 占总评 60%，远高于 problem sets 的 10%；这解释了为什么页面不应只
给出“运行 starter code”的建议。五份报告必须各自给出可复算结果：Lab 1 标出哪些 ECG
记录用于调 detector threshold、哪些用于检查，并给出滤波前后频谱和固定阈值下的计数；
Lab 2 把 codec 参数对应到重建 waveform、spectrogram 和可听伪影；Lab 3 在固定 MRI
slice 上给 tissue label 规则、区域计数和 overlay；Lab 4 给出 registration transform、
objective trace 和不同 initialization 的 overlay；Lab 5 并列 mixture 与 separated
traces，并解释 scale、sign、permutation ambiguity。Lab 2 的试听只能补充
waveform/spectrogram 数值，Lab 4 的 transform 还要注明像素坐标方向与 interpolation，
不能换一套切片后偷偷重调参数。

同一批记录上反复调 threshold 后得到的数字不能称为泛化性能；若有数据切分，必须写清
parameter-selection 与 final-check 两组。Registration 的 objective 下降不自动等于
解剖结构对齐，BSS 分量也不能直接命名为“母体”或“胎儿”而不说明歧义。这些结果只回答
给定教学数据上的信号处理问题，不是医疗器械 validation。

## MATLAB 迁移要保留数据语义

2007 课程在 MIT Server 的 MATLAB electronic classroom 运行；外部读者可下载说明、
starter `.m` 和数据，却没有原来的服务器、助教和现场 lab。商业 MATLAB 可能需要许可，
而 Python/NumPy/SciPy、GNU Octave 等开源路线可以降低软件成本；后两者属于 EEDIY
迁移，不是官方支持环境。

迁移前先原样保存 archive 和第三方来源说明；若重命名文件，要在 manifest 中保留
subject 与 condition identifier，也不要随意重新发布由第三方许可提供的 medical
images。迁移后逐项核对 array orientation、MATLAB 1-based indexing、filter initial
state、FFT normalization、image coordinate convention、optimizer tolerance 和
random seed。旧 `.mat`、压缩影像和自定义 `.m`
函数可能需要分别处理；能打开文件不等于数值语义已经一致。

## 五组数值解释留在各自报告里

五份 numbered problem sets 单独归档；Lab 1–5 的代码分别跟随本实验报告，数据出处和
许可说明也放在使用它们的实验旁边。Lab 0 只在 MATLAB 工具不熟时保留，不计作第五个正式实验。读完
五份报告后再横向比较：ECG/BSS 的 stationarity 或 independence 假设、segmentation 的
Gaussian 假设、registration 对 interpolation 和 initialization 的敏感性不能混成一个
“总体准确率”。

这份导读保留 ECG、speech、segmentation、registration、BSS 五种不同解释，而不是用
一个现代深度学习分类器替掉整门课。无需购买采集硬件，更不得为了“真实性”自行连接人体，
或把任何一份教学数据输出用于诊断。
