### 课程定位

MIT **HST.582J Biomedical Signal and Image Processing, Spring 2007** 适合已经会 DSP、想看它怎样进入心脏学、语音与医学成像的人。课程核心是 5 个 MATLAB 实验。Lab 1 会做 ECG 滤波与室性心律失常检测器，Lab 3/4 使用临床脑部 MRI；这些是教学任务，不是诊断授权。

正式先修可为 6.003、2.004、16.004 或 18.085。学习需要能解释采样/混叠、FIR/IIR 稳定性、DFT 泄漏/窗函数、Bayes 二类边界，以及二维协方差、特征向量和主成分分析（PCA）。

[Lecture Notes](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/lecture-notes/) 覆盖 24 个讲次位置，但 MRI、外科应用、随机信号 III 与收尾课没有对应公开讲义，部分材料来自 1999–2001。这是历史档案，不是 2026 年临床实践标准。

### 报告比“代码能跑”更重要

官方 [Syllabus](https://ocw.mit.edu/courses/hst-582j-biomedical-signal-and-image-processing-spring-2007/pages/syllabus/) 规定 lab report 占 60%，problem set 占 10%。Lab 1 报 threshold-selection/check split、前后频谱与 fixed-threshold count；Lab 2 连接 codec parameter、waveform、spectrogram 与 audible artifact；Lab 3 给 tissue rule、region count 与 overlay；Lab 4 给 transform、objective trace 和多 initialization overlay；Lab 5 并列 mixture/separated trace，并解释 scale、sign、permutation ambiguity。

说明中还要明确算法假设：ECG 与 BSS 的平稳性/独立性，分割的密度模型，配准对插值、坐标方向与初值的敏感性。Lab 2 的试听只能补充波形/声谱图，不能替代数值；Lab 4 的目标函数降低也要回到固定切片的叠加图检查。五种解释不能压成一个总体准确率。

在课程数据上反复调参无法证明泛化；目标函数下降也不自动证明解剖结构对齐。每份结论只针对课程提供的教学数据，不升级为医疗器械验证。每个实验都应保留一项失败案例：误检 ECG 段、语音伪影、分割漏区、配准局部错位或 BSS 泄漏，并把失败对应到算法假设。

### 工具与环境

2007 课程运行在 MIT Server 的 MATLAB electronic classroom；公开包没有原 server、TA 与现场 lab。迁移到 Python/NumPy/SciPy 或 GNU Octave 时，保存原 archive 与 attribution，并核对 array orientation、1-based indexing、filter initial state、FFT normalization、image coordinates、optimizer tolerance 与 seed。能打开 `.mat` 或 compressed image 只说明格式兼容，数值一致性仍需单独验证。

若重命名数据文件，manifest 必须保留 subject 与 condition identifier；第三方 medical image 还要逐项检查再分发许可。迁移后的新图应与旧实现共享相同 input、normalization 和 evaluation slice，避免在“修兼容性”时悄悄改变实验问题。以最小数据片段对齐旧实现，再跑完整数据；这能把 migration bug 与算法本身的局限分开。

每个 Lab 1–5 的 code、report、data license 分开存放，Lab 0 不算正式 lab。不要用统一 deep-learning classifier 覆盖 ECG、speech、segmentation、registration 与 BSS 的不同假设。

### 生物医学边界停在离线教学数据

只使用 OCW data package，不接人体 electrode、不采集 volunteer signal、不处理新 patient record，也不把 assignment accuracy 写成 clinical sensitivity/specificity。human measurement、identifiable health data 或 clinical decision 需要机构伦理、隐私与专业监督。5 份可复算 report 与 5 份 problem-set 记录足以呈现学习成果；它们不代表诊断性能。

HST.582J 的五个实验共享 DSP 工具，却不共享评价标准：ECG 看事件与误检，语音看编码失真，MRI 分割、配准与 BSS 各有自己的模型假设。
