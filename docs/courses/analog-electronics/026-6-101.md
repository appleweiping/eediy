## 实践与验收

**实践闭环**

**《Introductory Analog Electronics Laboratory · MIT 6.101》模拟前端增益—噪声—失真权衡**

这是维护者为《Introductory Analog Electronics Laboratory · MIT 6.101》建议的自学项目，不是课程官方作业。为模拟电子设计低压模拟前端，通过 SPICE 和可选限流原型量化增益、带宽、噪声、失真与饱和之间的取舍。

**来源：** 维护者建议项目

**交付物**

- 含偏置、器件额定值、稳定性和测试点的原理图与小信号计算
- 覆盖工作点、AC、噪声、瞬态和容差扫描的 SPICE 工程
- 原始频响、输出噪声、THD 和削顶波形，至少覆盖 3 种输入幅度
- 一份设计报告，列出规格矩阵、取舍、最坏角和失败修正

**验收**

- 标称中频增益与设计值相差不超过 5%，-3 dB 带宽达到预先声明规格
- 验证最小输入、最大线性输入、共模边界和电源余量四种边界
- 用手算 gm/增益/极点与 SPICE 交叉核对，关键量差异低于 10%
- 注入负载加倍或器件参数角，报告相位裕度、THD 或输出摆幅的首个失效

**复现要求**

- 提交原理图、模型、网表、计算、绘图源文件和 README
- 固定仿真器、器件模型版本、容差种子与全部分析参数
- 保存未处理波形、测量设置和自动生成的规格报告

**安全边界：** 低能量实验 — 实体原型仅限隔离、限流且不高于 12 V；核对器件额定值、功耗与极性，断电接线，不接市电、人体或大功率负载。

**风险、缺口与边界**

六个实验和一个为期七周的项目很有价值，但付费阅读材料与旧器件要求准备替代物料清单。

**完成证据**

- 按周学习日志：投入时间、问题、错误订正、决策、下一步，并链接本周可复现产物
- 设计审查包：需求与约束、方案权衡、可编辑源文件、适用的 ERC/DRC/时序/稳定性检查、导出物与复现实验
- 仿真包：模型或网表、输入、求解器与版本、参数扫描脚本、基准对照、预期结果及一条重新运行命令
- 代码仓库：固定依赖和工具链、最小运行命令、测试或波形/基准、预期输出与许可说明
- 实验包：原理图/装置设置、校准记录、原始数据、不确定度、安全检查、失败记录与从原始数据重建图表的步骤
