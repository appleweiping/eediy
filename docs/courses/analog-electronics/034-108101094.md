### 每个电路都追一次非理想

学 inverting stage 时，由 ideal gain 推到 finite open-loop gain、bandwidth、offset、
bias current、slew 和 output swing；学 filter 时，由 pole placement 写 transfer
function 和 Bode 预测，再跑 SPICE。每个 netlist 记录 op-amp model、supply、temperature、
source/load 和版本。振荡器还要解释 start-up 与稳幅机制，不能只看见一条周期波形。

2019 [Announcements](https://onlinecourses-archive.nptel.ac.in/noc19_ee10/announcements)
显示该运行有 8 次 weekly assignments，但匿名访问不保证永久保留完整题目、答案和 grader。
可按周做阶段题，用极限、SPICE 或教材复核；个人得分只代表这套自学练习。

### 把保护、增益、滤波和 offset 做进一个前端

做一条低压 sensor front end：输入保护、gain、active filter、offset 与输出接口。写清
signal range、noise/headroom 和 stability，再做 corner sweep 与关键频点实测。实际运放的
common-mode range、GBW、slew 和 load 条件需来自同一 datasheet 测试条件；拼接不同的 typical
数值会构造出实际不存在的器件。这个链路足以检验课程内容是否接起来，也不会把演示视频误当成完整
hardware lab。

最后反向读一次 datasheet：从输出失真或稳定性问题回到 common-mode、output swing、load
capacitance、GBW 和 phase margin 的测试条件。能指出哪一项最早成为设计限制，才算把平台题迁到
真实运放。
