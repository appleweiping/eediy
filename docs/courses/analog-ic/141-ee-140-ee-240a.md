### 访问与版本说明

Berkeley EE 140 / EE 240A Spring 2025 适合模拟基础扎实、愿意接受校园 Cadence 断点的人。两门课共用 lecture、homework、lab 与 project；本科读 Razavi 第 2 版，研究生读 Gray/Hurst/Lewis/Meyer 第 5 版，两本都是商业教材。[Catalog](https://www2.eecs.berkeley.edu/Courses/ELENG140/) 把 EE 105 列为先修，内容从 transistor amplifier、op-amp、feedback、frequency response，走到 bias/reference、ADC、switched-capacitor filter、comparator、hardware lab 和 design project。

这不是“找一套开源 SPICE 就能完整搬回家”的课程，但也远非不可学。公开讲义和题目足以讲清模拟 IC 的设计推理，校园 Cadence、配置好的 SKY130、GSI review 与团队集成则构成一道真实边界。接受这道边界，反而能更准确地挑出值得做的部分。

开课前用一只 MOS common-source 自测：从 bias 求 \(g_m,r_o\) 与 gain；由 capacitance 估 dominant pole 和 step response；加 feedback 后判断 loop gain、phase margin 与 swing。哪一层说不清，就补 device model、pole-zero 或 stability。

### 作业与反馈

21 份 PDF 从 diode/BJT/MOS、small signal、active load/current mirror、differential pair 与 2-stage op-amp，推进到 compensation、RHP zero、bias、cascode、switched capacitor、ADC/PGA、StrongArm、gain boosting 和 noise。做手算时，region、\(V_{OV}\)、gain/pole、swing/common-mode 与 power 应始终在同一页；否则一次尺寸修改很容易“修好”增益，却悄悄毁掉摆幅或功耗。

[Spring 2025 课程目录](https://people.eecs.berkeley.edu/~pister/140sp25/) 有 HW1–HW10，HW7 同时放着 original 和 v2。直接给出的当前 solution 只有 HW8、HW10，另有 Spring 2025 Midterm 2 solution。旧 solved exam 很多，但 term、topology 和 process parameter 不同，不能把它们写成十份当前 homework 都有答案。

仿真与手算打架时，优先区分 model simplification、schematic mistake 和 PDK behavior，再动 transistor size。固定 testbench、source/load、analysis type 与 measurement expression，比较修改前后的 operating point、small-signal parameter、dominant pole、output swing、common-mode range 和 power。这个习惯比某一组“最佳 W/L”更值得带走。

### 实验与项目

[Project specification](https://people.eecs.berkeley.edu/~pister/140sp25/labs/project.pdf) 要 3 人 analog team 集成 8-bit SAR ADC、switched-capacitor PGA、bandgap/temperature sensor、analog multiplexer 与 analog/digital regulator，battery 从 3.2 V 降到尽量接近 1.6 V，temperature range 为 0–70 °C。

真正棘手的不是某个 block 单独跑通：folded-cascode 的 gain/bandwidth 会限制 PGA 与 regulator，bandgap/noise 会进入 ADC，clocked switch 与 charge injection 会改变 sampled value，battery droop 又压缩所有模块的 headroom。局部优化后要回到 system waveform，分清 reference settling、PGA sampling、comparator decision 与 digital handoff；把异常统称为 “ADC noise” 只是在躲问题。

### 校外选一个 block，问规格还剩多少

没有 Berkeley server 和配置好的 Cadence/SKY130 时，可以选 folded cascode、bandgap、PGA 或 StrongArm，用许可清楚的 PDK、model 与 simulator 搭替代 testbench。它能训练同样的 `spec → hand analysis → schematic → corner/temperature → waveform → decision` 思路，却不会继承 Berkeley 的器件模型、corner、parasitic 和校园评阅。

校外改写最容易出现的错觉，是“网表能跑”就等于“工艺等价”。更诚实、也更有技术含量的问题是：换了 device model、corner、parasitic、noise 与 interface 之后，原规格还满足几条，为什么。Cornell ECE 3150 更适合作为完整公开反馈的起点；EE 140/240A 的价值，是接受 Cadence 断点之后，继续追 mixed-signal interface 的深度。

一张成功 waveform 不能代表已经覆盖 1.6–3.2 V、0–70 °C 与整机联调。若 testbench 条件和 measurement expression 都说不清，连图上那条曲线测的是什么也无法判断。
