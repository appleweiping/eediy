### 课程定位

MIT OCW [6.701 Introduction to Nanoelectronics, Spring 2010](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/) 是本科课。[Syllabus](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/syllabus/) 显示每周 2 次 1 小时 lecture 和 1 次 recitation，正式先修是 6.007 Electromagnetic Energy 或 6.003 Signals and Systems。课程由 quantization、wavefunction 与 Schrödinger equation 进入 molecule、nanotube、crystal、band、ballistic conduction、Ohm’s law、MOSFET 与 computation limit。

课程依赖 complex exponential、eigenvalue/eigenvector、ODE、probability normalization 和基本 electrostatic energy。用 1D infinite well 写 boundary condition、归一化 wavefunction，并解释 level spacing 怎样随长度变化；只能背答案时先补数学与基础量子。

### 8-part open textbook 本身就是课程

[Open Textbook](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/open-textbook/) 实际列出 Part 1–8。读法保持 `state → energy → occupation → transport`：先定 Hamiltonian 和 boundary，求 allowed state，再加入 contact/statistics，最后算 current。用一张 `length–energy–state–occupation–current` 比较表并排放 molecule、nanotube、crystal 与 MOSFET，避免把 DOS、carrier density 与 conductance 混成一种量。

这张表还要写 mode count、contact chemical potential、transmission 与 device electrostatics。几何首先改变 level spacing 和 available modes，reservoir 决定 occupation，transmission 才决定各 mode 对 current 的贡献。若某条曲线变化后无法指出是哪类参数改变，说明模型还没有真正接通；这比继续翻下一章更值得停下来订正。

前段用 boundary condition 解释 quantization；中段追踪 periodic structure、band formation 与 filling；后段再引入 Landauer transport、bulk limit、MOSFET 和 computation limit，并逐项写出 scattering、contact、electrostatics、temperature 等新增假设。2010 的器件案例有历史性，先进 CMOS 结构与材料数据应另查当前文献。

### 课程任务

[Assignments](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/assignments/) 列出 12 份 homework，没有完整官方 solutions。每题检查 normalization、units、energy reference、limiting size 与 occupation assumption；没有 analytical limit 或独立数值交叉检查时，暂不下定论。

Syllabus 另列 2 个 MATLAB project：Part 3 Problems 9–11，以及 Part 5 Problems 1、3。公开包给出任务指向，却没有完整 source code 和 official output。复建时固定软件版本、grid、boundary condition 与 convergence test；前者可检查 Hermitian、state normalization 与 eigenvalue convergence，后者检查 0-bias current、left/right contact symmetry 与 ballistic limit。代码应标为个人实现。

仿真说明还应列出原题边界、数值选择和失败案例，使读者能区分教材模型、个人实现与运行环境造成的差异；复建目标是可解释的独立实现，无需猜回旧学生代码。本征值排序、相位约定和 mode 截断也要固定，否则两次看似相同的图可能并非同一计算。

### 三份无解考试之后，再回看 ballistic MOSFET

[Exams](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/exams/) 提供 2010 midterm、2010 final 和 2011 final，均无 solutions。把 2010 midterm 作为中点计时检查，2010 final 作为结课首测，2011 final 作为迁移测试；逐题用 open-text definition、dimension、degeneracy、boundary condition 和 limiting size 订正，不引用非官方整套答案。

课程没有 classroom video；Syllabus 提到的 6.719 spin project 也不可用。一个务实的学习组合是
12 份完整解题、2 个做过 grid/boundary convergence check 的 simulation、三次考试订正，以及
一只 ballistic MOSFET 的综合分析：从 contact states、occupation 与 transmission 推到
current，再逐步加入 scattering 和 electrostatics，找出何时开始接近 bulk model。
