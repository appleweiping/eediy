### 18.06SC 胜在题目和解答真能对上

MIT [18.06SC](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) 适合第一次学线性代数、又希望题目有完整反馈的人。它把 Strang 阅读、讲解、录像、题目和答案按主题放在一起；[Resource Index](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/resource-index/) 比播放列表更能说明课程实际覆盖。内容从消元与四个基本子空间，走到最小二乘、特征值、正定矩阵和 SVD。目录把 18.02 列作先修，但课程说明也明确表示完成内容并不依赖微积分；真正要紧的是矩阵运算和向量几何。

### 作业与反馈

公开索引有 31 组 topic problems，全部配解答；Exam 1–3 与 [Final Exam](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/final-exam/) 也都有答案。独立完成每组题后，用第二种颜色标出错误原因，例如混淆 nullspace 与 left nullspace，或忘记检查 least-squares residual 是否与 column space 正交。“粗心”无法成为下一题可复用的诊断。

最能检验理解的练习，是把一个低秩矩阵查到底：行阶梯形、四个子空间的基与维数、最小二乘投影、特征结构和 SVD，并用手算小例子核对软件结果。若想增加可运行直觉，可参考 Eric Ayars 的非官方 [Elementary Linear Algebra notebooks](https://github.com/ea42gh/linear-algebra-notebooks)：它以 CC BY 4.0 发布，含 110 多个 Jupyter notebooks 和持续集成，属于独立编写的计算伴读，与 MIT 课程答案无关。

准备 3 类矩阵会让抽象概念落地：一个长方形且 rank-deficient 的矩阵，用来核对四个子空间与 least squares；一个 symmetric positive-definite 矩阵，用来比较能量、特征分解和 Cholesky；一个接近奇异的矩阵，用来观察条件数和舍入误差。每个例子都手算小尺寸版本，再用软件放大规模，并检查 \(A\mathbf x\)、正交残差或重构误差。只有输出 eigenvalues 而没有基、投影和残差，无法说明理解了哪一层结构。

尤其要比较 eigen-decomposition 与 SVD 的适用边界。拿一个非方阵或非对称矩阵，写出两者需要的条件、左右向量所在空间和重构方式；再改变一列的尺度，观察 singular values、condition number 与 least-squares solution 怎样变化。保存数值库版本与容差，避免把舍入差异误认成理论矛盾。这个例子会直接连接后续的数值线性代数、信号子空间和低秩近似，也能阻止“所有分解都在找主方向”的模糊说法。

### 下一门课真正会用到哪些东西

第一阶段应把消元理解为揭示子空间结构的方法；第二阶段要能从正交投影推出 normal equations；第三阶段则要解释 eigenvalue 与 singular value 分别回答什么问题。官方未设编程项目，因此无需虚构 “MIT project”。想加一点计算，可以做低秩图像近似：注明矩阵维数、截断规则和误差度量，并放一个可手算的微型矩阵在旁边。

离开课程前再做一张混合试卷。若面对新矩阵能判断问题属于 rank、subspace、projection 还是 spectral structure，并据此选择算法，就已经获得了 18.06SC 最有用的能力。
