## 三个变量不是这门课真正增加的难度

MIT [18.02SC 课程主页](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/)
对应 Denis Auroux 的 Fall 2010 OCW Scholar 版本。它沿用 Auroux 在 Fall 2007 的课堂录像，
再配独立学习用的习题课、讲义、problem set、考试与 Java Mathlet。真正的新难点不是把
\(x\) 换成 \(x,y,z\)，而是同时管理对象、坐标和方向：标量场还是向量场，曲线还是曲面，
积分区域怎样参数化，法向或边界方向由谁决定。

官方 [Syllabus](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/syllabus/)
把 18.01 单变量微积分列为先修，并给出约 150 小时、每个 session 至少约 1 小时的提供方
估计。它不要求教材，公开材料可以自成主线；150 小时仍只是课程方量级，不是学习者必须
照抄的日程。先用 Unit 1 的前 8 个 session 记录画图、推导、空白作答和订正时间，再决定
是否压缩录像。

相邻的 Fall 2010
[18.022 Syllabus](https://ocw.mit.edu/courses/18-022-calculus-of-several-variables-fall-2010/pages/syllabus/)
同样以 18.01 为先修，但采用 Colley 教材，在 34 次课堂中更强调 \(n\) 维空间、可微性、
moving frames、manifold 和 differential forms；原班还有周作业，作业、小时考试与期末
分别占 25%、45%、30%。需要大量图像、分段录像与已解练习来独立建立空间直觉时，优先
18.02SC；已经能算通三大积分定理，想把概念推广得更严谨，再选 18.022。

## 入场用三张图，而不是一份公式测验

在打开答案前做三项 EEDIY 诊断；它们不是 MIT 官方入学考试：

1. 给定两个不共线向量，算投影、叉积与由它们张成的平行四边形面积，并画清右手定向。
   若叉积只有行列式手势而没有几何含义，从向量和行列式开始。
2. 对 \(f(x,y)=x^2+xy+2y^2\)，画等高线，在一点给出 gradient、一个方向导数和切平面
   近似；若三个答案互不相连，先补单变量导数与线性近似。
3. 把单位圆盘上的 \(\iint (x^2+y^2)\,dA\) 改写为极坐标，并解释为什么面积元含
   \(r\)；若只会套 \(r\,dr\,d\theta\)，不要进入球坐标或曲面积分。

第 1 项诊断方向，第 2 项诊断局部线性化，第 3 项诊断 Jacobian。后续错误也按这三类
编码；这样能区分算术失误和“对象根本没画对”。

## 用“对象—坐标—定理”重排四个单元

官方 [Unit 1](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/1.-vectors-and-matrices/)
从 vectors、determinants、planes、matrices 和 linear systems 走到 parametric curves；
Unit 2 把多变量函数接到 tangent approximation、optimization、chain rule、gradient、
directional derivative 与 Lagrange multipliers；Unit 3 处理 double integral、平面向量场、
line integral 与 Green's theorem；Unit 4 则进入 triple integral、surface flux、
divergence theorem 和 Stokes' theorem。

不要按“学完一种积分就清空工作区”的方式推进。每遇到新对象都填写同一张几何契约：
定义域维数、值域维数、参数、微元、方向约定、单位和可用定理。例如，line integral 必须先
区分标量沿弧长累计和向量场做功；surface integral 必须说明 \(dS\) 还是有向
\(\mathbf n\,dS\)；换坐标必须把区域、边界与 Jacobian 一起换。最难的部分通常不是积分
技巧，而是法向反了、边界方向不一致或参数化重复覆盖。

在 EE 中，gradient 和 Jacobian 可用于器件/电路模型的局部灵敏度与多参数线性化；double
或 triple integral 可累计面电荷、体电荷和能量密度；line、surface integral 以及
divergence/curl 则是电磁场积分式与微分式之间的数学接口。18.02SC 不教授材料本构关系、
Maxwell 边界条件或具体器件模型；把数学对象映射到这些量是 EEDIY 的迁移解释，不是课程
官方实验。

## Maxwell 只在数学链闭合后进入

Unit 4 的官方
[Physics Applications](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/4.-triple-integrals-and-surface-integrals-in-3-space/physics-applications/)
把 Session 97 标为 Curl and Physics，把 Session 98 标为 Maxwell's Equations，并用
Gauss 与 Stokes 连接积分形式和微分形式。这里适合做“定理审计”，不适合假装已经学完
电磁学：对每条式子写出区域、边界、定向、光滑性假设和单位，再说明是哪一个积分定理完成
转换。若只记住 \(\nabla\cdot\) 和 \(\nabla\times\) 的符号，回到 Unit 3 的 Green 与
line integral，而不是继续背 Maxwell 四方程。

一个低风险的补充产物可以是 **EEDIY 场审计 notebook，不是 MIT 官方作业**：选两个解析
向量场，在矩形/圆柱等简单区域上分别计算 divergence/curl、边界积分与区域积分，并用数值
采样检查方向和 Jacobian。必须同时保留解析推导、网格收敛、方向翻转测试、软件版本和原始
输出；数值相等不能替代定理条件。

## 四道一小时关卡不能用解答代替

官方 [Exam 2](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/2.-partial-derivatives/exam-2/)
展示了 Scholar 的反馈结构：每个 unit 有一套一小时考试，并配 review、practice material、
正式试卷与 solution；各 part 的 problem set 和 session problem 也有解答。先在草稿中画
对象和方向，再闭卷计时；看解答后把错误归到对象、坐标、定向、定理条件或计算。若只是最后
符号相反，仍要追到哪一步法向或边界方向改变，不能写成“粗心”。

[Final Exam](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/final-exam-1/)
是 1 次三小时综合期末；课程共有 4 次一小时 unit exam。公开页提供试卷与解答，但没有为
校外学习者列出自动 grader 或 MIT 成绩。Java Mathlet 若因现代浏览器不支持而无法运行，
标为 legacy optional，以手绘截面、本地等高线/向量场图替代；不要把插件可用性混成积分
能力。
