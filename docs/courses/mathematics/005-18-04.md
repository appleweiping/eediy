# MIT 18.04: Complex Variables with Applications

## 课程简介

- **所属大学：** MIT
- **课程编号：** 18.04
- **官方先修：** MIT 的正式先修是 18.02，以及 18.03 或 18.032 二选一
- **本站建议背景：** 本站的 18.03SC 页面可作为微分方程的公开复习入口，但不是满足 MIT 要求的唯一方式
- **访问条件：** 无需注册公开访问
- **资料状态：** 2026-07-30；公开材料导读

### 一套适合 EE 的复变函数课

MIT 18.04 Spring 2018 的优点是材料属于同一学期：官方
[Syllabus](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/pages/syllabus/)
把 37 个 [lecture blocks](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/pages/lecture-notes/)
一路排到留数、保角映射、Laplace 变换和解析延拓。它没有公开视频，适合愿意读推导、做题，
并想把频域、二维场和边值问题背后的数学补扎实的人。这类学习目标与课程尤其匹配；只想快速查
积分公式，不必完整修读。

正式先修是 18.02 与 18.03，或同等的 18.032。开课前应熟悉曲线积分、常系数微分方程、
复指数和多值辐角；这些基础不稳时，留数计算可能还能模仿，branch、收敛环域和围道选择却会
持续出错。

### 题目比视频更重要

最好的节奏是读一小段讲义，独立做例题，再看
[Recitations](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/pages/recitations/)
中教师如何选择围道或判断 Laurent 展开的区域。9 套
[Problem Sets](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/pages/problem-sets-and-solutions/)
都有解答；完成自己的推导再对照答案，并把错误分成代数、遗漏定理条件和策略选择。

每道复对数题写清 branch 与 branch cut，每个 Laurent series 写中心与环域，每次用 residue
theorem 都列出围道内奇点并解释辅助圆弧为何消失。这些条件比最终那个数更能说明是否理解。

### 最后独立做一道没见过的留数或保角映射题

[Exams](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/pages/exams/)
提供练习卷、正式卷和解答，适合在完成对应单元后闭卷检查。结课时另选一道没见过的题：用留数做
逆变换，或用保角映射处理二维电场边界，并说明解的适用区域、奇点与失效条件。能为每一步
解析操作辩护，比记住一张熟悉的围道图更接近这门课的目标。
