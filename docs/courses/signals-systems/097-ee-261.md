### 变换约定决定 Fourier 图像怎样解释

Stanford SEE [EE261](https://see.stanford.edu/Course/EE261) 是 Brad Osgood 的 Fall 2007
课程，从 Fourier series/transform 走到 distributions、sampling、DFT/FFT、2D transforms
和 Radon tomography。[Syllabus](https://see.stanford.edu/materials/lsoftaee261/Syllabus.pdf)
把目标写成识别何时、为何、怎样使用 transform。它适合已有 calculus、complex exponentials
与基础 signals 背景，想理解 Shah/Poisson、diffraction、lattices 和 imaging 共用语言的人；
第一次学习 LTI、Laplace/z-transform 或 filter implementation 时，从工程导论起步更合适。

### 课程结构

representation 镜头连接 orthogonality、duality、scaling 与 convolution；distribution
镜头说明 delta/Shah 在普通函数语言失效处怎样工作；sampling 镜头从 Poisson summation
推到 spectrum replication、aliasing 与 finite-record leakage；geometry 镜头把 rotation、
lattice 和 projection-slice theorem 接到 tomography。所有推导共用一张 convention sheet：
指数符号、\(2\pi\)、频率单位、sinc/Shah 定义、DFT normalization 与 2D determinant scaling。

[scikit-image](https://github.com/scikit-image/scikit-image) 是 BSD-3-Clause
image-processing 库，仓库自带 Radon transform 与 reconstruction 示例。它既不是 EE261
starter，也不是 solution set。可从简单 phantom 重做 sinogram，改变 projection angle count 和
image resolution，检查坐标方向、filter normalization 与重建误差，再把结果对应回
projection-slice theorem。

结课选 2 个应用：sampling/audio 与 diffraction、crystallography 或 tomography 中的另一项。
每项从约定和核心推导开始，再用课程数据或可分享输入验证，并用 Parseval、单位或 inverse
transform 做反向检查。一张图若无法说明 normalization、坐标变换和 approximation，仍不算
EE261 式的 Fourier 论证。

### 与工程型 signals/DSP 课程的边界

[MIT 6.003](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/) 更适合建立
continuous/discrete LTI、differential/difference equations 与 Laplace/z-transform；
[MIT RES.6-008](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/)
更重 IIR/FIR structure、coefficient quantization 和 realizable implementation。EE261 的
优势是 Fourier ideas 的数学与几何迁移，不能代替完整 DSP implementation course。无论采用
哪套软件，都应以一个高斯或矩形输入做往返变换，核对幅度、单位和坐标方向；这一小检查能在复杂
成像结果出现以前抓住约定不一致。
