# Cornell University ECE 3400: ECE Practice and Design

### 课程重点

Cornell [ECE 3400](https://ocw.ece.cornell.edu/courses/ece-3400-ece-practice-and-design) 公开的是 Spring 2016：每周 3 次 lecture，前半学期做 4 个 lab，后半由 7–9 人完成 maze-mapping robot，没有考试。[Syllabus](https://ocw.ece.cornell.edu/courses/ece-3400-ece-practice-and-design/ece-3400-syllabus) 要求机器人辨认路径和墙、寻找 source beacon，并把地图传给 base station；学生还在 6 个项目中轮换领导。想只学传感器接线可选更短实验，想练接口、集成和团队决策则值得做。

课程假定学习者会基础模拟/数字电路、微控制器编程、焊接测量和状态机。独学无法复制大团队，但仍能练到接口怎样约定、设计选择怎样改变，以及一个模块怎样交给下一个模块继续集成。

### 实验与项目

[Projects and Labs](https://ocw.ece.cornell.edu/courses/ece-3400-ece-practice-and-design/ece-3400-projects-and-labs) 公开 Lab 1–4 与 final brief，但没有 solution。[Lab 1](https://ocw.ece.cornell.edu/files/2017/03/ece3400_lab1-1ll6xvm.pdf) 训练仪器、接线和基础控制；后续每项分别为 sensing、motion、communication 或 integration 消除风险。到 [Lab 4](https://ocw.ece.cornell.edu/files/2017/03/ece3400_lab4-25e5n88.pdf) 时，每个模块应能靠事先采集的输入或 fixture 离线回归。

Notebook 是每天真正用来做决定的地方：日期和版本说明测的是哪套系统，schematic 与测点说明信号从哪里来，预期和原始数据决定下一步改哪里。团队用 owner 明确谁负责接口；独学可以隔一天重看同一页，专门寻找前一天忽略的假设。

### Final project 从接口表开工

[Final Project brief](https://ocw.ece.cornell.edu/files/2017/03/ece3400_finalproject-2jk3dax.pdf) 给出 2016 竞赛规格。开工动作是抽取场地、墙/路径、beacon、通信、得分和时间约束，据此选择底盘、sensor、processor 与 radio。接口表至少写供电、逻辑电平、pinout、消息字段、坐标系、单位、update rate、timeout 和安全停止。

集成从手动停止和 teleoperation 起，依次加入直线/转向、单传感器、局部地图、beacon、无线和全自主；一次只增加一个闭环。最终在相同条件重复多次，报告成功率、地图误差、beacon false positive/negative、丢包和电池状态。

### 集成测试

公开页没有 lecture notes、考试、lab solution、器材、团队分配和现场 checkoff。无实体平台时可用 simulator、sensor replay、地图和 base-station mock，但要说明未验证的动力学、噪声与 RF。

独立学习时，把 lab notebook、注明日期的接口版本、BOM、源码/原理图、原始 telemetry 和重复演示结果放在同一工程里。遇到真正影响设计的决定时，说明当时看到了什么数据、为何没有选另一个方案。伦理问题也落到动作上：相机数据何时删除、无线频段是否允许、电池怎样处置、失控时怎样停机。接口一旦改变，就沿地图和运动模块各跑一次测试，看看影响究竟传到了哪里。
