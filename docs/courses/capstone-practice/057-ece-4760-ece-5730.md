# Cornell University ECE 4760 / ECE 5730: Digital Systems Design Using Microcontrollers

## 课程简介

- **所属大学：** Cornell University
- **课程编号：** ECE 4760 / ECE 5730
- **官方先修：** Cornell ECE 4760/5730 policy 要求 ECE 3140 或任课教师许可，并预期 C、电子装配与数学基础
- **本站建议背景：** 本站未另设准备条件

### 三次累计实验，再进入完整嵌入式项目

想把定点 DSP、DMA、图形、控制和机电接口累积成一个系统，Cornell [ECE 4760/5730](https://ece4760.github.io/) 值得选；只想做几个独立外设 demo，则没必要承担这门课的工作量。3 个 lab 共同服务于系统集成。当前板卡是 Pico 2 的 RP2350；站内仍有 2025、2022 的 RP2040 录像和 2021 的 PIC32 档案。概念可以借用，board target、pin mapping、SDK 和寄存器不能混用。

[Policy](https://vanhunteradams.com/Pico/CourseMaterials/Policy.html) 以 ECE 3140 或教师许可为先修，并默认学生会 C、电子制作和数学。可用当前 demo 具体检查这些基础：在 Pico 2 上输出 GPIO/PWM，再保存一张带时间、电压刻度的示波器 trace；困难通常对应 CMake、datasheet 阅读或测量能力的缺口。

### 实验与项目

课程用约 3 周完成一个 lab，再留 4–5 周做 final project。

- [Birdsong](https://vanhunteradams.com/Pico/Birds/Birdsong.html) 用 DDS、定点数、SPI DAC、keypad 和去抖状态机合成约 2–7 kHz 的鸟鸣；频谱、扫频时序和交互共同说明实现质量。
- [Digital Galton Board](https://vanhunteradams.com/Pico/Galton/Galton.html) 在 60 fps VGA 上并发模拟碰撞与二项分布，并用 DMA 播放声音；要同时报告帧率、吞吐量和分布误差。
- [1D Helicopter](https://vanhunteradams.com/Pico/Helicopter/Helicopter.html) 集成 I2C IMU、互补滤波、PWM、隔离和 PID。plant model 或录制 IMU 数据用于校正符号与饱和，实体台架留到这些结果稳定之后。

前两项建立定点、DMA、显示和可观测性，跳过它们直接上闭环，会把软件故障第一次暴露在高风险装置上。

接入 Pico 2、真实传感器或 actuator 之前，可以用 [sensor sampler 小练习（非 Cornell 官方实验）](https://github.com/appleweiping/eediy/tree/main/examples/sensor-sampler)观察 timeout 和 cancellation 怎样隔开状态机与 target adapter。它只在 host 上模拟错误路径，没有验证 RP2350、实体传感器或总线。

### Helicopter 只在具备台架条件时复建

[Motor Circuit](https://vanhunteradams.com/Pico/Helicopter/MotorCircuit.html) 的隔离侧用 12 V 驱动 MOSFET gate，电机侧为 5–6 V，处理器侧与电机侧分别供电且不共地。电机电流路径不得走无焊面包板；逐项核对 4N35、MOSFET 和续流二极管方向，并配置限流、机械限位、防护和可触及急停。PWM 停止态、开环方向与 IMU 符号应在接入闭环前确认。没有示波器、限流电源和安全台架时，仿真闭环是合适范围，实体装置不具备安全复建条件。

### 结课项目

[Final Project](https://vanhunteradams.com/Pico/CourseMaterials/Final_Project.html) 要求 2–5 页 proposal，并用周报、demo 和可重建的网页推进；官方给最后 4–5 周每周约 16–20 小时。选题时只挑一个 sensor 和一个 actuator，把两端的接口、core、stretch、fallback、BOM、成本和风险说透。最终网页应含原理图、版本、原始测量、scope trace、速度或精度、失败尝试与引用。

公开站能取得 lab writeup、demo code 和历届项目网页，但不提供 Canvas、课程硬件、工作人员签核或现场指导。Birdsong 的定点数、Galton Board 的并发，或 Helicopter 的闭环限制，至少应有一项真正改变 final project 的设计；否则三个 lab 只是彼此无关的演示。
