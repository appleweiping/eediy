### 课程材料

MIT [RES.6-008](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/) 页面写着 Spring 2011，课程说明却明确说这套材料由 CAES 在 1987 年为在职工程师制作。20 讲的黑板、画质与器件例子属于那个年代，但 difference equation、z-transform、DFT、滤波器结构和有限字长并没有过时。想第一次系统学习离散时间 DSP，它依然是一套非常紧凑的主线；若连续时间 LTI、卷积、Laplace/Fourier 还不熟，应补 6.003。

这门课的优点恰恰是慢。Oppenheim 在黑板上把一个对象从序列变到变换、再变到结构，推导没有被幻灯片切碎。缺点也很明确：Required text 是 Oppenheim 与 Schafer 1975 年版，OCW 只有章节映射，没有公开整书。

### 课程结构

[Video Lectures](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/video_galleries/video-lectures/) 有 Lecture 1–20，外加 2 个 sampling/aliasing demonstration；两个 demonstration 单列，目录里没有 Lecture 21 或 Lecture 22。官方 [Study Materials](https://ocw.mit.edu/courses/res-6-008-digital-signal-processing-spring-2011/pages/study-materials/) 配有 20 组 homework，Lecture 2–20 另有 19 份 solution packet。

按四段走最顺：1–7 是 difference equation、convolution、DTFT、z-transform；8–10 是 DFS、DFT、circular convolution；11–17 是结构、量化与 IIR/FIR 设计；18–20 收到 FFT。每一段都选同一个小系统，让时域、变换域、框图与实现结构互相对上。因果性、稳定性、ROC、下标约定和有限精度不要藏在图注之外。

### 一条短序列，足够拆穿大多数 DFT 糊涂账

手算两条短序列的 linear convolution，再决定 padding，用 DFT 相乘得到同一结果；接着故意去掉 padding，看 time aliasing 怎样出现。频谱横轴同时写 bin、Hz 与归一化角频率，窗长也写清。只增加 FFT size 时，采样点变密并未提高真实分辨率——这句话若不能在刚才那条序列上解释，DFT 还没有真正落地。

滤波器部分则让 FIR 与 IIR 面对同一组通带、阻带和延迟要求，再比较乘加量与系数敏感度。把 IIR 从 direct form 换成 second-order sections 后，别只看幅频曲线；冲激响应、极点半径、内部状态范围、溢出和群时延往往更能说明量化发生了什么。1987 年的硬件可以跳读，这些数值结构今天仍会出现在定点 DSP、FPGA 和 MCU 里。

### 用一个高阶 IIR 把老课接到今天

Sascha Spors 的非官方 [Digital Signal Processing notebooks](https://github.com/spatialaudio/digital-signal-processing-lecture) 来自罗斯托克大学硕士课程，以 CC BY 4.0 发布，覆盖 spectral analysis、random signals、quantization、filter realization/design、练习与 CI。它适合补一个现代 Jupyter 环境，却无法充当 RES.6-008 的题解。

很合适的收尾是选一个稳定高阶 IIR：写出差分方程、系统函数、ROC 与 pole-zero，分别做 direct form 和 SOS，再扫 coefficient word length。看输出误差怎样跟着极点移动、内部状态和 scaling 改变。官方归档没有 exam、code lab 或 project，所以这只是注明来历的延伸。若最后能解释“理想 \(H(z)\) 相同，为何有限精度输出不同”，这套 1987 录像就已经成功接上了今天。
