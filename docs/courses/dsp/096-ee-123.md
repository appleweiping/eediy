### 把 DSP 推到无线链路的实验课

Berkeley [EE 123 Spring 2019](https://sites.google.com/berkeley.edu/ee123-sp19/)
是 4 学分本科课，先修为 EECS 120 或教师许可。它从 DTFT/z-transform、DFT/FFT、sampling、
filter design 延伸到 wavelets、2D processing 和 compressed sensing，并用 RTL-SDR、
Raspberry Pi、AFSK/APRS 把算法接到无线链路。它适合理论与 Python/Jupyter 都已稳定，愿意
处理设备和版本问题的人；无线发射许可不明确时，只选择 receive-only/offline 路线。

### Labs 的价值在链路逐层显形

[Labs](https://sites.google.com/berkeley.edu/ee123-sp19/labs) 从 Lab 0 环境配置、sonar matched
filter、RTL-SDR/ADS-B、spectrogram/FM demodulation 走到 AFSK 与 AX.25/APRS。2019 的
Drive 快照、OS image、Python package 和 SDR driver 可能已漂移；应从
[Python page](https://sites.google.com/berkeley.edu/ee123-sp19/python) 建环境，保存版本与
compatibility diff。含 prerecorded data 的内容可离线复现，但不能据此声称整套硬件 lab
已经公开或通过原 grader。

### 75 秒项目检验压缩、调制与协议预算

[Project](https://sites.google.com/berkeley.edu/ee123-sp19/project) 要求在 75 秒内通过
2 台手持电台传输尽量高质量的视频，并限制直接使用现成压缩与通信实现；labs 提供的
AFSK1200 packet modem 是最低基线。站外作品应固定测试视频、payload、noise/loss model
和 PSNR，再比较压缩率、ECC overhead、BER/packet loss 与同步成本。结果必须解释瓶颈在
compression、modulation、synchronization 还是 protocol，而非只展示“视频传出来了”。

### 发射与离线复现必须分开

原课的美国 amateur-radio 组织与设备设置只属于 Spring 2019 语境，不自动构成其他地区的
许可。无合规设备、执照或现场负责人时，使用预录 IQ/audio 和仿真信道完成 offline
reproduction：固定 sample rate、bandwidth、symbol rate、frequency offset、random seed
和 75 秒净 payload。具备合法环境时再增加 power、antenna、callsign 与许可记录。任何路线
都保留可复跑 baseline 和失败版本；购买硬件或发射前应按所在地、日期、频段重新核查规则。

这门课最有意思的约束，是把整条 source-to-packet chain 压进 75 秒；离线信道同样能暴露压缩、同步与协议开销之间的冲突。
