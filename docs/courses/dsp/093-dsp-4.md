### 访问与版本说明

[EPFL DSP 4 当前课程页](https://www.coursera.org/learn/dsp4) 列出 3 个 modules、
2 次 graded assignments 和 4 个 ungraded labs，分别落在 image processing、
digital communications/ADSL 与 real-time audio。
它适合已掌握卷积、DFT、滤波与采样，想观察同一套工具怎样受 rate、distortion、BER 和
deadline 约束的人；只想学图像压缩时可单独选前段，实时硬件路线还需要 C/C++、buffer 与
数字音频接口基础。

### 实验与项目

四个官方 ungraded lab 是 Haar Bases for Image Compression、The Telephone Channel、
Simple Data Transmission 与 Voice Transformers。下面把中间两项通信 lab 合成一份，
所以三份 portfolio 只是**非官方自学组合**，与 Coursera 的两次计分作业及平台评分结构分开。

图像部分给出 coefficient rule、compression ratio 与重建误差，再挑一张纹理或边缘失真的
图像解释原因。通信部分把 telephone-channel model 与 simple-transmission modem 接起来，
写清采样率、symbol rate、channel/noise model 和 BER。实时音频部分先离线确认 Voice
Transformers 算法，再测 block execution time、buffer deadline 与 dropped blocks；没有板卡时
只做 offline reproduction。三部分共用一张“表示—算法—实现约束”表，
但评价指标不能互换：图像看 rate–distortion，通信看 bandwidth–BER，实时音频看听感与
deadline。

### 代码来源与硬件边界

旧版 [DSPNumex](https://github.com/LCAV/DSPNumex) 的
[NumEx8](https://github.com/LCAV/DSPNumex/tree/master/NumEx8) 只补 image processing。
实时部分另有官方 [mooc-hwlab](https://github.com/LCAV/mooc-hwlab) 与
[在线教程](https://hwlab.learndsp.org/)，涵盖 Nucleo、STM32CubeIDE 和 audio passthrough；
购买前应核对 [bill of materials](https://hwlab.learndsp.org/bill-of-materials) 与板卡版本。
这些公开材料不包含 Coursera grader、教师反馈或证书，旧 IDE/API 也可能需要最小兼容修改。
硬件目录写明 commit、工具版本、wiring、baseline 和 worst-case execution time。实时路线
以不加效果时的稳定音频直通为基准，随后逐块加入处理并找出首次出现缓冲欠载、削波或时限
超出的条件；离线路线则用相同帧长和采样率模拟这些约束。这样作品说明的是算法怎样受实现平台
限制；一次能播放的声音只能说明某个输入下的功能。

DSP 4 的实时部分真正关心哪个 block 最先耗尽 deadline、buffer 或 dynamic range，以及算法
怎样为它让步。最值得做的取舍往往很具体：缩短 filter、减小 frame，还是牺牲一点听感来换
稳定直通；仅仅听到声音回答不了这个问题。
