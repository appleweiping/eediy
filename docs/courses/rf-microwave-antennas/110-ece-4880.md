## 修复后再判断：这是 RF 系统课，不是 RFIC 课

Cornell ECE 4880 *Radio Frequency Systems* 的公开归档固定在 Fall 2016。[官方课程主页](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems)把它定位为 component-view 的 RF link design：主要在 signal 与 Simulink 层面串起 filter、amplifier、LNA、PA、mixer、converter、receiver architecture 和 wireless standard，同时把 gain、noise、mismatch、nonlinearity 与 phase noise 等器件非理想性折回信号模型。它不以晶体管偏置或版图为主，也不是天线制造课。

官方先修是 ECE 3030 或 instructor consent。注册时可选 3 units lecture-only，或 4 units lecture 加 labs。前者评分为 HW 20%、Prelim 1 为 20%、Prelim 2 为 25%、Final 35%；后者为 HW 15%、Prelim 1 为 15%、Prelim 2 为 20%、Lab 20%、Final 30%。这些是 Fall 2016 的校内规则，只能用来恢复学习重心，不能作为公开学习者的学分或实验资格。

### 六级 lab ladder 需要哪些真实证据

[官方 projects and labs page](https://ocw.ece.cornell.edu/courses/ece-4880-radio-frequency-systems/ece-4880-projects-and-labs)列出 6 份 lab PDF，没有 lab solutions。Lab 1 是 RF instrumentation 与 spectrum exploration；Lab 2 用 VNA 做 two-port S-parameter、de-embedding 和 filter characterization；Lab 3 测 splitter 与 directional coupler；Lab 4 研究 RF amplifier；Lab 5 进入 oscillator 与 mixer；Lab 6 是 2–3 周 free-lab proposal，要交系统目标、block diagram、实现和测试计划。最后一份材料涉及 600 MHz–2 GHz、约 30 dBm，并把 jammer 列作示例之一；这绝不是家庭或开放空间的复现实验邀请。

### 进入 Lab 1 之前的测量门槛

1. 在 50 Ω 系统中完成 dBm、W 与 Vrms 的双向转换，说明 dB 是比值而 dBm 是绝对功率参考，并能发现把 voltage gain 直接当 power gain 的错误。
2. 给一个 two-port S-parameter matrix，计算 input reflection、transducer gain 或 mismatch，并在 Smith chart 上说明移动方向；再解释 reference plane 改变为何需要 de-embedding。
3. 对一个 receiver chain 做 link budget、cascade noise figure 和 IIP3/IM3 估算，同时指出 image、LO leakage 或 blocker 会落在哪里。

依据前述官方 syllabus、notes 与 homework/lab 索引，第 1 题单位混乱时，先补 sinusoid、power 和 logarithmic units；第 2 题不会时，回到 ECE 3030、transmission line 与 network parameters；第 3 题只会相加 gain 而不会移动噪声与非线性参考面时，先补 Friis 和 intercept-point 定义。通过后按“补 Lecture 1–5 → HW 1–10 盲做/校正 → Lecture 6–11 与 Handout 1–9 → Prelim 1/2 限时 → Fall 2015 Final 迁移测试”推进。不要用答案齐全掩盖前五讲和现场仪器反馈的缺失。

## 这里必须分成 bench 与 simulation 两条路

物理 Lab 1–6 只应在具备授权频谱、校准仪器、合格监督和明确功率限制的 RF laboratory 内进行。优先使用 shielded enclosure、dummy load、attenuator、DC block 与 instrument protection；上电前核对 analyzer 最大输入、amplifier stability、connector power rating 和 emergency shutdown。不得在开放空间搭建 jammer、未知天线或高功率 transmitter，也不得干扰 Wi-Fi、Bluetooth、导航、广播、蜂窝或他人测量。[美国 FCC Part 15 当前文本](https://www.ecfr.gov/current/title-47/chapter-I/subchapter-A/part-15)只适用于对应司法辖区；其他地区必须按当地监管和机构许可执行。

没有合规实验室时，默认走 simulation-only：用 synthetic signal、公开或自建 Touchstone model、受控噪声和非线性模块完成链路分析。可以交付 schematic/block diagram、仿真参数、raw sweep、unit test、误差预算和失败案例，但不能声称完成 VNA calibration、spectrum-analyzer checkout、600 MHz–2 GHz 发射或约 30 dBm 功率测试。课程也没有公开 lab answer、设备预约、工作人员检查、Simulink license、课堂讲评或 grader；这些都应列入完成声明。

即使进入合规 bench，记录也不能只放仪器截图：要写校准面、线缆与衰减器连接、仪器量程、扫频设置、环境条件、不确定度和异常运行。仿真路径则把这些字段换成模型来源、插值方式、数值容差与失效区间；两条路径的证据形式不同，不能用一张曲线互相冒充。

[MIT 6.661 Spring 2003 lecture-notes page](https://ocw.mit.edu/courses/6-661-receivers-antennas-and-signals-spring-2003/pages/lecture-notes/)公开 24 份编号 notes，assignments 页面另公开 Problem Set 1–13 且每份都有 solution。Syllabus 安排两场 1.5-hour closed-book quiz，分别位于 Lecture 14 与 Lecture 24 之后，并注明没有 final；但本次审查的 OCW 页面没有公开 quiz papers 或 quiz solutions。课程覆盖 noise、receivers、optical detection、antennas、binary communication、coding、interferometry、radar、remote sensing 与 estimation，也没有公开 bench labs。需要 component nonideality、Simulink 和 RF bench 语境时选 Cornell；没有实验室、想用更完整解答学习 receiver/antenna/random-signal theory 时选 MIT。两门课可以前后衔接，不能互相伪装成对方缺失的实验或前五讲。

### EEDIY 只补一个无发射路径的接收链

EEDIY 补充项目是“被动接收链的可审计级联模型”，不是 Cornell 官方 Lab 6。用 Python 或 Simulink 表示 gain、S-parameter/mismatch、noise figure、IIP3 与 phase noise，扫描 blocker power、source/load mismatch 和 filter bandwidth；同时用 Friis/cascade 公式做独立解析核对。交付一个无发射路径的 block diagram、合成或许可明确的 Touchstone 数据、单位测试、原始 sweep、结果图和适用范围。验收时必须能故意交换两级顺序并看到 noise/IIP3 预测按理论改变，能识别非被动或单位错误的数据，并由空环境一条命令重建全部结论。
