# MIT 6.452: Principles of Wireless Communications

### 课程形式

MIT [6.452 Spring 2006](https://ocw.mit.edu/courses/6-452-principles-of-wireless-communications-spring-2006/)
讲 fading、diversity、power control、MIMO、multiuser/broadcast、OFDM 与 UWB。
[Syllabus](https://ocw.mit.edu/courses/6-452-principles-of-wireless-communications-spring-2006/pages/syllabus/)
要求 6.450 或教师许可，以及 digital communications、probability 和 linear algebra。它适合
已掌握 AWGN、matched filter 与调制，想通过 Tse–Viswanath 深入 channel/CSI/power
assumptions 的人；需要连续讲义、视频和题解时不宜把它当唯一主课。

### 材料颗粒度决定学习方法

[Assignments](https://ocw.mit.edu/courses/6-452-principles-of-wireless-communications-spring-2006/pages/assignments/)
只有 3 份 problem sets，且没有 solutions；题目大量引用教材。每题明确 channel model、
CSI at transmitter/receiver、power constraint、metric 与 limiting case。MIMO 比较还要固定
matrix rank/dimension；fading 结果区分 ergodic capacity、outage 与 BER。一个 Rayleigh
outage 或 2×2 MIMO Monte Carlo 可以作独立数值检查，MIT 并未把它列为 lab。

### 论文 review 才是原项目形态

[Project page](https://ocw.mit.edu/courses/6-452-principles-of-wireless-communications-spring-2006/pages/projects/)
说明原项目是 paper review；[readings](https://ocw.mit.edu/courses/6-452-principles-of-wireless-communications-spring-2006/pages/readings/)
给出候选论文，却没有 rubric、代码、数据或反馈。review 应说明问题与 baseline、信道假设、
核心结论、方法和局限，再重算一张图或一个特殊情形。专有数据不可得时，改用合成信道，并把
作者设定与合成设定并列。

最后做一次 assumption transplant：改变论文中的 CSI、fading 或 power 条件，先预测哪条结论
会变，再用小模型检查方向。Spring 2006 的 UWB/系统例子有明确年代；讨论现代标准时另引当前
规范。图中分别标出作者结果、自己的重算与概念示意，并在合成信道旁写明仍有哪些统计性质、
又丢掉了哪些时间或空间相关性。最有价值的不是画出相似曲线，而是指出一个结论究竟依赖
transmitter CSI、fading law 还是 power constraint；这三者换一个，工程判断可能完全相反。
