## 这不是“再学一遍调制”，而是从距离走到现代译码

MIT 6.451 **Principles of Digital Communication II, Spring 2005** 是 David Forney 的研究生课程，也是 6.450 之后的第二学期。官方 [syllabus](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/syllabus/) 把 6.450 写成严格先修：原班没有修过者须通过面谈说明准备情况。它从 AWGN 信道中的 constellation、coding gain 与 hard/soft decision 起步，随后进入 linear block code、finite field、Reed–Solomon、convolutional code、trellis、codes on graphs、sum-product、turbo/LDPC/RA、lattice/trellis code，最后回到 linear Gaussian channel。这里的主线不是“记住更多码名”，而是解释一种几何或代数结构怎样改变可达误差率，以及译码器为何能够利用这种结构。

2005 是课程版本，不是视频发布日期的模糊标签。OCW 保存的是当年课程档案：公开讲义、视频、题目和答案，但没有校外 TA、作业批改、MIT 学分或证书。原班每周两次、每次 1.5 小时，标为 12-credit H-level；这些数字说明校内负荷，不能直接换算成“看 3 小时视频即完成一周”。

## 先做三个门槛题；不会就回到 6.450

第一题：对 BPSK 或一个小型 QAM constellation，从条件密度写出 log-likelihood ratio，比较 hard decision 与 soft decision 丢掉了什么信息，并给出 uncoded error probability 的高 SNR 近似。第二题：在一个小有限域上完成加、乘、逆元运算，从 generator matrix 得到 parity-check matrix，并解释 syndrome 的含义。第三题：为一个短 convolutional code 画 trellis，手算一段 Viterbi path metric；或者为一个极小 factor graph 写出一次 sum-product message update。

三题至少独立完成两题，才适合进入 Lecture 1。若第一题只能背 Q-function、第二题把模 2 运算与一般有限域混为一谈、第三题不知道状态与路径指标的区别，先补概率、线性代数和 6.450。这个 placement diagnostic 是 EEDIY 的编辑门槛，不是 MIT 的先修豁免。

## 25 讲要按三次“换语言”来读

官方 [calendar](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/calendar/) 列出 Lecture 1–25。Lecture 1–4 用 Euclidean distance、AWGN capacity、small constellation 与 hard/soft decoding 建立几何语言；Lecture 5–12 转入 binary block code、finite field 和 Reed–Solomon 的代数语言；Lecture 13–21 再转入 convolutional code、trellis、graph、sum-product 以及 turbo/LDPC/RA 的算法语言；Lecture 22–25 处理 lattice/trellis code 与 linear Gaussian channel。三次换语言时都应写一张“对象—指标—译码器”对照表，避免只会在各章节内部推导。

官方 [video index](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/video_galleries/video-lectures/) 提供 25 讲视频及对应可下载 notes；[readings and lecture notes](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/readings-and-lecture-notes/) 还给出完整讲义 PDF。更有效的顺序是先看讲义定义和本讲结论，再看视频中推导的转折点，最后合上材料重建证明骨架。若只是把视频当背景音，有限域到图算法的两次抽象跳跃很容易被“听懂了”掩盖。

## 10 份题必须先锁首稿，再看官方解

官方 [assignments](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/assignments/) 公开 Problem Set 1–10，并为每份都附 solution。2005 syllabus 说明最后一份当年不收，但仍要求完成；原班 solution 在截止课次结束后发放，评分为 0、1、2。独立学习时应保留这种延迟：先锁定首稿、假设和失败点，再开答案；否则“看懂解答”会替代 model selection、bound choice 和 decoder construction。

每题订正记录至少标一类错误：channel/model、distance or bound、algebra/field、trellis/graph construction、algorithm update、asymptotic interpretation。重做不能照抄原式，应换 constellation、code parameter 或 received sequence。若 Problem Set 1–2 在建立模型前就必须翻答案，立即退出本课并补 6.450；若到 Problem Set 5 仍不能从 code structure 推出 minimum distance 或 syndrome 关系，也应暂停而不是继续堆术语。

## 六套考试用来测迁移，不用来刷熟题

官方 [exams](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/exams/) 公开 2002、2003、2005 的 midterm 与 final，六套试卷均附 solution。原 2005 课程大致按 midterm 35%、final 50%、problem sets 15% 计分；midterm 可带 3 张纸，3 小时 final 可带 5 张纸。比例和携带材料规则属于历史校内班，不会为校外学习者产生 MIT 成绩。

建议把 2002 midterm 用作前半程诊断，2003 midterm 用作订正后的平行卷，2005 midterm 保留到 Lecture 12 后；三个 final 中只精做两套，第三套留作未见迁移。评分只使用官方 solution 与事先写好的 partial-credit rubric，并报告未能判定的步骤。能够背出 Reed–Solomon 结构但不能面对新 received word 选择译码路径，不算通过。

## EEDIY 只补一个可复现的译码比较，不虚构 MIT lab

本课公开页面没有官方 hardware lab、code starter 或 autograder。EEDIY 建议的补充产物是一份固定随机种子的 simulation notebook：比较 uncoded BPSK、一个短 block/convolutional code，以及 hard/soft 或 Viterbi decoding 的 BER–\(E_b/N_0\) 曲线；先用 uncoded BPSK 的解析结果校准噪声方差，再报告置信区间、样本数、码率归一化和运行环境。它是 EEDIY supplement，不是 MIT 6.451 的官方作业、实验或通过证明。

不要把 notebook 变成通信库的一次黑箱调用。至少保留 encoder、channel、metric、decoder 和 estimator 五个可单测层；对零噪声、极高噪声、已知短序列与解析基线做检查。Monte Carlo 曲线若只凭“形状合理”判定，常会把 \(E_s/N_0\) 与 \(E_b/N_0\)、双边噪声谱密度与每维方差混在一起。

## 退出标准是一份可审计的通信论证

结课包应包含三道门槛题、25 讲的对象—指标—译码器索引、Problem Set 1–10 的首稿与 error taxonomy、至少一套 midterm 和一套 final 的限时记录、公式页，以及 EEDIY simulation notebook 的测试与 BER 报告。对每个结论都能回答：使用了什么信道模型、性能指标来自哪里、译码复杂度如何增长、近似在哪个区间成立。

若无法从 Euclidean distance 解释 coding gain，无法把 generator/parity-check/trellis/graph 互相转换，或无法说明 sum-product 的消息在图上代表什么，就不应以“看完 25 讲”结课。本页证据等级为 R0，只记录官方材料审读；纠错请给出课程 ID 101、具体 lecture/problem/exam 与官方来源，不要提交未授权答案或声称获得 MIT 评分。
