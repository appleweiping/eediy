### 6.451 从距离一路走到现代译码

MIT [6.451 Spring 2005](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/syllabus/) 是 David Forney 的研究生课程，并把 6.450 列为严格先修。它适合已经掌握 detection、想从 classical coding 深入现代 iterative decoding 的学习者。课程从 AWGN 中的 constellation、coding gain 与 hard/soft decision，走到 linear block code、finite field、Reed–Solomon、convolutional code、trellis、codes on graphs、sum-product、turbo/LDPC/RA 和 lattice codes。主线在于说明几何或代数结构怎样改变距离、误差率和译码复杂度，码名只是索引。

这门课切换符号体系很快。若 log-likelihood ratio、有限域上的矩阵运算或 Viterbi path metric 仍是新内容，补过 detection、finite field 和短 trellis 再读 6.451 会轻松得多。

### 课程结构

[Calendar](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/calendar/) 的 Lectures 1–4 建立 Euclidean distance 和 hard/soft decoding 的几何语言；5–12 转入 block code、finite field 与 Reed–Solomon 的代数语言；13–21 再转到 convolutional code、trellis、graph、sum-product 与 turbo/LDPC/RA 的算法语言；22–25 处理 lattice/trellis codes 与 linear Gaussian channel。[Readings and Lecture Notes](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/readings-and-lecture-notes/)提供完整讲义，是这门老课今天仍适合自学的重要原因。

block code 段最适合留一个能手算的小例：同时写 \(G\)、\(H\)、codewords、syndrome 与 minimum distance，并验证 \(GH^\mathsf{T}=0\)。到了 Reed–Solomon，再把 field representation、evaluation points 和 error/erasure budget 接到同一套代数关系上。这样能看出两类码共享什么、又在哪里分开。

trellis 与 factor graph 则把重点从结构转到消息传递。Viterbi 的 branch/path metric 和 survivor，BCJR 的 forward/backward quantity，以及 sum-product 的 message normalization，各自在回答不同问题。零噪声和很短的 received sequence 往往比长 BER 曲线更容易暴露 termination 或 LLR sign 错误；性能比较还应同时看 distance/bound 与状态数、边数或迭代次数。

### 作业与反馈

[Assignments](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/assignments/) 的 Problem Set 1–10 全有 solution。题目从几何、有限域一路跟到 graph decoding，连续性比单独找几套 coding theory 练习好得多。解答最适合在独立尝试后用来确认符号与推导转折。

[Exams](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/pages/exams/) 保存 2002、2003、2005 的 midterm 与 final，共 6 套且都有答案。它们能检验不同语言之间的转换是否真的熟练，也是公开包里最接近原课节奏的材料。

### 公开实现用于读懂译码器

Veeresh Taranalli 的非官方 [CommPy](https://github.com/veeresht/CommPy) 采用 BSD-3-Clause，包含 convolutional/Viterbi、BCJR/MAP、turbo、LDPC、有限域与 channel models。它独立于 6.451 starter code，很适合在手算短 trellis 后对照 hard/soft decoding 和 BER，并观察 encoder、metric 与 decoder 之间的接口。

6.451 最有价值的地方，是把 classical coding 的几何与代数自然带到 factor graph 和 iterative decoding。若只想快速调用现代 FEC 库，这门课会显得过重；若想知道这些译码器为何成立，它的讲义、题集和考试仍是一套罕见的完整路线。
