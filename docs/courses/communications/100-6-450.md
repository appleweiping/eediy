## 从 bit interface 向两端展开

6.450 的主角不是某一种调制，而是 source 与 channel 之间的 bit-stream interface。先画一条可追责的链：source distribution → source code/quantizer → waveform and signal space → noisy channel → sufficient statistic → detector/decoder。对每个箭头写输入对象、输出对象、loss criterion 与假设。若 entropy、energy、probability of error 和 bandwidth 被混在同一列，先补概率、线性系统与向量空间。

MIT 的 [syllabus](https://ocw.mit.edu/courses/6-450-principles-of-digital-communications-i-fall-2006/pages/syllabus/) 将 6.450 定为 Fall 2006 graduate introduction，prerequisite 是 6.011，并要求良好的本科 probability 与 linear systems 背景。课程明确把这套材料称为 6.451、6.452 与 6.441 的 baseline。上面的 chain audit 是 EEDIY placement exercise，不是 MIT 官方开学测验。

## 2006 课程由 3 个年代层组成

课堂 calendar 有 25 sessions。第 1–7 讲从 layered view、discrete source encoding、entropy、Markov sources 与 Lempel–Ziv 进入 quantization 和 waveform encoding；第 8–12 讲处理 measure、Fourier/sampling、degrees of freedom、signal space、Nyquist、PAM/QAM；第 13–19 讲进入 random processes、Gaussian/WGN、filtering、detection、theorem of irrelevance 与 baseband；第 20–24 讲处理 wireless、Doppler/time spread、coherence、discrete-time baseband fading、RAKE 与 CDMA；第 25 讲 review。这条次序的关键是分层而不割裂。信源部分给出需要传输的速率和允许失真，波形部分决定有限自由度怎样承载符号，随机过程部分把噪声投影到判决空间，无线部分再说明先前的固定信道假设何时失效。每进入下一层，都要把上一层留下的接口量带过去；否则容易分别会算熵、频谱和误码率，却不能判断它们是否属于同一个通信系统。

[Lecture Notes](https://ocw.mit.edu/courses/6-450-principles-of-digital-communications-i-fall-2006/pages/lecture-notes/) 不是 25 份逐讲 slides，而是一部公开 manuscript：Preface/contents、Chapter 1–9 和 bibliography。9 章依次是 digital communication、discrete source coding、quantization、source/channel waveforms、vector/signal space、channels/modulation/demodulation、random processes/noise、detection/coding/decoding、wireless digital communication；syllabus 称它为唯一 required text。

[Video Lectures](https://ocw.mit.edu/courses/6-450-principles-of-digital-communications-i-fall-2006/video_galleries/video-lectures/) 明确来自 Fall 2003，而非 2006 课堂。公开序列是 Lecture 1–24，没有独立的 Lecture 25 review video。学习日志应保留 “2006 syllabus/manuscript + 2003 videos” 的 provenance，遇到编号或措辞差异以相应年份材料为准。

## 用 4 个接口检验学习顺序

接口 A 是 source→bits。必须能从 prefix-free condition、Kraft inequality、entropy bound 和 AEP 解释 code length，不只会跑 Huffman；quantization 还要写 distortion measure 与 rate。接口 B 是 bits→waveforms。用 orthonormal basis 把连续波形变成 signal-space vector，区分 energy、dimension、bandwidth、symbol interval，并从 zero-ISI condition 推出 Nyquist pulse 约束。

接口 C 是 waveform→decision。先从 WGN 下的 sufficient statistics 和 Euclidean distance 推出二元与 M-ary detector，再解释 matched filter 为什么保留与判决有关的信息；BER 曲线必须写 \(E_b/N_0\)、prior 与 mapping。接口 D 是 decision→wireless channel。把 Doppler spread/time spread 与 coherence time/frequency 配对，区分 flat/frequency-selective 与 coherent/incoherent detection，再说明 RAKE 或 CDMA 解决的是哪一层结构。

推进条件不是视频看完，而是相邻接口能闭合：source rate 能进入 waveform rate，waveform 能进入 channel model，channel statistics 能进入 detector，detector metric 能产生可解释的 error event。每阶段保留至少 1 个 counterexample，例如 prefix code 不唯一、bandlimited 不等于 time-limited、最小距离结论依赖噪声模型、Rayleigh fading 不能直接用 AWGN 公式。接口记录还应注明“优化了什么”和“付出了什么”：压缩率提高可能增加延迟或对模型失配更敏感，频谱效率提高可能缩小判决距离，匹配滤波的最优性依赖已知脉冲和噪声结构，分集收益则需要额外观测与相关性假设。只报最终误码率会隐藏这些交换关系，也无法解释系统在带宽、功率或信道统计改变后为何失效。

## 6.02、6.450 与 6.451 是三种不同任务

MIT [6.02 Digital Communication Systems](https://ocw.mit.edu/courses/6-02-introduction-to-eecs-ii-digital-communication-systems-fall-2012/) 是本科 EECS introduction，以 bits、signals、packets 3 层串联 compression/error correction、physical channels 与 networks；prerequisites 是 18.03 和 6.01，题集要求 6.00/6.01 水平 Python，并包含 programming tasks 与部分 real-world channel experiments。需要第一次把代码、链路与 packet network 接起来时选 6.02。

6.450 不讲 packet routing 那条主线，而是把 source coding、quantization、signal-space geometry、random processes、optimal detection 与 wireless baseband model 做成研究前的数学骨架。MIT [6.451 Principles of Digital Communication II](https://ocw.mit.edu/courses/6-451-principles-of-digital-communication-ii-spring-2005/) 则把 6.450 列为严格 prerequisite，重点转向 approaching the Shannon limit：linear/block/convolutional codes、Viterbi、trellis、turbo/LDPC、sum-product/BCJR、lattice and coded modulation。基础链路不稳选 6.02；要严谨建立 source-to-detector 选 6.450；要把 coding gain 与 modern codes 推到底选 6.451。

## 4 个决策题决定是否能进入第二门

以下均为 EEDIY 自拟决策题。决策题 1：给定 memoryless source，构造 prefix code，比较 expected length 与 entropy，并说明为何 block extension 能改变 redundancy。决策题 2：给定 symbol period 和 channel bandwidth，推导一个 zero-ISI pulse criterion，并解释 matched filtering 后 noise variance。

EEDIY 决策题 3：在 WGN 中为 3 个 signal-space points 画 decision regions，推导 pairwise error 与 union-bound 结构；决策题 4：给定 delay/Doppler parameters 与 symbol duration，判断 channel 的 coherence regime，并选择 coherent、incoherent 或 diversity/RAKE 思路。依照上文官方 9 章 manuscript 的编号，第 1 项失败回 Chapter 2–3，第 2 项回 Chapter 4–6，第 3 项回 Chapter 7–8，第 4 项回 Chapter 9。至少 3 项能无解答完成并由第二种方法核对，才建议进入 6.451。

## 非官方 Monte Carlo 只补缺失的实验接口

公开 6.450 没有 software requirement、code repository 或 laboratory。EEDIY 可另做 1 个明确标为 non-official 的 baseband simulation：实现 BPSK/QPSK 或小型 QAM，生成 AWGN，比较 analytic 与 Monte Carlo BER；再加入 1 个 flat Rayleigh case，报告 confidence interval、random seed、sample count、normalization 与 stopping criterion。目标是验证 detector 与 channel 假设，不是生成一条看起来平滑的曲线。仿真报告先写理论事件再写程序事件：发送符号怎样归一化，噪声方差怎样从谱密度得到，接收统计量在哪个时刻取样，错误怎样计数。若理论曲线与实验曲线不合，优先检查能量定义、复噪声的实虚部方差、映射和瞬态，而不是调整随机种子。只有误差来源被定位，代码才是通信论证的一部分。

扩展到 pulse shaping 时必须记录 roll-off、samples per symbol、filter delay、matched-filter sampling instant 与 transient discard；扩展到 fading 时区分 perfect/estimated/no CSI。不得用低样本量“证明”极低 BER，也不要把 baseband simulation 写成 RF transmission、MIT lab 或 hardware result。Python/NumPy、Julia、MATLAB/Octave 都可用，版本和单位必须固化。
