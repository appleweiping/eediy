### 6.01SC 的独特之处是把四种抽象放在一起

MIT [6.01SC](https://ocw.mit.edu/courses/6-01sc-introduction-to-electrical-engineering-and-computer-science-i-spring-2011/) 面向 independent study，公开 notes、lecture/recitation videos、software/design labs、homework、nano-quizzes 与历年考试。它适合愿意在同一门课里切换 Python object、state machine、difference equation、feedback、KCL、op-amp、Bayesian estimation 和 search 的学习者。课程无正式先修，把 8.02 列为 corequisite；若只想学现代 Python、完整电路分析或当代机器人，都有更专门的课，本课的价值在于看见状态、因果和接口如何跨对象复用。

### 课程结构

[Resource Index](https://ocw.mit.edu/courses/6-01sc-introduction-to-electrical-engineering-and-computer-science-i-spring-2011/pages/resource-index/) 分成 4 个 unit。Unit 1 用 object、procedure 与 state-machine combinator 训练接口组合；Unit 2 用 difference equation、system function 和 feedback 解释动态；Unit 3 通过 KCL、op-amp、Thevenin/Norton 与 superposition 建模电路；Unit 4 用 Bayes 和 search 处理不确定状态与规划。

四段不能只采用“看讲义—做题”一种方式。Unit 1 要写测试并暴露 mutable state；Unit 2 让手推响应与数值曲线核对 pole、gain 与初值；Unit 3 标明节点和参考方向，写 KCL 并查残差；Unit 4 固定地图、噪声模型和随机种子，比较 uniform-cost 与 A* 的选择。每个 unit 收尾时更换物理对象但保留接口，再问：状态由谁保存，输出依赖哪些当前量，模型在哪个假设下失效。

state machine 是四个 unit 的共同支点。对一个有记忆的组件，同时写转移图、`getNextValues` 风格的接口契约和几步手算 trace，并保存一组会触发非法状态的输入；接入线性系统时，把 sample period、初值与 saturation 明写成参数；接入电路或 Bayes 模块时，则让单位、观测噪声和不可能状态在边界处被拒绝。这样组合失败时能定位到状态、模型或接口，而不会把整套系统当成一段无法拆开的 Python。

这也给出了选课分界：若最想深入的是 node/mesh、器件与实验，应把 6.002 作为主课；若缺的是 LTI、convolution 和频域表示，应转 6.003；若希望第一次看见 software、signals、circuits 与 probabilistic reasoning 如何共享抽象，6.01SC 才有独特价值。

### 工具与环境

官方 [Software and Tools](https://ocw.mit.edu/courses/6-01sc-introduction-to-electrical-engineering-and-computer-science-i-spring-2011/pages/software-and-tools/) 使用 Python 2.6、`lib601`、`soar`、Pioneer 3-DX 和 Circuits Maximus。研究原实现可放进隔离 VM；日常学习更适合用 Python 3 重写小接口，并记录与原库的差别。公开页面没有现代机器人 replacement BOM，迁移到现有平台需要重新定义坐标、采样、噪声、饱和与停机方式；没有硬件时，用模拟器和低压电路模型完成抽象练习即可。

### 考试之外，再接一个综合模型

公开 nano-quiz 有解答，4 份书面 homework 与部分 lab 问题没有完整反馈。[Final Exam](https://ocw.mit.edu/courses/6-01sc-introduction-to-electrical-engineering-and-computer-science-i-spring-2011/pages/final-exam/) 累计覆盖全课，并保存多个学期的试卷与答案。做卷子时把错误标成 abstraction、model、calculation 或 code，而不只追最终数值。

一个合适的综合模型，是在虚拟走廊中让 state-machine controller 读取带噪距离，用线性控制移动，再以 Bayes 定位、用 search 规划回程。每层都能独立替换和测试，并明确模型失效输入。若代码、状态图和方程对同一系统给出一致解释，就抓住了 6.01SC 最难被单科替代的部分。
