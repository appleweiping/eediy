## 为什么先学 6.041SC

如果让我给第一次学工程概率的人只留一门公开课，我会先留 6.041SC。它能接到通信、
随机信号、控制和器件噪声，又确实具备独立学完所需的题目与反馈。它不是统计软件课，
也不是以测度论为起点的
严格概率论：25 讲从离散概率和一般随机变量推进到 Bernoulli / Poisson 过程、有限状态
Markov chain，最后用大数律、中心极限定理、Bayesian inference 与 classical inference
收束。四个单元和每一讲的材料关系，可以先在
[课程主页](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/)
上扫一遍，再决定是否投入。

这门课真正罕见的地方不是“有视频”，而是做错以后容易找到下一步。MIT 把 lecture video、slides、
教材章节、recitation、tutorial、TA help video 和 problem set 放进同一套
[Resource Index](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/pages/resource-index/)；
11 份 problem set 有解答，两次 quiz 和 final 也能闭卷自测。独立学习时，能在做错后
迅速定位到同主题的 recitation 或 help video，比单独拥有一条播放列表更重要。

## 先做三道不计分的准备题

官方 [Syllabus](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/pages/syllabus/)
把 18.01 与 18.02 列为先修，并点名数列、极限、无穷级数、链式法则，以及一重（普通）
积分和多重积分。不要只按课程名判断；开始前应当能完成下面三件事：

1. 独立计算一维、二维积分，并能在三角形或圆形区域重新写出积分限；
2. 给含参数的 PMF/PDF 做归一化，再用求和或积分计算期望；
3. 处理二元变量替换时，知道 Jacobian 为什么出现以及放在哪里。

若前两项都困难，先补单变量与多变量微积分。线性代数不是官方先修，但 Lecture 16–18
处理 Markov chain 时，矩阵乘法、特征向量和稳态分布会直接出现。这里的危险信号不是
“公式记不住”，而是连续型随机变量一进入二维区域就无法写出积分域；遇到这种情况，
暂停 Unit II 补积分，比继续刷视频有效。

## 四段学习顺序

**Lecture 1–7：离散概率与离散随机变量。** 每讲先独立做 recitation problem，再看
solution 或 help video。完成 Problem Set 1–4 后闭卷做 Quiz 1；若条件概率题仍靠套
Bayes 公式而不能画出事件关系，不应进入连续部分。

**Lecture 8–12：一般随机变量。** 重点是连续随机变量、continuous Bayes、derived
distribution、convolution、covariance 与 iterated expectation。多元积分负担会在这里
突然上升；Problem Set 5/6 的错误应单列成日志，区分积分域、变量变换和概率概念三类。

**Lecture 13–18：随机过程。** 主角是 Bernoulli process、Poisson process 和有限
Markov chain。不要把它误认为完整的随机信号课：课程没有系统展开 WSS、自相关和功率谱。
更好的检查方式，是把 packet arrival、photon count 或 component state 写成一个过程，
然后指出独立性、无记忆性或平稳假设何时会失效。

**Lecture 19–25：极限定律与推断。** 完成 Problem Set 9–11 后再做 final。若只能把样本
代入估计公式，却解释不了 estimator 自身为何是随机变量，应回到大数律、CLT 与
conditional expectation，而不是继续记检验步骤。

MIT 报告在校版本平均每周投入 11–12 小时，范围包含 lecture、recitation、reading、
homework 和 exam；这不是自学者的统一工时。更可信的做法是记录 Lecture 1–3、
Recitation 1–3 与 Problem Set 1 的真实用时，再按自己的题目完成率外推。

## 11 份题集怎么用

课程给出的练习很明确：11 份 problem set、recitation/tutorial problems、两次 quiz 和 final；
这些入口及答案集中在
[Problem Sets](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/resources/problem-sets/)
与 [Final Exam](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/pages/final-exam/)
页面。别把答案当下一步提示。先设 30–45 分钟独立尝试窗口，写下究竟卡在积分域、条件
事件还是建模假设，再看解答；看完后隔一天重做关键题。只“看懂答案”不会暴露变量变换、条件化和建模假设中的
真实缺口。

课程本身没有 programming assignment。若需要代码反馈，可以自建一个明确标为
EEDIY 补充、而非官方 lab 的 notebook：一部分模拟 Poisson arrival，在多个时间窗下比较
样本均值/方差与理论值；另一部分模拟有限 Markov chain，比较稳态向量和长时间状态频率，
再故意构造不遍历的 chain，说明稳态直觉失效的条件。它只补数值直觉，不能替代
Problem Set 7–9 的推导。

## 版本与已知限制

这套 Scholar 材料组合了 2010 课程内容与 2013 年新增的 51 个 TA 视频，例子并非围绕
现代机器学习设计。课程没有官方代码任务，Unit III 也不能替代通信或 DSP 中完整的随机
信号课程。教材是 Bertsekas 与 Tsitsiklis 的 *Introduction to Probability* 第二版；
课程页列出的章节顺序比自行按书从头读更适合作为主线。

需要离线学习时可使用 MIT 的
[Download Course](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/download/)
入口；下载包、站内材料和其中第三方内容仍各有自己的许可。真正开始前，不妨只打开
Lecture 1、对应 recitation 和 Problem Set 1：如果这一小组材料能让你独立作答、订正并
在隔天重做，后面的 24 讲才值得排进日程。
