# MIT 18.05: Introduction to Probability and Statistics

## 课程简介

- **所属大学：** MIT
- **课程编号：** 18.05

- **本站建议背景：** 本站未另设准备条件

- **资料状态：** 2026-07-30；公开材料导读

### 概率与统计要连着学

MIT 18.05 Spring 2022 把概率模型、条件概率、期望和极限定理接到 Bayesian inference、
hypothesis testing、bootstrap 与 regression；R studio 则让抽样误差变成可观察的结果。
官方 [Syllabus](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/syllabus/)
只要求 18.02 水平的多元微积分，统计基础不在 prerequisite 列表。适合想建立完整推断链的 EE 学生，不适合
只想背几种检验名称的人。

[课程下载包](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/download/)
含两册课程读物、课堂材料、R 代码和 studio 文件，但没有公开视频。最关键的资源是
“阅读问题—课堂题—计算实验”的连续设计。

### 作业与反馈

[Problem Sets](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/problem-sets/)
公开 11 套题及解答，其中前 10 套还有 checker。完成推导，用 checker 定位错误，随后再
看解答；反复猜数值只会绕过统计推理。10 次 R studio 覆盖模拟、Bayesian updating、区间、
检验、bootstrap 和回归。每次留下可运行代码、固定 seed、一张图和几句解释。改用 Python
没有问题，但要检查分位数、方差自由度和单双尾检验等默认值；函数名的逐字翻译无法保证统计含义一致。

### 学习成果

[Exams](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/exams/)
提供 2 次 midterm、综合 final、练习卷与解答，可用来检查自己会不会选择方法。结课时找一组
无敏感信息的电阻、电压或传感器重复测量：写清抽样机制、estimand 和模型假设后，给出区间、
效应大小及结论不能推广到哪里。若同时给 Bayesian 与 frequentist 解释，术语各守本义；
单独一个 p-value 无法回答工程师真正关心的“差多少、误差多大、换一批样本还成立吗”。
