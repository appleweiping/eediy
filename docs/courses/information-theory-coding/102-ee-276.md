## 18 讲如何把“压缩”和“通信”接起来

[官方 outline](https://web.stanford.edu/class/ee276/outline.html)估计安排 18 lectures。前段建立 entropy、conditional/joint entropy、relative entropy、mutual information、AEP 与 typicality；随后用 prefix code、Shannon code、Kraft inequality、Huffman code、entropy rate 和 universal compression 回答“源最少需要多少 bit”；中段以 channel capacity、continuous information、AWGN、direct/converse channel coding 回答“噪声信道最多能可靠传多少”；末段进入 polar codes、rate distortion、method of types、strong/joint typicality。

这些主题不宜按术语表平铺。建议维护一张 theorem dependency sheet：每条结论写清随机变量、分布、block length、极限方式和使用的 inequality。例如 AEP 先把长序列压缩成 typical set 的计数问题，source coding converse 再说明低于 entropy 的代价；capacity 的 direct part 构造可行 code，converse 则把任何 code 的性能压回 mutual information 上界。若笔记只剩结论，没有 quantifier 与失败条件，后面的 rate distortion 和 method of types 会变成无法校验的公式堆。

### 打开 solution 之前，先过 proof gate

1. 给一张小型 joint pmf，独立计算 H(X)、H(X|Y) 与 I(X;Y)，并用 KL divergence 或 chain rule 解释 I(X;Y) 为什么非负。
2. 对一个 convexity 题，能正确选择 Jensen、log-sum 或 data-processing inequality，写出等号条件，而不是只给数值例子。
3. 能说明 law of large numbers 在 AEP 中控制什么，区分 convergence in probability 与逐点相等，并完成一次 Gaussian density 与 differential entropy 的代数整理。

若第 1 题连 support 为 0 的项都处理不清，先补离散概率、conditional distribution 和 expectation；若第 2 题只能背 inequality 名称，先补 convexity 与基本证明；若第 3 题把有限 block 的频率直接当作极限概率，先补随机变量收敛。每推进一个主题，再从 theorem 的结论倒推必须满足的假设，并找一个删掉假设便失效的例子。证明题保留逻辑骨架，构造题保留码本或算法，计算题保留精确式、近似式和误差来源。

## 最后才做 finite-block 计算实验

EEDIY 补充项目是“BSC 上有限 block coding 与容量界的对照”，不是 Stanford 官方 project。先推导容量 `1-h2(p)`，再实现 repetition、random linear code 与一个小型 polar code，在相同 channel crossover probability 下扫描 block length、rate 和 decoding error；保留 code construction、seed、原始 trial count 与 confidence interval。验收要求包括独立 encoder/decoder round trip、极端 `p=0` 与接近 `p=0.5` 的边界测试、经验误码率和理论界的差异解释，以及他人一条命令可重建图表。只用合成 bit 和模拟信道，不引入真实个人数据或通信内容。
