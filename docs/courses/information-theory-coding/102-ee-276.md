### 一门公开证明与题解的信息论课

以下内容对应 Stanford EE276 Winter Quarter 2025-26。
[Course information](https://web.stanford.edu/class/ee276/info.html) 从 entropy、mutual
information 和 compression 走到 channel capacity、error correction 与 rate distortion，
先修只写 undergraduate probability，但实际门槛是能用概率语言组织证明。它适合想把
achievability、converse 和 finite-block construction 接起来的人；只会代 Shannon 公式时，
需要补 conditional probability、convexity 和随机变量收敛。

### 课程结构

[Outline](https://web.stanford.edu/class/ee276/outline.html) 估计安排 18 lectures：AEP/
typicality、prefix/Huffman/universal compression、channel capacity 与 AWGN、direct/
converse coding、polar codes、rate distortion 和 method of types。每个 theorem 记录随机
对象、分布、block length、极限方式、关键 inequality 和 equality condition，再写一个删去
假设便失效的例子。这样 source coding 与 channel coding 才不只是两组公式。

[dit](https://github.com/dit/dit) 是活跃的 BSD-3-Clause discrete information
theory 库，含 distribution、entropy/mutual information、channel capacity、
Blahut–Arimoto rate-distortion 与 tests。它与 EE276 answer key 无关。手算 binary source
和 BSC 后，可用完全相同的 probability、log base 与 distortion measure 核对数值，并固定
package version 和 tolerance；库输出不能代替 achievability 或 converse proof。

### Finite block 暴露“界”与“构造”的距离

结课做 BSC finite-block study，并明确是独立数值项目：推导 capacity `1-h2(p)`，实现
repetition、random linear 与小型 polar code，在相同 crossover probability 下扫描 block
length、rate 和 decoding error。保存 construction、seed、trial count、confidence interval，
并检查 `p=0` 与接近 `p=0.5` 的边界。最重要的结论是具体 code 与渐近 capacity 为何仍有距离，
而非挑一条最好看的曲线。报告还要把编码失败分成码本构造、译码规则与有限样本估计，说明每类
误差怎样影响结论；这样数值实验才真正回应前面定理中的量词与极限。
