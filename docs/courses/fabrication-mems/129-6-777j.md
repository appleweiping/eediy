### 课程定位

MIT **6.777J / 2.372J Design and Fabrication of Microelectromechanical Devices, Spring 2007** 由 Carol Livermore 与 Joel Voldman 授课。Syllabus 说明每周 2 次、每次 1.5 小时，已有 microfabrication experience 更好。公开主线是 device design、lumped modeling、transduction、readout、packaging 与 tradeoff，不提供 PDK、recipe、mask submission、fabrication 或 test service。

适合直接学习的人应能推导 parallel-plate actuator 的 energy/force/stability，估 cantilever
stiffness、first resonance 与 scaling，由最终 cross-section 倒推 deposition、lithography、
etch、sacrificial layer 和 release，并把 capacitive/resistive sensor 接到 small-signal
readout 后将 noise referred to input。

### 用一个器件检查 25 讲的力学、电学与工艺

[Calendar](https://ocw.mit.edu/courses/6-777j-design-and-fabrication-of-microelectromechanical-devices-spring-2007/pages/calendar/) 与 [Lecture Notes](https://ocw.mit.edu/courses/6-777j-design-and-fabrication-of-microelectromechanical-devices-spring-2007/pages/lecture-notes/) 给出 25 讲。始终维护 `specification → process cross-section → transducer model → electronics/noise/feedback → package/test`。

不必为每讲另造一个“成果”。拿电容式加速度计贯穿全课更容易看懂：Lecture 1–5 的材料与工艺决定梁、质量块、间隙和 release；Lecture 6–18 再用梁刚度、共振、阻尼、电容变化与 readout noise 解释它如何响应；Lecture 19–25 把 packaging、tradeoff 和 capacitive accelerometer 本身接回来。

最值得追的一项取舍是 gap。间隙变小会提高电容灵敏度和静电力，却也让 pull-in、stiction、工艺偏差与 package parasitic 更难处理；梁厚、质量块面积和 cavity pressure 又会同时改变带宽与噪声。把这些量放在同一个器件上比较，比做几张互不相干的有限元彩图更接近这门课的设计方法。

用能手算的 lumped model 判断趋势；只有当 fringing field、非线性位移或封装阻尼真的会改变结论时，才需要 higher-fidelity model。更复杂的模型应回答一个一阶模型回答不了的问题，而不是把 boundary condition 与 linearization point 藏在软件默认值里。

### 作业与反馈

[Assignments](https://ocw.mit.edu/courses/6-777j-design-and-fabrication-of-microelectromechanical-devices-spring-2007/pages/assignments/) 有 Problem Set 1–7；Problem Set 1–4、6、7 有 solutions，Problem Set 5 没有。页面另有 Treasure Hunt，以及 Problem Set 4 的 `prob6_10.m`、`prob6_11.m`。独立作答后，再按 assumption、equation、unit、order of magnitude 与 numerical implementation 订正；旧 `.m` 文件需要记录 MATLAB/Octave version 与最小 compatibility diff。

原课的 [Syllabus](https://ocw.mit.edu/courses/6-777j-design-and-fabrication-of-microelectromechanical-devices-spring-2007/pages/syllabus/) 规定 7 份 homework 占 15%，未公开题面的 take-home design problem 占 35%，final project 占 50%。独学者可自拟 design review 补训练，却不能据此生成 MIT grade。

### Team project 要复建阶段审查

[Project](https://ocw.mit.edu/courses/6-777j-design-and-fabrication-of-microelectromechanical-devices-spring-2007/pages/projects/) 要求 4–5 人；Lecture 17 交 1–2 页 preliminary report，Lecture 22 交 2–5 页 interim report，Lecture 25 后 5 天做 30 分钟 presentation，final report 目标 25–30 页。例题包括 throughput 超过 1000 cells/s 的 DEP sorter、piezoresistive biomolecular sensor、RF-IF filter 和 micro flex-tester。

没有设施时，可以把 project 改成一个器件的 design study，但不必伪装成完成制造。沿上面的加速度计或官方例题，挑 release gap、package pressure 或 input-referred noise 之一作为真正决定方案的问题，再用截面、估算与数值模型说明哪个选择更可信、哪些量仍必须等实物才能测。

### 访问与版本说明

通用的 fabrication 停止条件见[实验安全指南](../../guides/safety.md)。校外可以完成器件规格、截面、模型、readout/noise 与 package 判断；没有实际 fabrication/test，就不要把 CAD 或 process diagram 写成 fabricated/measured。

[MIT 6.152J](https://ocw.mit.edu/courses/6-152j-micro-nano-processing-technology-fall-2005/)
更偏 diffusion、oxidation、lithography、CVD 及机构内 fabrication/test；6.777J 更偏从
specification 走到 device、readout 与 package。最后挑一个参数——beam thickness、gap 或
cavity pressure 都可以——看它怎样同时改变 mechanics/thermal/fluid、input-referred noise、
package constraint 与最终 observable。6.777J 最难也最有价值的地方，就是这些变化必须落在
同一个器件上，而不是分散在几张互不相干的模型图里。
