# Cornell University ECE 4740: VLSI Systems

### 课程定位

Cornell [ECE 4740 课程页](https://ocw.ece.cornell.edu/ece-4740-course-details)
保存的是 Spring 2018 senior-level 版本。课程从晶体管和 switching network 进入组合/时序
逻辑、clock、PLA 与 memory，再落到 floorplan、CMOS scaling、timing、算术、定点优化、
功耗和性能。它关注同步 CMOS 系统中功能、面积、速度与复杂度的取舍；若只想练 FPGA HDL，
或想学模拟 IC 版图，应换另一条路线。

指定教材是 Weste 与 Harris 的 *CMOS VLSI Design* 第四版。这门课适合已经能从 Boolean
function 画互补 CMOS 网络，分析 setup/hold 和 critical path，并读懂基本版图规则。
这些判断还不熟时，商业 CAD 只会把概念缺口藏在界面后面。

### 访问与版本说明

[Lecture Notes and Handouts](https://ocw.ece.cornell.edu/ece-4740-course-details/ece-4740-lecture-notes-and-handouts)
可按“器件—门—模块—系统”阅读：从 capacitance 与 delay 推到 gate sizing 和 power，
再把 adder、memory、datapath 接到 floorplan、clock 和 architecture transform。
计算时始终注明工艺、负载与时钟目标，避免把一张课件里的经验数字外推到其他工艺。

课程说明写每学期有 4–5 次 homework、3 次 prelim、4 个 extensive design lab 和约 1/4
学期的 final project；但公开
[Homework and Labs](https://ocw.ece.cornell.edu/ece-4740-course-details/ece-4740-homework-and-labs)
快照只列 3 份 homework 与 Lab 1–5，没有 solution、exam 或 project brief。这个差异意味着
Spring 2018 档案能支持部分复做，不能恢复完整校内课程。

每个公开 lab 都把逻辑功能、临界路径、负载、面积主项和功耗来源的手算，与 handout 指定的
CAD flow simulation、synthesis 或 layout 结果配对。至少比较功能波形、timing report、面积或
cell count，并保留一个违反约束的反例。若改用现代开源 PDK 或 FPGA，应明确标成适配实现；
LUT 数不能直接和 standard-cell 面积比较。

### 实验与项目

由于原 final project 未公开，可另做一个规模受控的同步 datapath，例如定点 FIR、迭代
乘法器或小型 accelerator。这是独立延伸，Cornell 档案中没有对应题目。项目可包含规格、
接口时序、golden model、随机与边界测试、综合约束，以及至少 2 种 architecture 的
timing/area 比较。

最后追两条线：一组输入从规格走到 test vector、波形和综合网表；一条 critical path 从
时钟目标走到约束、时序分析和结构修改。器件或工艺、工具版本和未知项都应说清。公开档案没有
商业许可证、Cornell lab 环境、prelim 或评分服务，所以做到独立小 datapath 就停，不必替
Cornell 发明缺失的第四份作业或原 project。
