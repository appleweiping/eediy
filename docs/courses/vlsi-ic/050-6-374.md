# MIT 6.374: Analysis and Design of Digital Integrated Circuits

### 先修要求

MIT 6.374 是 Fall 2003 的 transistor-level 数字集成电路课。官方
[Syllabus](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/syllabus/)
要求 6.012 或同等器件物理，以及 6.004 或同等逻辑设计。一扇 CMOS inverter 足以检验这些
基础：画 VTC 与 noise margin，估算上升/下降延迟和翻转能量，再解释版图寄生怎样改变结果。
只会写 Verilog 的学习者需要补 MOS 与 RC；数字逻辑尚未成体系时，可选
[Berkeley EECS 151](https://www2.eecs.berkeley.edu/Courses/EECS151/) 一类 top-down 课程。

6.374 追问一个 CMOS gate、interconnect、clock 或 memory cell 为什么慢、为什么耗能，
以及 layout 在哪里破坏理想模型；RTL 只是这条分析链的上层边界。

### 课程结构

官方 [Calendar](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/calendar/)
列出 24 次课堂：MOS model、inverter VTC、delay 和 power 引出 static、dynamic 与
pass-transistor logic，随后是 logical effort、算术单元、latch/register、metastability、
interconnect、clock，以及 ROM、SRAM、DRAM 和 VLSI test。公开站没有完整 lecture video，
因此主线应围绕每个设计量建立可交叉检查的账。

一个代表性逻辑路径至少要同时留下 DC transfer、手算 RC/delay、pre-layout SPICE、
transistor count、activity/energy 假设和 extracted capacitance。这样才能判断更快的拓扑
是否以面积、功耗或噪声裕量为代价。

### 课程任务

[Assignments](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/assignments/)
公开 Problem Set 1–5 及全部 solution，PS1–PS4 另有 FAQ；PS3、PS5 使用 0.25 µm
CMOS 参数。独立解答应写出模型、近似和单位；答案适合用来定位 device region、漏算 capacitance、
critical path 或 energy/power 定义错误。

[Exams](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/exams/)
只提供 Quiz 1、Quiz 2 题面，没有可确认的配套解答。直接公开的
[project guidelines](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/3fd5ad1346a5389abc54bd158606a17a_guidelines.pdf)
规定报告上限 2 页，要求说明成功与失败的想法、3 个创新点和 simulation path，但没有统一
电路题目。它适合作为报告格式，不能被写成一个已公开的 final project。

### 工具与环境

官方 [Tools](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/tools/)
列出 Magic、HSPICE、NanoSim，syllabus 还提到 IRSIM。旧商业许可证、model 与
0.25 µm 工艺并不随网页自动获得，也不能和现代 PDK 的面积、delay、leakage 直接比较。

可在合法且版本固定的现代 PDK/EDA 环境中选择 inverter 和一条逻辑路径，比较手算、
pre-layout、DRC-clean layout、extraction 与 post-layout 结果，并注明这是独立适配实现。
同时写清 PDK、工具、supply、temperature 与 extraction rule；若没有合法工具，以 solved
problem sets 和分析结束。最重要的判断是模型从手算、pre-layout、寄生提取到 post-layout
的哪一层开始失效，而不是假装现代 PDK 的数字能与 2003 年工艺直接横比。
