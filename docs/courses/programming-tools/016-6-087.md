## 实践与验收

**实践闭环**

**《Practical Programming in C · MIT 6.087》可复现工程计算工具**

这是维护者为《Practical Programming in C · MIT 6.087》建议的自学项目，不是课程官方作业。为编程与工程计算实现一个读取工程数据、计算指标并生成报告的命令行工具，重点验证接口、数值边界和可重复构建。

**来源：** 维护者建议项目

**交付物**

- 带类型/接口说明的命令行源代码，支持 CSV 输入和机器可读 JSON 输出
- 至少 20 个单元测试、5 个集成测试和一份小型基准数据集
- 原始基准输出、运行时和峰值内存记录，以及错误输入日志
- 一份用户与设计报告，说明算法、复杂度、兼容性和已知限制

**验收**

- 所有测试在干净环境通过，测试覆盖率达到 85% 或列明无法覆盖的路径
- 对空文件、NaN、极大数和错误列名给出非零退出码与可读错误
- 用第二个库或手算样例交叉核对至少 10 个数值结果，误差低于 1e-9
- 在 10 倍数据量下测量时间与内存增长，并与声明的复杂度对照

**复现要求**

- 提交版本化源文件、测试、示例数据、README 和许可说明
- 固定编译器/解释器、依赖与操作系统信息，提供单命令安装和测试
- 保存原始基准数据与报告构建日志并附校验和

**安全边界：** 仅仿真 — 工具只处理仓库中的合成或公开样例数据；不得以管理员权限运行不受信任输入。

**风险、缺口与边界**

没有视频；部分 UNIX 工具示例已经过时。

**完成证据**

- 按周学习日志：投入时间、问题、错误订正、决策、下一步，并链接本周可复现产物
