### 五天 MATLAB 启动器

MIT 6.057 January IAP 2019 用 5 次、每次 2 小时的 session 介绍 MATLAB。官方
[Syllabus](https://ocw.mit.edu/courses/6-057-introduction-to-matlab-january-iap-2019/pages/syllabus/)
从数组和绘图走到 control flow、curve fitting、数值计算、function 与 toolbox。它适合已经
需要在电路、信号或控制课里写计算脚本的人，课程范围就是五天工具入门，完整编程与数值分析需由后续课程承担。来自 Python/C
时尤其注意 1-based indexing、矩阵与 element-wise operator 的区别，以及脚本对 workspace
的隐式依赖。

### 每讲当天写成代码

[Lecture Notes](https://ocw.mit.edu/courses/6-057-introduction-to-matlab-january-iap-2019/pages/lecture-notes/)
有 5 份课件。每读完一份便到干净目录重建示例；连续浏览 5 讲会错过大量操作细节。
[Assignments](https://ocw.mit.edu/courses/6-057-introduction-to-matlab-january-iap-2019/pages/assignments/)
含 Homework 1–4，Homework 2–4 另有 starter/data ZIP，但没有答案或考试。保存原始输入，
用 vectorized 与 loop 两种实现核对关键结果；浮点比较写明 tolerance，拟合结果同时画
residual，而不只报系数。

### 做完就接到真实课程

最后做一个小型 EE notebook：导入带单位的测量数据，处理异常值，画有标签的图，拟合明确模型，
再把核心计算提取成有输入输出契约的 function。README 写 MATLAB release、toolbox、运行命令
和预期结果。没有许可证可迁移到 GNU Octave，但要记录不兼容函数。6.057 的价值是快速开机；
若不立刻在后续课程中继续使用，5 天语法很快就会散掉。

MIT 官方公开材料没有视频、答案、grader 或大型项目，它单独提供不了“工程编程基础”。
最合适的位置是在一门会持续使用矩阵、绘图和拟合的课程之前，用一周消除工具摩擦。
