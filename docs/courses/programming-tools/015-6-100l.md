### 真正面向第一次编程的人

MIT 6.100L Fall 2022 是 6.100A 的 full-semester version，使用 Python 3，面向 little
to no programming experience。官方 [Syllabus](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/syllabus/)
安排 26 讲，从 object、binding、branch 和 loop 走到 function、mutation、testing、
exception、class、complexity、search/sort、hashing 与 simulation。它适合第一次把
specification 变成可靠小程序的 EE 学生；不会教寄存器、仪器通信或实时系统。

慢节奏用来反复检验同一概念。list 从索引与遍历开始，随后会在 mutation、
aliasing、函数参数和 object state 中再次改变含义。运行代码前写下变量绑定与返回值的预测；预测错时
缩成最小例子，盲改到测试变绿只会隐藏误解。

MIT Emerging Talent 的 [ET6 Programming With Python](https://github.com/MIT-Emerging-Talent/ET6-Programming-With-Python)
是 MIT-license 的独立伴读，README 把 predictive stepping、`python -m trace` 和 unit
test 连成一套练习。它只处理独立练习，不提供 6.100L 题解。可把自己写的短 alias、loop 或 function 例子放进去：
手写 trace 后再运行，第一处分歧比最终输出更能说明 binding 理解错在哪里。

### 编程练习

[Finger Exercises](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/finger-exercises/)
适合检查 control flow、return、mutation 与 edge case；独立完成一版后才看已发布答案。
[Problem Sets](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/lists/problem-sets/)
公开 PS0–PS5 及 code bundle，从利息和 bisection 逐渐扩展到图像处理与 steganography。
student tester 只覆盖部分情况，所以每份题还要主动加入空容器、重复值、极端数值和格式错误。

做 problem set 时，用几行列出输入、输出、不变量与错误行为，再实现最小版本。通过样例后，
删掉临时 print，从全新进程运行，并逐项核对 docstring 是否足以确定参数、返回值与异常。
任何仍需口头补充的参数，都说明接口还没有写完。对 alias 与 clone、exception 触发条件和 complexity
中的 input size，也应能用一个最小程序解释；这种例子比背定义更能暴露理解偏差。

课程官方止于 PS0–PS5；下面的作品是明确的非 MIT 官方延伸。写一个读取合成波形 CSV 的小脚本，
检查 sample interval、空行、非数字和越界值，输出统计量、threshold crossings 与机器可读摘要。
把 parser、计算和输出拆开，为 normal、boundary 与 invalid input 各写测试，再用列顺序改变但
语义相同的数据检查接口。项目不需要 FFT 或硬件采集；另一台机器能按 README 运行，坏输入产生
清楚且可预测的结果，已经足以呈现课程真正训练的 decomposition、state、testing 与 debugging。
