### 三类计算统一使用 MVA/kV base

第一条是网络稳态：从 line/component model 形成 \(Y_{bus}\)，区分 PQ、PV 与 slack bus，再做 Gauss–Seidel 或 Newton–Raphson load flow。结果页至少保留 bus type、初值、mismatch norm、PV reactive limit 和 line-loss balance；“converged”本身不说明符号、限值或网络模型正确。

第二条是故障：画出 positive、negative、zero sequence network，按故障类型连接并重构相量。常见错误往往落在 base conversion 或 sequence connection 前后不一致，而非矩阵算术。第三条是稳定性：由故障前潮流给出 operating point，再写 single-machine infinite-bus swing equation，报告 integration step，并用 energy/equal-area 或步长收敛作独立检查。三段的因果关系应始终可追踪。

### 用 3–5 bus 系统联合检查潮流、故障与稳定性

选择 synthetic 或许可清楚的教学网络，保存 one-line diagram、bus/branch data、base table 与假设；依次完成 load flow、3-phase 和 unbalanced fault、再把同一工作点送入 swing simulation。潮流用 2-bus 手算或另一实现核对 residual，故障核对序网络和相量重构，稳定性扫 clearing time 与 integration step。组合图应呈现“故障前状态—故障期间电气量—清除后运动”这条链；三张互不相干的截图无法表达这种因果关系。

[pandapower](https://github.com/e2nIEE/pandapower) 由 University of Kassel 与
Fraunhofer IEE 团队开发，采用 BSD-3-Clause license，仓库含 power-flow、unbalanced 与
short-circuit notebooks。它不是 NPTEL dataset 或 lab。把同一 3–5 bus system 的 base、
element table 与版本固定后，可核对 bus voltage、mismatch 和 fault current；swing
simulation 仍需单独建模，不能把稳态工具输出冒充 dynamic validation。

这是一项数值项目，NPTEL 未将其列为官方 lab，也不能升级为真实电网运行建议；不要使用保密拓扑、继保整定或未经授权的 SCADA/PMU 数据。课程中的 fault 与 stability 是模型对象，任何涉及市电、三相电源、transformer、switchgear 或故障注入的实体工作都只应在机构批准、专业人员负责的实验室进行。
