### 访问与版本说明

MIT [6.630 Fall 2006](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/)
按 [Syllabus](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/pages/syllabus/)
把 14 周分为 Maxwell/polarization、transmission lines、boundaries/waveguides/materials，
以及 lumped/loaded line structures。它适合已会 vector calculus、phasor、ODE、RLC 与
telegrapher equation，想从场边界走到导波结构的人；无法由 phasor Maxwell equation 推平面
波、解释 reflection coefficient 或写切/法向边界条件时，应补场论与电路基础。

### 用一本连续教材补足讲义的跳跃

[Study Materials](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/pages/study-materials/)
是阅读入口和局部材料，并非自洽教材。学习记录应固定 time/frequency domain、source、
loss、material 与 reference direction，再用 dimension、energy flow 和 limiting case
检查。Hertzian dipole、terminated line 与 rectangular waveguide 可作贯穿对象：分别连接
radiation scaling、standing wave/input impedance 与 TE/TM cutoff，避免按 PDF 名称写
14 周摘要。

### 作业与反馈

[Assignments](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/pages/assignments/)
公开 10 套 problem sets，没有 solutions；[Exams](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/pages/exams/)
只提供 2 次 quiz 题面，也没有 rubric。每题至少用单位、极限、功率守恒或独立扫频校准；
无法验证的结论保留为 unresolved。quiz 用作闭卷诊断，订正应定位 assumption、boundary
condition、phasor sign 或 algebra，平滑曲线本身无法证明推导正确。

### MATLAB 只用于检查近似

[Tools](https://ocw.mit.edu/courses/6-630-electromagnetics-fall-2006/pages/tools/)
保留 dipole、media、resonance、reflection coefficient 与 array scripts，但 Parallel Plate
Waveguide movies/scripts 标为 no longer available；这些属于附加演示材料，无法补成课堂视频或硬件 labs。结课选
terminated line 或 rectangular waveguide，给出解析边界、power flow、数值 sweep 和
approximation breakdown。脚本记录单位、normalization 与参数，只改一个物理量并预言趋势；
缺失 movie 只记为缺口，不用文字猜测结果。最终报告还要把解析解、离散采样和绘图窗口分开，
说明偏差来自物理近似还是数值显示。对传输线可比较开路、短路与匹配负载的功率流；对波导可在
截止频率两侧检查传播常数和能量方向，使图形变化回到边界条件本身。

6.630 的核心习惯，是看到一条漂亮曲线时仍追问它来自 boundary condition、近似，还是绘图窗口；传输线和波导都绕不开这个问题。
