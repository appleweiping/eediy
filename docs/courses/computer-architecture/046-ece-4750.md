### 实验与项目

[Lab logistics](https://www.csl.cornell.edu/courses/ece4750/handouts/ece4750-lab-logistics.pdf)
说明原班以 2 人组、私有 GitHub 仓库、milestone、checkoff 和 staff feedback 推进。校外能
看到 brief，却拿不到完整 starter、`ecelinux`、Canvas、私有 CI 和 instructor tests。

[Lab 1](https://www.csl.cornell.edu/courses/ece4750/handouts/ece4750-lab1-imul.pdf)
做 32-bit fixed/variable-latency iterative multiplier；基线 FSM 是 35 cycles。除了乘积，
还要测 request acceptance、response backpressure、reset 和周期改进。Lab 2 实现 stall 与
bypass 两种 5-stage TinyRV2 processor，并用相同程序比较 hazard、cycles 与 CPI。Lab 3
比较 direct-mapped 和 2-way write-back/write-allocate cache，定向制造 compulsory、
conflict、capacity miss 与 dirty eviction。

[Lab 4](https://www.csl.cornell.edu/courses/ece4750/handouts/ece4750-lab4-sys.pdf)
把 processor、cache、ring network 组合为 single-core/4-core system。官方分析用 5 种配置
跨 5 个 microbenchmarks，共 25 次运行和 2 张 speedup/CPI 图。每个柱子都应追溯到 raw log、
config、commit 和 seed；缺完整 scaffold 时宁可缩小并明确省略项，也不虚构 25 次结果。

### 校外路线从测试确定重建范围

把 Section 代码运行环境、命令、pytest 与一张 annotated handshake trace 固定下来之后，按
Lab 1 brief 从接口和 requirement-to-test map 开始独立实现。随后对 Labs 2–4 二选一：
只重建 test/microarchitecture model，或逐层重建 scaffold。每层都保留 minimized failure、
waveform/event log、correctness regression、cycle/CPI 与设计取舍。

理论也要服务这些决策：pipeline 写 hazard 条件与处理，cache 拆 tag/index/offset，
multicore 明确 partition 和 synchronization。只看 27 讲而没有 trace 与数据，不足以解释实验。

### 性能结论必须能追到原始证据

这套 lab 以仿真为主，不需要凭空购买 FPGA。工具与 cross compiler 版本写进 README；公开
repo 根目录未声明 license 时，只链接原站，不镜像教学代码。个人独立实现可自行许可，但要把
Cornell 材料排除在分发物之外。

最终至少完成 multiplier 的 protocol tests、一个 pipeline hazard matrix、一个 cache
directed trace，以及在可用范围内的 integration experiment。报告同时给 correctness、
cycle、CPI、clock/memory assumption，并把失败波形与对应设计选择直接关联。能解释一次
优化为什么只对某些输入有效，比声称“通过 Cornell hidden tests”更符合这门课的训练目标。

baseline 与 optimization 要来自同一 commit lineage、workload 和 timing boundary，并附
raw logs。若 tool option、memory model 或输入分布改变，就重新建立基线；否则 cycle 或 CPI
的差异不能归因于设计。

比较性能时，把功能测试、cycle-level trace、综合得到的 clock constraint 和 end-to-end
runtime 放在同一 workload 下。缺少任一层，就无法判断瓶颈来自微体系结构、工具约束，还是
测量窗口本身。
