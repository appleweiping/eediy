### 课程定位

MIT [6.823 Fall 2005](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/)
研究 ISA、pipeline、memory hierarchy、protection 与 parallel execution 之间的约束。
官方 [Syllabus](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/syllabus/)
要求 6.004 或同等背景：你应能读组合/时序逻辑，跟踪 assembly、exception 和 cache，并把一段
程序追到 datapath。Hennessy/Patterson 教材的版次映射在
[Readings](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/readings/)；
2005 产品数字应与仍有效的 dependency、ordering、coherence 机制分开记录。
它适合已有组成与数字逻辑基础、准备研究设计取舍的人；CPU 初学者更适合基础组成课。

### 课程结构

[Lecture Notes](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/lecture-notes/)
从 ISA/microprogramming、pipeline、VM/cache、protection/I/O 走到 superscalar、VLIW、
vector、multithreading 与 SMP。每个主题画一张结构图、写一个不变量和一个反例：forwarding
消掉哪些 RAW hazard、何时仍 stall，store buffer 怎样维持可观察顺序，TLB miss 与 page
fault 又为何不同。

[Assignments](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/assignments/)
训练从 specification 推机器行为。按依赖顺序做：把 instruction 从 ISA 写到 single/multicycle
control，再逐 cycle 画 pipeline；之后用具体 address 追 CPU、TLB、cache、page table 与
memory，最后才进 dynamic scheduling、prediction 和 multiprocessor。小型 cache/branch
trace simulator 可以辅助，但要与手算 trace 对上后才有校验意义。

### 作业与反馈

[Exams](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/exams/)
提供 5 次 90-minute quiz 及大量解答。第一次不计时恢复 microarchitectural state，第二次再
闭卷；订正区分 specification、cycle boundary、address bits、ordering 与 arithmetic。

每个模块都做一份初稿、订正版和 design comparison，说明两种实现的 performance、
complexity 与 correctness condition。学完应能回答一项优化在哪类 workload 有效、牺牲了什么
简单性、又靠什么机制恢复 observable behavior。能做这种判断，才比复述 superscalar 或 cache
coherence 的名词更接近 6.823。

最有用的加试是做一次 counterfactual：移除 forwarding、缩小 reorder window 或改变 memory latency，
写下状态轨迹和 bottleneck 的预测，再用 simulator 验证。若预测方向错了，回到 dependency、queue
pressure 与 ordering rule；只改图表说明无法修正推理。
