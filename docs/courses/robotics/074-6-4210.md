### 课程定位

MIT [6.4210 Robotic Manipulation](https://ocw.mit.edu/courses/6-4210-robotic-manipulation-fall-2022/) 把 perception、planning、dynamics/control 与 learning 放进 cluttered manipulation 这一个问题里，适合想从算法走到完整机器人系统的学习者。OCW 归档的是 Fall 2022；[在线教材](https://manipulation.csail.mit.edu/) 属于持续更新的 living notes，因此今天看到的章节、notebook 和 `pydrake` API 可能已经不同。

[Course Information](https://manipulation.csail.mit.edu/Fall2022/index.html) 要求基础线性代数，并列出 probability、algorithms、basic neural networks 与 Python/Jupyter。robotics 背景可以空缺，但 NumPy shape、least squares 和坐标变换若同时吃力，前几份作业会很快卡住。

### 课程任务

[Schedule](https://manipulation.csail.mit.edu/Fall2022/schedule.html) 列出 Problem Set 1–10：PS1–PS3 处理 simulation、kinematics、frame、pose、Jacobian 与 optimization；PS4–PS5 进入 geometry、point cloud、registration 和 grasping；PS6–PS8 连接 behavior、deep perception 与 planning；PS9–PS10 转向 control、project check-in 和 reinforcement learning。

PS4–PS8 是全课最有辨识度的一段。同一张末端动画可能同时掩盖 perception 与 planning 的错误：point cloud 或 candidate grasp 已偏离时，planner 再聪明也救不回来；几何输入正确但 collision query 或 solver 失败，问题才真正落在规划层。固定场景、object pose 与 random seed 后比较这些中间量，比单看 success rate 更能解释系统为何失败。

### 工具与环境

当前官方仓库的 [commit cdb8c90f402c9201999bb90a27a034cf2e5d166c](https://github.com/RussTedrake/manipulation/commit/cdb8c90f402c9201999bb90a27a034cf2e5d166c) 可作为现代阅读入口；其中 [pyproject.toml](https://github.com/RussTedrake/manipulation/blob/cdb8c90f402c9201999bb90a27a034cf2e5d166c/pyproject.toml) 标为 `2025.10.20`，声明 `python>=3.10,<4.0` 与 `drake>=1.45.0`。它并非 Fall 2022 notebook 的原始环境，旧题出现 API、geometry 或 solver 差异是正常的，从较小的 notebook 熟悉今天的 Drake 更省力。

全部内容都可以在仿真中学习，无需机械臂。把 simulation ground-truth port 直接接给 controller 会得到虚假的成功率；实体机械臂还需要现场监督、限速限力、急停和碰撞保护，公开课程材料不提供这些现场条件。

### 结课项目

官方 [Project](https://manipulation.csail.mit.edu/Fall2022/project.html) 用 4–5 周，可由 2–3 人完成；preproposal 约 500–750 词，proposal 约 1000 词，个人/两人/三人视频为 3/4/5 分钟，report 建议 1500–4500 词。clutter clearing、peg-in-hole 或 planner benchmark 都足够成题，区别在于它们分别把 occlusion、contact 或 search complexity 推到台前。

这门课最值得带进项目的是对失败来源的分解，模型复杂度反而排在后面：pose 与 occlusion 影响 perception，mass 与 friction 影响 contact，collision margin、termination 和 runtime 则暴露 planner 的取舍。能在这些维度上解释 success rate 的变化，才真正把前半程的感知和后半程的规划接到了一起。
