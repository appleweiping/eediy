# MIT 6.186: Mobile Autonomous Systems Laboratory

### 课程定位

已经会 Java/Linux、基本接线和状态机，又想做一次短而密的机器人系统冲刺，才适合 MIT [6.186 MASLab](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/)；零基础应先补编程与嵌入式实验。公开档案保存的是 January IAP 2005：3–4 人在 4 周内做一台能在未知场地寻找目标的自主机器人。[Syllabus](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/pages/syllabus/) 安排 15 次、每次 2 小时的 session，并明确大量工作发生在课外。

### Checkpoint 比决赛录像更重要

[Calendar](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/pages/calendar/) 依次经过 OrcPad hello world、edge/bump detection、feature detection、寻找红球、design review、取得 1 个得分点、2 次 mock contest 和 final contest。每一站都留下输入、预期、原始 telemetry、失败边界和修复。例如“找到红球”应同时给出距离、照度、遮挡和 false positive，而不只是一段成功视频。

[Assignments](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/pages/assignments/) 还要求 daily lab entry 与 5–10 页 final report。把硬件变化、软件 commit、参数和实验结果放在同一条日志，才能分辨改进来自算法、光照、电池还是机械。

### 替换旧平台时逐项映射接口

[Kit contents](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/resources/kitcontents) 和 [lecture notes](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/pages/lecture-notes/) 对应 2005 的 OrcPad、旧 Java/CVS/Ant、相机、IR 与电机环境。现代复建可以换成差速底盘或 simulator，但须列出旧 sensor/actuator/API 的映射，以及 latency、噪声和动力学怎样变化。

按传感器单测、执行器单测、里程计、离线视觉、局部行为、状态机、整场任务集成。视觉固定一组未参与调参的 frame corpus；里程计至少测直线、原地转向和闭环；每次自主运行同时保存图像、检测结果、pose、状态与 motor command。

### 两次 mock contest 分别暴露什么

架空底盘用于测方向，同时限制 PWM 与电流，并验证程序崩溃后仍可急停；没有合适场地与监护，就在仿真中完成接口和 mock contest，并明确未验证的摩擦、光照与碰撞。

平台替换表、BOM/接线、校准、checkpoint、daily log、2 次 mock contest telemetry 与 final run 应围绕同一台机器人。官方 [Projects](https://ocw.mit.edu/courses/6-186-mobile-autonomous-systems-laboratory-january-iap-2005/pages/projects/) 很适合看 2005 队伍怎样解释系统取舍；今天真正要说清的，则是一次识别失败、一次控制震荡和一次安全停机各自怎样改变了下一轮运行。公开档案不含当年的 kit、场地、导师反馈或可直接运行的 OrcPad 环境；现代复建能继承的是 checkpoint 顺序，不是 2005 年的支持条件。
