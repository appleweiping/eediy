## 每一类仪器都沿同一条 measurement chain 验证

课程最有用的连接不是“模拟表到数字表”的年代顺序，而是 measurand → sensing /
conversion mechanism → loading/conditioning → indication → uncertainty。对 Lecture 3
和 6 的 PMMC/moving-iron demonstration，先问 torque 与 damping 怎样产生，再问 meter
接入后改变了哪个 circuit quantity。到 Lecture 23 的 error calculation，把 absolute、
relative 与 limiting error 写回测量链；到 Lecture 42 的 CT/PT，则要把 ratio、phase
error 与 burden 放在一起，而不是只背变比；ratio/phase error 的完整处理跨 Lecture
42–44，不能只引用 Lecture 42。

进入电子仪器段以后仍用同一张链。Lecture 58 的 frequency meter 要说明 gate time、
counter quantization 与 input conditioning；Lecture 64–65 的 dual-slope DVM 要从
integrator、reference、clock 推出 rejection 与 resolution；Lecture 80–81 的
oscilloscope 要把 probe loading、vertical path、time base 与 trigger 分开。每一组留下一
张“输入范围—传递关系—主要误差—校准/检查方法—危险边界”卡片，能复述工作原理却填不出
后 3 项，就还没有形成测量判断。

开始前可用 3 个动作定位缺口。给出间接测量式与各输入量的 limiting error，计算
absolute/relative error 和 worst-case propagation；对 Wheatstone bridge 的小电阻变化
求 sensitivity，并区分 accuracy 与 resolution；给 dual-slope integrator，说明
integration time 怎样影响 line-frequency rejection 与 conversion time。第 1 项失败回看
Lecture 23，第 2 项失败回看 Lecture 24，第 3 项失败回看 Lecture 64–65。它们是 EEDIY
诊断，不是 NPTEL certificate 的评分题。

## 市电、三相和 instrument transformer 只观察，不复刻

官方 lecture 目录含 single-phase energy meter、wattmeter/energy-meter 与 three-phase
supply connection、CT/PT、magnetic measurement 和 oscilloscope demonstration。这些
标题说明课堂覆盖范围，不是一份家庭接线授权。家庭环境不得复刻 mains、three-phase、
energized wattmeter/energy meter 或 instrument-transformer 实验；尤其不要在带电 primary
下开路 CT secondary，也不要让 earth-referenced oscilloscope ground clip 接到未知
potential。触电、arc、过流、ground fault 与储能风险需要合格设备、保护、SOP 和现场监督。

可以做的 EEDIY 补充全部留在 simulation/analysis，并明确不是 NPTEL lab：用 SPICE 或
方程模型比较 voltmeter loading；对 Wheatstone/Kelvin bridge 做 sensitivity 与 resistor
tolerance Monte Carlo；实现 dual-slope DVM 的离散时间模型；为 digital frequency meter
扫描 gate time 与 quantization error。每个 notebook 保存 schematic/equation、输入范围、
单位、随机种子、solver 与 raw output，并用解析极限或 archived assignment 做独立检查。
不要把理想 SPICE waveform 写成“校准过的仪器实测”。
