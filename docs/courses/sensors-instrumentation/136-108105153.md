### 课程结构

Lecture 1–12 是 PMMC、electrodynamic、moving-iron、damping 与 galvanometer；13–27 是 ammeter/voltmeter/ohmmeter、4-terminal resistance、bridge 与 wattmeter；28–46 是 energy meter、potentiometer、AC bridge、CT/PT 与 magnetic measurement；47–70 是 counter、op-amp、frequency meter、DVM、ADC/DAC；71–84 是 instrumentation amplifier、generator、555 timer 与 oscilloscope。

每类仪器都沿 `measurand → conversion → loading/conditioning → indication → uncertainty` 阅读，并记下 input range、transfer relation、dominant error、calibration/check method 与 hazard boundary。Lecture 23 连接 absolute/relative/limiting error；Lecture 42–44 解释 CT/PT burden 如何同时改变 ratio 与 phase；Lecture 58 把计数窗口与 quantization 变成 frequency-counter resolution；Lecture 64–65 推 dual-slope rejection；Lecture 80–81 分开 probe loading、vertical path、time base 与 trigger。reference、校准日期和可追溯性缺口应与公式误差分开记录。

### Simulation 检查仪器判断

可做 voltmeter loading、Wheatstone/Kelvin bridge tolerance Monte Carlo、dual-slope DVM 与 frequency-counter counting-window model。每份 notebook 保存 equation/schematic、domain、units、seed、solver 与 raw output，并用 analytical limit 或旧题复核；SPICE waveform 只说明模型行为，不能当作 calibrated measurement。

bridge 项目比较 nominal 与 tolerance distribution，并解释 source resistance、lead resistance 或 detector sensitivity 从哪里进入；dual-slope 项目从 integrator、reference 和 clock 推出 line-frequency rejection；counter 项目扫描计数窗口后要同时报告 update rate。把这些量放回同一测量链，才能看见分辨率提升通常会交换速度、loading 或 noise。uncertainty budget 应区分可由重复样本估计的随机项、由规格或校准给出的系统项，以及当前无法量化的 model-form 项；总误差不能只靠位数相加。

### 改一次量程，重算 loading、resolution 与 conversion time

从电压表（voltmeter）、电桥（bridge）、双积分数字电压表（dual-slope DVM）或频率计（frequency counter）中选一个，只改变量程、输入阻抗、积分时间或计数窗口中的一项，并把修改前后的传递关系（transfer relation）、负载效应（loading）、分辨率（resolution）与转换时间（conversion time）并排比较。如果预测只改变显示位数，说明测量链还没有真正闭合。仿真与旧题一致只能有限校验公式实现，不能证明真实仪表的准确度、校准状态或安全等级。
