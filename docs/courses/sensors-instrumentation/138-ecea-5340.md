## 原生主线只有一条：从 thermistor 分压到可提交的数据

Module 1 介绍热敏电阻、RTD 与热电偶等温度传感器；Module 2 转入 PSoC 原型开发、引脚、放大器、多路复用器（MUX）、数模/模数转换器（DAC/ADC）和 C 代码，并安排热敏电阻实验的四个部分；Module 3 扩展到旋转编码器、旋转变压器与流量传感器；Module 4 处理反相、同相、求和、差分与仪表放大器的非理想特性，以及 Johnson、1/f、散粒与量化噪声；Module 5 收束到热敏电阻数据采集、截图和课程项目评估。这是官方页面给出的五段结构，不应被改写成一门通用“传感器百科”。

学习时始终沿同一条测量链留证据：温度 → 热敏电阻阻值 → 分压电压 → 模拟前端 → ADC 码值 → C 程序换算 → LCD 读数 → 校准后数据。每走一段都写清传递函数、量程、负载效应、噪声来源、量化误差和校准残差。Module 3 的旋转与流量内容用于测试这套方法能否迁移到另一种换能器，不要另起一个与课程项目无关的“智能传感器作品”冒充官方作业。

最有价值的地方正是 Module 2 与 Module 5 首尾相接：pin configuration、ADC、C 与 thermistor 的错误会在最终数据里重新出现。最容易卡住的也因此不是背 sensor taxonomy，而是把 schematic、firmware、reference resistor、ADC range、display 和 raw data 对到同一版本。若只保留一张成功截图，无法判断 conversion equation、calibration 或接线是否正确。

## 3 个桌面诊断决定先学课程还是先补理论

诊断 1：为 \(R_T\) 与已知电阻组成的分压器推导 \(V_{ADC}(R_T)\)，选择高边或低边接法，并从 ADC 参考电压求出可用码值范围；再说明自热怎样造成系统误差。诊断 2：给定仪表放大器的增益、输入共模范围、失调与噪声密度，判断目标传感器信号是否会饱和，并估算带宽内的总噪声。诊断 3：写一段小型 C 程序，把 ADC 码值换算成温度，处理越界值和错误状态，再格式化到 LCD。

第 1 项失败先补 basic circuits、loading 与 calibration；第 2 项失败先补 op-amp/instrumentation amplifier 与 noise integration；第 3 项失败先补 embedded C、integer/float conversion 和 peripheral state。以上是 EEDIY placement check，不是 Coursera quiz。若 3 项中有 2 项无法独立完成，先走课程 ID 136 的理论路线，再决定是否购入硬件。

## BOM 可核验，但平台不是 hardware-neutral

CU 的官方[实验 BOM](https://www.colorado.edu/ecee/media/2412)在本次审读时标注 updated 2025-02-03，并与 Coursera 页面列出的核心链一致：PSoC 5LP `CY8CKIT-059`、LCD `NHD-0216BZ` 系列、thermistor `570-1229-ND`、precision resistor `A105970CT-ND`，再加 breadboard、wire 与 oscilloscope 等通用实验设施。料号只用于版本核对，不构成购买建议；价格、库存、地区配送和 specialization 的额外器材都可能变化。购置前逐项对照当前 lab handout，而不是按旧博客的购物车下单。

Infineon 的官方[`CY8CKIT-059` product page](https://www.infineon.com/evaluation-board/CY8CKIT-059)仍将该 PSoC 5LP prototyping kit 标为 active/preferred，并说明 onboard KitProg 与 PSoC Creator 工作流。硬件仍在供应不等于教学栈现代化。官方[PSoC Creator 4.4 release notes](https://www.infineon.com/assets/row/public/documents/30/96/infineon-psoc-creator-4.4-release-notes-software-en.pdf?fileId=8ac78c8c7e7124d1017ed9c7639e367a)日期为 2020-10-13，环境以 Windows 为中心；virtual machine、driver、USB enumeration 与当前 OS compatibility 都可能成为前置工作。

所以开工前要建立一张兼容性清单：操作系统与架构、PSoC Creator 4.4 构建版本、开发板修订号、KitProg 固件、USB 驱动、LCD 引脚映射、仪器型号和课程讲义版本。只有开发板枚举、最小闪灯/ADC 示例、LCD 测试与示波器探头检查全部通过，才进入热敏电阻实验。移植到其他 MCU、Arduino 或通用 ADC 可以作为 EEDIY 的迁移练习，但不等于完成原版 PSoC 5LP 作业。

兼容性排查应保留失败证据，而不是只写最终安装成功。USB 设备未枚举时，先区分 cable、driver、KitProg firmware 与 host policy；ADC example 错误时，再区分 pin routing、reference、clock 与 code generation。每次变更记录旧值、新值和观察结果。这样可以判断问题属于旧工具链还是电路本身，也能让后来者复现必要的修复，而不把一次偶然重启写成通用方案。

## 实验记录必须能从原始数据追到接线

获得正式材料与器材后，执行顺序不是一次把所有导线接完。先断电核对原理图与引脚映射；再限流上电，完成开发板自检；然后用已知电压检查 ADC 传递关系；接入分压器后保存原始 ADC 码值；最后才拟合热敏电阻关系、显示温度并运行 Module 5 的数据采集。每一步都保留预期值、实测值、仪器设置、来源版本和异常处理记录。

依据官方课程页列出的结构，完成包应包含：五个 module 的访问与状态表、五项 assignment 的提交和反馈状态、PSoC 项目源代码、原理图、引脚映射、最终物料清单、原始热敏电阻数据、校准曲线与残差、至少一张带时基/幅度刻度及探头信息的示波器截图、LCD 输出、版本与故障日志，以及 Module 5 课程项目的提交证据。若 Coursera 不允许公开题目或提交物，只记录散列值、日期与不泄露答案的反思；不要公开测验答案或受限题面。

校准记录不能只存换算后的温度。原始 ADC code、reference voltage、resistor tolerance、采样时刻和环境条件应当同表保存；拟合后检查残差是否随温度单调漂移，判断是模型、self-heating、接触、电源还是量化造成。LCD 显示是界面检查，不是测量真值。只有原始值到显示值的每一步都可追踪，最终截图才有解释力。

若重复测量无法落在预期不确定度内，先检查接触与供电，再讨论拟合函数；不要用增加小数位掩盖重复性不足。

本指南的安全范围是隔离、current-limited、≤5 V 的低能量桌面电路，且改线前断电。不得连接人体、医疗传感器、市电、未知电源、裸露加热器或其他高温源；temperature input 优先使用安全、稳定、可验证的环境变化。课程证书或一次正确读数都不构成产品、医疗或 safety certification。
