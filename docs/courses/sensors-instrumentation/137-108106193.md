### 课程结构

Week 1–2 定义 measurand、transduction law、sensitivity、range、linearity、resolution、hysteresis、response time 与 cross-sensitivity。Week 3–5 从 capacitive/thermal sensor 扩展到 chemical、electrochemical、optical、magnetic、acoustic 和 microfluidic sensing；为所选对象建立 static relation 与 first/second-order dynamics，再比较另一原理的 noise、bandwidth、drift 与 packaging。

Week 6–7 是 microfabrication、PVD/CVD、lithography、wet/dry etch 与 microscopy。只画带 critical dimension、interface、residual stress 和 inspection checkpoint 的 paper cross-section。Week 8 把 transduction 接到 instrumentation amplifier、filter 与 ADC，检查 signal range、source impedance、input-referred noise、gain、bandwidth、common-mode、saturation 与 clipping。

同一模型还应附 calibration equation 与 uncertainty budget，把 sensitivity、offset、nonlinearity、temperature coefficient、reference error、amplifier noise 和 ADC quantization 全部折回 measurand 单位。只有回到被测量单位，才能比较电子噪声、量化误差与封装漂移谁主导实际误差。说明哪些误差可由校准消除，哪些会随时间、温度或 package 漂移；只给一个 `R²` 无法区分这些来源。残差若随输入、方向或环境呈结构性变化，应分别检查非线性、迟滞与温度补偿，不宜用更复杂拟合抹平。

### Calibration project 补上实践

公开层没有 kit、BOM、raw calibration data、code repository、build procedure、tests 或 answers；最后的 experimental demonstration 只供观察，缺少可重复 lab 的条件。可用 low-voltage commercial sensor 或 synthetic data 建 calibration curve，分开 repeatability、drift、quantization、reference uncertainty，并分别观察 disconnect、saturation 与相关的 cross-sensitivity。

采样前写明 reference instrument、sampling interval、settling criterion 与 repeats，并让数据覆盖工作区间、升降方向和相关环境变化；fault data 不进入 fitting。static behavior 看 residual，dynamic behavior 看 step response/bandwidth。若升降方向出现系统残差，应讨论 hysteresis、contact 与 thermal equilibrium，而不是用高阶曲线吞掉机制差异。synthetic data 只能验证分析流程，不能证明真实 hysteresis 或 ageing。

paper cross-section 与 readout 还要在一个具体耦合上闭合：electrode area、film thickness 与 dielectric choice 会改变 parasitic/source impedance，package 会改变 thermal time constant 与 cross-sensitivity，excitation 则可能以 self-heating 换取 signal。把所选耦合估算到 calibration residual，并说明它在什么工作区间开始主导，才真正连接 physics、fabrication 与 circuits。

### 用校准方程和不确定度复核读出

交付 transduction equation、static/dynamic model、paper process cross-section、readout/noise budget、calibration residual 与 uncertainty。若当前 cohort 有 weekly assignment，只按账号实况使用；公开页没有时，不虚构“8 套有解作业”。

Week 6–7 的 vacuum、deposition、etch、plasma 与 electron microscopy 只在受控设施操作。low-voltage 实测也要记录 reference instrument range、calibration state 与环境；display resolution 只表示显示粒度，不能代表 sensor accuracy。

这门课最值得记住的区别，是 display resolution、repeatability 与 sensor accuracy 从来不是同一个量；calibration chain 正是把它们分开的地方。
