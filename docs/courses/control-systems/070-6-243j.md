### 6.243J 追问线性结论在何处失效

线性控制已稳、想追问局部结论在哪里失效，才适合 MIT [6.243J](https://ocw.mit.edu/courses/6-243j-dynamics-of-nonlinear-systems-fall-2003/)；只会调 PID 还太早。这门 Fall 2003 研究生课从 flow、equilibrium 与 linearization，进入 Lyapunov/storage、input-output stability、bifurcation、feedback linearization、backstepping 和 adaptive control。[Syllabus](https://ocw.mit.edu/courses/6-243j-dynamics-of-nonlinear-systems-fall-2003/pages/syllabus/) 以 6.241 或同等 linear control 为背景。

所需基础可用 1 个二维 vector field 检查：找 equilibrium、算 Jacobian、画 nullcline，说明 non-hyperbolic 点为何让 linearization 沉默，再尝试 1 个 Lyapunov candidate。ODE existence/uniqueness、quadratic form 和 chain rule 不稳时需要补强。

### Lecture notes 要与反例一起读

[Lecture Notes](https://ocw.mit.edu/courses/6-243j-dynamics-of-nonlinear-systems-fall-2003/pages/lecture-notes/) 是主材料。每个 theorem 标注 local/global、autonomous/time-varying、stability/asymptotic/exponential，并配 1 个满足条件和 1 个刚好失败的例子。几条 trajectory 不能推出 global stability，Jacobian 无结论时也无法据此判断 unstable。

仿真 phase portrait、level set 与 parameter sweep 时保存 solver、tolerance、初值网格和 event。invariant 或 \(\dot V\) 给出预测，图则用于寻找反例；经过 discontinuity 或 stiff region 的曲线本身也要验证。

挑一个线性化结论不够强的平衡点，比较线性化、能量函数和直接积分给出的三种判断。若线性化只说明局部稳定，就沿不同方向放大初值，寻找首次越出估计吸引域的轨迹，并把该边界与 Lyapunov sublevel set 对照。这样可以看见“仿真似乎收敛”和“定理覆盖该初值”之间的差距。

### 作业从相图推进到 nonlinear design

[Assignments](https://ocw.mit.edu/courses/6-243j-dynamics-of-nonlinear-systems-fall-2003/pages/assignments/) 含 PDF 与部分 `.m` 文件，顺序覆盖 ODE/invariant set、linearization、Lyapunov/storage、bifurcation、input-output property、feedback linearization/backstepping 和 adaptive idea。每题写明 region of validity 与 candidate 来源，并检查正定、导数符号、radially unbounded 和最大不变集。

2003 的 MATLAB/Simulink、Control Systems 与 LMI toolbox 需要适配。保留原 quantity，记录替代函数、solver、版本、tolerance 与 constraint residual；旧 `.m` 难以运行时，computational part 仍需用注明差异的环境完成。

### 综合练习

[Exams](https://ocw.mit.edu/courses/6-243j-dynamics-of-nonlinear-systems-fall-2003/pages/exams/) 提供 2 次 24-hour take-home quiz；原课 homework 50%，每次 quiz 25%，没有 final。独学按正常作息完成，并分类订正 candidate 选择、local/global 混淆、invariant 漏检和数值越界。

可以选 pendulum 或 saturated second-order plant：从开环相图开始，加入 local feedback、feedback linearization 或 backstepping，再测试 input saturation 与参数偏差。结果里写清 convergence region、peak control、steady-state error、failure initial condition 和反例索引。自适应设计若缺 persistent excitation，只能声称 tracking error 行为，不能声称参数已辨识。

这个案例还要回答闭环在何处良定义：feedback linearization 的 decoupling term 何时接近奇异，backstepping 的虚拟控制量怎样进入后续递推，饱和后原 Lyapunov 导数为何失去符号。选一个失败初值，判断该改控制律还是缩小适用区域；这正是 6.243J 与线性控制课的分界。
