## EE263 在 2025 年换了课程

这里介绍的是 Stephen Boyd 的 2008 年 *Introduction to Linear Dynamical Systems*
归档，不是当前 Stanford EE263。自 Fall 2025 起，
[EE263 首页](https://ee263.stanford.edu/) 已把课程改为
*Matrix Methods: Singular Value Decomposition*；旧课的 linear dynamical systems
内容由 EE363 接手并深化。现在再说“EE263 视频、作业和考试都很完整”，很容易把两个
实质不同的课程拼在一起。

当前 EE263 是高阶应用线性代数：range/null space、orthogonality、QR、least
squares/least norm、eigenvalues、symmetric matrices、SVD、Gaussian 与 MMSE，应用
连接信号、机器学习、控制、导航、电路和金融。当前先修是 Engr 108/Math 104 水平线代
加基础概率；旧版 LDS 则需要线性代数、微分方程、Laplace transform 和 transfer
functions。两者都值得学，但入口、工具、作业和目标不同。

## 当前 Matrix Methods 公开了什么

Summer 2026 是现场课，录像只在 Canvas，校外读者看不到。截至
2026-07-29，[Lectures](https://ee263.stanford.edu/lectures.html) 发布到第 12 组
slides，从 linear functions、工程实例、range/null space、rank、orthogonality 和 QR
推进到 least squares、multi-objective least squares 与 least-norm。Fall 2025 的完整
30 组 slides 显示后半还有 projectors、recursive estimation、Gauss–Newton、
eigendecomposition、SVD、Gaussian/MMSE 和 spectral graph embedding。

当前 [Homework](https://ee263.stanford.edu/homework.html) 使用 Julia，其他语言不受
支持或评分，数据为 JSON，推导和代码通过 Gradescope 提交；核验日公开 HW1–HW5。
[Exams](https://ee263.stanford.edu/exams.html) 把 Homework 25%、Midterm 25%、Final
50% 列为 approximate grading policy，并保留调整可能；两场考试原则上现场、禁电子
设备，可带一张公式表。想学当前这门 SVD/MMSE 课，就按这些 Julia 作业和当期 slides
另开一套笔记；2008 视频和 MATLAB 数据不属于它。

## 公开自学更适合 2008 LDS 归档

[Stephen Boyd 2008 Archive](https://ee263.stanford.edu/archive/) 提供 20 讲 slides、
support notes、414 页 course reader 和完整 homework problem bank；
[Stanford Engineering Everywhere](https://see.stanford.edu/Course/EE263) 另有 20 场
视频与 transcript、9 组 homework 编排、练习/正式 midterm 与 final，以及 MATLAB
数据。如果要从公开网页独立学完一门课，我会选这套 2008 归档：讲义、视频、题目、
考试和数据都能接得起来。

20 讲可分成 4 段：

1. **矩阵问题语言：**应用线性代数、QR、least squares 与 least norm；
2. **自主系统：**matrix exponential、eigenvectors、diagonalization、Jordan form，
   解释状态怎样随时间演化；
3. **输入输出系统：**forced response、aircraft dynamics 等实例把矩阵模型接到系统；
4. **结构性质：**symmetric matrices、norm、SVD、controllability/state transfer 和
   observability/state estimation。

这不是一门只复习矩阵分解的课。旧作业把无线功率控制、机械系统、AR/MA/ARMA、网络、
tomography、温度控制、最小输入和状态转移都写成矩阵或 LDS 问题；课程价值在于同一套
语言贯穿建模、估计和控制。

## 开始旧版前，先做 3 道小题

给定二阶状态方程，写出状态转移并逐项检查矩阵维度；给定一个 overdetermined system，
区分 least-squares residual 与解本身；给定传递函数，说清它和 state-space realization
的关系。若只能调用矩阵求逆函数，却解释不了 range、null space 与条件数，先补线性代数；
若看见 `ẋ = Ax + Bu` 还连不到微分方程和输入响应，先补动态系统。这 3 道题比一句
“学过线代”更能判断旧版作业是否做得动。尤其要把矩阵尺寸写在每一步旁边；旧题从状态、
输入一路推到输出，尺寸一旦在中途错位，后面的数值结果再漂亮也没有意义。

## 2008 归档的 20 讲怎么排

先用 course reader 与 slides 完成 QR、least-squares/least-norm 基础，并做对应
homework；再进入 autonomous LDS，从 `ẋ = Ax` 连接 matrix exponential 与
eigenstructure；随后做输入输出和 aircraft/机械实例；最后用 controllability 与
observability 回答“状态能否到达、能否从输出推回”。每一段都留下模型、推导、数值
结果和误差检查。

旧版 MATLAB 数据可以迁移到 Python/Julia，但先记录变量、矩阵维度和一份可对照的原始
结果。迁移不只是改文件后缀：还要设数值容差，检查稀疏/稠密、列主序和绘图差异。若
数据文件已经失效，应回到归档或 SEE 页面核对来源，不要拿当前 Julia homework 的 JSON
冒充旧题数据。

结课时可挑一个旧作业中的建模主题，交出问题定义、矩阵模型、可复现代码以及解析/数值
交叉检查，再用 controllability、observability 或 estimator error 说明模型在哪些条件
下失效。这是从旧作业延伸出的自学成果，不是 Stanford 官方 final project。

## 两个版本分别怎么记

当前课仍会随 Summer 2026 更新，slides、HW 数量和考试信息都要附核验日期。
[2007–08 Course Information](https://web.stanford.edu/class/archive/ee/ee263/ee263.1082/courseinfo.html)
把当时的 approximate grading policy 列为 Homework 15%、take-home midterm 40%、
take-home final 45%，同时保留调整可能；这些比例只属于历史版本。当前课程没有指定
required/optional textbook；
Boyd 与 Vandenberghe 的
*Introduction to Applied Linear Algebra* 只是较初阶参考，也不完全对应当前内容。

选择很简单：要学 SVD/MMSE 和 Julia 作业，看当前 Matrix Methods；要一套视频、题目、
考试和 MATLAB 数据齐全的公开课程，用 2008 LDS 归档。笔记标题里直接写清版本，别再把
两套材料混成“EE263”。
