### 当 Bode 图真的接上一台电机，6.302 才开始

MIT 6.302 最适合已经会 LTI 与频域分析，却还没有在真实 plant 上做过 classical loop shaping 的人。它的 [Syllabus](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/syllabus/) 把 6.003、2.003、16.04 或同等背景列为入口，还假设有电路、物理、数学和先前 circuit laboratory 经验。课程用 servomotor 与 op-amp 把 return ratio、root locus、Nyquist、Hall/Nichols、Bode、lead/lag 和 minor-loop compensation 收进同一条反馈环。

如果目标是 state-space，6.241J 更合适。若 \(T=L/(1+L)\) 还只是背下来的式子，应回补 Laplace、block diagram 和 LTI。进入 6.302 时，至少要能从力矩或电路方程推出低阶模型，并指出 reference、disturbance、measurement noise 与 control effort 分别从哪里进入。

### 访问与版本说明

[Calendar](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/calendar/) 列出 L1–L24 和 R1–R26，从 desensitivity、modeling、transient response 走到 Nyquist、Bode margins、loop shaping、oscillation 与 conditional stability。[Problem Set 1–10](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/assignments/) 只有题目；[Recitations](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/recitations/) 实际能下载 24 份 handout，R21、R22 缺失。

[Labs](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/labs/) 的安排更有课程味道：同一台 servomotor 连做 1A–1D，开头测 static gain 与 time constant，再建 open-loop model、加 compensation、比较 predicted/observed response；之后只从 PLL、thermal control、magnetic levitation 中挑 1 个 Lab 2 project。四个短实验共用硬件，让一个模型不断遇到新证据。

### 评价标准

为二阶电机或带 minor loop 的运放写清工作点、单位，以及被忽略的 pole、delay、friction 与 saturation。随后用同一套 sign convention 做 root locus 和 Nyquist，把 tracking、disturbance rejection、sensor noise、control effort 与 robustness 分配到不同频带。lead、lag 或 minor loop 每加一项，都要能说出哪条规格变好、哪条变差。

[python-control](https://github.com/python-control/python-control) 是活跃的 BSD-3-Clause 控制库，覆盖 state-space、Bode、Nyquist、root locus 与 time response。拿它做第二种数值实现很顺手：同一 nominal/perturbed plant、同一正负号，再手算一个频点核对 margin。但 saturation 仍在 LTI 模型之外，软件画出的平滑 step 不能替 actuator voltage/current 与 slew-rate 检查。

作业没有答案，可用量纲、极限情形与第二种稳定性判据互查。[Exams](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/pages/exams/) 有 2003 Quiz 1 和 2003、2004、2005、2007 final，全部无解；2005 Final Problem 4 还缺 figures，这道题的条件不能靠猜。

### 实验与项目

PLL 路线看 lock range、capture behavior 与 noise；thermal 路线要面对 heater power、sensor lag 和温度上限；maglev 则离不开受限运动、coil current、flyback 与失电落下状态。实体实验必须有低压限流、旋转防护或热/线圈风险控制和独立关断；条件不足，就在 MATLAB/Octave 或 Python-control 里比较 nominal 与 perturbed plant。

最有说服力的结尾，是把 nominal success 与 failure boundary 并排：gain 再大一点，delay 开始诱发振荡；指令再快一点，saturation 让线性 settling-time 预测失效；friction 或 dead zone 让重复 step 不再重合。6.302 看重的远不止一组漂亮 margin，更在于发现哪项未建模因素会第一个让 margin 失去解释力。
