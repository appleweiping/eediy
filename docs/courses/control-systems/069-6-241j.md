### 6.241J 把状态空间推到结构与鲁棒性

已经掌握线性 ODE、矩阵与 Laplace，想把状态空间推进到 controllability、observability 和 MIMO，适合选 MIT [6.241J](https://ocw.mit.edu/courses/6-241j-dynamic-systems-and-control-spring-2011/)；只想调 PID 应选更基础的反馈课。Spring 2011 归档还覆盖 minimal realization、system norms、robust stability/performance，以及 optimal/robust control design。按 [Syllabus](https://ocw.mit.edu/courses/6-241j-dynamic-systems-and-control-spring-2011/pages/syllabus/)，每周 2 次 90 分钟 lecture 加 1 次 1 小时 recitation。

所需基础包括线性 ODE、eigenvalue、rank、orthogonality、quadratic form、convolution 与 Laplace/Fourier。可用 1 个二阶 ODE 检查这些概念：写出 2 种 realization，检查 controllability/observability，并解释 pole、mode 与 input-output response 的区别。

### 拿一个 plant 做完建模、结构分析与性能评估

选质量—弹簧—阻尼或电机：物理方程、continuous/discrete solution 与 realization 构成建模层；controllability、observability、decomposition 与 minimality 构成结构层；state feedback、observer 或 least-squares estimator 构成设计层；参数不确定性、system norm、small-gain margin 与 MIMO performance 则检验 robust stability 和 performance。

每层保留手算小矩阵、数值结果、单位、初值、solver 与差异。贯穿全程的 plant、sampling period 和 metric 能让变化归因到理论或实验。官方没有 lab，这个 notebook 是自拟验证工具。

为主要定理维护一张假设—结论—反例卡：PBH test 在哪个 system class 下成立，minimal realization 为何同时要求 controllable 与 observable，Lyapunov equation 的正定结论需要什么谱条件。作业订正后新增反例；背出 rank condition 却解释不了不可控 mode 对 response 的影响，仍未掌握结构。

贯穿 plant 的 observer 与 controller 分开设计、合并验证。改变初始估计误差、measurement noise 与一个 plant parameter，分别画 true/estimated state、control effort 和 output error。separation principle 的名义结论不能替代 saturation、noise 与 model mismatch 下的性能检查。

### 作业与反馈

[Exams](https://ocw.mit.edu/courses/6-241j-dynamic-systems-and-control-spring-2011/pages/exams/) 适合做 2 轮：不限时版本写全条件，一周后闭卷重做错题。OCW 没有 grader、TA feedback 或实验检查，不能把自测换算为 MIT 成绩。

离开软件，解释一个 pole 为什么不可移动、一个输出为什么看不见某个 mode、least squares 什么时候不唯一，以及 uncertainty 何时会越过 small-gain stability margin；再回到贯穿全课的 plant，看数值结果是否真的呈现这些结构。能把结构、鲁棒稳定性与性能放在同一模型里，才适合继续走向更专门的 \(H_\infty\)、MPC 或非线性控制。
