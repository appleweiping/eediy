### Independent exercises for outside learners

The public themes support self-authored notebooks for direct
convolution, pole-zero stability, aliasing, DFT/FFT scaling, FIR/IIR
tradeoffs, an explicit multirate chain, and an audio or image synthesis
report. These self-authored notebooks are not official UIUC labs and do not
reuse the official lab numbering. Each notebook should rerun from an empty
kernel and state the data license, environment, sampling rate, frequency axis,
assertions, and a failed input.

Pass the same short audio clip through an FIR, an IIR, and an explicit
multirate chain. Mark impulse response and delay in time, then check passband,
stopband, and alias images in frequency. Finally omit one anti-alias filter on
purpose and follow the error from spectrum into sound. One notebook then joins
convolution, sampling, filter design, and multirate processing from the course
schedule instead of drawing a separate plot for every term.

A good notebook lets a reader trace raw data into the frequency axis, filter
specification, delay, numerical error, and a bad input. The most revealing
failure is a plausible plot with the wrong coordinates: one missing
normalization, incorrect sample rate, or omitted filter delay can make an
attractive but false spectrum. Aligning the same signal across direct
convolution, an FFT, and a multirate chain is what gives ECE 311 more value
than a gallery of final plots.
