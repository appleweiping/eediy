### Independent exercises for the published outline

Group the topics into convolution and system properties, z-transforms,
DTFT/sampling, the DFT, and filters/multirate processing. Keep a derivation
and short script for each part: construct an aliasing counterexample,
distinguish zero-padding from true DFT resolution, and measure actual FIR
ripple from passband/stopband specifications. Carry a fixed
signal from pole-zero and spectral predictions into a filter implementation,
explaining a failure in an error log.

These independent exercises have no official UIUC homework or exam
counterpart; name their source as “public outline + outside textbook,” and keep
HTTP 401 files out of a public repository. If access changes, append a new date
after the 2026-07-30 entry. The most useful repetition follows one fixed
signal: predict its spectrum from poles and zeros, then carry it through
sampling, the DFT, and an FIR while locating where aliasing, zero-padding, and
measured ripple enter. That joins about 40 meetings into one causal chain
instead of a set of unrelated scripts.
