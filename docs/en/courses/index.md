# Course Catalogue

[Learning routes](../routes/index.md)

The catalogue organizes courses by track. Each page answers practical questions first: where to begin, which assignments or labs are public, what is missing, and whether an independent learner can realistically continue.

## Choose a track, then one course

1. If your goal is still vague, start with the learning routes. If you already know the subject, open its track directly.
2. Usually choose one main course per subject. Open its first assignment or lab before committing, then check prerequisites, access, and equipment.
3. A page based only on public materials says so plainly. It must not sound like experience from someone who completed the course.
