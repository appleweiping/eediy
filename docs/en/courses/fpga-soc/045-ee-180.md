### A Fast Course at the Hardware/Software Boundary

Stanford's [EE180 course home](https://web.stanford.edu/class/ee180/) for
Winter 2026 uses 18 lectures to move from assembly and the hardware/software
interface through processors and pipelines, caches and memory, virtual memory,
OS support, I/O, and accelerators. The
[course-information PDF](https://web.stanford.edu/class/ee180/ee180info.pdf)

### Leave a Trace after Every Lecture

Track registers and memory for ISA material; draw forwarding, stalls, and
flushes cycle by cycle for pipelines; split tag/index/offset and calculate
AMAT for memory; and state data movement, latency, throughput, and energy
assumptions for accelerators and I/O. Reading the commercial textbook and
slides alone easily becomes architecture vocabulary recognition.

### Performance evaluation

The most useful EE180 habit is asking whether the bottleneck actually moved.
For the same workload, examine instruction mix, IPC or CPI, clock, cache
misses, memory stalls, data-movement time, accelerator utilization, an energy
proxy, and total runtime together. First confirm that the output is unchanged;
then vary working-set size, memory latency, or input size to find the
break-even point and failure range. A speedup plot shows one local improvement
but not whether the cost moved into the cache, memory, or host interface.

A failed optimization is often more informative than a clean success:
computation may become faster while data movement, working-set spill, or
synchronization makes the end-to-end run slower. Compare the baseline and
optimized version on the same input and measurement window, then vary problem
size and locality until the conditions for the bottleneck shift are clear.
Without the counter sampling interval, warm-up, repeat count, and noise range,
a change of a few percent may be jitter. An unexplained anomaly often reveals
a missing part of the model. A self-authored cumulative problem can connect pipelines,
caches and virtual memory, and accelerator tradeoffs, but it is not a Stanford
grade.
