### Use the Department Page for Scope and Fall 2024 Starters for Projects

Choose Berkeley **CS 61C: Great Ideas in Computer Architecture** when C-level debugging is already comfortable and you want to know how C code looks to an ISA, a datapath, memory, and parallel hardware. Start with Nand2Tetris or 6.004 instead when pointers and basic digital logic are both new. The [department course page](https://www2.eecs.berkeley.edu/Courses/CS61C/) gives the stable scope: C and assembly, processor organization, memory systems, I/O, parallel computing, and programming preparation comparable to CS 61A plus CS 61B. The course keeps changing scale: C pointers and memory layout, RISC-V registers and calling conventions, CPU datapaths, caches, parallel optimization, and virtual memory. Review programming first if pointers, recursion, and basic data structures are not independently debuggable. Review digital logic before Project 3 if Boolean logic, combinational and sequential circuits, and state machines are entirely new. Cornell ECE 4750 is a natural continuation for a deeper RTL microarchitecture project.

### Labs and projects

The official [lab starter](https://github.com/61c-teach/fa24-lab-starter) introduces the C diagnostics, RISC-V simulator, Logisim, and parallel-performance tools. The labs are more than warm-ups: they introduce the tools each project will need.

- [Project 1 starter](https://github.com/61c-teach/fa24-proj1-starter) is `snek`, a C exercise in dynamic structures, ownership, and testing. A sanitizer report usually says more than “it stopped crashing.”
- [Project 2 starter](https://github.com/61c-teach/fa24-proj2-starter) is `CS61Classify`, where RISC-V routines implement matrix operations and handwritten-digit classification; calling conventions, strides, and address arithmetic are the important interfaces.
- [Project 3 starter](https://github.com/61c-teach/fa24-proj3-starter) is `CS61CPU`, a Logisim processor whose ALU, register file, immediate generator, and control eventually meet in an instruction trace.
- [Project 4 starter](https://github.com/61c-teach/fa24-proj4-starter) is `CS61kaChow`, which optimizes a C kernel with OpenMP, SIMD, and memory-access changes and makes the cache material visible in running time.

The strength of the 4 projects is the descending viewpoint: C objects give way to RISC-V instructions, instructions to control signals in a datapath, and memory access to cache and parallel-optimization questions. Understanding those interfaces matters more than the code volume of any individual project.
