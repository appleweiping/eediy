### An Information-Theory Course with Public Proofs and Solutions

This guide fixes Stanford EE276 at Winter Quarter 2025-26. The
[course information](https://web.stanford.edu/class/ee276/info.html) moves
from entropy, mutual information, and compression into channel capacity,
error correction, and rate distortion. It lists undergraduate probability,
but the practical threshold is writing proofs in probabilistic language. It
fits learners who want to connect achievability, converses, and finite-block
constructions. Review conditional probability, convexity, and random-variable
convergence first if Shannon formulas are still being substituted mechanically.

### Course structure

The [outline](https://web.stanford.edu/class/ee276/outline.html) estimates 18
lectures covering AEP/typicality, prefix/Huffman/universal compression,
channel capacity and AWGN, direct/converse coding, polar codes, rate
distortion, and the method of types. For every theorem, record the random
objects, distribution, block length, limiting mode, key inequality, and
equality condition, then construct a case that fails when an assumption is
removed. Source and channel coding then become a connected argument rather
than separate formula sets.

[dit](https://github.com/dit/dit) is an active BSD-3-Clause discrete
information-theory library with distributions, entropy and mutual
information, channel capacity, Blahut–Arimoto rate distortion, and tests. It
is not an EE276 answer key. After hand-calculating a binary source and BSC,
check the same probabilities, log base, and distortion measure while pinning
the package version and tolerance. Library output does not replace an
achievability or converse proof.

### Finite blocks expose the gap between bounds and constructions

Finish with a BSC finite-block study, explicitly labeled an independent numerical project.
Derive capacity `1-h2(p)` and implement repetition, random linear, and a small
polar code under the same crossover probability while sweeping block length,
rate, and decoding error. Preserve construction, seed, trial count, confidence
interval, and the `p=0` and near-`p=0.5` boundaries. The important conclusion
is why a concrete code remains separated from asymptotic capacity, not which
curve looks best. When a run fails, distinguish codebook construction,
decoding rule, and finite-sample estimation: each one changes the claim in a
different way and maps back to a different quantifier or limit in the theory.
