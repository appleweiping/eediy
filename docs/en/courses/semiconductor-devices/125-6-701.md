### Course fit

MIT OCW [6.701 Introduction to Nanoelectronics, Spring 2010](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/) is an undergraduate course. Its [Syllabus](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/syllabus/) shows 2 lectures of 1 hour and 1 recitation per week, with formal prerequisites of 6.007 Electromagnetic Energy or 6.003 Signals and Systems. It moves from quantization, wavefunctions, and the Schrödinger equation through molecules, nanotubes, crystals, bands, ballistic conduction, Ohm’s law, MOSFETs, and computation limits.

Enter with complex exponentials, eigenvalues/eigenvectors, ODEs, probability normalization, and basic electrostatic energy. For a 1D infinite well, state the boundary conditions, normalize a wavefunction, and explain how level spacing changes with length. Revisit mathematics and elementary quantum mechanics if that answer is only memorized.

### The 8-part open textbook is the course

The [Open Textbook](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/open-textbook/) actually lists Part 1–8. Keep the sequence `state → energy → occupation → transport`: define the Hamiltonian and boundaries, solve for allowed states, add contacts/statistics, and only then calculate current. Put molecules, nanotubes, crystals, and MOSFETs side by side in a `length–energy–state–occupation–current` table so DOS, carrier density, and conductance remain distinct.

Add mode count, contact chemical potential, transmission, and device electrostatics to that table. Geometry first changes level spacing and available modes, reservoirs determine occupation, and transmission determines the current contribution of each mode. If a changed curve cannot be traced to the parameter class that changed, the model is still disconnected; correcting that is more valuable than advancing to another chapter.

The first block explains quantization from boundary conditions; the middle block tracks periodic structure, band formation, and filling; the final block introduces Landauer transport, the bulk limit, MOSFETs, and computation limits while naming added assumptions about scattering, contacts, electrostatics, and temperature. Device examples from 2010 are historical, so verify current advanced-CMOS structures and material data separately.

### Coursework

[Assignments](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/assignments/) lists 12 homework sets without a complete official solution set. Check normalization, units, energy reference, limiting size, and occupation assumptions, and leave a result unresolved when neither an analytical limit nor independent numerical check exists.

The Syllabus also lists 2 MATLAB projects: Part 3 Problems 9–11 and Part 5 Problems 1 and 3. The public package identifies the tasks but supplies neither complete source code nor official output. Pin software, grid, boundary conditions, and a convergence test. For the former, check Hermiticity, state normalization, and eigenvalue convergence; for the latter, check 0-bias current, left/right contact symmetry, and the ballistic limit. Label the code as a learner implementation.

The simulation notes should also list original prompt boundaries, numerical choices, and failed cases so readers can separate textbook models, learner implementation, and runtime differences. Reconstructing old student code by guesswork is not the goal. Fix eigenvalue ordering, phase convention, and mode cutoff as well; otherwise two similar-looking plots may not represent the same calculation.

### After three unsolved exams, return to the ballistic MOSFET

[Exams](https://ocw.mit.edu/courses/6-701-introduction-to-nanoelectronics-spring-2010/pages/exams/) provides the 2010 midterm, 2010 final, and 2011 final, all without solutions. Use the 2010 midterm as a timed midpoint check, the 2010 final as the first end-of-course test, and the 2011 final for transfer. Correct each problem through open-text definitions, dimensions, degeneracy, boundary conditions, and limiting size, not an unofficial full answer set.

There are no classroom videos, and the 6.719 spin project mentioned in the
Syllabus is unavailable. A practical study set is 12 complete solutions, 2
simulations with grid and boundary convergence checks, corrections for all 3
exams, and a ballistic-MOSFET analysis that moves from contact states,
occupation, and transmission to current, then adds scattering and
electrostatics until the bulk model becomes appropriate.
