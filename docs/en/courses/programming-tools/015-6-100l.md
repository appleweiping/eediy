### Built for a Genuine First Programmer

MIT 6.100L Fall 2022 is the full-semester version of 6.100A. It uses Python 3
and targets students with little to no programming experience. The official
[syllabus](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/syllabus/)
spans 26 lectures, moving from objects, bindings, branches, and loops through
functions, mutation, testing, exceptions, classes, complexity, search and
sort, hashing, and simulation. Choose it when you are first learning to turn
a specification into a dependable program. It does not teach registers,
instrument communication, or real-time systems.

The slower pace does not mean thin content. A list first appears through
indexing and iteration, then changes meaning again through mutation, aliasing,
function arguments, and object state. Predict bindings and return values
before running code. When the prediction fails, reduce it to a minimal example
instead of editing blindly until a test turns green.

MIT Emerging Talent's
[ET6 Programming With Python](https://github.com/MIT-Emerging-Talent/ET6-Programming-With-Python)
is an MIT-licensed independent companion whose README connects predictive
stepping, `python -m trace`, and unit tests. It is not a source of 6.100L
answers. Put a short aliasing, loop, or function example of your own into that
workflow: write the trace before execution and diagnose the first divergence,
not merely the final output.

### Treat the 2022 PDF as the PS0 Prompt

The official [Fall 2022 PS0 PDF](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/mit6_100l_f22_ps0.pdf)
asks you to create `ps0.py` and calculate `x=5`, `y=8`, `z=x+y`, and
`numpy.log2(z)`. The [PS0 code package](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/resources/mit6_100l_f22_ps0_code_zip/)
also contains a conflicting 2021 instruction file that still says 6.0002, and
it does not provide a ready-made `ps0.py`. Use the 2022 PDF as the prompt and
`pkgtest.py` only as an import test for NumPy and Matplotlib. A current Python
release or another editor is usually fine; record any path, package-API, or
old-syntax changes.

### Programming practice

Use the [finger exercises](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/finger-exercises/)
to check control flow, return values, mutation, and edge cases, but write your
version before inspecting a released answer. The
[problem sets](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/lists/problem-sets/)
publish PS0–PS5 and code bundles, progressing from interest and bisection to
image processing and steganography. Student testers cover only part of the
behavior, so add empty containers, duplicate values, extreme numbers, and
malformed input.

For each set, write inputs, outputs, invariants, and failure behavior before
implementing the smallest version. After examples pass, remove diagnostic
prints, restart in a fresh process, and check whether the docstring fully
determines parameters, return values, and exceptions. Any parameter that still
needs an oral explanation marks an unfinished interface. Explain alias versus
clone, exception triggers, and the “input size” in a complexity claim with
minimal programs rather than definitions.

The official course stops at PS0–PS5; the following is explicitly a non-MIT
extension. Write a small script that reads synthetic waveform CSV, checks
sample intervals, blank rows, nonnumeric data, and out-of-range values, then
emits statistics, threshold crossings, and a machine-readable summary.
Separate parsing, calculation, and output; test normal, boundary, and invalid
inputs; and try a semantically identical file with reordered columns. No FFT
or hardware acquisition is needed. A README that lets another machine run the
program, together with predictable behavior for bad input, is enough to make
the course's real skills—decomposition, state, testing, and debugging—visible.
